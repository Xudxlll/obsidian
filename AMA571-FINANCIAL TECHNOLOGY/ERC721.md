# Implementing Roles

• Import AccessControl from OpenZeppelin   
• Define roles: bytes32 public constant MINTER\_ROLE   
• Grant roles in constructor or separate function

• Add modifier: require(hasRole(MINTER\_ROLE, msg.sender))   
grantRole() and revokeRole() for management

# Core Concepts

Proxy Pattern

Separate storage and logic

delegatecall

Execute logic in proxy context

Storage collision

Careful slot management

Initializers

Replace constructors

?? OpenZeppelin provides battle-tested implementations

# Proxy Pattern Types

# Transparent Proxy

Admin vs user calls routed differently

Simple, well-established

X Higher gas costs

# UUPS Proxy

Upgrade logic in implementation

Lower deployment gas

× More complex, easy to brick

![](images/1fe20d6795556f3f00d2189f84c36af8e5fd2844c0297c9bdf4ddcd6943283e5.jpg)

UUPS for advanced users, Transparent for beginners

# Critical Considerations

Storage layout must remain compatible   
Never use constructors (use initializers)   
Disable implementation initialization   
Test upgrade paths thoroughly

# ERC-1155 Introduction

35 minutes

# What is ERC-1155?

Multi-Token Standard: fungible, non-fungible, and semi-fungible tokens in one contract

# Key Features

Multiple token types in single contract   
Batch operations: mint/transfer multiple IDs at once   
Gas efficient for managing collections   
Supports both unique and edition-based tokens

Standard Author: Enjin (gaming focus)

# Troubleshooting Guide

# Metadata not showing on Etherscan

• Ensure tokenURI is accessible via IPFS gateway   
• Check contract verification status

• Verify JSON has 'name' and 'image' fields   
• Confirm Pinata IPFS URLs are working

# Transaction failing / out of gas

• Verify test ETH balance in MetaMask   
• Confirm connected to Sepolia network

• Check compiler version matches pragma   
• Try increasing gas limit manually

# Contract deployment errors

• Ensure Injected Provider is connected   
• Verify MetaMask is on Sepolia (Chain ID 11155111)

• Check constructor parameters are correct   
• Compile before deploying

# Transfer not working

• Verify you're the token owner   
• Use safeTransferFrom, not transferFrom

• Check approval if using third-party transfer   
• Confirm recipient address is valid
