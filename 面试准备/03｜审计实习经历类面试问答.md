## 先准备哪些故事

经历类问题没有唯一的标准答案。重点是把自己做的那一小部分讲具体，讲得前后一致，也讲得出哪里得到过帮助。

| 问题 | 本篇建议素材 | 回答的重心 |
| --- | --- | --- |
| 最困难的事 | 折旧重算公式有结果，边界却不对 | 怎样拆解不会的问题 |
| 最开心的事 | 离场复盘时意识到自己开始跟得上工作 | 什么让自己感到进步 |
| 最有成就感的事 | 能从附注数字追到明细和底稿 | 交付具体有了什么变化 |
| 犯过的错误 | 监盘混淆箱和件 | 怎样承认、纠正和预防 |
| 被指出问题 | 附件已补，正文仍写未取得 | 怎样消化反馈 |
| 重复劳动 | 找凭证、整理附件和索引 | 怎样保证质量和耐心 |
| 沟通困难 | 不会准确提出资料需求 | 怎样把问题问具体 |
| 压力最大 | 离场前同时处理复核、回函状态与交接 | 怎样安排优先级 |
| 主动改进 | 把“见资产文件夹”改为具体索引 | 怎样在职责内多做一步 |
| 最大收获 | 从按客户汇总转为看逐笔未结款项 | 怎样改变思考方式 |
| 遗憾与不足 | 前期急着算表，没有先确认口径 | 能否提出可执行的改进 |
| 再来一次 | 接任务先问目的、资料、截止日和交付要求 | 是否真正完成复盘 |

**建议最先练Q01—Q05**。先说一句结论，再讲一件事：当时负责什么、具体卡在哪里、自己怎样处理、谁帮助或复核、最后有什么变化。第一次控制在约一分钟，细节留给追问。以下时间只是练习目标，可以按自己的语速删减。

## Q01｜实习中，你觉得最困难的一件事是什么？

**情境参考回答：**

我觉得最困难的是第一次做固定资产折旧重算。开始以为有原值、年限和残值率，把公式写出来就能完成。真正算的时候才发现，月中启用、年底新增、已经提足还在使用的资产，不能不加判断地用同一个公式拖下去。

当时我直接用日期差算月份，有的案例少了一个月；梁老师还指出，一项已经提足的机器，在我的表里仍然有本期折旧。我最不确定的是，这到底是自己算错了，还是台账有问题。

后来我先请她确认计算规则和比较期间，再把几个特殊情况单独拿出来，先在纸上数月份、算剩余可计提金额，再去改公式。改完也没有直接认定客户有差错，而是把规则、测试例子和待核事项一起交她复核。

这件事让我学会，遇到不确定的问题，先把前提拆清楚，比不断试公式更有用。

**面试官在看什么：** 能否说明真正的难点，以及自己如何学习、验证和求助。“工作量很大”需要继续解释，单独说出来信息不足。

**可能追问：**

- **“到底哪里少了一个月？”** 在首尾月均应计提的教学例子中，4月1日至12月1日相差8个完整月，但4月至12月有9个计提月份。要先确认起止规则，再决定是否加1，不能所有日期差都无条件加1。
- **“是你独立解决的吗？”** 计算框架和检查由我练习执行，规则由梁老师确认，问题也是在她复核和提示下逐步改正的。
- **“最后帮客户补提了多少？”** 本情境没有可核验的真实调整金额，十二月实提数还待终版核对，不能把教学公式错误说成客户少提折旧。

## Q02｜实习中，你最开心的一个时刻是什么？

**情境参考回答：**

我最开心的是离开驻场前那次很短的内部复盘。刚开始我连拿到一张表要先核什么都不太确定，遇到差异容易直接问老师“这个怎么办”，自己也说不清卡在哪一步。

到后面整理交接时，我至少能先把问题列出来：用了哪版数据，已经查了什么，缺哪份依据，哪些还需要老师判断。复盘时，梁老师提到我比刚来时更知道先列问题、再找证据，不再只盯合计。

我听到后挺开心，因为自己前面花了不少时间找附件、改索引、重做表，有时也会觉得进展很慢。那一刻发现，这些反复做的小事确实让我开始跟得上团队的工作方式。

这只是一个很小的反馈，但对刚接触实际工作流程的人来说，挺有鼓励的。

**面试官在看什么：** 哪些事情能带来持续的工作动力，以及能否注意到具体、渐进的成长。这里的“开心”侧重心情与被理解的感受。

**可能追问：**

- **“所以只是因为被表扬？”** 反馈让我开心，是因为它对应到一个自己能感受到的变化：从说不清问题，到能把检查过程和缺口说明白。
- **“能举一个变化吗？”** 原来交接写“见资产文件夹”，后来会写明具体底稿、附件索引、版本和待核事项。

## Q03｜实习中，你最有成就感的一件事是什么？

**情境参考回答：**

我比较有成就感的是后期协助核对财务报表附注时，终于能把一个披露数字的来龙去脉接起来。

前面做抽凭、折旧重算和明细核对时，我对这些任务的理解还比较零散。到核固定资产附注时，需要分别对原值、累计折旧的期初、本年增减和期末，再往回找对应明细、底稿和证据。我才看到前面的工作是怎样接到财务报表里的。

这中间也有返工，合计对上不代表各列分类正确。我按梁老师的意见逐列回查，把来源索引补清楚，不能确认的仍然保留待复核。

成就感主要来自我能解释自己整理的表了：数从哪来，和哪份资料对应，还有什么没查完。我的工作仍是协助核对选定科目的附注明细，但我开始理解这份交付为什么有用。

**面试官在看什么：** 能否说清成果及本人贡献。“有成就感”可以来自可追溯、可复核的交付，不一定来自发现重大问题。

**可能追问：**

- **“你独立编了整份附注？”** 没有，我协助选定科目的明细与来源核对，草稿交梁老师复核，财务报表及披露责任仍属于管理层。
- **“它和最开心的事有什么区别？”** 最开心偏向得到具体反馈时的感受；这件事更偏向交付和理解的变化，能把以前分散的工作接起来。
- **“怎么证明你理解了？”** 可以现场说明固定资产原值与累计折旧各自的变动关系，以及为什么期末净值不能把两张变动表简单相加。

**对应素材：** [[佛山市瑞志会计师事务所—审计助理（嘉洛智能案例）/2025-01-21｜Day 26｜协助财务报表附注，把明细和披露表逐项勾起来|Day 26]]；专业追问见[[02｜审计实习面试问答与连续追问#Q54｜请手算一个固定资产附注变动表，原值、折旧和净值怎样勾稽？|固定资产附注变动表]]。

## Q04｜讲一件你犯过的错误，当时是怎么处理的？

**情境参考回答：**

年末监盘时，我有一次差点把外包装的箱数当成表里要求的件数记录。现场要跟着找物料、看标识、记数量，我当时有点急着跟进度，没有先确认单位。

梁老师提醒后，我先停下来，在客户配合和现场允许的条件下重新核对数量，把原记录更正，并写明是自己混淆计量单位，不能把它列成客户盘亏。我也回头检查了同批记录里是否还有类似问题。

之后我记录前会先看物料编码、规格和单位，记录时再把核数方式写清楚。自己不能确认怎样核的项目，就及时问老师，不凭包装标签直接勾完。

这次让我意识到，现场核对不能只求快。记录里一个看起来很小的单位差异，也可能让后面的人误解发生了什么。

**面试官在看什么：** 是否承认具体错误，能否及时纠正，并检查同类影响。不要把缺点包装成“我太认真”或“我要求太高”。

**可能追问：**

- **“你有没有发现客户少了货？”** 这个例子是我自己的记录问题，不是已经查实的客户盘亏。
- **“你负责客户盘点吗？”** 客户负责盘点，我按审计组安排协助观察、抽盘和记录，没有负责整个仓库的盘点组织。

## Q05｜有没有被带教指出问题，甚至有点受挫的时候？

**情境参考回答：**

有，后期修改底稿时，我觉得自己已经补了附件，就认为这条问题差不多处理完了。复核时却发现，正文还写着“未取得”，附件和文字状态是矛盾的。

当时会有点挫败，因为自己确实花时间找到了资料，却还要返工。后来我理解到，复核的人不能靠猜来判断我做到了哪一步，收到资料、检查资料和形成待复核说明也不是同一个状态。

我把正文改成实际执行的状态，再检查同类底稿是否也有遗漏。回复意见时，也从只写“已修改”，改为说明补了什么、放在哪里、检查到哪一步，还有什么没解决。

这件事让我更能接受具体的复核意见。它提醒我，工作完成要从接手和复核的人能否看懂来判断。

**面试官在看什么：** 能否把受挫后的情绪转成行动，不急着辩解，也不空泛地说“虚心接受”。

**可能追问：**

- **“你觉得老师太挑细节吗？”** 这条意见确实反映了状态不一致，可能影响别人理解已执行的工作，我需要改。
- **“会不会以后又漏？”** 我会增加附件、正文、状态表的对应检查；这是降低遗漏的方法，不能保证自己从此绝不出错。

## Q06｜每天找凭证、整理底稿，会不会觉得很枯燥？

**情境参考回答：**

会有，尤其是连续找凭证、核附件、命名和补索引的时候。一开始，我也更期待做一些能直接看出分析结果的工作，觉得整理资料进展慢。

但做过之后发现，复核时如果找不到具体附件，前面写了“已检查”也很难说明做了什么。例如不同年份可能有相同凭证编号，索引少了年份，后来就容易找错；合同只有第一页，也不等于需要的内容已经齐了。

我会按确认的清单分批做，每批核一下已取得、已检查和待补资料，把缺口及时整理给梁老师。确认命名和索引方式后再统一处理，也能少一些返工。

这些工作确实重复，但当我知道它支持哪个核对目标，做起来会更有耐心。不会把每一分钟都说得很兴奋，但我会认真把负责的部分做清楚。

**面试官在看什么：** 是否有现实的工作预期，以及怎样在重复任务中维持质量。

**可能追问：**

- **“怎么提效？”** 统一命名、索引和状态字段，按批检查；先确认格式再批量处理。涉及受限资料要按授权方式保存，不能为方便随意搬到私人设备。
- **“你一天做多少？”** 按真实记录说明本人批次和口径，本案例不虚构数量或节时百分比。

## Q07｜你有没有遇到沟通不顺畅的情况？怎么解决？

**情境参考回答：**

我一开始比较不擅长把资料需求问具体。例如准备银行函证时，只说“还缺银行资料”，别人很难知道是哪个主体、哪个账户、哪个期间，或者具体缺什么。

我后来先把清单整理给梁老师看，分清自己已经拿到的资料、真正的缺口，以及需要她确认的范围和办理事项。对外提出需求时，再按她确认的安排，把主体、账户标识、资料名称和期间写清楚，已经取得的就不重复索要。

在这个情境里，十二月还没有结束，年末余额也不能提前填。我可以先准备账户信息和控制表，把年后才具备的资料单列出来。

这让我学到，沟通前先做好自己的整理，能让对方更容易回应。遇到不能决定的事项，我会带着具体问题找老师，而不是自己猜着处理。

**面试官在看什么：** 是否能理解对方需要什么信息，避免把沟通困难一概归因于客户不配合。

**可能追问：**

- **“客户一直不给怎么办？”** 记录缺什么、影响哪项工作、已沟通到哪里，及时报告带教，由她决定后续沟通和程序，不自行写成已取得。
- **“你负责全部客户沟通？”** 没有，我按分工协助整理与跟进，重要范围和程序由带教确认。

**对应素材：** [[佛山市瑞志会计师事务所—审计助理（嘉洛智能案例）/2024-12-27｜Day 10｜准备银行函证清单，不把年末余额提前填进去|Day 10]]。沟通措辞为基于原任务的情境补写。

## Q08｜实习中压力最大的时候是什么时候？你怎么安排？

**情境参考回答：**

压力比较大的是离场前集中处理复核意见的时候。一边要改计算和索引，一边有新资料要对应，还要把回函状态和未完成事项交清楚。事情同时来时，我很容易看到哪条就先改哪条，改完又漏掉关联的表。

后来我先把意见分成自己能改的、等客户资料的和需要老师判断的，再请梁老师确认优先级。会影响其他表数字的修改先处理，改完一起查相关明细和附注；需要现场取得的资料也及时报出来，不能等离场才发现。

我汇报时会说明已经完成什么、卡在哪里和还需要什么帮助。离场前仍然没有解决的事项，就写清当前状态和后续责任。

最后完成的是自己这部分修改和交接，项目还有后续程序。这让我学会了在时间有限时把进度和风险说清楚。

**面试官在看什么：** 有没有排序、依赖检查和及时汇报，而不只是说“靠加班扛过去”。

**可能追问：**

- **“来不及，你牺牲哪项检查？”** 我会先报告时限冲突和影响，请带教确认安排，不私自省掉必要检查或把待核写成完成。
- **“是不是所有问题最后都解决了？”** 没有，仍有回函和判断事项由团队继续跟进。

## Q09｜有没有一件事，是你主动多做了一步的？

**情境参考回答：**

交接时有一件很小的事。我的初稿有些位置只写“见资产文件夹”，自己知道是哪份，但陈经理顺着一张汇总表往下找时，仍然需要问我。

他指出后，我没有只改被问到的那一行，而是把同类索引一起检查了一遍，补上具体底稿、附件位置、版本和待复核状态。碰到资料还只在工作副本里的，也按要求确认受控目录的位置。

这个改进不是什么新系统，主要是把自己看得懂的路径改成别人能接着用的说明。它没有让所有事项都完成，但使我交出去的工作更容易继续核对。

我理解的主动性，是发现自己这部分还有可以补清楚的地方，及时处理；涉及审计判断和后续安排，仍然请负责的老师决定。

**面试官在看什么：** 能否在权限内补足交付。这个故事始于别人的反馈，主动性体现在扩大检查同类问题，不能讲成完全由自己首先发现。

**可能追问：**

- **“这不是老师让你改的吗？”** 最初的问题确实由经理指出；我多做的是检查其他同类索引，而不是只修那一处。
- **“节约了多少时间？”** 没有测算，不给百分比；可以具体说明接手人能从哪张表追到哪份依据。

## Q10｜这段经历最大的收获是什么？

**情境参考回答：**

最大的收获是，我开始在计算之前先问清楚一个数字代表什么，而不是拿到数据就急着套公式。

账龄分析给我的印象很深。我最初想按客户找一个最后交易日，再统一算账龄，梁老师让我回到逐笔未结款项。同一客户可以同时有旧欠款和新销售，新交易不会让旧欠款重新起算；收到一笔款，也要查它对应哪笔余额。

后来我先明确未结金额、形成日期、合同到期日和统一截止日，再按确认的口径计算和汇总。涉及无法匹配的回款，保留待确认，而不是为了把表做满随便归进去。

我觉得这个习惯比多记一个函数更有用。以后处理财务或研究数据，也需要先确认口径、来源和期间，再分析结果。当然，这并不意味着我已经能独立判断坏账或投资价值。

**面试官在看什么：** 能否用一个具体例子证明成长，而不只是说“提升了专业能力和沟通能力”。

**可能追问：**

- **“账龄长就一定收不回来吗？”** 不能单凭账龄下结论，需要结合具体证据和适用的减值要求评价；本人的工作是基础整理与核对。
- **“你说的统一截止日是什么？”** 该案例按2024年12月31日分析年末余额，不能随打开文件的日期变化。

## Q11｜实习里有没有遗憾，或者你觉得自己做得不够好的地方？

**情境参考回答：**

我觉得前期做得不够好的是，比较急着把表填出来，没有先确认自己是否理解了输入和核对目标。有时问老师，也只说“这个对不上”，没把自己检查过什么整理好。

比如折旧重算，如果期间还没有统一，就急着比较两个合计，很容易把自己的计算问题当成待解释差异。这样老师还要先帮我还原前提，沟通效率也不高。

后来我会先记录资料版本和比较期间，再写自己检查过的步骤，标明究竟是哪一项输入或规则拿不准。不会的仍然需要问，但问题能具体一点。

如果再做一次，我会从第一天就养成这个习惯。这个不足对我来说很实际：尽快交出一张表，不等于交出一份别人能复核的工作。

- **“现在已经完全改掉了吗？”** 还需要刻意提醒自己，目前会用输入、期间、来源和待确认问题的小清单来约束，不说已经彻底消除。
- **“会不会问太多打扰别人？”** 先完成自己能够核实的部分，整理后集中请教；会影响方向或结论的关键问题及时问，不能为了少问一直做错。

## Q12｜如果让你重新做这段实习，你会怎样做得更好？

**情境参考回答：**

我会更早做三件事。

第一，接任务先确认核对目标、资料版本、期间和交付要求。有些地方不清楚就先问，避免做完才发现方向不一致。

第二，从第一次计算就保留小范围手算和特殊情况检查。像折旧的未开始计提、已提足和处置，先检查规则，再复制公式，不等大表做完才发现整列都有问题。

第三，边做边留来源和状态，区分收到资料、已经检查、待补和待复核。这样每天汇报和最后交接都能更具体。

我不会说再来一次就能独立负责项目。更现实的目标是少一些可以避免的返工，让带教更容易看清我已经做了什么，以及哪些地方还需要她帮助。

**面试官在看什么：** 复盘能不能变成接任务、执行、交付三个阶段的具体动作。

**可能追问：**

- **“三件事只能先做一件呢？”** 先确认目标和输入。前提理解错了，公式和整理越快，后面返工可能越多。
- **“和你现在应聘的岗位有什么联系？”** 按目标岗位举一个具体联系，例如研究岗的数据期间、单位和版本检查；不把这套练习扩大成已经具备独立研究能力。

## 练习时，注意这几处

1. **先直接回答题目**。问困难，就先说难在哪里；问开心，就说哪个时刻；问成就感，就说交付有何变化。
2. **讲一个故事就够了**。一次回答尽量只留一个场景、一处转折和一个变化，专业细节等对方追问。
3. **分清“我”和“我们”**。自己的整理、核对和修改可以展开讲；带教的规则确认、复核和判断，要保留她的贡献。
4. **故事中的结果可以很小**。能解释一张表、把索引写清楚、及时纠正单位，都能体现工作态度，不必添上重大舞弊、客户表扬或效率百分比。
5. **不必背出日记的所有日期和原句**。理解前后关系更重要，但不能把十二月的准备说成已经取得年末回函，也不能把离场说成报告正式出具。

可以录一次一分钟回答，回听时只查四件事：有没有具体动作、有没有说出帮助来自谁、有没有一个可说明的变化、有没有把模拟内容误说成真实任职。三道核心题可以分别记成：**困难——折旧边界；开心——看到自己的进步；成就感——解释清楚交付**。
