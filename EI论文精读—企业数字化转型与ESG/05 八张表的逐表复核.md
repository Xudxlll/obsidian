## 表1：变量定义

来源：[[EI会议 独立一作.pdf#page=2|PDF p.2／印刷p.59，Table 1]]。

| 变量 | 角色 | 原文定义的中文转述 |
| --- | --- | --- |
| ESG | 因变量 | ESG评级赋1—9分 |
| DT | 核心解释变量 | 数字化转型水平之和；原文该定义略显残缺 |
| Size | 控制变量 | 企业总资产 |
| Age | 控制变量 | ln(当前年−上市年+1) |
| Growth | 控制变量 | (当期营业收入−上期营业收入)／上期营业收入 |
| Lev | 控制变量 | 总负债／总资产 |
| Indep | 控制变量 | 独立董事人数／董事总人数 |

**读表动作：** 先确认谁是结果、谁是主要解释因素，再检查每个变量的单位。DT对数变换、Size对数口径、ESG年度化、Age是否纳入等问题见[[03 数据样本与变量字典]]。

## 表2：描述统计

来源：[[EI会议 独立一作.pdf#page=3|PDF p.3／印刷p.60，Table 2]]。

| 变量 | N | 均值 | 标准差 | 最小值 | 最大值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Size | 24,643 | 23.109 | 1.417 | 19.716 | 26.430 |
| Growth | 24,643 | 0.184 | 0.427 | -0.660 | 4.330 |
| Lev | 24,643 | 0.486 | 0.188 | 0.054 | 0.906 |
| Indep | 24,643 | 0.378 | 0.058 | 0.286 | 0.600 |
| Top1 | 24,643 | 0.336 | 0.150 | 0.081 | 0.743 |
| Board | 24,643 | 2.149 | 0.203 | 1.609 | 2.708 |
| DT | 24,643 | 67.322 | 111.999 | 0.000 | 1470.000 |
| ESG | 24,643 | 4.295 | 1.081 | 1.000 | 7.750 |

**怎样理解：** 样本平均杠杆率为48.6%，独立董事比例为37.8%，第一大股东平均持股33.6%。Growth均值0.184相当于18.4%的样本平均营业收入增长率；标准差42.7个百分点提示差异较大。

DT标准差大于均值，且最大值远高于均值，提示上尾较长、企业差异明显；仅凭这五个统计量不能完整确认分布形状，应查看直方图和分位数。ESG最大7.75与整数赋分说明不一致，需要查聚合口径；它不等于评级体系最高只有7.75。

**不能误读：** 每个变量N相同，并不能证明所有回归都用同一个估计样本，因为各回归表未给N；也不能证明不存在缺失值，因为可能已先行筛选。

## 表3：基准回归

来源：[[EI会议 独立一作.pdf#page=3|PDF p.3／印刷p.60，Table 3]]。

| 变量 | 系数 |
| --- | ---: |
| DT | 0.0935*** |
| Size | 0.3535*** |
| Lev | -1.2191*** |
| Growth | -0.1520*** |
| Board | -0.0065 |
| Indep | 1.2667*** |
| Top1 | -0.1504*** |

**核心发现：** DT系数为正，按表注在1%水平显著。

**几个有单位意识的解释：** 在这份线性模型中，Lev增加0.1，即负债率提高10个百分点，对应ESG拟合差异约$-1.2191\times0.1=-0.12191$分；Indep提高10个百分点对应约0.12667分；Top1提高10个百分点对应约-0.01504分。它们都是模型内条件关联，不是管理措施的确定效果。

**为什么不能比较系数绝对大小来排名重要性？** 不同变量的单位不同：比率、原始量、对数量不能直接对比。需要统一变化幅度或标准化口径，且先解决DT定义。

**Board不显著：** 只能说当前表中未发现明确偏离0的证据，不能说董事会人数在任何情况下都与ESG无关。

**缺失的报告信息：** 标准误、t值、完整p值、估计N、拟合优度、截距、固定效应和标准误处理。Age也未列出。

## 表5：Bootstrap

来源：[[EI会议 独立一作.pdf#page=4|PDF p.4／印刷p.61，Table 5]]。

| 变量 | 原表Average percentile列 | 2.5%分位点 | 97.5%分位点 |
| --- | ---: | ---: | ---: |
| DT | 0.084*** | 0.071 | 0.094 |
| Size | 0.335 | 0.323 | 0.349 |
| Lev | -1.203 | -1.281 | -1.139 |
| Growth | -0.180 | -0.208 | -0.152 |
| Board | 0.043 | -0.034 | 0.107 |
| Indep | 1.299 | 1.026 | 1.493 |
| Top1 | -0.264 | -0.369 | -0.178 |

**列名问题：** 原表写Average percentile，正文则明确称DT的average coefficient estimate。暂按正文理解为重抽样系数平均值，保留原列名供核对，不把它误当作另一个分位点。

**可读出的结果：** DT区间完全大于0；Board区间包含0。不能因其他行没有星号，就忽略它们的区间信息。95%区间不含0的判断与***所代表的1%显著性也不是同一个精度的报告，星号依据需要原输出。

**版本问题：** 本节文字称原OLS为0.083，表3为0.0935。重抽样均值0.084与0.083接近，但不能据此改掉表3。也不能确认两次分析使用相同样本、同样的DT变换和控制项。

**没有说明：** 重抽样按企业还是按行进行、随机种子、有效重复次数、失败重复处理。5,000次是论文报告的设定，尚未由代码复核。

## 表8：盈利水平交互项

来源：[[EI会议 独立一作.pdf#page=5|PDF p.5／印刷p.62，Table 8]]。

| 变量 | 系数 |
| --- | ---: |
| DT | 0.0008*** |
| Size | 0.3387*** |
| Lev | -1.1263*** |
| Growth | -0.1980*** |
| Board | 0.0001 |
| Indep | 1.3437*** |
| Top1 | -0.2312*** |
| Profit_Level | 0.2590*** |
| DT_Profit_Level | -0.0000 |

正文另报交互项p=0.888。

**较稳妥的结论：** 该设定下未发现盈利分组对DT斜率的显著调节证据。

**不能这样说：** “高盈利企业数字化与ESG无关”“高低盈利组效果完全相同”“Profit_Level显著说明高盈利企业数字化效果更强”。主效应和交互效应回答的问题不同。

**量纲疑点：** DT从表3的0.0935变成0.0008，比例约116.9倍。可能是DT变换、计量单位、样本或模型变化，也可能是表格错误；目前没有证据判断。不能拿这两个系数直接说明“加入盈利变量后数字化效果大幅衰减”。

## 总体读表结论

论文在已展示的基准、分位数、重抽样与产权两列结果中，都报告了正的DT系数；但统计表的口径与文字解释存在多处冲突。比较可信的是“方向上的经验关联”，精确效应大小、组间差异和因果解释仍需原数据与完整输出支持。
