## 一 为什么利率是"资产价格之锚"？

**1. 折现模型中的核心角色：利率**

在所有基于现金流的估值方法（如 DCF 债券定价 房地产估值等）中，利率承担着两重角色：

时间价值：未来的钱不如现在值钱 → 需要折现

风险补偿：风险越高，要求的收益率越高 → 折现率上升 → 估值下降

核心公式回顾：

$$
\text { 估值 } = \sum_ {t = 1} ^ {T} \frac {C F _ {t}}{(1 + r) ^ {t}}
$$

其中：

- $CF_t$：第 $t$ 年的现金流

- $r$：折现率（通常与无风险利率、风险溢价等相关）

举例说明：

如果你预期未来 3 年每年获得 100 元，折现率为 5%，现值为：

$$
\frac {100}{(1 + 5\%) ^ {1}} + \frac {100}{(1 + 5\%) ^ {2}} + \frac {100}{(1 + 5\%) ^ {3}} = \frac {100}{1.05} + \frac {100}{1.1025} + \frac {100}{1.1576} \approx 272.32 \text{元}
$$

若折现率升至 10%，现值降为：

$$
\frac {100}{(1 + 10\%) ^ {1}} + \frac {100}{(1 + 10\%) ^ {2}} + \frac {100}{(1 + 10\%) ^ {3}} = \frac {100}{1.1} + \frac {100}{1.21} + \frac {100}{1.331} \approx 248.69 \text{元}
$$

小结：利率越高，未来现金流现值越低，资产估值越保守

| 资产类别 | 影响机制 |
| --- | --- |
| 债券 | 直接决定价格(折现未来现金流) |
| 股票 | 利率↑→DCF估值↓→股价承压 |
| 房地产 | 贷款成本↑→房价↓ |
| 大宗商品 | 通常反向相关:利率↑→商品价格↓(因持仓成本↑) |

**案例**：

2022年美联储加息周期，科技成长股和美债价格同步下跌，黄金等无息资产阶段性上涨

实战提示：关注利率变化，是资产配置和风险管理的核心。

## 二 期限结构理论（Yield Curve Theories）

> [!warning] 理论与转写提示
> 下文部分数学符号存在原始识别残缺。远期利率不一定等于现实世界预期短期利率；期限溢价、凸性和模型假设均可能影响两者关系。不能把期望的乘积一概视为乘积的期望。

### 1. 预期理论（Expectations Theory）详解

长期利率 ≈ 未来一系列短期利率的预期均值

年期利率 $\approx \frac { 1 } { 1 0 } \sum _ { i = 1 } ^ { 1 0 }$ 未来第 年 年期利率

含义：

如果市场预期未来短期利率会上升，长期利率就会上升，收益率曲线变陡

**一 核心思想**

在预期理论（Expectations Theory）下：

长期利率 ≈ 未来一系列 短期利率预期 的几何平均

在风险中性 无风险溢价的理想条件下成立

数学表达式：

$$
(1 + y _ {n}) ^ {n} = \prod_ {k = 0} ^ {n - 1} \left(1 + \mathbb {E} _ {t} [ r _ {t + k, 1} ]\right)
$$

其中：

$y _ { n } \colon$ 当前 n 年期零息收益率（n 年零息债券利率）

$r _ { t + k , 1 } :$ 在未来第 t+k 年时的一年期短端利率

$\mathbb { E } _ { t } [ \cdot ]$ ：在时间 t 下，根据当时信息对未来变量的预期值

这些期望利率 $\mathbb { E } _ { t } [ r _ { t + k , 1 } ]$ 从哪来？

这里的"期望"并不是指数学上有个神秘分布，而是指市场在当前时点 t 对未来短期利率的预估 来源主要有三类：

**1. 理论上**：

在风险中性世界（即无风险溢价），长期利率必须等于未来短端利率的无偏预期平均

所以 $\mathbb { E } _ { t } [ r _ { t + k , 1 } ]$ 就是"市场共识的预期短端利率"

2. 现实操作上：这些预期不是凭空捏造的，通常来自：

当前收益率曲线：通过数学反推 $( \mathrm { b o o t s t r a p p i n g + f o r w a r d r a t e \vec { l } \cdot \overleftarrow { \Xi } } )$

市场定价：比如 OIS 曲线 利率互换 国债期货

宏观预测：央行利率政策前景 通胀预期 经济模型

**3. 直观理解**：

你可以把 $\mathbb{E}_t[r_{t+1,1}]$ 理解成"市场今天认为，等过一年之后的一年期利率大概会是多少"

它是预估的未来利率，不是今天的实际利率

**直观解释**：

左边 $( 1 + y _ { n } ) ^ { n } \colon$ 一次性买一张 n 年期零息债券的增长倍数

右边乘积：逐年滚动买一年期债券，利率取决于市场对未来的预期

二者相等 → 长期利率由未来短端利率预期决定

**二 零息收益率 & 乘积符号的含义**

**1. 什么是零息收益率**？

零息债券：不付票息，到期一次性支付本金和利息

零息收益率：投资者买入 n 年期零息债的年化收益率

**2. 为什么公式里是"1+利率"**？

如果一年期利率 = 3%，本金 $1 ~ \overline { { \pi } } - \overleftarrow { \Phi } \sqrt { \Xi } = 1 + 0 . 0 3 = 1 . 0 3$

多年投资时，总收益是每年"1+利率"的连乘积，因此公式写成乘积形式

**3. 乘积符号 的含义**

类比：

求和： $\begin{array} { r } { \sum _ { k = 0 } ^ { n - 1 } a _ { k } = a _ { 0 } + a _ { 1 } + \cdot \cdot \cdot + a _ { n - 1 } } \end{array}$

求积： $\prod _ { k = 0 } ^ { n - 1 } a _ { k } = a _ { 0 } \times a _ { 1 } \times \cdots \times a _ { n - 1 }$

所以：

$$
\prod_ {k = 0} ^ {n - 1} (1 + \mathbb {E} _ {t} [ r _ {t + k, 1} ]) = (1 + \mathbb {E} _ {t} [ r _ {t, 1} ]) \times (1 + \mathbb {E} _ {t} [ r _ {t + 1, 1} ]) \times \dots \times (1 + \mathbb {E} _ {t} [ r _ {t + n - 1, 1} ])
$$

它表示：资金逐年滚动投资 1 年期债券，最终的本金增长倍数

**4. 对应关系**

左边：一次性投资 n 年期零息债券，增长因子 $= ( 1 + y _ { n } ) ^ { n }$

右边：每年滚动投资 1 年期债券，增长因子 = 连乘积

二者相等 → 长期利率 = 未来短端利率预期的几何平均

**三 直观生活类比：银行定存**

假设你有一笔钱要存 3 年：

方案 A：一次性存 3 年定期

银行给你一个固定的 3 年期年化利率（比如 4%）

3 年后本息合计 $\dot { \mathbf { \theta } } = ( 1 + 0 . 0 4 ) ^ { 3 }$

**方案 B：逐年存 1 年定期，按市场预期滚动**

第一年存 1 年，利率是 $\mathbb { E } _ { t } [ r _ { t , 1 } ]$

第二年再存 1 年，利率是 $\mathbb { E } _ { t } [ r _ { t + 1 , 1 } ]$

第三年继续存 1 年，利率是 $\mathbb { E } _ { t } [ r _ { t + 2 , 1 } ]$

3 年后本息合计 $\dot { \mathbf { \eta } } = ( 1 + \mathbb { E } _ { t } [ r _ { t , 1 } ] ) ( 1 + \mathbb { E } _ { t } [ r _ { t + 1 , 1 } ] ) ( 1 + \mathbb { E } _ { t } [ r _ { t + 2 , 1 } ] )$

**结论**：

方案 A 和方案 B 的结果必须接近，否则投资者会有套利机会

所以 3 年期利率 = 市场对未来 1 年期利率的预期平均

这个类比就是：

买长期债券 ≈ 一次性存长期定存

逐年滚动短期债券 ≈ 每年存 1 年定期，按未来利率走

四 对数近似与算术平均

为什么要讲对数近似？

我们有精确公式：

$$
(1 + y _ {n}) ^ {n} = \prod_ {k = 0} ^ {n - 1} (1 + r _ {k}), \quad r _ {k} = \mathbb {E} _ {t} [ r _ {t + k, 1} ]
$$

但在实际应用中，几何平均（连乘积）计算复杂，我们更希望得到：

$$
y _ {n} \approx \frac {1}{n} \sum_ {k = 0} ^ {n - 1} r _ {k}
$$

（算术平均形式）

这样就能直观地说："长期利率 ≈ 未来短端利率的简单平均" 对数近似帮我们建立这个联系

**方法一：详细的泰勒展开推导**

1. 取对数

$$
n \ln (1 + y _ {n}) = \sum_ {k = 0} ^ {n - 1} \ln (1 + r _ {k})
$$

**2. 泰勒展开**

$$
\ln (1 + x) = x - \frac {x ^ {2}}{2} + \frac {x ^ {3}}{3} - \dots
$$

代入：

$$
\sum \ln (1 + r _ {k}) = \sum r _ {k} - \frac {1}{2} \sum r _ {k} ^ {2} + O (r _ {k} ^ {3})
$$

因此：

$$
\ln (1 + y _ {n}) = \bar {r} - \frac {q}{2} + O (r ^ {3})
$$

其中

$\begin{array} { r } { \overline { { r } } = \frac { 1 } { n } \sum r _ { k } } \end{array}$ （算术平均）

$\begin{array} { r } { q = \frac { 1 } { n } \sum r _ { k } ^ { 2 } } \end{array}$ （二阶均值）

3. 再展开左边

$$
\ln (1 + y _ {n}) = y _ {n} - \frac {y _ {n} ^ {2}}{2} + O (y _ {n} ^ {3})
$$

结合：

$$
y _ {n} \approx \bar {r} - \frac {\operatorname{Var} (r)}{2}
$$

4. 结论

长期利率 ≈ 未来短端利率的算术平均 − 方差的一半

即：几何平均比算术平均略小，差额和未来利率不确定性（波动）有关

**方法二：简化的对数近似推导**

对于利率通常较小的情况（如 $r _ { k } < 1 0 \% )$ ，我们可以直接使用：

$$
\ln (1 + x) \approx x \quad (\text {当} x \text {较小时})
$$

推导过程：

从原始公式出发：

$$
(1 + y _ {n}) ^ {n} = \prod_ {k = 0} ^ {n - 1} (1 + \mathbb {E} _ {t} [ r _ {t + k, 1} ])
$$

第一步：两边取对数

$$
n \ln (1 + y _ {n}) = \sum_ {k = 0} ^ {n - 1} \ln (1 + \mathbb {E} _ {t} [ r _ {t + k, 1} ])
$$

第二步：对小利率使用近似 $\ln ( 1 + x ) \approx x$

$$
n \cdot y _ {n} \approx \sum_ {k = 0} ^ {n - 1} \mathbb {E} _ {t} [ r _ {t + k, 1} ]
$$

第三步：两边除以 n

$$
y _ {n} \approx \frac {1}{n} \sum_ {k = 0} ^ {n - 1} \mathbb {E} _ {t} [ r _ {t + k, 1} ]
$$

结论：长期利率 ≈ 未来短端利率预期的算术平均

数值验证这个近似的精度：

如果利率在 1%-5% 范围内， $\ln ( 1 + x ) \approx$ 的误差通常小于 0.1%

比如： $\ln ( 1 . 0 3 ) = 0 . 0 2 9 5 6$ ，而直接用 ，误差仅为

对于实际应用，这个精度已经足够

五 数值例子

假设市场预期：

明年短端利率：3%

后年短端利率：4%

第三年短端利率：5%

精确计算

$$
(1 + y _ {3}) ^ {3} = (1. 0 3) (1. 0 4) (1. 0 5) = 1. 1 2 4 7 6
$$

$$
y _ {3} = (1. 1 2 4 7 6) ^ {1 / 3} - 1 \approx 3. 9 9 9 6
$$

算术平均

$$
\bar {r} = (0. 0 3 + 0. 0 4 + 0. 0 5) / 3 = 4 \%
$$

方差修正

$$
\operatorname{Var} (r) = 0. 0 0 0 0 6 6 7
$$

$$
y _ {3} \approx 0. 0 4 - 0. 0 0 0 0 3 3 3 = 3. 9 9 6 7
$$

与精确值几乎一致。

**六、小结**

1. 零息收益率 $y _ { n } \colon$ 买 n 年期零息债的年化收益率

2. $\mathbb { E } _ { t }$ ：今天的视角下，对未来短端利率的期望

3. 公式含义：长期利率 = 未来短端利率预期的几何平均；近似等于算术平均

4. 修正项：由于几何平均 < 算术平均，长期利率比算术平均略小，差额与未来利率波动性相关

5. 直观解释：买一张长期债券 ≈ 每年都滚动买 1 年期债券

6. 生活类比：一次性存 3 年定存 vs 每年存 1 年定存

### 2. 流动性溢价理论（Liquidity Premium Theory）

核心思想：投资者厌恶利率风险，持有更长期限需要"额外补偿" → 期限溢价 $T P _ { n } .$ 2

修正后的关系：

$$
y _ {n} = \frac {1}{n} \sum_ {k = 0} ^ {n - 1} \mathbb {E} _ {t} [ r _ {t + k, 1} ] + T P _ {n}
$$

其中：

第一项：未来短端利率预期的算术平均（预期理论部分）

$T P _ { n } \colon$ n年期的期限溢价（Term Premium）

**关键特征**：

$T P _ { n }$ 往往随时间变化，不一定总为正

在QE（量化宽松） 负利率环境下可能偏低甚至为负

即使未来短端利率预期不变，仅靠正的期限溢价也可能让曲线"常态向上倾斜"

**经济直觉**：

长期债券面临更大的利率风险（久期风险）

投资者要求额外收益来补偿这种不确定性

解释了为何正常情况下收益率曲线向上倾斜

实际应用：

央行QE购买长期债券 → 压低期限溢价 → 收益率曲线平坦化

市场恐慌时，避险需求推高长期债券价格 → 期限溢价下降

### 3. 分段市场理论（Segmented Markets Theory）

核心思想：不同期限由不同"栖息地"的投资者主导，期限间并非完全可替代，供需失衡会单独推升/压低某一段的利率

**典型的投资者栖息地分布**：

| 期限段 | 主要投资者类型 | 投资动机 |
| --- | --- | --- |
| 短期(1-2年) | 货币基金、银行 | 流动性管理、准备金配置 |
| 中期(3-7年) | 企业财务、中小银行 | 资产负债匹配、收益优化 |
| 长期(10年+) | 养老金、保险公司 | 负债久期匹配、长期收益稳定 |

**关键机制**：

期限特异性需求：每个投资者群体有明确的期限偏好

有限替代性：跨期限投资需要承担额外的久期风险或再投资风险

供需独立性：某一期限的供需失衡不会完全通过套利传导到其他期限

偏好栖息地理论（Preferred Habitat）变体：

投资者可以离开自 己的偏好期限投资，但需要额外溢价补偿

因此期限溢价具有期限特异性： $T P _ { n } = f ( \mathbb { i } \mathbb { X } , \mathbb { H } \mathbb { H } \mathbb { B } \mathbb { H } \mathbb { Y } \mathbb { i } , \mathbb { i } \mathbb { \neq } , \mathbb { Z } _ { \mathbb { H } } ^ { \mathbb { \neq } } \mathbb { k } \mathbb { \neq } )$

**实际影响因素**：

监管要求：银行资本充足率 保险偿付能力要求

会计制度：持有至到期 vs 交易性金融资产的会计处理

发行结构：政府债券发行计划 企业债发行节奏

回购操作：央行在不同期限的操作频率和规模

结果：曲线形状不仅是"对未来短端的期望"，还包含：

供需技术面因素

监管和久期偏好

发行与回购等操作性因素

**量化应用实例**：

当某期限出现供需失衡时，该期限利率会偏离理论值

交易策略可以利用这种"期限错配"进行套利

典型案例：2020年疫情期间，美联储大量购买长期债券，长端利率被人为压低

## 收益率曲线从哪里来？如何获取数据？

**问题：我们一直在讲"收益率曲线"，但这个曲线具体在哪里看到**？

### 一 收益率曲线的构建原理

收益率曲线并不是直接"观察"到的，而是通过市场上实际交易的债券价格反推计算出来的：

1. 原始数据：市场上各种期限债券的实时价格

2. 计算过程：价格 → 到期收益率（YTM）→ 零息收益率

3. 插值拟合：用数学方法连接各个期限点，形成平滑曲线

## 收益率曲线的实战解读与应用

### 二 曲线形状怎么读？

向上倾斜（橙色正常）：温和增长/通胀预期 + 正的期限溢价；或预期短端会缓慢上行

变平（绿色）：加息周期尾声或经济前景不明，未来短端上行空间有限/或下行概率提升

倒挂（蓝色）：市场预期未来短端会下行（经济放缓 政策转向），常见于紧缩后段

驼峰/钟形（中段高）：近端预期加息，远端预期回落（长期增长/通胀锚定）

关键点：曲线 = 预期（短端路径） + 期限溢价（风险/供需） 解读时两者都要想

### 三 意义：为什么它是重要的宏观信号？

1. 政策预期：从 OIS/国债曲线抽前几次"隐含加息/降息路径"，评估货币政策方向与节奏

2. 增长/通胀线索：长端名义利率 ≈ 实际利率 + 通胀补偿（再叠加期限溢价） 长端变化对"长期增长与通胀锚"很敏感

3. 金融条件：曲线陡峭化改善银行净息差 $( N I M ^ { \alpha } )$ ），倒挂挤压息差。金融周期与信用扩张会受影响

4. 企业与财政：融资期限选择 负债久期管理 再融资成本与债务可持续性

5. 资产定价折现率：权益 房产 基础设施等长期资产的估值都对长端利率/期限溢价高度敏感

### 四 量化与交易层面的"怎么用"？

**1) 常用指标（信号口径）**

斜率 $( \mathbf { S l o p e } ) : ~ S _ { 1 0 Y - 2 Y } = y _ { 1 0 } - y _ { 2 } ; ~ \exists \downarrow ~ 1 0 Y - 3 M , ~ 5 Y - 2 Y$

曲率（Curvature/Butterfly）： （正负代表中段相对高/低）

远期利差：如 5y5y（5年后起的5年远期）相对当前5Y/10Y

期限溢价估计：把曲线拆成"预期路径 + 溢价"（模型口径，用于研判"预期 vs 技术面"）

**2) 交易结构（国债/互换/期货均可构造）**

陡峭化/变平（Steepener/Flattener）：多长空短或反之，做曲线形状；可区分牛/熊（牛=利率下行，熊=利率上行）陡峭化/变平

蝶式（Butterfly）：做曲率（多翼空腹，或多腹空翼），赌中段相对高/低

跨期限对冲：利用关键期限久期（Key Rate Duration）中性化总久期，纯粹暴露在某一段的形状变化上

跨市场价差：美债 vs 掉期（Swap Spread） 不同国家主权曲线的相对价值（需要汇率/基差管理）

**3) Carry & Roll-down（静态持有收益）**

Carry：持有债券期间的票息/应计收益 − 融资成本

Roll-down：如果曲线形状不变，债券"随时间向短端滚动"到更低收益率点位，价格自然抬升

组合思路：在风险可控下最大化 carry+roll 的期限分布，是很多固收量化策略的基石

**4) 定价与风控**

远期曲线定价：利率互换 期权 债券期货对套保/估值都依赖整条曲线（贴现 + 前景利率）

风险分解：用 Key Rate Duration / DV01 by bucket 看哪一段最敏感，做分段对冲

因子建模：Nelson–Siegel–Svensson（水平/斜率/曲率三因子）用于拟合与回测；或使用仿射无套利模型做情景推演

### 五 注意事项（常见"坑"）

曲线口径要一致：国债 vs OIS vs 掉期曲线含的信用/流动性不同；"斜率信号"要在同一曲线体系里算

期限溢价是时变的：别把全部斜率都解读成"政策预期"——供需 监管（如LCR/NSFR） QE/缩表 发行结构都会改曲线

基差与技术面：新券（on-the-run）"特殊性" 再抵押/回购紧张 季末效应等会扭曲点位

回测要分周期：紧缩期 宽松期 危机期的斜率/曲率因子表现差异很大，建议做分 regime评估

## 四 实战问答与案例解析

**1. 如果央行加息，哪类资产最先受到冲击**？

**答案**：

债券类资产（尤其是长期债券）最先受到冲击，其次是成长型股票等对利率敏感的资产

**讲解**：

央行加息 = 提高基准利率 → 整体市场无风险利率上升

债券未来现金流折现时利率更高 → 价格下跌

股票估值模型（如 DCF）折现率↑ → 估值下调

成长股未来现金流比重大，折现敏感性更强 → 首当其冲

房地产等依赖杠杆的资产也受冲击（贷款利率上升）

**2. 债券价格和利率的关系是怎样的**？

**答案**：

负相关：利率上升 → 债券价格下降；利率下降 → 债券价格上升

**讲解**：

债券价值 = 未来固定现金流的折现值：

$$
P = \sum_ {t = 1} ^ {T} \frac {C}{(1 + r) ^ {t}}
$$

市场利率 r 上升 → 分母变大 → 每期折现现金流减少 → 债券价格下跌

利率下降 → 分母变小 → 债券更值钱

久期越长的债券，对利率的敏感度越高，风险也越大

**3. 10年期国债收益率为何被称为"风险资产的定价锚"**？

**答案**：

它反映了长期无风险回报率，几乎所有风险资产（如股票 REITs 公司债）都以此为基础进行估值折现或风险溢价比较

**讲解**：

股票预期收益率 = 10年期国债收益率 + 风险溢价

10年期利率上涨 → 所有资产的折现率提高 → 估值下调

投资者会比较："我买10年国债就有 X% 收益，股票要不要承担更高风险？"

所以 10YYield 是整个市场定价逻辑中的锚点

**4. 举例说明收益率曲线的倒挂意味着什么**？

**答案**：

倒挂 = 短期利率 > 长期利率 → 通常预示经济衰退或市场悲观预期

**举例说明**：

正常：2Y 利率 2%，10Y 利率 3% → 趋势健康，未来利率预期上涨

倒挂：2Y 利率 4%，10Y 利率 3% → 市场预期未来利率下跌，或经济衰退

历史上，每次倒挂几乎都伴随经济衰退（如2008金融危机前）

量化策略会用"10Y-2Y 利差"作为风险预警信号或资产配置调整依据

# 股票选股中的利率敏感性分析
def interest_rate_factor(stock_returns, rate_changes):
    """计算股票对利率变化的敏感性（类似Beta）"""

    # 计算利率Beta
    rate_beta = []
    for stock in stock_returns.columns:
        # 回归：股票收益 = α + β × 利率变化 + ε
        y = stock_returns[stock].dropna()
        x = rate_changes.reindex(y.index).dropna()

        if len(x) > 30:  # 确保样本足够
            beta = np.cov(y, x)[0, 1] / np.var(x)
            rate_beta.append((stock, beta))

    return rate_beta

# 根据利率环境调整选股权重

def rate_risk_management(portfolio, rate_scenarios):
    """利率情景分析和风险管理"""

    # 情景分析
    scenarios = {
        'base_case': 0,  # 利率不变
        'rate_up_100bp': 1,  # 利率上升100bp
        'rate_down_50bp': -0.5,  # 利率下降50bp
    }

    portfolio_pnl = {}
    for scenario, rate_change in scenarios.items():
        pnl = 0
        for asset, weight in portfolio.items():
            # 根据资产类型计算利率敏感性
            if asset.endswith('_bond'):
                duration = get_duration(asset)
                asset_pnl = -duration * rate_change * weight
            elif asset.endswith('_equity'):
                rate_beta = get_rate_beta(asset)
                asset_pnl = rate_beta * rate_change * weight

            pnl += asset_pnl

        portfolio_pnl[scenario] = pnl

    return portfolio_pnl
