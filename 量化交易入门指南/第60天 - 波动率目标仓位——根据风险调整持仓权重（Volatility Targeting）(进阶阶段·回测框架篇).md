## 一 概念讲解：为什么要做波动率目标？

在深入波动率目标仓位的技术细节之前,我们需要先理解为什么波动率目标仓位如此重要 波动率目标仓位不是可选的优化,而是决定策略能否在真实市场中稳定运行的关键风控机制

如果你等权买入 10 只股票：

有的股票波动率 15%

有的股票波动率 60%

那么组合风险会被高波动股票"绑架"

波动率目标仓位的目的：

市场变动大 → 自动降杠杆/降仓位

市场平稳 → 自动加仓

让策略净值曲线更平滑 回撤更可控

这是很多 CTA 宏观 股票多因子策略的"底层风控器"

## 二 数学/逻辑推导（核心公式）

理解了波动率目标仓位的重要性后,我们需要掌握其数学原理 波动率目标仓位的核心在于通过数学公式精确控制组合风险,这是专业量化系统必须掌握的基础

## (A) 单资产：目标波动率控制

你希望策略年化波动率为 $\sigma _ { \mathrm { t a r g e t } }$

资产的年化波动率为 $\sigma _ { t }$

则仓位缩放系数（杠杆）：

$$
w _ {t} = \frac {\sigma_ {\mathrm{target}}}{\sigma_ {t}}
$$

$\sigma _ { t } \overrightarrow { \Xi }  w _ { t } / \vert \cdot$ （降仓）

• $\sigma _ { t }$ 低 → 大（加仓）

通常会加一个上限防止极端加杠杆：

$$
w _ {t} = \min \left(w _ {\max}, \frac {\sigma_ {\text {target}}}{\sigma_ {t}}\right)
$$

## (B) 多资产组合：用组合波动率做缩放

先给出一个基础权重 $w ^ { ( 0 ) }$ （比如多因子得分转成权重/等权）

计算组合波动率：

$$
\sigma_ {p, t} = \sqrt {w ^ {(0) T} \Sigma_ {t} w ^ {(0)}}
$$

然后整体缩放：

$$
w _ {t} = w ^ {(0)} \cdot \frac {\sigma_ {\mathrm{target}}}{\sigma_ {p , t}}
$$

这叫 Volatility Scaling / Vol Target Overlay

非常常见：先做 alpha 选股，再用波动率目标做"风控层"

### 3.1 估计波动率（滚动年化）

```python
import numpy as np
import pandas as pd

def ann_vol(returns: pd.Series, window=20, trading_days=252):
    """滚动年化波动率"""
    vol = returns.rolling(window).std() * np.sqrt(trading_days)
    return vol
```

### 3.2 单资产波动率目标仓位

```python
def vol_target_weight(vol: pd.Series, sigma_target=0.10, w_max=2.0):
    """
    vol: 年化波动率序列
    返回：每天的仓位倍率（可 >1 表示加杠杆）
    """
    w = sigma_target / vol
    w = w.clip(upper=w_max)
    return w
```

## 思考题的深度解析

我们深入分析了三个关键思考题:

思考题1: 如果市场突然进入高波动,波动率目标策略会怎么做？

答案: 会自动降仓/降杠杆,因为 $\sigma _ { t }$ 变大,导致 $w _ { t } = { \sigma } _ { t a r g e t } / { \sigma } _ { t }$ 变小；目的就是让组合风险恒定,减少回撤

核心价值: 理解波动率目标仓位对市场波动的自动响应机制,掌握风险控制的核心逻辑

思考题2: 为什么必须给 $w _ { t }$ 设置上限 $w _ { \mathrm { m a x } } ?$

答案: 因为当波动率非常低时,公式会让仓位无限放大,实盘中会导致过度杠杆和尾部风险暴露,所以必须限制最大仓位/最大杠杆

核心价值: 理解杠杆上限的必要性,掌握防止极端情况的风险控制方法

## 思考题3: 在多资产组合里,如果只用各自波动率倒数分配权重,会忽略什么风险？

答案: 忽略了相关性风险：两只股票即使各自波动不大,但高度同涨同跌时,组合风险仍可能很高；所以更严谨的做法需要协方差矩阵

核心价值: 理解相关性风险的重要性,掌握组合风险管理的正确方法

核心洞察: 这些思考题帮助我们理解波动率目标仓位的复杂性和重要性,掌握不同场景下的风险控制策略<sub>。</sub>

## 最后的提醒

在实现波动率目标仓位时,请始终记住:

1. 波动率目标仓位不是可选的: 波动率目标仓位不创造Alpha,但它决定Alpha能不能活着走到最后,是策略稳定性的关键

2. 相关性风险不能忽略: 必须使用协方差矩阵计算组合波动率,忽略相关性风险会导致风险低估

3. 杠杆上限必须设置: 当波动率非常低时,必须限制最大仓位/最大杠杆,防止过度杠杆和尾部风险暴露

4. 模块化设计很重要: Alpha层和风控层分离,可以随意换Alpha,风险层完全不动,这是专业量化系统的标准做法
