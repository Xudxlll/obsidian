## 一 滑点到底是什么？（一句话版）

在深入滑点建模的技术细节之前,我们需要先理解滑点的本质。滑点不是简单的"成本",而是交易执行过

程中不可避免的现实。

滑点 = 你期望成交价 − 实际成交价

在回测里：

你以为 自 己在 close / open 成交

实盘中你只能在 bid / ask + 冲击 成交

滑点是"交易执行层"的成本,而不是信号层的问题

## 二 滑点的两大来源（非常重要）

理解了滑点的定义后,我们需要深入分析滑点的两大来源。这两个来源共同决定了滑点的大小和特征,是滑点建模的基础。

## 1 冲击成本（Market Impact）

你下单,本身就改变了市场。

举例（极其真实）：

卖一只有 2 万股

你要市价买 10 万股

结果：

前 2 万吃掉卖一

后 3 万吃卖二

再吃卖三……

你的平均成交价一定高于卖一

这部分成本 = 冲击成本

## 2 随机滑点（Random Slippage）

即使你下很小的单：

网络延迟

对手盘撤单

同一时间别人的抢单

撮合顺序随机性

都会让你的成交价 围绕一个期望值随机波动。

这就是为什么：

同样的策略,每次实盘结果都不一样。

## 三 冲击成本的经典建模方式

理解了滑点的两大来源后,我们需要掌握冲击成本的具体建模方法。冲击成本是滑点中最可预测的部分,也是专业量化系统必须精确建模的环节。

## 模型 1：线性冲击模型（最常用）

$$
\text { Impact } = \alpha \cdot \frac {Q}{A D V}
$$

Q：你的下单量

$\mathsf { A D V } \colon$ 日均成交量

• $\alpha :$ 市场冲击系数 （经验参数）

成交价模型：

$$
P _ {e x e c} = P _ {m i d} \times (1 + \mathrm{Impact})
$$

机构日频 多因子回测常用

## 模型 2：平方根冲击模型（更接近真实）

$$
\text { Impact } = \alpha \cdot \sqrt {\frac {Q}{A D V}}
$$

这是 Almgren–Chriss 框架中的经典结论：

小单冲击很小

大单冲击急剧上升

专业量化/卖方模型标配

## 模型 3：基于盘口深度（L1/L2）

若你有盘口：

$$
P _ {e x e c} = \frac {\sum_ {i} P _ {i} \cdot V _ {i}}{\sum_ {i} V _ {i}}
$$

即 VWAP across order book。

高频 / Tick 回测必用

## 四 随机滑点模型（让回测"更真实"）

掌握了冲击成本的建模方法后,我们需要引入随机性。如果你的回测 每次结果都一样,反而是危险信号。随机滑点模型让回测结果更接近真实交易的不确定性。

## 最简单的随机滑点

$$
\epsilon \sim \mathcal {N} (0, \sigma^ {2})
$$

$$
P _ {e x e c} = P _ {d e t e r m i n i s t i c} \times (1 + \epsilon)
$$

：滑点波动率（如 5–20bp）

## 更真实：与流动性挂钩

$$
\sigma = \beta \cdot \frac {Q}{A D V}
$$

下单越大 → 不确定性越大。

## 高频中常见的非对称滑点

买单：更容易 向上滑

卖单：更容易 向下滑

可以用 偏态分布 （Skewed Normal）。

## 五 完整滑点模型（组合版，实战推荐）

理解了冲击成本和随机滑点后,我们需要将它们组合成一个完整的滑点模型。这个综合模型是实战中最常用的,也是你以后回测可以长期用的模型。

综合模型：

$$
P _ {e x e c} = P _ {m i d} \cdot \left(1 + \alpha \sqrt {\frac {Q}{A D V}} + \epsilon\right)
$$

其中：

第一项：理论中间价

第二项：确定性冲击成本

第三项：随机滑点

这是你以后回测可以长期用的模型

六 Python 示例（滑点函数）

掌握了理论模型后,让我们通过代码来具体实现。这个Python函数展示了如何将理论转化为可执行的代码,可以直接集成到回测系统中。

```python
import numpy as np

def slippage_price(mid_price, qty, adv,
    alpha=0.1,
    sigma=0.02,
    side='buy'):
    # 冲击成本（平方根模型）
    impact = alpha * np.sqrt(qty / adv)

    # 随机滑点
    eps = np.random.normal(0, sigma * qty / adv)

    # 买卖方向
    sign = 1 if side == 'buy' else -1

    exec_price = mid_price * (1 + sign * impact + eps)
    return exec_price
```

可以把这个函数 直接塞进 Backtrader 的 broker 或策略里。

## （1）为什么平方根冲击模型比线性模型更合理？

因为真实市场中,流动性并非线性消耗； 前几档容易成交,越往后价格跳跃越大, 平方根模型更符合订单簿结构。

## （2）如果你的策略在「不加滑点」时年化 25%,

「加滑点 + 冲击成本」后变成 5%, 你应该怎么做？

说明策略 alpha 边际很薄,被交易成本吃掉； 要么：

减小下单量

延长持仓周期

改为低频

或直接放弃该策略

这是非常正常 也是非常正确的结论

## （3）为什么高频策略比日频策略更依赖精细滑点模型？

因为高频策略的 alpha 边际更薄,交易成本占比更高,滑点的细微差异都会显著影响策略收益。高频策略需要更精确的滑点建模来捕捉市场微观结构的细节。

## 冲击成本的三种经典建模方式

我们系统解析了三种经典的冲击成本建模方法:

① 线性冲击模型（最常用）

公式: $\textstyle { \mathrm { I m p a c t } } = \alpha \cdot { \frac { Q } { A D V } }$

成交价: $P _ { e x e c } = P _ { m i d } \times ( 1 + \mathrm { I m p a c t } )$

适用场景: 机构日频 多因子回测

优点: 简单易用,参数少

缺点: 对流动性消耗的假设过于简化

## ② 平方根冲击模型（更接近真实）

公式: $\textstyle { \mathrm { I m p a c t } } = \alpha \cdot { \sqrt { \frac { Q } { A D V } } }$

理论基础: Almgren–Chriss 框架

特点: 小单冲击很小,大单冲击急剧上升

适用场景: 专业量化/卖方模型

核心优势: 更符合订单簿结构,前几档容易成交,越往后价格跳跃越大

## ③ 基于盘口深度（L1/L2）

公式: $\begin{array} { r } { P _ { e x e c } = \frac { \sum _ { i } P _ { i } \cdot V _ { i } } { \sum _ { i } V _ { i } } } \end{array}$

本质: VWAP across order book

适用场景: 高频/Tick 回测

核心价值: 最接近真实成交价格

核心洞察: 平方根冲击模型比线性模型更合理,因为它更符合真实市场中流动性的非线性消耗特征。专业量化系统应该使用平方根模型或基于盘口深度的模型。

## 随机滑点模型的实现方法

我们深入讲解了随机滑点模型的三种实现方式:

## ① 最简单的随机滑点

分布: $\epsilon \sim \mathcal { N } ( 0 , \sigma ^ { 2 } )$

成交价: $P _ { e x e c } = P _ { d e t e r m i n i s t i c } \times ( 1 + \epsilon )$

参数: 为滑点波动率（如 5–20bp）

优点: 简单易实现

缺点: 未考虑流动性影响

## ② 与流动性挂钩的随机滑点

公式: $\begin{array} { r } { \sigma = \beta \cdot \frac { Q } { A D V } } \end{array}$

特点: 下单越大,不确定性越大

核心价值: 更真实地反映市场不确定性

适用场景: 中低频策略

## ③ 非对称滑点（高频常见）

特点: 买单更容易向上滑,卖单更容易向下滑

实现: 使用偏态分布（Skewed Normal）

适用场景: 高频策略

核心价值: 捕捉买卖方向的不对称性

核心要点: 如果你的回测每次结果都一样,反而是危险信号。随机性不是缺陷,是现实。只有引入随机滑点,回测结果才能更接近真实交易的不确定性。
