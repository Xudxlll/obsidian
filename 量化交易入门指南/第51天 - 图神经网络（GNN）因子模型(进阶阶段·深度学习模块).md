## 量化交易进阶:第51天 - 图神经网络（GNN）因子模型(进阶阶段·深度学习模块)

原创 逻辑与流 逻辑与流 2025年11月 16 日 21:54 北京 2人

本文系统讲解如何将图神经网络（GNN）用于量化因子增强：基于行业 相关性 产业链 共同持仓与ETF成分等关系构建“股票图”，通过图卷积/注意力/异质图Transformer等机制在股票之间传播与聚合信息，产出节点向量 h\_i（Deep Factor） 对比行业图/相关性图/产业链图/Deep Factor 的适配场景与优劣，说明为何GNN应作为“因子工厂”（特征提取器）接入线性模型 CatBoost/XGBoost LSTM/Transformer等预测器以完成排序 组合与风险管理，并给出稳健性评估与落地建议

——“股票不是独立样本，而是一个图”

传统量化模型（LR / XGBoost / MLP / LSTM）都假设：

一只股票的特征独立于其他股票

但真实市场完全不是这样：

同行业的股票会联动

产业链上下游会传导风险

大盘情绪会影响全市场

公募基金持仓结构会引起“抱团风格”

ETF → 成分股之间有强相关

因此：

股票不是一条条孤立的数据，而是一个巨大的“股票关联图（Stock Graph）”<sub>。</sub>

图神经网络（GNN ）正是为这种“样本之间有关联”的任务而生

为什么 GNN 适合股票预测？

因为你的输入不再是：

单只股票

X\_i = [PE\_i, PB\_i, ROE\_i, Momentum\_i, Volatility\_i]

而是：

股票图 Graph G = (Nodes, Edges)

每个节点 = 一只股票

节点特征 = 股票因子

边特征 = 行业关系/产业链/相关性

GNN 的目标：

让每只股票吸收来自“邻居股票”的信息，

得到新的“图因子”（graph-enhanced factor）<sub>。</sub>

## 一 如何构建“股票图”？（核心）

GNN 的关键是如何定义股票之间的边（Edges）<sub>。</sub>

## 1）行业图（最常用 结构最清晰）

同一个行业 → 连边

细分行业越小，连边越强

例如：

贵州茅台 —— 五粮液 —— 泸州老窖

恒瑞医药 —— 迈瑞医疗 —— 药明康德

这反映 行业风格联动<sub>。</sub>

## 2）相关性图（Correlation Graph）

计算 60 日收益率的相关系数：

corr(i, j) > 0.6 → 连边

优点：

自动反映市场资金抱团

随市场变化自动调整图结构

缺点：

容易过拟合

大盘下跌时强相关

## 3）产业链图（Supply Chain Graph）

从 WIND / Choice / 公司公告构建：

上游原料供应商 → 中游制造 → 下游零售

优点：

可以识别最真实的 传导链 盈利结构 逻辑关系

## 4）基金持仓图（Co-holding Graph）

两只股票被相同基金大量持仓 → 连边

适合研究：

抱团股（A 股经常出现）

换手导致的连带下跌

板块流动性冲击

## 5）ETF 指数图

例如：

沪深300 → 成分股

中证白酒 → 白酒股

中证新能源 → 新能源股

能捕捉：

指数调仓

ETF 申赎带来的流动性冲击

## 二 GNN 如何“增强因子”？

传统因子：

X\_i = [PE\_i, PB\_i, ROE\_i, Momentum\_i]

GNN 聚合邻居信息后的因子：

X'\_i = GNN(i | neighbors)

也就是：

你的因子 = 自 己的特征 + 邻居股票的特征池化

在图卷积（GCN）里：

X'\_i = Mean( X\_i, X\_neighbors )

在 GAT（注意力图网络）里：

X'\_i = Σ attention(i, j) \* X\_j

GNN 能判断哪些同类股票最重要，自动加权学习“股票风格联动特征”

## 三 常用的 GNN 模型

对于股票预测，一般最常用：

✔ GCN + LSTM

✔ GAT（图注意力）

✔ HGT（产业链）

## 四 图因子是怎么用在量化中的？

训练后的节点表示（node embedding）：

h\_i = GNN(X\_i, neighbors)

即：

h\_i 就是“深度学习因子（Deep Factor）”

然后你可以：

把 h\_i 放入 LSTM 预测 5 日收益

把 h\_i 放入 CatBoost

把 h\_i 当作新的 alpha 因子做线性组合

计算 h\_i 与收益的 RankIC

用 h\_i 排序建组合

## 五 四种图神经网络量化模型的区别（最清晰版本）

我用一句话概括：

（A）行业图：关系固定 最稳定 → 适合风格因子

（B）相关性图：关系动态 最敏感 → 适合捕捉资金抱团

（C）产业链图：因果结构 最真实 → 适合基本面逻辑

（D）Deep Factor：统一框架，把图 embedding 当新因子，用于任何模型下面我详细展开

## （A）行业图 + GAT ——“行业内部的风格传导”

## 图结构怎么构造？

节点：股票

边：同一行业（或同一细分子行业）股票互相连边

边权重：GAT 自学注意力权重（股票对股票的影响力）

## 适用场景

✓ 研究 行业轮动 风格因子（价值/成长）

✓ 适合基本面投资，不经常变化

✓ 数据简单 稳定 无噪声

优点

图结构非常稳定（行业不会乱动）

特别适合 GAT 的注意力机制：

例如白酒行业中：

㊙ 茅台 → 五粮液 → 泸州老窖 影响力不同，GAT 会自动学习

缺点

行业内部差异大（比如医药有创新药 器械 原料药），图太粗糙

无法捕捉市场短期情绪

## 一句话总结

行业图适合做“稳定的 月级别风格 alpha”

（B）相关性图 + GCN —— “资金抱团 + 市场风格”的动态捕捉

图结构怎么构造？

用 60 日滚动收益率相关性 构造图：

corr(i, j) > 0.5 → 连边

图结构 每天更新一次

## 适合场景

✓ 捕捉 抱团股（比如 A 股白酒 新能源）

✓ 捕捉 风格切换（高股息 → TMT，周期 → 消费）

## 优点

市场在涨跌时，图会自动变化，能反映当下风格

无需行业分类即可找“市场真实关系”

## 缺点

噪声很大（相关性本来就不稳定）

图不稳定，容易过拟合

有时市场整体下跌 → 所有人都高度负相关

## 一句话总结

相关性图适合“情绪型 alpha”，捕捉 1–20 日 收益的短期 signal

## （C）产业链图 + HGT —— “真实经济关系的因果图”

图结构怎么构造？

这是最专业 最高阶的图：

节点类型（heterogeneous graph，有多类型节点）：

上游材料

中游制造

下游品牌

经销商

终端零售

基金

ETF

行业指数

公司本身

边类型（多关系）：

“供应 → 制造”

“制造 → 品牌”

“基金 → 股票”

“ETF → 成分股”

“行业指数 → 股票”

## 适合场景

✓ 长期限逻辑（业绩 产业增长）

✓ 套利与高频预测（产业链传导）

✓ 传染效应（产业链利润压缩 供给紧张）

优点

结构真实（不是用相关性凑出来的）

异质图 Transformer（HGT）能识别不同关系的不同权重

解释性很强：能说清楚“为什么上涨”

## 缺点

构图难

数据来源依赖 Wind/Choice

工程复杂度高

一句话总结

产业链图代表“基本面因果 alpha”的最高级形态

## （D）Deep Factor —— 统一框架：任何图 → 输出 embedding 作为因子

无论你用：

行业图（A）

相关性图（B）

产业链图（C）

GNN 输出的节点 embedding：

h\_i = GNN(X\_i, neighbors)

都可以看成：

深度学习得到的新因子（Graph Factor 或 Deep Factor）

你可以把它：

加入你的因子库

放入你的多因子框架

优点

统一框架，高度灵活

你不需要直接用 GNN 预测收益

你把 GNN 当作“因子增强器”

缺点

需要管控过拟合

因子解释性较弱

一句话总结

Deep Factor 是“用图神经网络 自 动生成 alpha 因子”的通用 方法<sub>。</sub>

## 六 着重讲解一下行业

行业图（Industry Graph）＝ 把 所有股票 按行业关系连起来的图

是一种 结构数据（Graph），用来表达股票之间“行业结构上的相似性”

## 一句话解释

行业图 = 股票是节点 + 行业关系是边

并不是只分析白酒或医药，而是把所有行业的结构建成图，让模型自动从行业关系中学习特征

## 行业图怎么构造？

1）股票作为节点

每个节点 = 一只股票

例如：贵州茅台 五粮液 海天味业 恒瑞医药……

2）边来自行业类别

最简单做法：

同一行业内 → 节点两两相连

不同行业之间 → 不连边

示例（极简）

白酒行业的图：

茅台 — 五粮液 — 泸州老窖 → 完全连通

医药行业的图：

恒瑞 — 科伦 — 复星医药 → 完全连通

两个行业彼此不连边

这相当于告诉 GNN：

“同一行业的公司更相似，应该互相传播信息 ”

## “行业图” vs “选择一个行业分析”

<table><tr><td>概念</td><td>目的</td><td>数据范围</td></tr><tr><td>行业图(Industry Graph)</td><td>利用行业结构增强特征学习</td><td>所有股票</td></tr><tr><td>选择一个行业分析</td><td>行业研究 / 主题投资</td><td>白酒/医药等 少量股票</td></tr></table>

行业图是结构化建模，用于深度因子构建；

选择一个行业，是传统行业研究，不是图模型

## 为什么行业图对 GNN 因子有用？

因为 GNN 擅长处理“关系”：

同行业公司会互相影响（供需 / 估值 / 情绪）

行业内收益率相关性更强

行业内基本面结构更接近

GNN 会让信息沿着边传播，比如：

茅台的收益/估值因素，会传播给五粮液 泸州老窖，帮助模型学习行业共性因子

行业图是最简单 最稳定的图

## 行业图能学到的 6 类核心信息

① 行业内的“共振”特征（行业 Beta）

同一行业的股票通常会一起涨跌——

情绪共振

需求周期共振

政策驱动

估值扩张或收缩

GNN 会自动从“行业内部的边”中学到：

“这些股票的特征应该相互影响 ”

因此能提取出类似于行业 Beta 的深度因子

例如：

茅台 ↑ → 五粮液 泸州老窖也会收到信息传递，从特征中学习到“行业共振”

这类行业共振因子在回测中往往收益很高

② 行业内的相对收益关系（alpha 因子）

行业内部股票互相比更有可比性

比如白酒行业内部：

谁利润增长更快

谁估值更便宜

谁短期回调更大

谁库存压力更小

行业图帮助模型聚焦于同类竞争者的相对表现：

“你在行业里的相对位置好不好？”

这可以让模型对单只股票的 alpha 判断更准确

③ 行业间的风格轮动关系（跨行业信息）

行业图不是孤岛，它包含 多个行业

行业之间虽然不连边，但模型能通过每个行业内部的表现学到：

哪个行业进入景气周期

哪个行业在下行

哪些行业相互替代

哪些行业受宏观影响更强

这形成 风格轮动因子

例如 GNN 会捕捉到：

新能源 ↓ 时 → 化工材料 ↑

地产 ↓ 时 → 银行/基建 ↑

这类“隐含行业关系”是传统因子很难捕捉的

④ 行业内的异常点（outliers）

行业内部股票连接成团，因此 GNN 很擅长找异常行为

如果行业都涨，只有你跌 → 模型学到你是弱势

如果行业都跌，只有你涨 → 模型学到你是强势

异常点是极好的交易信号

⑤ 行业噪声过滤（denoising）

深度模型常过拟合，而行业图相当于正则化

GNN 强制模型在同一行业的股票之间做平滑，使噪声减少

例如：

某只小市值医药股涨停，但行业整体弱势 →

图结构会自动压低其权重，避免模型过度高估

⑥ 行业中长期结构（结构型 Alpha）

行业图可捕捉：

行业龙头 vs 次龙头结构

高成长子行业 vs 老行业

高估值行业 vs 低估值行业

新能源产业链 vs 传统产业链的格局

这些结构会长期存在，而 GNN 能稳定学出来

## 总结一句话

行业图不是为了“圈选一个行业研究”，

而是为了 让模型理解行业结构，并将这种结构用于预测收益率

它可以从全市场中学到行业层面的：✔ 行业共振✔ 相对收益✔ 风格轮动✔ 异常点✔ 噪声过滤✔ 结构型 Alpha

这是单纯用表格数据无法做到的

## 行业图（全 A 股）最后到底得到的是什么？

## 答案非常关键：

最终得到的是整个市场每只股票的 “深度学习因子”（Deep Factor） h\_i<sub>。</sub>

简单说：

我们不是为了得到“白酒因子”或“医药因子”，

而是得到一个 ——

“包含行业 + 风险 + 同涨同跌结构 + 相关性” 的超级复合因子

这个因子是一个向量（比如 32 维 64 维），叫 node embedding：

$$
\mathrm {h\_ {i} \in R^ {\wedge} 32}
$$

每只股票一个

但我只想研究白酒，为什么要全部股票？

因为：

白酒公司受到消费板块的影响

消费板块受到经济周期影响

周期股会影响金融股

金融股再反过来影响消费

行业之间是 网络结构，不是孤立的

所以你必须把全市场放进去，才能“让信息流动”

图神经网络就是模拟这种“信息传播”的：

白酒 → 食品饮料 → 消费 → 大盘 → 行业轮动 → 白酒

你的模型会自动学到：

板块联动

行业相似性

上下游关系（若加入供应链图）

风格暴露（价值/成长等）

系统性风险

行业轮动节奏

这些都是手工因子很难做的

一个包含行业特征的“深度因子向量”

所以 h\_i 是一个“浓缩了全市场关系”的超级因子

## 为什么说它是“超级因子”？

因为它包含：

① 行业因子（类似中证行业指数）

模型会自动学到哪些股票属于同一板块 联动性如何

② 风格因子（价值/成长/大小盘）

从输入的 PE PB 波动率等特征自动抽取出来

③ alpha 因子（收益信号）

训练时你用未来收益/涨跌作为标签，模型会学习预测能力

④ 风险因子（共性成分）

从图结构（行业 相关性）自然学到

所以它比 PE<sub>、</sub>PB<sub>、</sub>ROE 这些浅层因子更强<sub>。</sub>

## 最终结果是什么？

最终你得到的不是一个“行业因子”，

也不是多个“每个行业一个因子”

而是：

一个更强的 “Deep Factor”（每只股票一个向量）

然后你可以：

✔ 1. 直接用 h\_i 来排序建多空组合

（像普通因子一样用）

✔ 2. 计算 h\_i 与收益的 RankIC

（检验因子有效性）

✔ 3. 喂给 CatBoost/XGBoost

（提升预测准确率）

✔ 4. 喂给 LSTM/Transformer

（做时序因子）

✔ 5. 放入风险模型

（分解行业暴露 风格暴露）

## � 你真正关心的核心概念

行业图不是为了研究行业，而是为了让深度模型“理解整个市场的结构”，从而生成更强的因子

这就是为什么全 A 股都要放进去

## 总结 Day 51：

GNN 是“股票之间的关系因子模型”

它让模型从行业 风格 产业链 资金流等结构中学习更强的 alpha

GNN 模型的最终目的是什么？

一句话：

GNN 的目的不是直接预测收益，而是“学习一个更强的因子（Deep Factor）”<sub>。</sub>

我们平时手工构造因子（PE<sub>、</sub>PB<sub>、</sub>ROE<sub>、</sub>动量<sub>、</sub>波动率<sub>、</sub>换手率……），这些都是“浅层因子”<sub>。</sub>

但市场真实关系是复杂 + 非线性 + 有网络结构的

所以 GNN 会学习到一个新的“深度因子 h\_i”，它包含：

公司的自身的特征（基本面 技术指标等）

邻居公司的行业关系

同产业链公司的上下游关系

市场相关性信息

行业板块风险因素

甚至“风格”信息（价值/成长/周期/医药/科技）

你可以把 h\_i 理解成：

一个由网络信息 + 数据自动生成的“超级 Alpha 因子”

## 为什么还要把 GNN 产出的 h\_i 再放到别的模型里？

因为 GNN 只负责“加工因子”，并不一定最擅长：

最终的收益预测（MLP/LSTM/CatBoost 更强）

横截面排序（线性模型更稳定）

风险控制（线性模型容易解释）

因子组合（传统方法更成熟）

所以通常流程是：

GNN 因子（Deep Factor）在量化中的常见使用方式

1.（最常见）把 h\_i 当 “因子” 去做线性回归 / RankIC

h\_i = GNN(X\_i, neighbors)

RankIC(h\_i, future\_return)

GNN 负责学习：

行业关系

供应链

同涨同跌结构

风险暴露

信息传递

线性模型负责最终的：

排序

组合

风险分配

这是最稳健 机构最常用的方式

2. 把 h\_i 放进 CatBoost / XGBoost 预测未来收益

深度因子 h\_i 作为特征：

pred = CatBoost(h\_i, other\_features)

CatBoost 善于处理：

树模型可解释性强

能挖掘非线性

不需要归一化

抗噪能力强

GNN 学表达能力，CatBoost 学预测能力，强强组合

3. 把 h\_i 放进 LSTM / Transformer（做时序）

使用过去60天的 h\_i：

[h\_i(t-60) … h\_i(t)] → LSTM → 预测未来收益

这是像深度对冲基金（Citadel /Two Sigma）常用的做法

GNN 捕捉横截面结构，LSTM 捕捉时间结构

4. 直接用 h\_i 排序做多空组合

这是最直接的：

分5组：Q1..Q5

Q5-Q1 = 多空收益

如果有效：

h\_i 越高 → 未来越涨

h\_i 越低 → 未来越跌

把 h\_i 当成超强的“复合因子”

## 那么 GNN 的位置到底在哪里？

不是：

预测模型本身

而是：

因子加工 & 表达学习（Representation Learning） 的关键步骤

就像 CV（计算机视觉）里：

CNN 负责提特征（feature extractor）

分类器/检测器负责输出结果

在量化里：

GNN = 特征提取器（Feature Extractor）

CatBoost/LSTM/Linear = 预测器（Predictor）

你可以理解为：

原始特征 X →（GNN）→ Deep Factor h\_i →（ML模型）→ Predict

## （类比）为什么要这样设计？

类比：你看股票 K 线

只是 K 线 → 信息少

加一堆技术指标 → 信息丰富

再用行业/关系 → 信息更丰富

GNN 就像是：

自动学习“隐藏的信息”，比如：

哪些股票会一起涨？

哪些公司供应链联系紧密？

哪些板块关系强？

这些都是普通因子算不出来的

## 最终总结（你一定要记住）

GNN 的最终目的：生成更强的因子（Deep Factor）<sub>。</sub>

它不会替代 CatBoost<sub>、</sub>LSTM，而是：

用图结构增强因子

→ 得到更强的 h\_i

→ 再交给预测模型

GNN 是“因子工厂”，

CatBoost/线性模型/LSTM 才是“预测器”

## 结论

定位：GNN 是因子增强器与特征提取器，不直接取代预测器

方法：通过行业/相关性/产业链等图结构，让信息在股票间传播，形成更具解释力和预测力的 DeepFactor h\_i

落地：将 h\_i 接入线性模型 CatBoost/XGBoost LSTM/Transformer 等，完成排序 组合与风险管理

实践建议：先从稳定的行业图 + GAT/GCN 入手，逐步引入相关性图与产业链异质图（HGT），并严格做过拟合与稳健性检验（RankIC 分组回测 时变检验）
