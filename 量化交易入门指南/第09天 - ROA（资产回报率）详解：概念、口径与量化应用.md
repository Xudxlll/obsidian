本文为量化交易学习系列第9天内容，深入解析ROA（资产回报率）的概念定义 计算公式 TTM口径理解 杜邦分解关系以及在量化投资中的实际应用策略 通过详细的理论讲解和实际案例，帮助读者掌握这一重要的财务分析工具

## 一 ROA（Return on Assets，资产回报率）是什么（概念 & 口径）

定义

企业把"占用的全部资产"用来赚钱的效率

### 常见公式

$$
\mathrm{ROA} = \frac {\text {净利润(TTM)}}{\text {平均总资产(TTM)}}
$$

净利润（TTM）：过去 12 个月滚动净利，能平滑季节性

平均总资产：通常取期初与期末总资产的平均；更严谨可用季度滚动平均

## 二、TTM口径详解

### (1) ROA 公式为什么分子分母都带 TTM？是不是一样的？

净利润（TTM）：这是过去 12 个月的净利润（利润表的流量项，需要累积 4 个季度才能得出年化效果）

平均总资产（TTM）：这里的 TTM 不是说"资产也得累积"，而是指与分子保持一致的 12 个月期间 资产是存量指标，不用累积，一般做期初 + 期末平均，或者 4 季度平均

严格来说，TTM（Trailing Twelve Months）= 最近 12 个月滚动值，这个概念主要是针对 利润表 现金流量表这种"流量项"

净利润（流量项）：要累加最近 4 个季度，才得到 TTM

总资产（存量项）：在某一时点就能观察，不需要"累加" 所以更准确的说法是 平均总资产，而不是"资产TTM"。

所以你看到很多书 报告里写 ROA = 净利润（TTM） / 平均总资产（TTM），其实是个"缩写习惯"

分子 TTM：确实是滚动 12 个月

分母 TTM：本质上是"这 12 个月期间的平均资产"，有时也会写成 Avg Assets。

总结：全称其实不一样，只是为了方便，都挂了个 "TTM" 标签，严格区分应该是：

$$
\mathrm{ROA} = \frac {\text {Net Income (TTM)}}{\text {Average Total Assets (Period Avg)}}
$$

**1. TTM 的本质**

TTM (Trailing Twelve Months)= 过去 12 个月 的滚动值

它的意义是：避免季节性影响，用最近一年的数据来代表公司的真实经营水平

**2. 分子：净利润（TTM）**

净利润是 流量项（Flow），在一段时间内产生

所以需要把最近 4 个季度的净利润加起来，才得到过去 12 个月的 滚动利润

举例：2025Q2 的净利润 $\begin{array} { r l } { \left( \mathsf { T T M } \right) } & { = 2 0 2 4 \mathrm { Q } 3 + 2 0 2 4 \mathrm { Q } 4 + 2 0 2 5 \mathrm { Q } 1 + 2 0 2 5 \mathrm { Q } 2 \Rightarrow \underline { { \mathbb { J } } } \| \uparrow \mp \frac { 3 5 } { 2 } \pounds \frac { \pm } { 2 } \mp \frac { 7 } { \ 8 } \| \mathsf { J } _ { \circ } \| } \end{array}$

所以分子 TTM 是"累加"的含义

**3. 分母：平均总资产**

总资产是 存量项（Stock），在某一时点存在

比如 2025Q2 财报里的总资产，是截止 6 月 30 日的一个时点数

**但 ROA 的分子是"一段时间赚的钱"**，如果分母只取一个时点，就会失真

→ 解决办法：取区间的平均值，比如 (期初资产 + 期末资产) ÷ 2

因为净利润是 过去 12 个月的滚动数，所以最好也取 过去 12 个月的平均资产（有的数据库也叫 "AssetsTTM"）。

所以分母写成 "TTM"，其实是说：分母和分子对应同一个时间窗口 并不是说资产也要"累加 12 个月 "。

**4. 为什么要保持"口径一致"**？

这是量化研究里经常强调的点

如果分子用的是 过去一年净利润，而分母只取了 最新时点的资产，就会出现"时间错配"：

资产可能在年内增长很多，

但净利润还是滚动一年累计数

结果 ROA 会被高估或低估

所以常见做法是：

$$
\mathrm{ROA} = \frac {\text {Net Income (TTM)}}{\text {Average Total Assets (TTM)}}
$$

这里的 "TTM" 其实代表的是 过去 12 个月的时间窗口，并不是说资产要像利润一样"滚动累加"，只是取区间平均

**5. 举个例子**

假设某公司：

2024Q2 总资产 = 100

2025Q2 总资产 = 200

过去 4 个季度净利润 = 30

**计算 ROA**：

平均资产（TTM） = (100 + 200)/2 = 150

净利润（TTM） = 30

ROA = 30 / 150 = 20%

如果你只用"期末资产 200"，则 ROA = 30 / 200 = 15%，会低估真实效率

**总结**：

分子（净利润 TTM）：流量 → 累加 12 个月

分母（平均资产 TTM）：存量 → 取过去 12 个月的平均值

两者都叫 TTM，是为了保证"同一个时间窗口"，但计算逻辑完全不同

## 三 常见变体（按研究目的选口径）

经营 ROA：用经营利润（或 EBIT NOPAT）/ 平均经营资产（剔除多余现金 金融资产 商誉等） 更贴近"主营效率"

税前 ROA：EBIT / 平均资产；跨公司比较时减少税率差异的影响

有形 ROA：净利 / （总资产 − 商誉与无形资产），避免商誉拉大分母稀释指标

金融业 ROA（如银行）：多用 净利润 / 平均生息资产，因为资产结构与一般公司不同

### 注：EBIT NOPAT 是什么？

这些是利润口径，不同口径会影响 ROA ROE 的计算

EBIT (Earnings Before Interest and Taxes)

**中文叫"息税前利润"**

公式：EBIT = 营业收入 - 营业成本 - 营业费用

不考虑利息和所得税，用来比较不同资本结构 不同税率的公司

NOPAT (Net Operating Profit After Tax)

**中文叫"税后经营净利润"**

公式：NOPAT = EBIT × (1 - 所得税率)

**反映"公司主营业务真正创造的 税后可分配的利润"**，不受融资方式影响，更贴近经营本质

在量化里，有时我们不用净利润（因为里面有财务费用 投资收益等杂项），而是用 EBIT 或 NOPAT 来计算 经营性 ROA

所以它们不一样：

分子（净利润）是一年赚的钱

分母（平均资产）是一年内持有的资源规模

**这个比例才是"资产利用效率"**

## 四 和 ROE/杜邦分解的关系

$$
\mathrm{ROA} = \frac {\text {净利润}}{\text {总资产}} = \frac {\text {净利润}}{\text {销售收入}} \times \frac {\text {销售收入}}{\text {总资产}} = \text {净利率} \times \text {资产周转率}.
$$

它同时反映"赚得多不多"（净利率）和"转得快不快"（周转）

$$
\mathrm{ROE} = \frac {\text {净利润}}{\text {净资产}} = \mathrm{ROA} \times \frac {\text {总资产}}{\text {净资产}} = \text {净利率} \times \text {资产周转率} \times \text {权益乘数}.
$$

ROE 高可能来自杠杆，并不一定代表经营效率强；而 ROA 更"纯"，强调不靠加杠杆的赚钱能力

### 注：杜邦分解是什么？

这是财务分析里最经典的一个分解工具，用来把 ROE 或 ROA 拆开，看到底是哪里起作用

ROE 杜邦分解（三因素版）：

$$
\mathrm{ROE} = \frac {\text {净利润}}{\text {净资产}} = \frac {\text {净利润}}{\text {销售收入}} \times \frac {\text {销售收入}}{\text {总资产}} \times \frac {\text {总资产}}{\text {净资产}}
$$

即：

净利率（盈利能力）

× 资产周转率（效率）

× 权益乘数（杠杆）

ROA 杜邦分解（常见两因素版）：

$$
\mathrm{ROA} = \frac {\text {净利润}}{\text {销售收入}} \times \frac {\text {销售收入}}{\text {总资产}}
$$

即：

净利率（赚得多不多）

× 资产周转率（转得快不快）

所以 ROA 可以理解成"不靠杠杆的纯内生效率"；而 ROE 可能高，但可能是杠杆堆上去的

## 五 完整的杜邦分解（含 ROA / ROE 关系）

> [!warning] 原文公式识别异常
> 本节部分五因素杜邦分解公式存在转写乱码，尚需对照原 PDF 核实；请勿直接据此计算。

### 1) 三因素（经典）杜邦分解 — 完整公式

$$
\boxed {\mathrm{ROE} = \frac {\text {净利润}}{\text {净资产}} = \underbrace {\frac {\text {净利润}}{\text {销售收入}}} _ {\text {净利率}} \times \underbrace {\frac {\text {销售收入}}{\text {总资产}}} _ {\text {资产周转率}} \times \underbrace {\frac {\text {总资产}}{\text {净资产}}} _ {\text {权益乘数}}}
$$

净利率= 净利润 / 销售收入（反映每卖 1 元赚多少钱）

资产周转率= 销售收入 / 总资产（反映资产使用效率）

权益乘数= 总资产 / 净资产（反映财务杠杆，越高表示用越多负债放大权益回报）

### 2) ROA（与上面关系）

$$
\boxed {\mathrm{ROA} = \frac {\text {净利润}}{\text {总资产}} = \frac {\text {净利润}}{\text {销售收入}} \times \frac {\text {销售收入}}{\text {总资产}} = \text {净利率} \times \text {资产周转率}}
$$

因此数学上有：

$$
\boxed {\mathrm{ROE} = \mathrm{ROA} \times \frac {\text {总资产}}{\text {净资产}}}
$$

（即 ${ \mathsf { R O E } } = { \mathsf { R O A } } \times$ 权益乘数 —— 高 ROE 可能来自高 ROA，也可能主要来自高杠杆）

### 3) 五因素（更细的）杜邦分解 — 完整公式

把"净利率"继续细分成税/利/运营等项：

$$
\boxed {\mathrm{ROE} = \frac {\text {净利润}}{\mathrm{EBT}} \times \frac {\mathrm{EBT}}{\mathrm{EBIT}} \times \frac {\mathrm{EBIT}}{\text {销售收入}} \times \frac {\text {销售收入}}{\text {总资产}} \times \frac {\text {总资产}}{\text {净资产}}}
$$

各项含义：

$\frac { \langle \# \mathcal { K } \mathbb { I } \rangle \langle \# \mathbb { I } \rangle } { \mathrm { E B T } }$ : 税负率相关（税后保留比率，称 tax burden，等于 1 − 实际税率）

$\frac { \mathrm { E B T } } { \mathrm { E B I T } }$ :利息负担相关（EBT=EBIT−利息，EBT/EBIT 反映利息冲击）

$\frac { \mathrm { E B I T } } { \mathrm { \sharp } _ { \mathrm { E H } } ^ { \mathrm { p } } \mathrm { \sharp } _ { \mathrm { E } } ^ { \mathrm { p } } }$ :营业利润率 / 经营利润率（经营层面赚钱能力）

后两项同上：资产周转率与权益乘数

### 数值例子（逐步算，保证没错）

假设：

销售（Revenue）＝1000

EBIT ＝ 70

EBT ＝ 60 （说明利息 = 10）

净利润 $( { \mathrm { N e t ~ l n c o m e } } ^ { \circ } ) ~ = ~ 5 0$ （说明税额 = 10）

总资产（Assets）＝ 500

净资产/股东权益（Equity）＝ 200

**逐步计算**：

1. 净利率 =

$$
\frac {\mathrm{净利润}}{\mathrm{销售}} = \frac {5 0}{1 0 0 0} = 0. 0 5
$$

（5%）

2. 资产周转率 =

$$
\frac {\mathrm{销售}}{\mathrm{总资产}} = \frac {1 0 0 0}{5 0 0} = 2. 0
$$

3. ROA = 净利率 × 资产周转率 =

$$
0. 0 5 \times 2. 0 = 0. 1 0
$$

（10%） 或直接 ROA =

$$
\frac {\text {净利润}}{\text {总资产}} = \frac {5 0}{5 0 0} = 0. 1 0
$$

4. 权益乘数 =

$$
\frac {\mathrm{总资产}}{\mathrm{净资产}} = \frac {5 0 0}{2 0 0} = 2. 5
$$

5. ${ \mathsf { R O E } } = { \mathsf { R O A } } \times$ 权益乘数 =

$$
0. 1 0 \times 2. 5 = 0. 2 5
$$

（25%） 或直接 ROE =

$$
\frac {\mathrm{净利润}}{\mathrm{净资产}} = \frac {5 0}{2 0 0} = 0. 2 5
$$

验证五因素分解：

税后保留率 =

$$
\frac {\mathrm{净利润}}{\mathrm{EBT}} = \frac {5 0}{6 0} = \frac {5}{6} \approx 0. 8 3 3 3 3 3 \ldots
$$

利息影响 =

$$
\frac {\mathrm{EBT}}{\mathrm{EBIT}} = \frac {6 0}{7 0} = \frac {6}{7} \approx 0. 8 5 7 1 4 2 8 5 7 \dots
$$

EBIT/销售 =

$$
\frac {7 0}{1 0 0 0} = 0. 0 7
$$

连乘：

$$
\frac {5}{6} \times \frac {6}{7} \times 0. 0 7 \times 2. 0 \times 2. 5 = \frac {5}{7} \times 0. 0 7 \times 5 = \frac {5}{7} \times 0. 3 5 = 0. 2 5
$$

—— 与上面 ROE 一致

## 六 ROA在量化中的典型应用

### 1）横截面选股（质量/盈利能力因子）

直观做法：每月/每季行业内按 ROA 排名，做分位或 Z 分数，买高 ROA 卖低 ROA（或只做多前 20%）

常与"价值 动量 规模 波动率"因子组合，提升信息比

评估：看 IC / Rank IC 分位收益 信息比 收益曲线稳定性等

### 2）趋势与变化率（ΔROA）

**仅看"高不高"不如看"变好没有"** 构造

$$
\Delta \mathrm{ROA}
$$

（QoQ/YoY/TTM 的变动）或加速度（Δ 的变化），常可捕捉改善拐点

策略：行业内先筛改善幅度，再叠加绝对水平，兼顾"好公司 + 变更好"

### 3）质量组合（Quality）

与毛利率 资产周转率 低杠杆 低应计（低应收/存货扩张）等合成质量分

文献与业界经验表明：高盈利 + 低应计的组合更稳健

### 4）估值/盈利联动（Profitability–Valuation Matrix）

将 ROA 与 PE/EV 等估值结合：优先"高 ROA 且不贵"

进一步可用近似 EVA 思想：关注

$$
\mathrm{ROA} - \mathrm{资本成本}
$$

（难点在于 WACC 估计，可用行业常数近似）

### 5）风险诊断与杠杆拆解

若 ROE 上升但 ROA 横盘/下滑，多半是杠杆推升，潜在回撤风险增大

在资本开支周期中，极高 ROA 往往均值回归（竞争进入）；更看好从较低水平持续改善的公司。

### 6）行业差异与中性化

资本密集行业天然 ROA 低，资产轻行业天然 ROA 高 必须行业内比较或做行业/市值中性化，避免风格暴露误判

## 七 ΔROA（QoQ /YoY /TTM 变动）是什么？

在量化里，不仅看 ROA 的绝对水平，还要看它的变化趋势

**常见定义**：

$$
\bullet \quad * * \Delta R O A (Q o Q) ^ {* *}:
$$

$$
\Delta \mathrm{ROA} _ {Q o Q} = \mathrm{ROA} _ {\text {本季度} T T M} - \mathrm{ROA} _ {\text {上季度} T T M}
$$

表示季度环比变化

$$
\bullet \quad * * \Delta R O A (Y o Y) ^ {* *}:
$$

$$
\Delta \mathrm{ROA} _ {Y o Y} = \mathrm{ROA} _ {\text {本季度} T T M} - \mathrm{ROA} _ {\text {去年同期} T T M}
$$

表示同比改善

$\begin{array} { r l } { \bullet } & { { } * * \Delta \mathrm { R O A } ( \mathsf { T T M } ) ^ { * * } } \end{array}$ ： 有人还会直接看 连续 4 个季度的 ROA 斜率 或 最近一年 ROA 的变动幅度，捕捉改善趋势

### 为什么 ΔROA 在量化里重要？

绝对高ROA ≠ 好股票：可能行业天生高，或者即将均值回归

ΔROA > 0（持续改善）：说明公司经营效率在提升，往往是股价驱动力

ΔROA < 0（持续恶化）：即使 ROA 水平高，但下滑趋势也可能带来估值杀

**举个例子**：

A 公司 ROA = 10%，但连续 3 个季度下降 → 市场会担心拐点向下

B 公司 ROA = 5%，但连续 3 个季度上升 → 可能估值还低，市场会提前定价

这就是所谓的 "趋势因子"（Trend），在因子库里经常和"绝对水平因子"一起用

## 八 数据口径与避坑（实务很关键）

TTM 对齐：净利与资产都用 TTM，避免季节性错配

平均资产：至少期初/期末平均；更好用滚动季度平均

公告延迟/避免前视偏差：使用实际披露日滞后入库；若拿不到，保守做法是财报期末后滞后 1–3 个月再生效。

一次性项目与商誉：尽量剔除大额非经常损益；需要时用"经营 ROA"

异常值处理：对极端 ROA（如分母很小或净利为负导致爆表）做 winsorize（如 1%/99% 截尾）或用 中位数±5×MAD 裁剪

标准化：行业内做 Z 分数或分位；再做市值中性化以控制规模偏差

缺失与负值：负净利会给出负 ROA，策略是否纳入需事先约定（常见做法：保留但在行业内排序；也可直接剔除连续亏损样本）

### 什么是"数据口径"？为什么总提这个？

"口径"就是到底用哪个定义 哪个版本的财务指标

在量化里，口径很关键，因为一旦没统一，回测和实盘会完全不一致

**几个例子**：

利润口径：净利润 / EBIT / NOPAT，算出来的 ROA 差别很大

资产口径：用总资产，还是剔除商誉的有形资产？

时间口径：用单季 用年报 还是 TTM？

公告口径：按财报期末日生效，还是按实际披露日滞后？

行业口径：不同数据库行业分类不一样，你要不要行业内标准化？

**总提"数据口径"**，是因为量化里细节=生死 比如：

你如果用未来财报数据来算当期 ROA（没考虑披露延迟），就是 前视偏差，回测会虚高

你如果不剔除异常值（比如资产太小的公司，ROA 爆表），信号就会失真

所以做因子研究时，口径对齐是第一步



ROA（资产回报率）是量化投资中最重要的财务指标之一，它衡量企业利用资产创造利润的效率 通过深入理解TTM口径 杜邦分解关系以及在量化策略中的实际应用，我们可以构建更有效的选股因子和风险管理工具

关键要点：

1. TTM口径的一致性：分子（净利润）需要累加12个月，分母（资产）取平均值
