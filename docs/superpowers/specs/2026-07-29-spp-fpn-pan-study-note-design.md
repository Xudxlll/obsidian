# SPP、FPN 与 PAN 详细学习笔记设计

## 目标

在 `深度学习` 文件夹中新建一篇可独立阅读的教材式笔记，系统解释早期 SPP-Net 的原始 SPP、YOLO 中的 SPP、FPN 和 PAN，并重点消除几种“金字塔”和多尺度操作之间的混淆。

## 输出文件

- 目标文件：`深度学习/SPP、FPN与PAN详细学习笔记.md`
- 来源笔记：`深度学习/08_目标检测_笔记.md`
- 不修改来源笔记及其他现有文件。

## 内容结构

1. 多尺度特征的必要性
2. 早期 SPP-Net 的原始 SPP
   - 不同候选区域与固定长度全连接输入之间的矛盾
   - `1×1、2×2、4×4` 输出网格
   - 固定长度公式与 `255×255×100` 示例
3. YOLO 中的 SPP
   - `1×1、5×5、9×9、13×13` 池化核
   - 步长、Padding、感受野与 Concat
   - 与原始 SPP 的本质区别
4. FPN
   - 自顶向下路径
   - 上采样、横向连接与多尺度输出
   - `13×13、26×26、52×52` 示例
5. PAN
   - 自底向上路径
   - 下采样与定位信息回传
   - 对 FPN 的补充
6. YOLOv4 中的组合数据流
7. 四者对比表
8. 易混点、记忆口诀与复习问题

## 表达方式

- 使用书面语和教材式层级标题。
- 先讲直觉，再讲结构与公式，最后给具体尺寸示例。
- 使用 Markdown 表格、LaTeX 公式和 ASCII 数据流图。
- 内部链接使用 Obsidian Wiki-link。
- 不引入未经说明的新图片，不复制或修改现有图片文件。

## 准确性边界

- 明确区分原始 SPP 中的“目标输出网格”与 YOLO SPP 中的“池化核尺寸”。
- 明确说明池化通常不改变通道数，而 Concat 会增加通道数。
- 明确说明 FPN 是自顶向下，PAN 是自底向上；二者是互补关系。
- 明确说明 YOLO 中的 SPP 通常保持特征图空间尺寸不变，其主要目标是扩大感受野，而不是生成固定长度向量。
- 对不同 YOLO 实现可能采用 `add` 或 `concat` 的差异使用限定表述，避免把某一种实现写成唯一标准。
