> [!abstract] 学习目标
> 把用户表达转换成更容易命中知识库的检索表达。

## 核心理解

用户问题常含省略、口语或模糊指代，而知识库使用正式术语。单查询改写把问题改成更明确的搜索表达；多查询从不同角度提出多个搜索式，合并召回结果。

改写应保留原意，尤其是时间、实体、否定和数值条件。例如“2023 年以前没有上市的公司”不能被改成“2023 年上市公司”。对话式改写还应只补全已有上下文，避免发明缺失信息。

多查询扩大覆盖，也增加延迟与噪声。生成若干查询以后，要去重、限制数量，并对返回文档按稳定 ID 合并，再进入融合或重排。

检索语句与最终回答可以不同：检索语句偏向关键词与实体，回答则需要自然、完整和可引用的表达。

## 课堂代码怎么读

课堂单查询示例经过 Prompt、LLM、字符串解析器返回改写文本；多查询例子再把结果解析成列表。检查异常情况下是否仍保留原问题作为一条召回路径。

> [!warning] 易错点与资料边界
> 改写输出不稳定时，按换行切分可能把编号、解释一起当查询。应校验列表结构，并用固定测试问题比较召回收益与新增成本。

## 复盘练习

为什么保留原问题进行检索通常有帮助？

> [!question]- 参考思路
> 改写可能丢失专有名词或限定条件。原问题提供一条未被模型变换的路径，有助于抵消改写偏差。

> **查询改写-单**
>
> ```python
> """
> 查询改写-单
> """
> from langchain_openai import ChatOpenAI
> from langchain_core.prompts import ChatPromptTemplate
> from langchain_core.output_parsers import StrOutputParser
> import os
> from dotenv import load_dotenv
>
> load_dotenv()
>
> rewrite_prompt = ChatPromptTemplate.from_template("""
> 你是一个查询改写专家。请将用户的提问改写为更适合信息检索的查询。
> 要求：
> 1. 去除口语化表达，使用规范的术语
> 2. 补充隐含的上下文信息
> 3. 提取核心检索关键词
> 4. 只输出改写后的查询，不要解释
>
> 用户提问：{question}
> 改写后的查询：
> """)
>
> llm = ChatOpenAI(
>     model="deepseek-chat",
>     api_key=os.environ.get("DEEPSEEK_API_KEY"),
>     base_url=os.environ.get("DEEPSEEK_BASE_URL"),
>     temperature=0.1
> )
>
> rewrite_chain = rewrite_prompt | llm | StrOutputParser()
>
> q = [
>     "我买的东西怎么还没到?",
>     "怎么退?",
>     "苹果怎么样?"
> ]
>
> for i in q:
>     rewritten = rewrite_chain.invoke({"question": i})
>     print(f"改写:{rewritten}\n")
> ```
>
