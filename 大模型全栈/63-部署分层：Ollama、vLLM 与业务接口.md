## 核心理解

Ollama 便于本地下载与运行模型；vLLM 面向模型推理服务与吞吐；FastAPI 位于业务封装层，接收请求、组织提示词、调用模型并返回业务结果。三者职责可以分层组合。

课程手册从 Ollama 的命令行与原生 HTTP 接口开始，再演示 Python 调用、OpenAI 风格接口与 FastAPI 包装，最后给出服务器上的 vLLM 启动流程。

接口兼容的价值是让调用方保持相近的请求结构，更换 base_url、model 和凭证即可接入不同后端；但聊天模板、参数支持、流式返回与工具能力仍需逐项验证。

部署验收应分别检查：模型已加载、接口可以请求、业务输入输出正确、并发与超时符合目标。成功看到一段文字只证明最小链路跑通。
