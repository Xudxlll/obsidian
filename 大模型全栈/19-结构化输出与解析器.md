> [!abstract] 学习目标
> 把模型文字变成程序能够校验的数据。

## 核心理解

结构化输出需要分三步理解：先约定字段与格式，再让模型生成，最后解析并验证。逗号分隔列表适合简单枚举，JSON 适合包含多个字段、嵌套对象或明确类型的任务。

解析器负责把文本转成 Python 对象，但“能解析”不等于“符合业务”。例如订单号可能是合法字符串，却长度不对；金额可能能转成数字，却不满足业务规则。必要时还需要字段级校验和错误处理。

`StrOutputParser` 主要提取文本，列表解析器返回列表，JSON 解析器返回字典或列表等 JSON 对象。若下游要接数据库或工具调用，应先明确输入契约。

正文保留两个课堂片段，因为原文的第二个标题与代码不符；这样既能回溯课堂记录，也能明确正确的概念对应关系。

## 课堂代码怎么读

两个原始片段实际都导入并使用 `CommaSeparatedListOutputParser`。真正的 JSON 解析示例出现在电影评论和订单抽取案例，可沿双链继续阅读。

> [!warning] 易错点与资料边界
> “代码块2：JSON解析器”下重复了列表解析代码，这不是 JSON 的标准写法。仅要求“不要输出额外文字”也不能保证永远解析成功。

## 复盘练习

一个 JSON 中 category 是“非常好”而允许值只有正、负、中，算成功吗？

> [!question]- 参考思路
> 语法解析可能成功，业务校验失败。应检查字段是否存在、类型是否正确、取值是否属于允许集合。
