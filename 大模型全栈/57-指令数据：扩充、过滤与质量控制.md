> [!abstract] 学习目标
> 先保证训练目标与数据质量，再扩大样本数量。

## 核心理解

指令微调数据常包含 instruction、可选 input 与 output。扩充指令可以覆盖更多表达，但训练需要可信回答，仅生成更多问题并不能直接得到完整 SFT 数据集。

课堂“自我进化”用少量种子示例让模型产生新指令，再以规则过滤和 ROUGE-L 相似度控制重复。这里描述的是数据迭代流程，并不是模型在无人验证下自动变得更聪明。

ROUGE-L 关注最长公共子序列，适合发现部分文本重叠，但语义重复可能词面不同，反例也可能词面非常接近。规则与相似度应作为筛选信号，再配合抽样检查与任务覆盖。

数据应记录来源、生成配置、过滤原因与版本；训练、验证和测试分组在扩充前就应规划，避免种子或改写样本跨集合泄漏。

## 课堂代码怎么读

先读 generate_new 的提示词与返回列表，再读 is_toxic、calc_rouge_l 和 filter_instructions。注意代码主要展示指令生成和过滤，完整回答生成与标注流程需要另补。

> [!warning] 易错点与资料边界
> 正则过滤覆盖有限，不是全面的质量或安全判定。原“数据清洗流水线.zip”没有内容，只有名称，已登记为缺少配套源码。

## 复盘练习

为什么先扩充再随机切测试集容易高估效果？

> [!question]- 参考思路
> 同一条种子指令的改写可能分散到训练和测试，模型见过近似任务，测试无法衡量真正未见问题上的泛化。

> [!quote]- 大模型全栈（下）.md · 自我进化
> 来源：原笔记第 1018–1126 行。
>
> **自我进化**
>
> ```python
> """
> 自我进化
> """
> import os
> from langchain_openai import ChatOpenAI
> from dotenv import load_dotenv
> import random
> import re
> from rouge import Rouge
>
> load_dotenv()
>
> llm = ChatOpenAI(
>     api_key=os.getenv("DEEPSEEK_API_KEY"),
>     base_url=os.getenv("DEEPSEEK_BASE_URL"),
>     model="deepseek-chat",
>     temperature=0,
> )
>
> # 种子数据集
> seed_instructions = [
>     "解释机器学习中过拟合的概念及常见解决方法",
>     "简述Python列表推导式的用法并举例",
>     "分析每日运动30分钟对心血管健康的益处",
>     "说明劳动合同试用期的法定最长时限",
>     "介绍制作戚风蛋糕的核心步骤和注意事项",
>     "解释什么是碳达峰和碳中和",
>     "对比有线耳机和蓝牙耳机的优缺点",
>     "描述太阳系八大行星的排列顺序",
>     "分享三个提升工作效率的实用方法",
>     "说明火灾逃生的基本原则和注意事项",
>     "解释银行定期存款和大额存单的区别",
>     "介绍三个适合新手的入门级健身动作",
>     "分析熬夜对身体的主要负面影响",
>     "简述中国古代四大发明分别是什么",
>     "说明正确的洗手步骤和时长要求"
> ]
>
> # 生成
> def generate_new(examples):
>     prompt = "参考以下示例指令的风格与领域，生成全新的中文通用知识类指令，要求清晰有明确回答指向，不重复示例内容，每行一条，不要编号和多余解释。\n\n示例：\n"
>     for ex in examples:
>         prompt += f"- {ex}\n"
>     prompt += "\n请生成8条新指令："
>
>     response = llm.invoke(prompt)
>
>     lines = [line for line in response.content.split("\n")]
>
>     return lines
>
> # 过滤
> def is_toxic(text):
>     TOXIC_PATTERNS = [
>         # 暴力伤害类：匹配"怎么打/杀/伤害某人"的意图
>         re.compile(r"(怎么|如何|怎样).{0,10}(打|杀|砍|伤害|弄死|报复).{0,10}(人|他|她|你|我|别人)"),
>         # 违法犯罪类：匹配"如何制作/购买毒品/枪支/爆炸物"
>         re.compile(r"(怎么|如何|怎样).{0,10}(制作|制造|购买|买到|合成).{0,10}(毒品|冰毒|海洛因|枪支|炸弹|爆炸物|假币)"),
>         # 色情低俗类：匹配明确的色情交易意图
>         re.compile(r"(哪里|怎么|如何).{0,10}(找|买|叫|约).{0,10}(小姐|妓女|外围|上门服务)"),
>         # 赌博类：匹配非法赌博渠道
>         re.compile(r"(赌博|博彩|赌钱).{0,10}(网站|平台|app|下载|注册)"),
>         # 个人信息非法获取
>         re.compile(r"(怎么|如何).{0,10}(查|获取|盗取|偷).{0,10}(别人|他人).{0,10}(身份证|手机号|银行卡|聊天记录|位置)"),
>     ]
>
>     for pattern in TOXIC_PATTERNS:
>         if pattern.search(text):
>             return True
>     return False
>
> # 评分
> def calc_rouge_l(text1, text2):
>     t1 = " ".join(list(text1))
>     t2 = " ".join(list(text2))
>     # print(Rouge().get_scores(t1, t2))
>     return Rouge().get_scores(t1, t2)[0]["rouge-l"]["f"]
>
> def filter_instructions(instruction, alldata):
>     if len(instruction) < 6 or len(instruction) > 100:
>         return False
>     if is_toxic(instruction):
>         return False
>     for i in alldata:
>         if calc_rouge_l(instruction, i) > 0.6:
>             return False
>     return True
>
> all_data = seed_instructions.copy()
> round_idx = 0
> while len(all_data) < 100:
>     round_idx += 1
>     print(f"第{round_idx}轮, 当前总总量:{len(all_data)}")
>
>     samples = random.sample(all_data, 4)
>     new_list = generate_new(samples)
>
>     passed = [x for x in new_list if filter_instructions(x, all_data)]
>
>     all_data.extend(passed)
>     print(f"生成:{len(new_list)}条,通过过滤:{len(passed)}条")
>
> with open("./output/self_inst_data.txt", "w", encoding="utf-8") as f:
>     f.write("\n".join(all_data))
> ```
>
