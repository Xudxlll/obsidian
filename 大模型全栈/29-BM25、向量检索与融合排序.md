> [!abstract] 学习目标
> 组合词项匹配与语义匹配，避免直接混加不同尺度的分数。

## 核心理解

BM25 擅长精确词项、编号和专有名词；向量检索擅长词面不同但语义相近的表达。混合检索先分别得到候选，再融合排序。

RRF 使用名次而不是原始分数：

$$
\operatorname{RRF}(d)=\sum_{r\in R}\frac{1}{c+\operatorname{rank}_r(d)}
$$

$c$ 是平滑常数，rank 通常从 1 开始。两个列表都靠前的文档会获得更高分；只在其中一个列表出现，也可贡献分数。

加权线性融合则先将不同来源分数缩放，再按权重组合。缩放方法、异常值和分数方向都会影响结果，因此没有通用最佳权重。

中文 BM25 需要合适的分词。建库与查询的分词方式、停用词和大小写规则应保持一致。

## 课堂代码怎么读

课堂先得到 BM25 与余弦排序，再用 `1/(60+rank+1)` 累加 RRF；后半段用 min-max 归一化演示线性融合。对照同一文档在两份排名中的位置，手算一次验证索引。

> [!warning] 易错点与资料边界
> 文档必须按稳定身份对齐。RRF 是排序信号，不是相关概率；不能把 0.03 的 RRF 分数解释为 3% 相关性。

## 复盘练习

为什么原始 BM25 分数不能直接加余弦相似度？

> [!question]- 参考思路
> 两者量纲和分布不同，数值大的那一路可能支配结果。可以基于排名融合，或经验证后选择适当校准与权重。

> **混合检索**
>
> ```python
> """
> 混合检索-RRF 和 WLC
> """
> from rank_bm25 import BM25Okapi
> import jieba
> from sentence_transformers import SentenceTransformer
> from sklearn.metrics.pairwise import cosine_similarity
> import numpy as np
>
> # 文档
> documents = [
>     "RAG通过检索外部知识库增强大语言模型的回答能力",
>     "向量数据库用于高效存储和检索高维向量，支持近似最近邻搜索",
>     "BM25是一种基于概率排序原理的信息检索算法",
>     "RAG系统可以结合BM25和向量检索实现混合检索",
>     "Python是一种高级编程语言，广泛用于数据科学和机器学习",
> ]
> query = "RAG如何结合BM25进行混合检索"
>
> # BM25检索
> tokenized_docs = [list(jieba.cut(doc)) for doc in documents]
> bm25 = BM25Okapi(tokenized_docs, k1=1.5, b=0.75)
> tokenized_query = list(jieba.cut(query))
> bm_scores = bm25.get_scores(tokenized_query)
> bm25_rank = np.argsort(bm_scores)[::-1]  # 降序
>
> # 向量检索
> model = SentenceTransformer("./bge-base-zh-v1.5")
> query_vec = model.encode([query])
> doc_vec = model.encode(documents)
> vec_sims = cosine_similarity(query_vec, doc_vec)[0]
> vec_rank = np.argsort(vec_sims)[::-1]
>
> # RRF融合
> rrf_scores = np.zeros(len(documents))
> for rank, doc_idx in enumerate(bm25_rank):
>     rrf_scores[doc_idx] += 1 / (60 + rank + 1)
>
> for rank, doc_idx in enumerate(vec_rank):
>     rrf_scores[doc_idx] += 1 / (60 + rank + 1)
>
> fused_rank = np.argsort(rrf_scores)[::-1]
> print(fused_rank)
>
> # 打印
> print(f"查询: {query}\n")
> print(f"{'排名':<6} {'BM25':<20} {'向量':<20} {'RRF':<20}")
> print("-" * 70)
> for i in range(len(documents)):
>     print(f"{i + 1:<6} "
>           f"{documents[bm25_rank[i]][:10]:<20}"
>           f"{documents[vec_rank[i]][:10]:<20}"
>           f"{documents[fused_rank[i]][:10]:<20}")
>
> print(f"RRF得分:")
> for i, idx in enumerate(fused_rank):
>     print(f"  {documents[idx][:10]}:{rrf_scores[idx]}")
>
> # WLC融合
> # 归一化
> def ln(scores):
>     return (scores - scores.min()) / (scores.max() - scores.min() + 1e-10)
>
> bm25_norm = ln(bm_scores)
> vec_norm = ln(vec_sims)
>
> wlc_scores = bm25_norm * .5 + vec_norm * .5
> wlc_rank = np.argsort(wlc_scores)[::-1]
>
> for i ,idx in enumerate(wlc_rank):
>     print(f"\n {i+1}. {documents[idx][:10]} 得分:{wlc_scores[idx]}")
> ```
