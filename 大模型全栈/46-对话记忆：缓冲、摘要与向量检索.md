> [!abstract] 学习目标
> 按记忆用途选择保存和注入方式。

## 核心理解

缓冲记忆保留原始历史，信息最完整但占用上下文。摘要记忆压缩旧内容，节省空间却可能丢失精确措辞。向量记忆把过去记录存入检索库，每轮只召回相关内容。

三者解决的问题不同：短期对话衔接适合缓冲，长期背景适合摘要，跨多次对话寻找具体事件可以考虑检索。也可以组合使用，但要明确优先级与来源。

记忆的写入和读取都需要设计。保存内容若包含误解，后续可能反复放大；检索相似也不代表当前仍有效，偏好变化与事实更新需要时效处理。

“保存到磁盘”是持久化，“放进本次请求”才让模型能使用。应用应区分用户、会话、时间和记录类型，避免把不同人的历史混在同一检索空间。

## 课堂代码怎么读

对照 buffer_demo、summary_demo、vec_demo，分别标出历史存在哪里、何时更新、以何种形式进入 prompt。向量例子还要检查保存整轮对话会不会让后续检索返回冗长重复内容。

> [!warning] 易错点与资料边界
> 摘要不是无损压缩；向量库不会自动识别过期偏好。课堂默认同一本地目录，仅适合说明机制，不构成完整的多用户记忆系统。

## 复盘练习

为什么摘要和原始记录最好保留关联？

> [!question]- 参考思路
> 摘要可能遗漏或误写细节。有原始来源才能在争议、更新或精确查询时重新核验，而不让错误摘要成为唯一事实。

> from dotenv import load_dotenv
> from langchain_openai import ChatOpenAI
> from langchain_core.messages import HumanMessage, AIMessage
> from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
> from langchain_core.output_parsers import StrOutputParser
> from langchain_chroma import Chroma
> from langchain_core.documents import Document
> from langchain_huggingface import HuggingFaceEmbeddings
>
> load_dotenv()
>
> llm = ChatOpenAI(
>     model="deepseek-chat",
>     api_key=os.getenv("DEEPSEEK_API_KEY"),
>     base_url=os.getenv("DEEPSEEK_BASE_URL"),
>     temperature=0,
>     streaming=True,
>     max_retries=2,
> )
>
> # Buffer 滑动窗口裁剪
> def buffer_demo():
>     print("Buffer 滑动窗口")
>     MAX_HISTORY_ROUNDS = 2
>     chat_history = []
>     prompt = ChatPromptTemplate.from_messages([
>         ("system", "你是一个友好的助手,结合对话历史回答用户问题"),
>         MessagesPlaceholder(variable_name="history"),
>         ("human", "{input}")
>     ])
>
>     chain = prompt | llm | StrOutputParser()
>
>     while True:
>         user_input = input("> ")
>         if user_input == "exit":
>             break
>         response = chain.invoke({"input": user_input, "history": chat_history})
>         print(f"🤖 {response}")
>
>         chat_history.append(HumanMessage(content=user_input))
>         chat_history.append(AIMessage(content=response))
>
>         if len(chat_history) > MAX_HISTORY_ROUNDS:
>             chat_history = chat_history[-MAX_HISTORY_ROUNDS:]
>
> # 摘要
> def summary_demo():
>     print("摘要压缩")
>     chat_history = []
>     summary = ""
>
>     prompt = ChatPromptTemplate.from_messages([
>         ("system", "你是一个友好的助手,结合对话摘要和最新的对话来回答用户问题"),
>         ("system", "早期对话的摘要:{summary}"),
>         ("human", "{input}")
>     ])
>
>     chain = prompt | llm | StrOutputParser()
>
>     while True:
>         user_input = input("> ")
>         if user_input == "exit":
>             break
>         response = chain.invoke({"input": user_input, "summary": summary})
>         print(f"🤖 {response}")
>
>         chat_history.append(HumanMessage(content=user_input))
>         chat_history.append(AIMessage(content=response))
>
>         if len(chat_history) > 2:

>     while True:
>         user_input = input("> ")
>         if user_input == "exit":
>             break
>
>         docs = retriever.invoke(user_input)
>         memory_context = "\n".join([d.page_content for d in docs])
>
>         response = chain.invoke({"input": user_input, "memory_context": memory_context})
>
>         print(f"🤖 {response}")
>         for d in docs:
>             print(f"召回内容: {d.page_content}")
>
>         # 新增向量
>         turn_doc = Document(page_content=f"用户:{user_input} 助手:{response}")
>         vector_store.add_documents([turn_doc])
>         print("💾 本论对话以存入向量库")
