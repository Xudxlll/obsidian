> [!abstract] 学习目标
> 区分原始文本续训、监督微调与更新参数范围。

## 核心理解

领域续训继续使用下一 token 预测目标，让模型适应法律等领域文本；SFT 则使用指令与回答，强调按要求完成任务。全参数与 LoRA 描述的是更新哪些参数，不是数据目标，两组概念可以交叉组合。

课堂“全量微调+续写”读取法律语料文本，tokenizer 编码后由因果语言模型计算损失，Trainer 更新未冻结参数。因此更接近全参数的领域语言模型续训。

单设备有效 batch 可近似写为“每步样本数 × 梯度累积步数”；多设备时还要考虑设备数。梯度累积减少每步显存负担，但不会消除模型权重、梯度、优化器状态和激活的占用。

训练前先检查可训练参数量、文本长度分布、截断比例和独立验证集。loss 下降只是训练目标改善，不自动表示领域问答准确率提高。

## 课堂代码怎么读

按读取文本、tokenize、加载模型、参数计数、TrainingArguments、DataCollator 和 train 阅读。`mlm=False` 对应因果语言模型训练，而不是 BERT 掩码目标。

> [!warning] 易错点与资料边界
> 原代码把 `use_cache` 误写成 `user_cache`，不会正确关闭期望的缓存选项。BF16、CUDA 与 device_map 的课堂设置并不适用于所有机器；本轮没有启动训练。

## 复盘练习

全参数训练和 SFT 是同义词吗？

> [!question]- 参考思路
> 不是。全参数说明更新范围，SFT 说明监督任务与数据形式；SFT 可以全参数训练，也可以只训练 LoRA 适配器。

> **全量微调+续写**

> ```python
> """
> 全量微调 + 续写
> """
> import os
> import torch 
> from datasets import load_dataset
> from transformers import AutoTokenizer, AutoModelForCausalLM, TrainingArguments, Trainer, \
>     DataCollatorForLanguageModeling
>
> MODEL = "./Qwen3-0.6B"
> OUTPUT_DIR = "./output/full_continued_Qwen3"
>
> # 分词器
> tokenizer = AutoTokenizer.from_pretrained(MODEL)
> if tokenizer.pad_token is None:
>     tokenizer.pad_token = tokenizer.eos_token
>
> # 读文本
> ds = load_dataset(
>     "text", split="train",
>     data_files="./data/legal_corpus_full.txt"
> )
>
> ds = ds.map(lambda e: tokenizer(e["text"], truncation=True, max_length=128), batched=True)
>
> # 加载因果大模型
> model = AutoModelForCausalLM.from_pretrained(MODEL, torch_dtype=torch.bfloat16, device_map="auto")
> model.config.user_cache = False
>
> # 参数总量
> trainable = sum(p.numel() for p in model.parameters() if p.requires_grad)
> print(f"训练的参数: {trainable}")
>
> # 微调
> args = TrainingArguments(
>     output_dir=OUTPUT_DIR,
>     per_device_train_batch_size=2,
>     gradient_accumulation_steps=4,
>     num_train_epochs=3,
>     learning_rate=2e-5,
>     bf16=True,
>     gradient_checkpointing=True,
>     logging_steps=5,
>     report_to="none",
>     save_strategy="no",
> )
> trainer = Trainer(
>     model=model,
>     args=args,
>     train_dataset=ds,
>     data_collator=DataCollatorForLanguageModeling(tokenizer=tokenizer, mlm=False),
> )
>
> trainer.train()
> model.save_pretrained(OUTPUT_DIR)
> ```
