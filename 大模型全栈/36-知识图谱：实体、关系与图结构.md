## 核心理解

知识图谱把事实组织成实体与关系，例如“人物—就职于—公司”。属性图还允许节点和边携带属性；Schema 约束可以有哪些实体类型、关系类型和字段。

课堂 NetworkX 示例先建立节点与关系，再计算或显示图结构。理解时要区分节点身份、显示名称、实体类型与边标签，不能只看一张连线图。

路径帮助表达多跳问题，例如先找导师，再找导师的学生。邻接矩阵的幂可以统计特定长度的游走，但“存在路径”不自动等于“业务关系成立”，还需检查方向与边的语义。

图谱适合明确关系、条件过滤和溯源，向量适合语义近似；它们可以互补。TransE 等知识表示学习把关系模式映射到向量空间，又与普通句向量的训练目标不同。

## 课堂代码怎么读

先核对 entities 与 triples 的结构，再看 `add_nodes_from`、`add_edge` 和子图操作。检查使用的 Graph/DiGraph 类型是否能表达同一实体对之间的多种关系。

> [!warning] 易错点与资料边界
> 示意图中的布局位置没有天然业务含义。若使用只保留一条边的简单图，多条同向关系可能被覆盖；实体名称相同也不一定是同一个实体。
>
> 原“图的基础实现”中 print(A) 具有意外缩进，直接作为独立脚本会报错；应在确认其所属代码层级后处理。

## 复盘练习

为什么“张三就职于甲公司”不应无条件当作对称关系？

> [!question]- 参考思路
> 方向携带语义。反向读取应表达“甲公司雇用张三”，不能仍把谓词解释成就职于。

> ```python
> """
> 知识图简单操作
> """
> import networkx as nx
> import matplotlib.pyplot as plt
> import numpy as np
>
> KG = nx.MultiDiGraph()
>
> # 实体(节点)
> entities = ["张三", "阿里巴巴", "杭州", "马云", "淘宝", "中国"]
> KG.add_nodes_from(entities)
>
> # 添加三元组  下课休息16:45
> triples = [
>     ("张三", "阿里巴巴", "工作于"),
>     ("阿里巴巴", "杭州", "总部位于"),
>     ("李四", "张三", "同事"),
>     ("阿里巴巴", "马云", "创始人"),
>     ("马云", "杭州", "出生于"),
>     ("淘宝", "阿里巴巴", "属于"),
>     ("天猫", "阿里巴巴", "属于"),
>     ("杭州分公司", "阿里巴巴", "属于"),
>     ("杭州分公司", "杭州", "属于"),
>     ("阿里巴巴", "中国", "属于"),
>     ("杭州", "中国", "属于"),
>     ("马云", "阿里巴巴", "曾任CEO"),
> ]
> for h, t, r in triples:
>     KG.add_edge(h, t, relation=r)
>
> # 度分析
> print("[度分析]")
> for node in KG.nodes():
>     print(f"{node}:出度={KG.out_degree(node)},入度={KG.in_degree(node)},总度={KG.degree(node)}")
>
> # 路径查询
> print(f"\n路径查询")
> for path in nx.all_simple_paths(KG, source="张三", target="中国", cutoff=10):
>     print(path)
>
>     edges = []
>     for i in range(len(path) - 1):
>         # {0:{关系:工作于},1:{关系:位于}}
>         edges_data = KG.get_edge_data(path[i], path[i + 1])
>         print(edges_data)
>         rel = list(edges_data.values())[0]['relation']
>         edges.append(rel)
>
>     # 拼接格式化字典 张三(工作于) -> 阿里巴巴(总部位于) -> 杭州(属于) -> 中国
>     path_str = " -> ".join([f"{path[i]}({edges[i]})" for i in range(len(edges))] + [path[-1]])
>     print(path_str)
>
> # 邻接矩阵
> print("\n邻接矩阵")
> subgraph_edges = [(h, t) for h, t, d in KG.edges(data=True) if d['relation'] == '属于']
> subGraph = nx.DiGraph(subgraph_edges)
> # 补全节点
> subGraph.add_nodes_from(entities)
> A = nx.adjacency_matrix(subGraph, nodelist=entities).toarray()
> 	print(A)
>
> # 两条路径计数
> A_np = np.array(A)
> A2 = A_np @ A_np
> print(A2)
>
> # 可视化
> plt.rcParams['font.sans-serif'] = ['SimHei']
> plt.rcParams['axes.unicode_minus'] = False
>
> plt.figure(figsize=(10, 6))
>
> pos = nx.spring_layout(KG, seed=42)
> nx.draw_networkx_nodes(KG, pos, node_size=2000, node_color='lightblue')
> nx.draw_networkx_labels(KG, pos, font_size=10, font_family='sans-serif')
> edge_labels = {(h, t): d['relation'] for h, t, d in KG.edges(data=True)}
> nx.draw_networkx_edges(KG, pos, edge_color='gray', arrows=True, arrowsize=50)
> nx.draw_networkx_edge_labels(KG, pos, edge_labels=edge_labels, font_size=8)
>
> plt.title("知识图谱示例")
> plt.axis('off')
> plt.tight_layout()
> plt.savefig("kg.png", dpi=150, bbox_inches='tight')
> ```
