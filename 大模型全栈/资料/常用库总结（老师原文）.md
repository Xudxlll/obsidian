# Transformer / HuggingFace 生态常用库总结

## (1) transformers 库

**名称：** transformers（HuggingFace 核心主库）

**安装：** `pip install transformers`

**核心定位：** 加载各种预训练模型和分词器，NLP任务一站式解决方案

**解决什么业务问题：** 文本分类、命名实体识别、掩码填空、文本生成、文本摘要、机器翻译、特征提取（句向量）

**重点掌握的API：**

| 函数/类                                                | 作用                                                      |
| ------------------------------------------------------ | --------------------------------------------------------- |
| `AutoTokenizer.from_pretrained()`                      | 加载分词器，把文本转成模型能使用的数字id                  |
| `AutoModel.from_pretrained()`                          | 加载基础模型（无任务头），输出隐藏层特征，用来拿句向量    |
| `AutoModelForMaskedLM.from_pretrained()`               | 加载带MLM头的模型，做[MASK]填空预测                       |
| `AutoModelForSequenceClassification.from_pretrained()` | 加载带分类头的模型，做文本分类/情感分析                   |
| `AutoModelForTokenClassification.from_pretrained()`    | 加载带token分类头的模型，做NER命名实体识别                |
| `AutoModelForCausalLM.from_pretrained()`               | 加载自回归生成模型（GPT/Qwen/LLaMA），做文本生成          |
| `AutoModelForSeq2SeqLM.from_pretrained()`              | 加载编码器-解码器模型（T5/BART），做翻译/摘要             |
| `pipeline()`                                           | 高级API，把加载模型+分词+推理打包成一行，直接用           |
| `tokenizer()`                                          | 对文本编码，返回input_ids、attention_mask、token_type_ids |
| `model.generate()`                                     | 生成式模型的文本生成接口，控制max_length、temperature等   |
| `Trainer`                                              | 封装好的训练器，自动完成前向/反向/优化/日志/保存          |
| `TrainingArguments`                                    | 训练超参配置对象，学习率、batch_size、epoch、保存策略等   |
| `model.save_pretrained()`                              | 保存模型权重到本地目录                                    |
| `tokenizer.save_pretrained()`                          | 保存分词器到本地目录                                      |

## (2) sentence-transformers 库

**名称：** sentence-transformers（句向量专用库）

**安装：** `pip install sentence-transformers`

**核心定位：** 基于transformers二次封装，专门生成句子/段落的稠密向量

**解决什么业务问题：** 语义相似度计算、文本检索召回、语义匹配、聚类、去重

**重点掌握的API：**

| 函数/类                      | 作用                                             |
| ---------------------------- | ------------------------------------------------ |
| `SentenceTransformer()`      | 加载句向量模型，传入模型名或本地路径             |
| `.encode()`                  | 把文本转成向量，输出numpy数组，自动处理分词+池化 |
| `util.cos_sim()`             | 计算两个向量的余弦相似度，返回tensor             |
| `util.dot_score()`           | 计算点积相似度                                   |
| `util.semantic_search()`     | 批量语义检索，在候选库中找最相似的top-k          |
| `SentenceTransformer.save()` | 保存模型到本地                                   |

## (3) datasets 库

**名称：** datasets（数据集处理库）

**安装：** `pip install datasets`

**核心定位：** 高效加载、处理、缓存NLP数据集

**解决什么业务问题：** 加载公开数据集、读取本地csv/json、批量文本预处理、训练/验证集划分、数据过滤

**重点掌握的API：**

| 函数/类               | 作用                                                     |
| --------------------- | -------------------------------------------------------- |
| `load_dataset()`      | 加载公开数据集或本地文件（csv/json/parquet）             |
| `Dataset.from_dict()` | 从Python字典构造数据集                                   |
| `.map()`              | 对数据集批量执行处理函数（如分词编码），batched=True提速 |
| `.filter()`           | 按条件过滤数据                                           |
| `.train_test_split()` | 划分训练集和测试集                                       |
| `.shuffle()`          | 打乱数据顺序                                             |
| `.select()`           | 按索引选择部分数据                                       |
| `.remove_columns()`   | 删除不需要的列                                           |
| `.rename_column()`    | 重命名列                                                 |
| `.save_to_disk()`     | 保存处理好的数据集到磁盘，下次直接加载不用重新处理       |
| `load_from_disk()`    | 从磁盘加载已保存的数据集                                 |

## (4) evaluate 库

**名称：** evaluate（评测指标库）

**安装：** `pip install evaluate`

**核心定位：** 统一的NLP任务评测指标计算库

**解决什么业务问题：** 计算准确率、F1、BLEU、ROUGE、MRR等各类评测指标

**重点掌握的API：**

| 函数/类                   | 作用                                                         |
| ------------------------- | ------------------------------------------------------------ |
| `load()`                  | 加载指定指标，如`evaluate.load("accuracy")`、`evaluate.load("f1")` |
| `.compute()`              | 传入预测值和真实标签，计算指标结果                           |
| `.add()` / `.add_batch()` | 批量添加预测结果，最后统一compute                            |

## (5) accelerate 库

**名称：** accelerate（分布式训练/推理加速库）

**安装：** `pip install accelerate`

**核心定位：** 抽象硬件差异，自动处理多GPU、混合精度、梯度累积

**解决什么业务问题：** 多卡分布式训练、大模型推理显存分配、混合精度训练加速

**重点掌握的API：**

| 函数/类             | 作用                                     |
| ------------------- | ---------------------------------------- |
| `Accelerator()`     | 创建加速器对象，自动检测硬件环境         |
| `.prepare()`        | 把模型、优化器、数据加载器交给加速器管理 |
| `.backward()`       | 替代loss.backward()，自动处理梯度缩放    |
| `.device`           | 获取当前设备（cpu/cuda）                 |
| `accelerate launch` | 命令行启动分布式训练脚本                 |

## (6) peft 库

**名称：** peft（Parameter-Efficient Fine-Tuning，参数高效微调库）

**安装：** `pip install peft`

**核心定位：** 冻结大模型主干，只训练少量参数（LoRA等），大幅降低显存需求

**解决什么业务问题：** 大模型低资源微调、LoRA适配器训练、多任务适配器管理

**重点掌握的API：**

| 函数/类                       | 作用                                         |
| ----------------------------- | -------------------------------------------- |
| `LoraConfig()`                | 配置LoRA参数：rank、alpha、目标模块、dropout |
| `get_peft_model()`            | 把基础模型包装成PEFT模型，只训练LoRA参数     |
| `PeftModel.from_pretrained()` | 加载已训练好的LoRA适配器                     |
| `.merge_and_unload()`         | 把LoRA权重合并回主干模型，方便部署           |
| `.save_pretrained()`          | 只保存LoRA适配器权重（文件很小，几MB）       |

---

## (7) trl 库

**名称：** trl（Transformer Reinforcement Learning，大模型对齐训练库）

**安装：** `pip install trl`

**核心定位：** 基于transformers+peft，专门做大模型对齐训练

**解决什么业务问题：** SFT监督微调、DPO偏好对齐、RLHF强化学习人类反馈

**重点掌握的API：**

| 函数/类         | 作用                                  |
| --------------- | ------------------------------------- |
| `SFTTrainer`    | 监督微调训练器，封装了大模型SFT全流程 |
| `DPOTrainer`    | 直接偏好优化训练器，用偏好对训练对齐  |
| `RewardTrainer` | 奖励模型训练                          |
| `PPOTrainer`    | 基于PPO算法的强化学习训练             |

## (8) bitsandbytes 库

**名称：** bitsandbytes（模型量化库）

**安装：** Linux: `pip install bitsandbytes`；Windows: `pip install bitsandbytes-win`

**核心定位：** 模型权重4bit/8bit量化，大幅降低显存占用

**解决什么业务问题：** 大模型本地部署显存不够、7B/14B模型在消费级显卡上跑起来

**重点掌握的API：**

| 函数/类                  | 作用                                               |
| ------------------------ | -------------------------------------------------- |
| `BitsAndBytesConfig()`   | 配置量化参数：load_in_4bit、load_in_8bit、量化类型 |
| `load_in_4bit=True`      | from_pretrained时传入，直接以4bit加载模型          |
| `load_in_8bit=True`      | 以8bit加载模型                                     |
| `bnb_4bit_compute_dtype` | 设置计算时的数据类型（如bfloat16）                 |

## (11) faiss 库

**名称：** faiss（向量检索库，Facebook开源）

**安装：** CPU版: `pip install faiss-cpu`；GPU版: `pip install faiss-gpu`

**核心定位：** 高效稠密向量相似度检索，支持亿级向量

**解决什么业务问题：** 向量库构建、海量文本快速检索、RAG召回、推荐系统召回

**重点掌握的API：**

| 函数/类                           | 作用                                     |
| --------------------------------- | ---------------------------------------- |
| `IndexFlatL2`                     | 暴力检索索引，精确但慢，小数据量用       |
| `IndexFlatIP`                     | 内积暴力检索（余弦相似度归一化后用这个） |
| `IndexIVFFlat`                    | 倒排文件索引，先聚类再检索，大数据量提速 |
| `IndexHNSWFlat`                   | HNSW图索引，检索速度快，内存占用大       |
| `.add()`                          | 把向量加入索引                           |
| `.search()`                       | 查询最相似的top-k向量，返回距离和索引    |
| `.save()` / `faiss.write_index()` | 保存索引到磁盘                           |
| `faiss.read_index()`              | 从磁盘加载索引                           |
| `faiss.normalize_L2()`            | 向量L2归一化，归一化后内积=余弦相似度    |

## (14) LlamaIndex 框架

**名称：** LlamaIndex（RAG/数据索引框架，原名GPT Index）

**安装：** `pip install llama-index llama-index-llms-openai llama-index-embeddings-openai`

**核心定位：** 专注于数据索引和检索增强生成（RAG），把各种数据源接入大模型

**解决什么业务问题：** 知识库问答、文档问答、企业私有数据RAG、多数据源检索

**重点掌握的API：**

| 函数/类                             | 作用                                           |
| ----------------------------------- | ---------------------------------------------- |
| `SimpleDirectoryReader()`           | 读取本地文件夹中的文档（pdf/txt/md等）         |
| `Document`                          | 文档对象                                       |
| `SentenceSplitter`                  | 句子级文档切分                                 |
| `VectorStoreIndex.from_documents()` | 从文档构建向量索引，自动做embedding+存储       |
| `.as_query_engine()`                | 把索引转成问答引擎，直接提问                   |
| `.as_retriever()`                   | 把索引转成检索器，只返回相关文档不生成答案     |
| `QueryEngine`                       | 问答引擎，查询→检索→生成                       |
| `RetrieverQueryEngine`              | 自定义检索+生成的问答引擎                      |
| `ResponseSynthesizer`               | 响应合成器，控制大模型如何根据检索结果生成答案 |
| `StorageContext`                    | 存储上下文，管理向量存储、文档存储、索引存储   |
| `.persist()`                        | 把索引持久化到磁盘，下次加载不用重新构建       |
| `load_index_from_storage()`         | 从磁盘加载已保存的索引                         |
| `Settings.llm`                      | 全局配置大模型                                 |
| `Settings.embed_model`              | 全局配置embedding模型                          |

## (15) vLLM 框架

**名称：** vLLM（大模型推理加速框架，UC Berkeley开源）

**安装：** `pip install vllm`（Linux推荐，Windows需WSL2）

**核心定位：** 大模型高吞吐量推理引擎，PagedAttention技术大幅提升推理速度和显存利用率

**解决什么业务问题：** 大模型在线推理服务、高并发API部署、批量推理加速

**重点掌握的API：**

| 函数/类/命令                 | 作用                                              |
| ---------------------------- | ------------------------------------------------- |
| `LLM()`                      | 创建vLLM模型实例，加载模型到GPU                   |
| `LLM.generate()`             | 批量生成文本，输入提示词列表，返回生成结果        |
| `SamplingParams()`           | 采样参数配置：temperature、top_p、max_tokens、n等 |
| `AsyncLLMEngine`             | 异步推理引擎，适合高并发在线服务                  |
| `vllm serve` 命令            | 一行命令启动OpenAI兼容的API服务                   |
| `--tensor-parallel-size`     | 张量并行，多卡推理                                |
| `--gpu-memory-utilization`   | GPU显存利用率，默认0.9                            |
| `--max-model-len`            | 最大上下文长度                                    |
| `--quantization`             | 量化方式：awq/gptq/squeezellm等                   |
| `--dtype`                    | 数据类型：float16/bfloat16/auto                   |
| `outputs[0].outputs[0].text` | 取生成的文本结果                                  |

## (16) Ollama 框架
