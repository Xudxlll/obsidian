题目 1：DataFrame 列操作与行访问综合

给定以下 DataFrame：

```python  
import pandas as pd  
df = pd.DataFrame({  
    'math':    [90, 78, 85, 92, 66],  
    'english': [80, 88, 72, 90, 75],  
    'physics': [70, 82, 88, 65, 91]  
}, index=['S101', 'S102', 'S103', 'S104', 'S105'])  
```

请完成以下操作，写出代码和结果：

1. 添加一列`chemistry`，值为 `[85, 76, 93, 70, 88]`  
```python
df['chemistry'] = pd.Series([85, 76, 93, 70, 88], index=['S101', 'S102', 'S103', 'S104', 'S105'])
```

2. 添加一列`avg`，值为每个学生三门主课（math、english、physics）的平均分  
```python
df1 = df[['math', 'english', 'physics']]  
df2 = df1.mean(axis=1)  
df['avg'] = round(df2, 2)
```

3. 使用`pop` 删除 `physics` 列  
```python
df.pop('physics')
```

4. 使用`loc` 访问 S103 和 S104 的 `math` 和 `english` 成绩  
```python
df3 = df.loc['S103':'S104', 'math':'english']
```

5. 使用`iloc` 访问第 0 行和第 2 行的所有列数据
```python
df4 = df.iloc[[0,2]]
```


题目 2：merge 连接方式对比

给定两个 DataFrame：

```python  
left = pd.DataFrame({  
    'emp_id': ['E1', 'E2', 'E3', 'E4'],  
    'name':   ['Alice', 'Bob', 'Carol', 'David'],  
    'dept_id': ['D1', 'D2', 'D1', 'D3']  
})

right = pd.DataFrame({  
    'dept_id':   ['D1', 'D2', 'D4'],  
    'dept_name': ['研发部', '市场部', '财务部']  
})  
```

请分别写出以下四种 merge 操作的结果（列出所有行），并简要说明每种连接方式的取键策略：

1. `pd.merge(left, right, how='inner')`  
```
   emp_id   name   dept_id   dept_name
0     E1   Alice      D1       研发部
1     E2    Bob       D2       市场部
2     E3   Carol      D1       研发部

策略：找到两个表中共同的列名“dept_id”，左表第0行的D1找到右边第0行的D1；左表第1行的D2找到右边第1行的D2；右边在第3行复制出一个D1以及研发部来匹配左表第3行的D1。
```

2. `pd.merge(left, right, how='left')`  
```
  emp_id   name dept_id dept_name
0     E1  Alice      D1       研发部
1     E2    Bob      D2       市场部
2     E3  Carol      D1       研发部
3     E4  David      D3       NaN

左表全部显示，D3在右表不存在，故设为NaN值
```

3. `pd.merge(left, right, how='right')`  
```
  emp_id   name dept_id dept_name
0     E1  Alice      D1       研发部
1     E3  Carol      D1       研发部
2     E2    Bob      D2       市场部
3    NaN    NaN      D4       财务部

右表全部显示，D4在左表不存在，故设为NaN值
```

4. `pd.merge(left, right, how='outer')
```
  emp_id   name dept_id dept_name
0     E1  Alice      D1       研发部
1     E3  Carol      D1       研发部
2     E2    Bob      D2       市场部
3     E4  David      D3       NaN
4    NaN    NaN      D4       财务部

显示左表和右边中所有的dept_id，如果在匹配过程中有一个表没有dept_id则相关的内容全部填NaN
```
