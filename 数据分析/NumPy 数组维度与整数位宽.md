# NumPy 数组维度与整数位宽

> [!abstract] 本文主线
> - 数组维度看的是数据有多少个轴，而不是有多少个元素。
> - 数组的 `shape` 表示每个轴的长度，`size` 表示元素总数。
> - `int32` 和 `int64` 是固定长度整数，区别在于占用空间和数值范围。

## 1. 什么是数组的维度

NumPy 数组的维度，也叫轴数，可以通过 `ndim` 查看：

```python
import numpy as np

a = np.array([1, 2, 3])

print(a.ndim)   # 1
print(a.shape)  # (3,)
print(a.size)   # 3
```

这里：

- `ndim=1`：数组只有一个轴。
- `shape=(3,)`：这个轴的长度为 3。
- `size=3`：数组总共有 3 个元素。

判断数组维度时，可以问自己：

> 需要几个索引，才能定位到数组中的一个元素？

例如：

```python
print(a[0])  # 1
```

只需要一个索引，所以 `a` 是一维数组。

## 2. 数组维度和几何空间维度不是一回事

```python
a = np.array([1, 2, 3])
```

它可以同时被描述为：

```text
数组结构：长度为3的一维数组
数学含义：三维空间中的一个点或向量
```

从 NumPy 结构看，只需要一个索引就能取出元素：

```python
a[0]  # 1
a[1]  # 2
a[2]  # 3
```

所以它是一维数组。

从几何意义看，`1、2、3` 可以分别表示 `x、y、z` 三个坐标，所以它又可以代表三维空间中的点 `(1, 2, 3)`。

> [!tip] 核心区别
> NumPy 数组维度看“需要几个索引定位元素”；几何空间维度看“一个点需要几个坐标表示”。

## 3. 零维、一维、二维和三维数组

### 3.1 零维数组

```python
a = np.array(1)

print(a.ndim)   # 0
print(a.shape)  # ()
print(a.size)   # 1
```

它保存一个标量，不需要索引就能表示这个值。

### 3.2 一维数组

```python
a = np.array([1, 2, 3])

print(a.ndim)   # 1
print(a.shape)  # (3,)
```

它有一个轴，轴上有 3 个元素。

### 3.3 二维数组

```python
a = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(a.ndim)   # 2
print(a.shape)  # (2, 3)
```

`shape=(2, 3)` 表示 2 行、3 列。定位一个元素需要“行、列”两个索引：

```python
print(a[0, 0])  # 第0行第0列：1
print(a[1, 2])  # 第1行第2列：6
```

### 3.4 三维数组

```python
c = np.array([[[1]]])

print(c.ndim)   # 3
print(c.shape)  # (1, 1, 1)
print(c.size)   # 1
```

它有三个轴，每个轴的长度都是 1。定位数字 `1` 需要三个索引：

```python
print(c[0, 0, 0])  # 1
```

## 4. 为什么三维数组可以只有一个元素

维度和元素数量是两个不同概念：

```text
ndim  → 有多少个轴
shape → 每个轴分别有多长
size  → 一共有多少个元素
```

对于：

```python
c = np.array([[[1]]])
```

可以把三个轴想象成 Excel 工作簿中的“工作表、行、列”：

```text
1个工作表
└── 工作表中有1行
    └── 这一行有1列
        └── 单元格中是1
```

它使用“工作表、行、列”三个轴组织数据，因此是三维数组；但元素总数为：

```text
1 × 1 × 1 = 1
```

同一个数字可以使用不同维度组织：

| 数组形式 | `ndim` | `shape` | `size` | 获取数字 |
| --- | ---: | --- | ---: | --- |
| `np.array(1)` | 0 | `()` | 1 | 直接使用数组 |
| `np.array([1])` | 1 | `(1,)` | 1 | `a[0]` |
| `np.array([[1]])` | 2 | `(1, 1)` | 1 | `a[0, 0]` |
| `np.array([[[1]]])` | 3 | `(1, 1, 1)` | 1 | `a[0, 0, 0]` |

> [!success] 维度的核心
> 数组维度不是由元素数量决定的，而是由元素的组织结构和轴数决定的。

## 5. 多个三维空间中的点为什么是二维数组

```python
points = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(points.ndim)   # 2
print(points.shape)  # (2, 3)
```

它可以表示：

```text
2个点 × 每个点有3个坐标
```

整个数据结构有“点”和“坐标”两个轴，所以是二维数组。定位一个具体坐标需要两个索引：

```python
points[0, 2]
#      ↑  ↑
#   第0个点的第2个坐标
```

## 6. `int32` 和 `int64` 是什么

`int32` 和 `int64` 都是 NumPy 的固定长度整数类型，数字表示每个整数使用多少个二进制位：

| 类型 | 二进制位数 | 每个元素占用 | 能表示的范围 |
| --- | ---: | ---: | --- |
| `int32` | 32 bit | 4 Byte | $-2^{31}$ ～ $2^{31}-1$ |
| `int64` | 64 bit | 8 Byte | $-2^{63}$ ～ $2^{63}-1$ |

具体范围：

```text
int32：-2,147,483,648 ～ 2,147,483,647
int64：-9,223,372,036,854,775,808 ～ 9,223,372,036,854,775,807
```

可以使用 NumPy 查看：

```python
print(np.iinfo(np.int32))
print(np.iinfo(np.int64))
```

## 7. bit、Byte 和 KB

```text
1 bit  = 1位二进制，只能是0或1
8 bit  = 1 Byte
32 bit = 4 Byte
64 bit = 8 Byte
1 KB   = 1024 Byte
```

因此：

```text
int32 = 32 bit = 4 Byte
int64 = 64 bit = 8 Byte
```

注意，4 Byte 不是 4 KB：

```text
4 Byte = 32 bit
4 KB   = 4096 Byte
```

`4 KB` 是 `4 Byte` 的 1024 倍。

## 8. 为什么 `1` 和 `10000000` 都占 4 Byte

只要数据类型是 `int32`，每个元素都会获得固定的 32 个二进制位：

```python
a = np.array([1], dtype=np.int32)
b = np.array([10_000_000], dtype=np.int32)

print(a.itemsize)  # 4
print(b.itemsize)  # 4
```

可以把 `int32` 想成固定为 4 Byte 的盒子：

```text
int32(1)          → 使用一个4 Byte的盒子
int32(10_000_000) → 也使用一个4 Byte的盒子
```

较小的数字只是在高位使用更多的 `0`，盒子的大小不会随数值改变。

查看整个数组占用的字节数：

```python
a = np.array([1, 2, 3], dtype=np.int32)

print(a.itemsize)  # 4：每个元素4 Byte
print(a.size)      # 3：共3个元素
print(a.nbytes)    # 12：共占12 Byte
```

计算关系为：

```text
nbytes = size × itemsize
```

## 9. 为什么整数能表示的范围有限

32 个二进制位总共有：

```text
2³² = 4,294,967,296
```

种不同组合。`int32` 需要同时表示负数、0 和正数，因此范围最终是：

```text
-2,147,483,648 ～ 2,147,483,647
```

正数一侧少一个，是因为非负数中还需要包含 `0`。

例如，14 亿没有超过 `int32` 的最大值：

```python
population = np.array([1_400_000_000], dtype=np.int32)
```

30 亿超过了 `int32` 的最大值，应使用 `int64`：

```python
number = np.array([3_000_000_000], dtype=np.int64)
```

## 10. 如何选择 `int32` 和 `int64`

- 数值确定不会超过约 21 亿，并且希望节省内存：可以考虑 `int32`。
- 数值可能很大，或者更重视数值范围：使用 `int64`。

如果数组有 100 万个元素，大致占用：

```text
int32：1,000,000 × 4 Byte ≈ 4 MB
int64：1,000,000 × 8 Byte ≈ 8 MB
```

> [!note] Python 普通整数与 NumPy 整数不同
> Python 的普通 `int` 可以根据数值大小动态扩展；NumPy 的 `int32` 和 `int64` 是固定长度类型，超过范围可能发生溢出或转换错误。

## 11. 最终记忆清单

> [!success] 核心结论
> - `ndim` 表示轴的数量。
> - `shape` 表示每个轴的长度。
> - `size` 表示元素总数，等于 `shape` 中各数字的乘积。
> - `[1, 2, 3]` 是长度为 3 的一维数组，但可以代表三维空间中的一个点。
> - `[[[1]]]` 是三维数组，因为需要三个索引定位元素；它的 `size` 仍然是 1。
> - `1 bit` 就是一位二进制，`8 bit = 1 Byte`。
> - `int32` 每个元素固定占 4 Byte，`int64` 每个元素固定占 8 Byte。
> - 固定长度整数的数值大小不会改变单个元素的内存占用。
> - `int32` 更节省内存，`int64` 能表示更大的整数。
