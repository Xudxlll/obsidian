# 1.1 机器学习概论

> [!info] 整理原则
> 本笔记依据课堂字幕整理，将教师讲授内容转写为适合阅读和复习的书面化课程笔记。笔记保留课程中涉及的概念、研究语境、例子、判断规则和方法差异，不采用压缩式摘要。

## 1. 大数据语境下的机器学习

### 1.1 结构化数据与非结构化数据

机器学习课程首先被放置在“大数据进入经济学与管理学研究”的背景下理解。传统经济学研究主要处理结构化数据，即以数值形式存在、可以被表格清晰组织的数据，例如财务指标、企业注册信息、宏观统计变量或调查数据。随着互联网、文本挖掘、图像识别、语音识别和遥感数据的发展，研究对象已经不再局限于数字表格。

非结构化数据是指不能直接用传统二维表格完全表达的信息，包括文本、图像、音频、视频、遥感图像、网络留言、购物记录、专利文本、政府留言板和工商企业注册资料等。教师强调，现实世界中的大量信息并不是以标准数值形式存在的，这使得传统统计软件和传统计量方法在处理规模、维度和数据类型上面临限制。

### 1.2 大数据的基本特征

课堂将大数据概括为几个重要特征。

第一，数据容量大。文本库、工商企业数据库、遥感图像或互联网行为数据往往达到几十 GB、几百 GB，甚至 TB 级规模。此类数据无法仅依靠人工或传统桌面软件在短时间内完成读取、清洗和建模。

第二，数据类型复杂。研究材料从单纯数值扩展到文本、语音、图像、视频和地理位置等多类型数据，研究者必须掌握能够处理多模态数据的工具。

第三，价值密度低。大规模文本、音频或视频材料中，真正与研究问题相关的信息通常只占较小部分，研究者需要借助算法完成筛选、降维、特征提取和预测。

第四，数据高维稀疏。尤其在文本、专利、企业信息和互联网行为数据中，一个样本可能对应成千上万个潜在特征，而每个样本中真正非零或有效的信息非常有限。高维稀疏性正是机器学习方法被引入社会科学研究的重要原因之一。

### 1.3 机器学习在经济学研究中的意义

教师特别强调，机器学习并不是脱离经济学的问题意识而单独存在。经济学和管理学顶级期刊中已经出现大量利用文本、音频、图像和语调数据研究资本市场、公司治理、政策沟通和市场反应的文献。例如，金融会计领域会研究文本语调、文本特征或语音语调如何影响资本市场定价；经济学研究中也会利用图像或遥感数据识别地区发展、企业行为和政策效果。

机器学习方法可以帮助研究者将非结构化材料转化为可计算的特征，并在高维特征空间中完成预测、分类、聚类或异质性识别。课程后续涉及的广义随机森林、随机森林和树模型，都可以被理解为利用数据驱动方法识别特征结构、探索样本异质性和辅助因果推断的工具。

## 2. 数据分析任务与机器学习任务

### 2.1 数据分析的四类任务

课堂将数据分析概括为四类任务：总结、估计、假设检验和预测。

总结是对数据特征进行描述，例如均值、方差、分布、频数和可视化。估计是利用样本推断总体参数。假设检验是判断某一统计假设是否能够被数据支持。预测则是利用已有样本中的规律，对新样本的结果进行推断。

机器学习主要服务于预测任务，但并不只限于预测。它也可以通过特征选择、降维和聚类帮助研究者理解数据结构。

### 2.2 sklearn 中的机器学习任务框架

教师借助 `sklearn` 说明机器学习任务的基本框架。常见任务包括：

| 任务 | 英文 | 标签特征 | 典型问题 |
|---|---|---|---|
| 分类 | classification | 因变量为离散类别 | 判断图片是猫还是狗，判断企业是否违约 |
| 回归 | regression | 因变量为连续数值 | 预测房价、销量、收益率 |
| 聚类 | clustering | 没有已知标签 | 将房源、企业或用户自动分组 |
| 降维 | dimensionality reduction | 高维特征压缩 | PCA、特征压缩、可视化 |
| 模型选择 | model selection | 选择算法与超参数 | 交叉验证、网格搜索 |
| 预处理 | preprocessing | 改造原始特征 | 标准化、编码、缺失值处理 |

分类和回归是监督学习中最基本的两个任务。分类任务中，标签 `Y` 是离散的；回归任务中，标签 `Y` 是连续的。聚类则属于无监督学习，模型只根据样本之间的相似性划分群体，而不依赖已知标签。

## 3. 计量经济学与机器学习的差异

### 3.1 研究目标的差异

计量经济学强调参数估计和因果解释。研究者通常关心某个政策、制度、变量或处理状态对结果变量 `Y` 的影响。例如，在政策评估中，核心问题是处理变量 `D` 对结果变量 `Y` 是否存在因果效应，以及该效应大小是多少。计量经济学因此强调无偏估计、外生性、识别假设和估计量性质。

机器学习强调预测能力和泛化能力。模型并不首先追问某个系数是否具有因果解释，而是关注给定一组特征 `X` 后，模型能否准确预测结果 `Y`。如果模型在未见过的新样本上仍然预测准确，则称其具有较强的泛化能力。

### 3.2 参数估计与预测函数

在线性计量模型中，研究者通常关注系数向量 $\beta$ 的估计。例如：

$$
Y = \beta_0 + \beta_1X_1 + \cdots + \beta_kX_k + \epsilon
$$

在满足一定经典假设时，普通最小二乘估计量可以被称为最佳线性无偏估计量，即 BLUE。此时，估计重点是 $\beta$ 的无偏性和解释性。

机器学习更关注预测函数 $f(X)$。即使模型系数不具备传统意义上的无偏解释，只要预测结果 $\hat{Y}=f(X)$ 在样本外表现良好，该模型仍然可能是有效的预测模型。

### 3.3 术语体系的差异

| 计量经济学术语 | 机器学习术语 | 含义 |
|---|---|---|
| 自变量 / 解释变量 | 特征 / 表征 | 输入变量 `X` |
| 因变量 / 被解释变量 | 标签 / 响应 / 目标 | 输出变量 `Y` |
| 观测值 | 样本 / 案例 | 一条数据记录 |
| 参数估计 | 模型训练 | 学习输入与输出之间的映射 |
| 样本外预测 | 泛化能力 | 对未见数据的预测表现 |

## 4. 训练集、验证集与测试集

### 4.1 数据划分的必要性

传统计量经济学模型往往使用全部样本进行估计，因为重点是参数识别和系数解释。机器学习模型则必须区分训练和评估，因为其核心目标是预测新样本。如果模型只在训练数据上表现良好，而在新样本上表现较差，则不能认为它具有实际预测能力。

因此，机器学习通常将数据划分为训练集、验证集和测试集。

### 4.2 三类数据集的功能

训练集用于学习模型参数，即让模型从样本中学习 `X` 到 `Y` 的映射关系。验证集用于模型选择和超参数调整，例如选择树的深度、随机森林中树的数量、正则化强度等。测试集用于最终评估模型在完全未参与训练与调参的数据上的表现。

如果反复使用测试集调参，测试集就会被间接“学习”，不再代表真正未知的数据。这种现象会造成评估结果虚高，属于一种数据泄露风险。因此，验证集和测试集的分离具有方法论意义。

### 4.3 房价预测例子

教师以房价预测为例说明数据划分。模型先在已知房屋特征和真实房价的样本上学习规律；然后在验证集上比较不同模型或不同超参数的预测误差；最后在测试集上评估最终模型的真实预测能力。若模型在测试集上误差较小，说明其样本外泛化能力较强。

## 5. 过拟合、欠拟合、偏差与方差

### 5.1 过拟合

过拟合是指模型在训练集上表现非常好，但在测试集或新样本上表现较差。其原因在于模型不仅学习到了真实规律，还学习到了训练数据中的偶然噪声。教师用猫狗识别的例子解释：如果模型只见过橘黄色猫，它可能把“橘黄色”误认为猫的必要特征；当出现白猫时，模型反而无法识别。

### 5.2 欠拟合

欠拟合是指模型过于简单，无法捕捉训练数据中的基本规律。此时，模型在训练集和测试集上表现都较差。教师用分类边界和回归曲线说明：如果真实关系明显非线性，而模型只能给出非常粗糙的线性边界，就会出现欠拟合。

### 5.3 偏差与方差

偏差刻画模型预测函数与真实数据生成过程之间的系统性偏离。高偏差通常对应欠拟合。方差刻画训练数据扰动对模型结果的影响程度。高方差通常对应过拟合。

偏差和方差之间存在张力。模型过于简单时，偏差较高但方差较低；模型过于复杂时，偏差可能降低但方差升高。机器学习调参的核心目标之一，就是在偏差和方差之间取得平衡，使模型具有较低的泛化误差。

### 5.4 模型复杂度的直观理解

在线性回归、多项式回归、决策树和随机森林中，模型复杂度都有不同表现。线性模型过于简单时可能无法拟合曲线；高阶多项式模型可能对训练点过度敏感；决策树如果不限制深度，可能不断分裂直到记住训练样本；随机森林则通过集成多棵树降低方差。

## 6. 本节应掌握的知识框架

### 6.1 学习重点

本节需要掌握机器学习与大数据之间的关系，理解结构化数据与非结构化数据的差异，明确分类、回归、聚类、降维、模型选择和预处理六类任务，能够区分计量经济学中的因果识别目标与机器学习中的预测目标。

### 6.2 易混点

机器学习不等同于计量经济学中的回归扩展。计量经济学首先关心“某个变量是否具有因果效应”，机器学习首先关心“模型是否能预测新样本”。训练集表现优异也不等于模型优秀，只有样本外预测表现良好，才能说明模型具有较强泛化能力。
