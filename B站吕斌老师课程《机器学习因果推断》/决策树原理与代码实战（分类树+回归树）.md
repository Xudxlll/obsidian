## 一、决策树基本概念

### 1. 什么是决策树

机器学习诞生于上世纪 70 年代，决策树和随机森林在当时就已经被提出。但直到今天，经管领域的顶刊论文中仍然频繁使用决策树和随机森林，原因在于：社会科学更看重**可解释性**——我们需要知道一个政策为什么产生某种后果，以及政策效果在不同群体中的异质性。神经网络、支持向量机、朴素贝叶斯等黑箱模型在经济学中的流行程度远不如决策树和回归类算法。

决策树是一类**有监督机器学习**算法。有监督的意思是：我们告诉机器什么样的 $X$ 对应什么样的 $y$，机器看过大量 $X \to y$ 的映射关系后，就掌握了分类规律，具备了对新样本进行分类的能力。

决策树的底层逻辑是：**通过对特征的不断提问来使样本越分越细**。整个过程就像猜人物游戏——先问「中国人还是外国人」、再问「50 岁以上还是以下」、再问「卡通还是真人」……通过层层提问不断缩小范围。

### 2. 决策树的基本结构

一棵决策树由四种节点构成：

| 节点类型 | 特征 | 说明 |
|---|---|---|
| **根节点** | 有出边、无进边 | 包含全部样本的起始节点 |
| **中间节点** | 既有进边也有出边 | 对特征进行进一步提问 |
| **叶子节点** | 有进边、无出边 | 分无可分，给出最终预测结果 |
| **父/子节点** | 上下对应关系 | 上层为父节点，下层为子节点 |

以西瓜分类为例：假设收集了 17 个西瓜，每个西瓜有色泽、根蒂、敲声、纹理、脐部、触感等特征，标签是「好瓜」或「坏瓜」。决策树可能先按「纹理是否清晰」提问，再按「触感是否硬滑」提问，再按「敲声是否沉闷」提问……越往下分，节点里的瓜越「纯」（同一类别的瓜占比越高）。

### 3. 决策树要解决的两个核心问题

> **问题一**：按什么特征进行切分？如何选择最佳节点和分支？

> **问题二**：树生长到什么时候停止？如何防止过拟合？

树的深度如果不加限制，理论上可以无限生长——样本足够大时，可以一直往下分。但生长过深会导致过拟合：模型捕捉了训练数据中太多的细节和噪声，对新样本的泛化能力反而下降。解决方法分为两大类：**剪枝参数**和**控制分裂的参数**。

## 二、节点不纯度与特征选择

### 1. 信息熵（Entropy）

**一句话说清**：熵衡量一个节点里样本的「鱼龙混杂」程度。熵越大，节点越不纯；熵越小，节点越干净。

如果要切分数据，好的切分应该让子节点的熵**尽可能小**——相当于每个子节点被某一类样本「统治」，不再混杂。

信息熵的计算公式：

$$
Entropy(t)=-\sum_{i=1}^{c} p(i|t)\log_2 p(i|t)
$$

其中 $p(i|t)$ 表示在节点 $t$ 中第 $i$ 类样本所占的比例。$c$ 是类别总数。

**性质**：在二分类问题中，熵是一个倒 U 型曲线——当正负样本各占一半（五五开）时，熵达到最大值；当某一类占压倒性优势时，熵趋近于 0。

### 2. 信息增益的计算（走一遍例子）

假设父节点有 28 个类一 + 16 个类二，总共 44 个样本。有两种切分方式：

| 切分方式 | 左子节点 | 右子节点 |
|---|---|---|
| A 类切分 | 14 个类一 + 4 个类二 | 14 个类一 + 12 个类二 |
| B 类切分 | 20 个类一 + 14 个类二 | 8 个类一 + 2 个类二 |

**步骤 1：计算父节点的熵**

父节点中类一占比 $p_1 = \frac{28}{44}$，类二占比 $p_2 = \frac{16}{44}$：

$$
Ent(D) = -\frac{28}{44}\log_2\frac{28}{44} - \frac{16}{44}\log_2\frac{16}{44}
$$

**步骤 2：分别计算各子节点的熵（以 A 类切分为例）**

左子节点 Ent₁（14 个类一 + 4 个类二），右子节点 Ent₂（14 个类一 + 12 个类二），同上方式计算。

**步骤 3：计算信息增益**

$$
Gain = Ent(D) - \left(\frac{|D_1|}{|D|}Ent_1 + \frac{|D_2|}{|D|}Ent_2\right)
$$

用父节点的熵减去两个子节点熵的加权平均。计算结果是：
- A 类切分：熵下降 **0.81**
- B 类切分：熵下降 **0.75**

因为 $0.81 > 0.75$，所以 A 类切分是更高效的分裂方式。

> **直觉理解**：信息增益本质上在衡量「这个问题问得好不好」。问「这个人是否大于 1000 岁」几乎零信息量，纯属废话；问「这个人是中国人还是外国人」则一针见血，能大幅降低不确定性。信息增益鼓励机器提「有含金量」的问题。

### 3. 基尼系数（Gini）

基尼系数是另一种衡量不纯度的方式：

$$
Gini(t) = 1 - \sum_{i=1}^{c} p(i|t)^2
$$

和信息熵一样，基尼系数也是一个倒 U 型曲线——五五开时最大，一类占优时趋近 0。两者的区别在于：

| 指标 | 特点 | 效果 |
|---|---|---|
| **信息熵** | 对不纯度变化更敏感 | 树的生长更精细，容易过拟合 |
| **基尼系数** | 相对温和 | 很多细枝末节不再切分，树更简洁 |

**使用建议**：如果模型过拟合，换成基尼系数降低拟合强度；如果欠拟合，换成信息熵提升拟合能力。数据量不大时（几千到几万条），可以两个都试一下，选效果更好的。

### 4. ID3 / C4.5 / CART 对比

| 算法 | 分裂准则 | 特点 |
|---|---|---|
| **ID3** | 信息增益（绝对值） | 用父节点熵减去子节点熵的加权和 |
| **C4.5** | 信息增益率（比率） | 将信息增益除以特征自身的信息量，缓解对多值特征的偏好 |
| **CART** | 基尼系数 | 用基尼系数代替信息熵，二叉树结构 |

三者**换汤不换药**，本质上都在衡量信息增益（不纯度的下降幅度），只是具体计算方式不同。sklearn 的决策树默认使用 CART 算法。

## 三、sklearn 决策树代码实战（红酒数据集）

### 1. sklearn 库简介

sklearn（scikit-learn）是 Python 做机器学习最主流的库，涵盖六大任务：**分类、回归、聚类、降维、模型选择、数据预处理**。决策树模块位于 `sklearn.tree` 下：

```python
from sklearn.tree import DecisionTreeClassifier   # 分类树
from sklearn.tree import DecisionTreeRegressor    # 回归树
from sklearn.tree import export_graphviz          # 导出可视化
```

**分类 vs 回归的区别**：唯一的区别是 $y$ 的类型。$y$ 是离散变量（0, 1, 2, 3...）就是分类任务；$y$ 是连续变量（房价、收入等）就是回归任务。

### 2. 建模三步走

sklearn 的建模流程始终是三步走，这是面向对象编程的体现：

```
第一步：实例化 → 生成一个空白的模型
第二步：拟合   → 用训练集数据训练模型
第三步：评价   → 用测试集数据评估模型表现
```

```python
# 第一步：实例化
clf = DecisionTreeClassifier()

# 第二步：拟合
clf.fit(X_train, y_train)

# 第三步：评价
score = clf.score(X_test, y_test)
```

> **为什么先实例化一个空模型？** Python 是面向对象语言，需要先「造」一个模型对象，再往里面「喂」数据。空模型就像一张白纸，什么都不会；经过 fit 之后才具备预测能力。

### 3. 训练集与测试集的划分

在计量经济学中很少谈训练集和测试集，但机器学习中这是核心概念。**训练集**用来训练模型，**测试集**用来评估模型的样本外表现——就像老师用课堂练习教学生，然后用学生没见过的题来考试。

通常按 **7:3** 比例切分：

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=30
)
```

> **顺序不能乱**：先 X 后 y，先 train 后 test。即 `X_train, X_test, y_train, y_test`。

> **random_state 的作用**：切分本身有随机性——同样的数据，不同的切分方式会导致模型表现不同。指定 `random_state`（随机数种子）后，每次切分的方式就固定下来，保证结果可复现。计算机里的「随机」是通过伪随机数表模拟出来的，给定种子就确定了序列。

### 4. 红酒数据集案例

红酒数据集（Wine Dataset）包含 178 瓶酒，13 个理化特征（酒精、苹果酸、灰分、类黄酮等），目标是判断每瓶酒属于 3 个类别中的哪一个。

```python
from sklearn.datasets import load_wine
from sklearn.tree import DecisionTreeClassifier

# 加载数据
wine = load_wine()
X = wine.data          # (178, 13) 的特征矩阵
y = wine.target        # (178,) 的标签

# 切分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=30
)

# 建模三步走
clf = DecisionTreeClassifier()
clf.fit(X_train, y_train)
score = clf.score(X_test, y_test)  # 约 87% 准确率
```

模型在测试集上的准确率约 87%，意味着每 100 瓶新酒，模型平均能分对 87 瓶。

> **numpy ndarray 的维度区分**：`data` 是二维数组（`(178, 13)`），最外层中括号包裹二维矩阵，里层中括号每行一个样本；`target` 是一维数组（`(178,)`），只有一个中括号。维度在后续操作中很重要，不统一会报错。

### 5. 决策树可视化

使用 `graphviz` 画出决策树的决策流程：

```python
import graphviz
from sklearn.tree import export_graphviz

dot_data = export_graphviz(
    clf,
    feature_names=wine.feature_names,
    class_names=wine.target_names,
    filled=True,      # 节点填色：颜色越深代表分类越纯
    rounded=True      # 圆角节点
)
graph = graphviz.Source(dot_data)
graph
```

- `filled=True`：给节点填色。颜色越浅，三类酒混杂程度越高；颜色越接近纯色（橙红/绿/紫），说明某一类酒占了绝对优势
- `rounded=True`：节点用圆角矩形显示

从可视化图中可以看到，树先按「类黄酮」分割，再按「颜色强度」分割，再按「花青素」分割……越往下层，节点越纯（熵越小）。

### 6. 特征重要性（feature_importances_）

特征重要性反映每个特征在分裂过程中贡献的大小。越靠近根节点的特征，重要性越高；越靠近叶子的特征，重要性越低。

```python
# 将特征名和重要性一一对应
[*zip(wine.feature_names, clf.feature_importances_)]
```

输出示例：类黄酮重要性 0.40（排名第一），酒精重要性 0.29（排名第二）——正好对应根节点首先按类黄酮切分、再按酒精相关的特征切分。

> **星号拆包技巧**：`*zip(...)` 外面加 `[...]` 可以直接将 zip 对象转换为可读的（特征名, 重要性）键值对列表。

## 四、决策树的核心参数与调参

决策树的 `DecisionTreeClassifier` 有大量参数，下面按重要程度逐一讲解。

### 1. criterion：信息熵 vs 基尼系数

`criterion` 控制节点分裂的评价标准：

| 取值 | 含义 | 特点 |
|---|---|---|
| `'gini'`（默认） | 基尼系数 | 更温和，不容易过拟合 |
| `'entropy'` | 信息熵 | 更敏感，树的生长更精细 |

**使用建议**：过拟合时换 `gini`，欠拟合时换 `entropy`。数据量不大时可以两个都试一下。

### 2. random_state：控制决策树的随机性

决策树具有**随机性**——同一份数据，不指定 `random_state` 的话，每次生成的树可能完全不同，测试集分数会波动（例如 87%～98%）。

**随机性来源**：sklearn 在实现时做了一个重要改进——每次分裂并不从全部特征中选择最优，而是从**随机抽取的一部分特征**中选最优。这样做是为了防止某个「坏特征」占据绝对主导地位。

> **猫狗大战的例子**：假设数据中所有黄色的动物恰好都是猫、所有白色的动物恰好都是狗。如果按全局最优切分，树会直接按「皮毛颜色」一刀切，分得特别干净。但「皮毛颜色」实际上是个坏特征（巧合性的关联），会让模型学到错误的规律。sklearn 通过从部分特征中随机选择来降低这种风险。

**区分两个 random_state**：
- `train_test_split` 中的 `random_state`：控制**训练集和测试集切分**的随机性
- `DecisionTreeClassifier` 中的 `random_state`：控制**树内部特征选择**的随机性

两者完全不同，不要搞混。

### 3. splitter：best vs random

| 取值 | 含义 | 效果 |
|---|---|---|
| `'best'`（默认） | 每一步选最优特征进行分裂 | 树较小较浅，倾向过拟合 |
| `'random'` | 分裂时增加随机性，不一定选最优 | 树更大更深，降低过拟合风险 |

将 `splitter` 从 `best` 改为 `random` 后，生成的树会明显「庞大」很多——因为模型的提问不再那么精准，有些「无厘头」的问题（类似于「这个人物是否大于 800 岁」）也被提了出来。这本质上是在降低模型复杂度，缓解过拟合。

> **直觉理解**：best 是每一步都走得最好，但可能每一小步最优加起来反而是次优；random 增加了随机探索，反而可能找到更好的整体路径。

### 4. 剪枝参数

剪枝参数的逻辑是：用一把「剪刀」对树进行修剪，限制树的复杂度。

#### 4.1 max_depth（树的最大深度）

一刀切的命令，直接限制树最多有几层。例如 `max_depth=3` 时，树只有 3 层，超过的直接砍掉。

> 深度越浅 → 拟合能力越弱 → 过拟合风险越低。

#### 4.2 min_sample_leaf（叶子节点最小样本数）

针对**切分后的子节点**说话：只有当切分后**叶子节点**的样本量大于等于该值时，才允许这次分裂。

例如 `min_sample_leaf=10`：如果一次分裂产生 5 个和 8 个两个子节点（都小于 10），这次分裂就不会发生。

#### 4.3 min_sample_split（内部节点最小样本数）

针对**切分前的父节点**说话：只有当**父节点**的样本量大于等于该值时，才允许对这个节点进行分裂。

例如 `min_sample_split=30`：如果父节点只有 26 个样本（小于 30），就不再分裂。

| 参数 | 作用对象 | 逻辑 |
|---|---|---|
| `min_sample_leaf` | 切分后的子节点 | 子节点样本数不够就不切 |
| `min_sample_split` | 切分前的父节点 | 父节点样本数不够就不切 |

> 两个参数都间接控制了树的深度，效果类似但有细微区别。

#### 4.4 max_features 与 min_impurity_decrease

- **`max_features`**：限制每次分裂时考虑的特征个数，会增加随机性，有避免过拟合的效果
- **`min_impurity_decrease`**：限制信息增益的最低门槛。例如设为 0.2，只有当分裂带来的不纯度下降超过 0.2 时才允许分裂

这两个参数实际调参中用得较少，了解即可。

### 5. 学习曲线：单参数调优

当只有一个参数需要调时（如 `max_depth`），可以用**学习曲线**：

```python
import matplotlib.pyplot as plt

test_scores = []
for i in range(20):
    clf = DecisionTreeClassifier(max_depth=i+1, random_state=30)
    clf.fit(X_train, y_train)
    test_scores.append(clf.score(X_test, y_test))

plt.plot(range(1, 21), test_scores, color='red', label='max_depth')
plt.legend()
plt.show()
```

学习曲线通常是**先增后减**的形状：
- 模型太简单时（深度很小），拟合能力不足 → 分数低
- 随着深度增加，模型捕捉规律 → 分数上升
- 深度过大，模型过拟合 → 分数下降并趋于平稳

**最优参数**选曲线峰值附近的取值（例如上例中深度约 3 层时效果最好）。

### 6. 网格搜索：多参数调优

当有多个参数需要同时调时，用**网格搜索**：

参数 A 有 5 个候选值，参数 B 也有 5 个候选值 → 5 × 5 = 25 种组合，每一种都训练并评估，选出最优组合。

> 网格搜索计算量很大，实际业务中往往采用**经验调参**：先固定最难调的参数，再逐层往下调简单的。也可以使用**贝叶斯优化**等更高效的方法。

## 五、偏差-方差权衡

### 1. 直觉理解

以房价预测为例，假设自然界存在一个真实的规律（上帝造物的法则），比如房价与公园数量呈先平后陡的上升关系。

| 模型 | 偏差（Bias） | 方差（Variance） | 直观表现 |
|---|---|---|---|
| **简单模型**（如 $y = ax + b$） | 大——无论怎么努力，直线永远无法拟合曲线 | 小——预测结果非常稳定、密集 | 总是打不中靶心，但弹孔集中 |
| **复杂模型**（如高次多项式） | 小——有能力逼近真实规律 | 大——稍微换个样本就上下乱窜 | 弹孔散布很大，但平均能命中靶心 |

> **偏差**：模型预测与真实规律之间的系统性误差。模型越简单，偏差越大。
>
> **方差**：模型在不同训练集上预测结果的波动程度。模型越复杂，方差越大。

### 2. 模型复杂度与泛化误差

模型的**泛化误差**（样本外的表现）可以分解为：

$$
\text{泛化误差} = \text{Bias}^2 + \text{Variance} + \text{不可约误差}
$$

随着模型复杂度上升，偏差不断减小，方差不断增大，两者的和呈**先下降后上升**的 U 型曲线。这就是为什么：

> **模型不是越简单越好，也不是越复杂越好，而是要选择一个中等复杂度的模型。**

这也解释了学习曲线为什么是先增后减的形状。

## 六、非平衡样本处理

### class_weight

当数据集中正负样本比例严重失衡时，模型可能「偷懒」——永远预测多数类也能拿到很高的准确率。

> **例子**：全球罕见病筛查系统。70 亿人中只有 7 个患病，模型如果永远输出「你是健康的」，准确率高达 99.9999999%，但毫无实用价值。

解决方法之一是指定 `class_weight` 参数，给少数类样本增加权重。背后的思想是 **bootstrap（有放回随机抽样）**——少数类样本看似只有一例，但在训练中被重复抽样了多次，从而在模型眼中「看起来」和多数类一样多。

> 除了 `class_weight`，评价非平衡样本的模型还需要关注**查准率（Precision）**和**查全率（Recall）**的综合表现，而不仅是准确率。

## 七、回归树

### 1. 回归树与分类树的区别

决策树不仅能做分类，也能做回归。区别仅在于 $y$ 的类型：

| 任务 | $y$ 类型 | 叶子节点输出 | sklearn 类 |
|---|---|---|---|
| **分类树** | 离散（0, 1, 2...） | 多数类的标签 | `DecisionTreeClassifier` |
| **回归树** | 连续（房价、收入等） | 节点内样本标签的均值 | `DecisionTreeRegressor` |

回归树的参数和分类树基本一致（`max_depth`、`min_sample_split`、`min_sample_leaf`、`splitter` 等），唯一不同的是评价指标。

### 2. 评价指标

#### 2.1 MSE（均方误差）

**一句话说清**：把所有样本预测值和真实值之间的差距平方后求平均。

$$
MSE = \frac{1}{N}\sum_{i=1}^{N}(\hat{y}_i - y_i)^2
$$

- **均**：$\frac{1}{N}$，求平均
- **方**：$(\cdots)^2$，平方
- **误差**：$\hat{y}_i - y_i$，预测值与真实值的差距

MSE 越小越好（是损失函数）。

#### 2.2 MAE（平均绝对误差）

把 MSE 中的平方换成绝对值：

$$
MAE = \frac{1}{N}\sum_{i=1}^{N}|\hat{y}_i - y_i|
$$

#### 2.3 负号技巧

sklearn 中有一个统一约定：**所有以 `neg_` 开头的指标都是损失函数**（越小越好），前面加负号后统一变成「越大越好」，方便和其他指标（如准确率、R²）统一比较。

```python
scoring = 'neg_mean_squared_error'   # 负均方误差，越大越好
scoring = 'neg_mean_absolute_error'  # 负平均绝对误差，越大越好
```

从 -70 变成 -30，就叫「改善了」。

### 3. R² 的深入理解

#### 3.1 R² 的定义

regressor 的 `score()` 接口返回的不是 MSE 也不是 MAE，而是 **R²**。R² 从信息论角度衡量模型捕获了多少数据中的变异信息：

$$
R^2 = 1 - \frac{\sum_{i=1}^{N}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{N}(y_i - \bar{y})^2}
$$

- **分母**：$y$ 的总变异性（每个 $y$ 相对于其平均值 $\bar{y}$ 的波动）
- **分子**：模型没有预测对的部分（残差平方和 RSS）

**一句话说清**：R² 表示在 $y$ 的所有波动性中，有多少是模型能够解释的。R² 越接近 1 越好。

#### 3.2 R² 为什么可以是负数

本科计量经济学中常说「R² 永远在 0 到 1 之间」，但**在机器学习中这不成立**。推导如下：

从总平方和的分解出发，利用完全平方公式展开后，除了 RSS（残差平方和）和 ESS（解释平方和），还有一项**交叉项**。这项交叉项在传统 OLS 中为 0，但在机器学习模型中**不一定为零**。

当模型的预测方向与真实趋势相反时（例如真实趋势上升、模型预测下降），交叉项可能为负，导致 $R^2 < 0$。实际情况中 $R^2$ 的范围是 **$(-\infty, 1]$**。

> **R² 为负意味着什么？** 你的模型连「用平均值瞎猜」都比不上。如果从街上随便抓一个人，最好的策略是用全国平均工资来猜他的收入；如果你的模型预测比这个平均猜法还差，R² 就为负。

#### 3.3 回归与分类的基准对比

| 任务类型 | 基准（瞎猜策略） | 评价指标 |
|---|---|---|
| **回归** | 用所有样本的平均值 $\bar{y}$ 来预测 | R²，跟平均数比有没有改善 |
| **二分类** | 随机猜，准确率 50% | 准确率，跟 50% 比有没有改善 |
| **多分类（$k$ 类）** | 随机猜，准确率 $\frac{1}{k}$ | 准确率，跟 $\frac{1}{k}$ 比 |

### 4. 交叉验证（Cross Validation）

简单的训练集/测试集切分存在随机性问题——切得不好效果很差，切得好效果很好。交叉验证解决了这个问题：

**做法**：将数据分成 10 份。第 1 次用前 9 份训练 + 最后 1 份测试，第 2 次用前 8 份 + 第 10 份训练、第 9 份测试……循环 10 次，取平均。

```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(
    regressor, X, y,
    cv=10,                            # 分成 10 份
    scoring='neg_mean_squared_error'  # 评价指标
)
scores.mean()  # 10 次交叉验证的平均结果
```

**直觉**：就像不再是「一考定终身」，而是考好几次模考，综合评分更稳健。

### 5. 加州房价案例

使用 `fetch_california_housing` 数据集，目标是用房屋特征（收入中位数、房龄、房间数等）预测房价中位数。

```python
from sklearn.datasets import fetch_california_housing
from sklearn.tree import DecisionTreeRegressor
from sklearn.model_selection import cross_val_score

housing = fetch_california_housing()
X = housing.data
y = housing.target          # 房价中位数（已取对数）

# 实例化空白模型
regressor = DecisionTreeRegressor()

# 交叉验证
scores = cross_val_score(
    regressor, X, y,
    cv=10,
    scoring='neg_mean_squared_error'
)
# 结果约为 -0.80

# 换成 MAE
scores_mae = cross_val_score(
    regressor, X, y,
    cv=10,
    scoring='neg_mean_absolute_error'
)
# 结果约为 -0.62
```

## 八、决策树的优缺点与经济学应用

### 1. 优点：可解释性强

决策树是**白盒模型**，整个决策过程一目了然。你可以清楚地看到模型按什么特征、以什么阈值进行判断，这在经管领域尤为重要——政策制定者和论文审稿人需要知道**为什么**得出这个结论。

### 2. 缺点：容易陷入局部最优

决策树的内部优化基于**贪婪算法**——每一步选当前最优，但不保证全局最优。这就像每一步都走得最好，但最终可能只是局部最高点，而非全局最高峰。

> 后续课程中的**随机森林**算法通过集成多棵树来克服这一缺点。

### 3. 适用场景

决策树的切分边界是**正交的**（一刀一刀的轴平行切分），因此：

- **擅长**：能通过多次正交切分分开的数据（如月亮形数据，准确率约 95%）
- **不擅长**：环形嵌套数据（准确率约 80%）

对于线性不可分的数据，可以通过映射到高维空间来解决（后续课程中的支持向量机思路）。

### 4. 经济学应用案例

> **2018 年《Real Estate Economics》论文**：利用机器学习回归树算法，在双重差分（DID）框架下研究首尔某条地铁开通对周边房价的**异质性处理效应**。

传统的 DID 只给出一个「平均处理效应」，但树的思路是：将不同位置、不同特征的房屋的处理效应高低作为「标签」，训练一棵树来发现「什么样的房子涨得最多、什么样的房子反而贬值」。这种思路进一步发展就是**因果森林**。

> **核心启示**：经管研究不需要用特别复杂的模型，决策树 + 随机森林 + 岭回归/套索回归基本就够了。模型的可解释性比复杂度更重要。
