# 3.1 随机森林原理与经济学应用

> [!info] 整理原则
> 本笔记依据课堂字幕整理，将随机森林放在集成学习、Bagging、群体智慧、随机性来源和经济学应用语境中展开。

## 1. 从决策树到集成学习

### 1.1 单棵决策树的局限

单棵决策树具有结构清晰、可解释性强、能够处理非线性关系等优点，但它也存在方差较大的问题。训练数据发生轻微变化，树的分裂结构可能出现明显变化，从而影响预测结果。换言之，单棵树容易过拟合，也容易对样本扰动敏感。

### 1.2 集成学习思想

集成学习通过组合多个基学习器获得更强的泛化能力。其直观思想是，多个具有一定判断能力且错误不完全一致的模型共同决策，通常比单个模型更稳定。

随机森林正是以决策树为基学习器的集成方法。它不是试图训练一棵完美的树，而是训练多棵有差异的树，再通过投票或平均形成最终预测。

## 2. Bagging 与 Boosting

### 2.1 Bagging

Bagging 是 Bootstrap Aggregating 的缩写，其核心是通过有放回抽样生成多个训练子集，并在这些子集上分别训练基学习器。分类任务中，多个模型通过投票给出最终类别；回归任务中，多个模型通过平均给出最终预测值。

Bagging 主要用于降低方差。由于不同基学习器看到的数据不同，它们的误差不完全一致，集成后可以抵消单个模型的随机波动。

### 2.2 Boosting

Boosting 的核心是串行训练。后一个模型会重点关注前一个模型预测错误的样本，并逐步修正整体模型的偏差。Boosting 更强调降低偏差，典型算法包括 AdaBoost、GBDT、XGBoost 等。

### 2.3 二者比较

| 维度 | Bagging | Boosting |
|---|---|---|
| 模型关系 | 并行 | 串行 |
| 主要目标 | 降低方差 | 降低偏差 |
| 样本机制 | Bootstrap 有放回抽样 | 根据错误调整样本权重 |
| 组合方式 | 投票或平均 | 加权组合 |
| 典型代表 | 随机森林 | AdaBoost、GBDT |

## 3. 随机森林的基本原理

### 3.1 随机森林的定义

随机森林是由多棵决策树构成的集成模型。对于分类任务，每棵树给出一个类别预测，最终结果由多数投票决定；对于回归任务，每棵树给出一个数值预测，最终结果通常取平均值。

### 3.2 群体智慧的条件

教师用“群体智慧”解释随机森林的有效性。群体智慧成立需要两个条件。

第一，单个基学习器应当具有一定预测能力。如果每棵树都接近随机猜测，集成结果也难以可靠。

第二，不同基学习器之间的相关性不能过高。如果所有树都高度相似，它们会犯相同错误，投票无法抵消误差。

随机森林通过样本随机性和特征随机性降低树之间的相关性。

## 4. 随机森林的随机性来源

### 4.1 样本随机性

随机森林使用 Bootstrap 自助采样，即从原始训练集中有放回地抽取样本生成每棵树的训练集。由于有放回抽样，不同树看到的样本集合不同，模型之间因此产生差异。

### 4.2 特征随机性

在每个节点分裂时，随机森林并不总是在全部特征中寻找最优分裂，而是在随机抽取的一部分特征中寻找最优分裂。这一机制进一步降低树与树之间的相关性。

### 4.3 袋外样本

由于每棵树使用有放回抽样，部分样本不会进入某棵树的训练集。这些未被抽中的样本称为袋外样本。袋外样本可以用于估计模型泛化误差，这相当于一种内置的验证机制。

## 5. n_estimators 与学习曲线

### 5.1 参数含义

`n_estimators` 表示随机森林中树的数量。树的数量较少时，模型方差可能较高；树的数量增加后，模型通常更加稳定。

### 5.2 学习曲线判断

课堂通过学习曲线观察 `n_estimators` 对模型表现的影响。一般而言，随着树数量增加，模型得分会先上升，随后趋于平稳。当继续增加树的数量只能带来极小收益时，就需要考虑计算成本。

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

scores = []
for i in range(1, 201, 10):
    rfc = RandomForestClassifier(n_estimators=i, random_state=0)
    score = cross_val_score(rfc, X, y, cv=10).mean()
    scores.append(score)
```

## 6. 随机森林的优缺点

### 6.1 优点

随机森林能够降低单棵决策树的方差，通常具有较好的预测性能；它可以处理非线性关系和特征交互；对异常值和噪声相对稳健；还能提供特征重要性指标，用于理解哪些变量对预测贡献较大。

### 6.2 缺点

随机森林的可解释性弱于单棵决策树。虽然可以观察特征重要性，但很难像单棵树那样直接展示完整决策规则。此外，随机森林在大规模数据和大量树的情况下计算成本较高。

## 7. 随机森林在经济学中的应用

### 7.1 预测任务

随机森林可以用于企业违约预测、房价预测、金融风险预测、文本分类、政策对象识别等任务。其优势在于能够处理大量特征，并自动捕捉复杂非线性关系。

### 7.2 异质性分析与因果推断

课堂提到，随机森林和广义随机森林可以辅助社会科学中的异质性处理效应分析。传统因果推断常从理论出发指定异质性维度，而树模型可以利用数据驱动方式探索哪些特征可能导致处理效应差异。

这并不意味着机器学习自动解决因果识别问题。机器学习可以帮助发现复杂模式和异质性，但因果解释仍然依赖识别假设、研究设计和经济学理论。

### 7.3 文献语境

课堂提到机器学习与社会科学因果关系的综述文献，以及电力市场、市场缺陷和监管问题中的应用。这说明随机森林在社会科学中既可以作为预测工具，也可以作为辅助识别异质性的工具。
