> 5.2 特征工程：过滤法、嵌入法、包装法


> [!info] 整理原则

## 一、特征选择的基本问题

### 1. 特征工程的三个方向

特征工程包括特征提取、特征创造和特征选择。特征提取是从原始材料中提取可建模变量；特征创造是基于业务理解构造新变量；特征选择是在已有变量中筛选更有价值的变量。

本节重点是特征选择。

### 2. 特征选择的目的

特征选择的目的包括降低维度、减少噪声、提高模型表现、降低计算成本和改善模型解释性。高维数据中并非所有特征都对预测有益，部分特征可能只带来噪声。

## 二、过滤法

### 1. 过滤法的定义

过滤法在模型训练之前使用统计指标筛选特征。它不依赖具体机器学习模型，所以计算速度快，适合在高维数据中先做粗筛。

### 2. 方差过滤

方差过滤的基本思想是：如果一个特征在样本中几乎不变化，它就难以区分样本，也很难为预测提供有效信息。

```python
from sklearn.feature_selection import VarianceThreshold

selector = VarianceThreshold(threshold=0.0)
X_var = selector.fit_transform(X)
```

阈值越高，被删除的特征越多。课堂强调，方差过滤一般先使用较小阈值去除明显无用的特征，再结合其他方法继续筛选。

### 3. 方差过滤与模型表现

过滤掉低方差特征后，模型表现可能上升，也可能下降。如果表现上升，说明被删除的特征主要是噪声；如果表现下降，说明删除过程损失了有效信息。所以，特征选择必须结合模型评价结果判断。

## 三、相关性过滤

### 1. 卡方检验

卡方检验可用于非负特征与分类标签之间的相关性筛选。它检验特征与标签是否独立，卡方统计量越大，说明特征与标签之间的关联越强。

```python
from sklearn.feature_selection import SelectKBest, chi2

X_chi = SelectKBest(chi2, k=300).fit_transform(X, y)
```

`SelectKBest` 用于选择得分最高的 `k` 个特征。如果 `k` 设得过小，可能删除有效特征；如果 `k` 过大，降维效果有限。

### 2. 使用 P 值确定 K

卡方检验可以返回统计量和 P 值。如果 P 值小于显著性水平，一般认为该特征与标签并非相互独立。课堂指出，利用 P 值确定保留特征数量比盲目画大量学习曲线更高效。

### 3. F 检验

F 检验既可以用于分类，也可以用于回归。`f_classif` 用于分类标签，`f_regression` 用于连续标签。F 检验一般要求数据近似满足正态性假设，所以使用前需要关注数据分布。

### 4. 互信息

互信息可以衡量更一般的依赖关系，不局限于线性相关。如果互信息大于 0，说明特征和标签之间存在一定信息关联。互信息适合捕捉非线性依赖，但计算解释不如简单相关系数直观。

## 四、嵌入法

### 1. 嵌入法的定义

嵌入法将特征选择嵌入模型训练过程。模型训练后会产生特征重要性或系数，你据此选择特征。

### 2. SelectFromModel

`SelectFromModel` 可以与具有 `feature_importances_` 或系数属性的模型配合使用，例如随机森林、决策树、带 L1 正则化的线性模型等。

```python
from sklearn.feature_selection import SelectFromModel
from sklearn.ensemble import RandomForestClassifier

rfc = RandomForestClassifier(n_estimators=100, random_state=0)
X_embed = SelectFromModel(rfc, threshold=0.001).fit_transform(X, y)
```

### 3. 阈值选择

嵌入法需要确定特征重要性阈值。阈值较高会保留较少特征，降低维度但可能损失信息；阈值较低会保留较多特征，模型表现可能稳定但降维效果有限。课堂通过学习曲线说明，阈值选择应基于模型表现，而不是随意指定。

### 4. 嵌入法的优缺点

嵌入法比过滤法更贴近具体模型，因为它利用模型训练过程中的重要性信息。但它也更慢，且阈值缺少类似 P 值那样明确的统计标准。

## 五、包装法

### 1. 包装法的定义

包装法将特征选择视为一个搜索问题。它反复训练模型、评价模型，并根据结果逐步保留或剔除特征。包装法一般比过滤法和嵌入法更耗时，但也可能获得更好的特征子集。

### 2. 递归特征消除 RFE

递归特征消除法（Recursive Feature Elimination, RFE）是一种典型包装法。它先使用全部特征训练模型，然后根据特征重要性删除最不重要的一部分特征，再重复这一过程，直到保留指定数量的特征。

```python
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestClassifier

rfc = RandomForestClassifier(random_state=0)
selector = RFE(rfc, n_features_to_select=50, step=50)
X_wrapper = selector.fit_transform(X, y)
```

### 3. support 与 ranking

`support_` 表示每个特征是否被最终选择；`ranking_` 表示特征重要性的排序。排名越小，特征越重要。

### 4. RFECV

`RFECV` 在 RFE 基础上加入交叉验证，用于选择更稳健的特征数量。它能够减少单次样本划分对特征选择结果的影响。

## 六、三类方法比较

### 1. 方法差异

| 方法 | 是否依赖模型 | 计算速度 | 选择依据 | 适用阶段 |
|---|---|---|---|---|
| 过滤法 | 否 | 快 | 方差、卡方、F 检验、互信息 | 高维数据初筛 |
| 嵌入法 | 是 | 中等 | 模型系数或特征重要性 | 与具体模型结合 |
| 包装法 | 是 | 慢 | 反复训练与评价 | 精细特征选择 |

### 2. 推荐顺序

课堂建议在大规模数据中先使用过滤法粗筛，例如方差过滤和相关性过滤；然后根据模型类型选择嵌入法或包装法进一步筛选。过滤法速度最快但较粗糙，嵌入法和包装法更精确但计算成本较高。

## 七、特征选择之外的进一步工作

### 1. 特征创造

特征选择只是从已有特征中筛选变量，而特征创造是构造新的信息表达。在实际竞赛和复杂项目中，模型效果往往更依赖高质量特征创造。

### 2. 特征提取

对于文本、图像和音频等非结构化数据，特征提取是进入建模前的关键步骤。例如，从文本中提取词频、情感、语调或主题，从图像中提取视觉特征，都属于特征提取。

## 八、本节学习重点

### 1. 不同方法解决不同问题

过滤法解决快速粗筛问题，嵌入法解决模型相关的重要性筛选问题，包装法解决精细搜索问题。三者不是互相替代关系，而是可以按数据规模和建模目标组合使用。

### 2. 特征选择必须以模型表现为依据

删除特征后模型表现提升，说明噪声减少；删除特征后模型表现下降，说明有效信息被损失。特征选择的最终标准不是保留特征越少越好，而是在维度、效率和预测表现之间取得平衡。


### 1. 三类方法对比

| 方法 | 是否依赖模型 | 速度 | 精细程度 | 适合什么时候用 |
|---|---|---|---|---|
| 过滤法 | ❌ 不依赖 | ✅ 快 | 粗 | 高维数据先粗筛 |
| 嵌入法 | ✅ 依赖 | 中等 | 较细 | 和具体模型一起筛 |
| 包装法 | ✅ 依赖 | ❌ 慢 | ✅ 最细 | 特征数不太大时精筛 |
