# 4.1 回归类算法概述和实战代码

> [!info] 整理原则
> 本笔记依据课堂字幕整理，将机器学习视角下的回归、计量经济学回归的差异、sklearn 线性回归流程和评价指标整理为课程阅读笔记。

## 1. 回归问题的机器学习视角

### 1.1 回归任务的定义

在机器学习中，回归任务是指标签变量 `Y` 为连续数值的预测问题。例如，预测房价、收入、销售额、股票收益率或企业绩效都属于回归任务。

机器学习中的回归不必然意味着因果解释。模型的主要任务是学习特征 `X` 与连续标签 `Y` 之间的映射关系，并在新样本上给出准确预测。

### 1.2 与计量经济学回归的区别

计量经济学中的回归通常服务于因果解释或参数估计，研究者关心某个解释变量对结果变量的边际影响是否显著、方向如何、大小多少。机器学习中的回归更关注预测误差，系数是否具有可解释性并不是首要标准。

因此，同样是线性回归，在计量经济学中常被理解为解释工具，在机器学习中则被理解为预测模型。

## 2. 线性回归模型

### 2.1 模型形式

线性回归可以写作：

$$
\hat{y}=\beta_0+\beta_1x_1+\cdots+\beta_kx_k
$$

其中，$\hat{y}$ 是预测值，$x_1,\ldots,x_k$ 是特征，$\beta_0,\ldots,\beta_k$ 是模型参数。机器学习中，模型训练的目标是使预测值尽可能接近真实值。

### 2.2 最小二乘思想

线性回归通常通过最小化残差平方和估计参数：

$$
\min_{\beta}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

这一目标函数使大误差受到更大惩罚，因此对异常值较敏感。

## 3. sklearn 线性回归流程

### 3.1 数据准备

机器学习建模需要准备特征矩阵 `X` 和标签向量 `y`。随后使用 `train_test_split` 划分训练集和测试集。

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=0
)
```

### 3.2 建模三步

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(X_train, y_train)
y_pred = lr.predict(X_test)
```

第一步实例化模型，第二步使用训练集拟合，第三步对测试集进行预测。

## 4. 回归评价指标

### 4.1 均方误差 MSE

均方误差定义为：

$$
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

MSE 越小，说明预测误差越小。由于误差被平方，大误差会被放大，因此 MSE 对异常值较敏感。

### 4.2 平均绝对误差 MAE

平均绝对误差定义为：

$$
MAE=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|
$$

MAE 的单位与原始标签一致，解释更直观。它表示平均预测偏差的绝对大小。

### 4.3 R²

决定系数 $R^2$ 衡量模型相对于均值预测的改进程度：

$$
R^2=1-\frac{\sum_i(y_i-\hat{y}_i)^2}{\sum_i(y_i-\bar{y})^2}
$$

如果模型预测效果优于均值模型，$R^2$ 较高；如果模型还不如直接预测均值，$R^2$ 可以为负。课堂特别强调，$R^2$ 并不必然位于 0 到 1 之间。

## 5. sklearn 中的负均方误差

### 5.1 scoring 规则

`cross_val_score` 中的评分指标通常遵循“越大越好”的规则。但 MSE 本身是损失函数，越小越好。为了统一评分方向，sklearn 使用 `neg_mean_squared_error` 表示负的均方误差。

```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(
    lr, X, y, cv=10, scoring="neg_mean_squared_error"
)
```

如果需要解释为 MSE，应取相反数。

### 5.2 参数顺序

评价函数通常要求真实值在前，预测值在后：

```python
from sklearn.metrics import mean_squared_error, r2_score

mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)
```

养成 `y_true` 在前、`y_pred` 在后的习惯，有助于避免后续使用非对称指标时出错。

## 6. 本节学习重点

### 6.1 思维转换

学习机器学习回归时，首先要从“解释某个系数”转向“预测连续结果”。这并不意味着系数解释不重要，而是说明不同任务有不同评价标准。

### 6.2 指标解释

MSE、MAE 和 R² 反映不同维度的模型表现。MSE 重视大误差，MAE 直观反映平均偏差，R² 反映相对于均值基准的改进。理解指标含义比机械调用函数更重要。
