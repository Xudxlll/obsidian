# 4.3 多项式回归与线性、非线性模型对比

> [!info] 整理原则
> 本笔记依据课堂字幕整理，将线性概念、非线性数据、分箱、多项式特征和广义线性理解整理为学术化阅读笔记。

## 1. 重新理解“线性”

### 1.1 变量关系的线性

当自变量变化引起因变量按固定斜率变化时，可以认为二者之间存在变量关系意义上的线性。例如，若房屋面积每增加一单位，房价平均增加固定数额，则该关系近似线性。

### 1.2 参数形式的线性

模型是否线性，还可以从参数角度理解。只要模型对参数 $\beta$ 是线性的，即使特征中包含 $x^2$、$x^3$ 或交互项，也可以被视为参数线性模型。例如：

$$
y=\beta_0+\beta_1x+\beta_2x^2+\epsilon
$$

该模型对 $x$ 的关系是非线性的，但对参数 $\beta_0,\beta_1,\beta_2$ 是线性的。

### 1.3 易混点

“线性模型”不等于“只能拟合直线”。多项式回归说明，经过特征变换后，线性回归可以拟合曲线。

## 2. 线性模型与非线性数据

### 2.1 线性模型拟合非线性数据的局限

如果真实数据关系呈曲线，而模型只能拟合直线，则模型会产生系统性偏差。这是欠拟合的一种表现。

### 2.2 特征变换的作用

解决非线性问题的一种方法不是立即更换模型，而是改造特征。例如，将原始特征 $x$ 扩展为 $x^2$、$x^3$ 或交互项，可以让线性回归在高维特征空间中表达非线性关系。

## 3. 分箱处理非线性问题

### 3.1 分箱的含义

分箱是将连续变量划分为若干区间，并将每个区间作为离散特征处理。例如，将年龄划分为青年、中年、老年，或将收入划分为低收入、中收入、高收入。

### 3.2 分箱的模型含义

分箱允许模型学习不同区间中的不同预测水平。它适合处理阈值效应、阶梯式变化或非平滑关系。

### 3.3 箱数选择

箱数过少会造成信息损失，箱数过多会增加模型复杂度并可能过拟合。因此，箱数应通过验证集表现、交叉验证或学习曲线选择。

```python
kbins = KBinsDiscretizer(n_bins=10, encode="onehot", strategy="uniform")

```

## 4. 多项式回归

### 4.1 多项式特征

多项式回归的核心是使用 `PolynomialFeatures` 生成高次项和交互项。它并不是一种全新的回归估计方法，而是“先扩展特征，再使用线性回归”。

```python
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline

model = make_pipeline(
    PolynomialFeatures(degree=3, include_bias=False),
    LinearRegression()
)
```

### 4.2 高维呈现，低维解释

教师将多项式回归概括为“高维呈现，低维解释”。原始数据可能只有一个或少数几个变量，但经过多项式扩展后，模型在高维特征空间中拟合关系。最终仍然可以将预测曲线投射回原始变量空间进行解释。

### 4.3 多项式次数与过拟合

多项式次数越高，模型表达能力越强，但过拟合风险也越高。低阶多项式可能欠拟合，高阶多项式可能在训练集上过度贴合样本点。因此，多项式次数需要通过验证集或交叉验证选择。

## 5. 线性模型与非线性模型的比较

### 5.1 线性模型的优点

线性模型结构简单、训练速度快、可解释性较强，适合作为基准模型。在线性关系近似成立时，线性模型能够以较低复杂度获得稳定预测。

### 5.2 非线性模型的优点

非线性模型能够捕捉曲线、阈值、交互和复杂边界。决策树、随机森林、多项式回归和分箱方法都可以表达非线性结构。

### 5.3 模型选择原则

模型是否“高级”不是选择依据。应当根据数据关系、预测表现、解释需求和过拟合风险选择模型。若简单模型已经表现良好，复杂模型未必必要。

## 6. 狭义线性模型与广义线性理解

### 6.1 狭义线性

狭义线性通常指变量之间以直线形式相关，例如 $y=\beta_0+\beta_1x$。

### 6.2 广义线性理解

广义上，只要模型对参数线性，就可以通过扩展特征表达更复杂的关系。多项式回归正体现了这一点：它在原始变量上表现为非线性曲线，但在扩展后的特征空间中仍然使用线性回归估计参数。

## 7. 本节学习重点

### 7.1 线性不是直线的同义词

理解多项式回归的关键，是区分“变量关系是否线性”和“模型对参数是否线性”。这是学习回归模型时最容易混淆的概念之一。

### 7.2 特征变换是建模能力的一部分

多项式特征、分箱和交互项都属于特征工程。很多非线性问题并不一定需要更复杂的算法，适当的特征变换即可显著增强模型表达能力。
