# 🍎 Mac 快捷键以及功能汇总

> 这篇笔记用于快速查询 Mac 系统快捷键，以及当前通过 **Raycast** 绑定的个人快捷键。

## 符号说明

| 符号 | 含义 |
|---|---|
| `⌘` | Command |
| `⌥` | Option |
| `⌃` | Control |
| `⇧` | Shift |
| `fn` | Function |

---

## 🚀 Raycast 自定义快捷键

> 目前绑定快捷键的软件为 **Raycast**。以下快捷键属于个人配置，不一定是 macOS 默认行为。

### 应用快速打开 / 隐藏

| 快捷键 | 功能 |
|---|---|
| `⌘ + 1` | 打开微信；再次按下隐藏窗口 |
| `⌘ + 2` | 打开词典；再次按下隐藏窗口 |
| `⌘ + 3` | 打开 VPN；再次按下隐藏窗口 |
| `⌘ + 4` | 打开历史剪切板；再次按下隐藏窗口 |

### 窗口管理

| 快捷键     | 功能                                        |
| ------- | ----------------------------------------- |
| `⌘ + ←` | 当前窗口左半屏；连续按可在 `1/2 → 2/3 → 1/3 → 1/2` 间循环 |
| `⌘ + →` | 当前窗口右半屏；连续按可在 `1/2 → 2/3 → 1/3 → 1/2` 间循环 |
| `⌘ + ↑` | 最大化当前窗口                                   |
| `⌘ + ↓` | 当前窗口自适应大小并居中                              |
|         |                                           |

## ✍️ 文本编辑快捷键

### 格式编辑

| 快捷键 | 功能 |
|---|---|
| `⌘ + B` | 加粗 |
| `⌘ + I` | 斜体 |
| `⌘ + U` | 下划线 |
| `⌘ + K` | 插入链接 |
| `⌘ + [` | 左对齐 |
| `⌘ + ]` | 右对齐 |
| `⌘ + ⇧ + \|` | 居中对齐 |
| `⌘ + +` | 增大字号 |
| `⌘ + -` | 减小字号 |
| `⌘ + ⇧ + C` | 复制格式 |
| `⌘ + ⇧ + V` | 粘贴格式 |

### 光标移动

| 快捷键 | 功能 |
|---|---|
| `⌘ + ↑` | 移到文档开头 |
| `⌘ + ↓` | 移到文档结尾 |
| `⌘ + ←` | 移到行首 |
| `⌘ + →` | 移到行尾 |
| `⌃ + B` | 左移一个字符 |
| `⌃ + F` | 右移一个字符 |
| `⌃ + P` | 上移一行 |
| `⌃ + N` | 下移一行 |

### 文本选择与删除

| 快捷键 | 功能 |
|---|---|
| `⇧ + ← / →` | 选择文字 |
| `⌃ + O` | 在光标后插入新行 |
| `fn + Delete` | 向后删除 |
