# Obsidian 快捷键

> [!info]
> 本笔记汇总 Obsidian 在 macOS 上常用的默认快捷键，并将需要自行设置的快捷键单独列出。

## 按键符号

| 符号 | 按键 |
| --- | --- |
| `⌘` | Command |
| `⌥` | Option |
| `⌃` | Control |
| `⇧` | Shift |
| `⇥` | Tab |
| `↩` | Enter / Return |

## 最常用快捷键

| 功能 | 快捷键 |
| --- | --- |
| 打开命令面板 | `⌘P` |
| 快速切换、打开或创建笔记 | `⌘O` |
| 新建笔记 | `⌘N` |
| 搜索当前笔记 | `⌘F` |
| 搜索整个仓库 | `⌘⇧F` |
| 阅读模式与编辑模式之间切换 | `⌘E` |
| 新建标签页 | `⌘T` |
| 关闭当前标签页 | `⌘W` |

## 阅读模式、实时阅览与源码模式

Obsidian 的三个常见显示状态可以分为两类：

| 类型 | 模式 | 用途 |
| --- | --- | --- |
| 视图 | 阅读模式 | 只显示渲染后的笔记，适合阅读，不适合直接编辑 |
| 编辑模式 | 实时阅览 | 隐藏大部分 Markdown 符号，同时可以编辑，适合日常使用 |
| 编辑模式 | 源码模式 | 显示完整 Markdown 源码，适合精确修改格式 |

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 阅读模式 ↔ 编辑模式 | `⌘E` | 回到编辑模式时，会恢复上一次使用的实时阅览或源码模式 |
| 实时阅览 ↔ 源码模式 | 默认未设置 | 建议自行设置为 `⌘⇧E` |

> [!tip]
> 如果需要使用 Note Toolbar 给选中文字高亮、加粗、斜体或添加删除线，应使用实时阅览或源码模式。阅读模式没有 Markdown 编辑器选区，编辑命令会显示为不可用。

## 文字格式与编辑

| 功能 | 快捷键 |
| --- | --- |
| 加粗 | `⌘B` |
| 斜体 | `⌘I` |
| 撤销 | `⌘Z` |
| 重做 | `⌘⇧Z` |
| 复制 | `⌘C` |
| 剪切 | `⌘X` |
| 粘贴 | `⌘V` |
| 无格式粘贴 | `⌘⇧V` |
| 全选 | `⌘A` |
| 删除当前行 | `⌘⇧K` |
| 删除前一个单词 | `⌥Backspace` |
| 删除到当前行开头 | `⌘Backspace` |
| 删除到当前行结尾 | `⌘Delete` |

> [!note]
> 没有选中文字时，`⌘C` 会复制当前段落，`⌘X` 会剪切当前段落。

## 光标移动与文本选区

| 功能 | 快捷键 |
| --- | --- |
| 按单词向左或向右移动 | `⌥←` / `⌥→` |
| 移动到当前行开头或结尾 | `⌘←` / `⌘→` |
| 移动到笔记开头或结尾 | `⌘↑` / `⌘↓` |
| 按单词向左或向右扩展选区 | `⌥⇧←` / `⌥⇧→` |
| 扩展选区到当前行开头或结尾 | `⌘⇧←` / `⌘⇧→` |
| 扩展选区到笔记开头或结尾 | `⌘⇧↑` / `⌘⇧↓` |
| 添加多个光标 | `⌥` + 鼠标点击 |
| 创建矩形选区 | `⌥⇧` + 鼠标拖动 |
| 取消或简化选区 | `Escape` |

## 标签页与链接

| 功能 | 快捷键或操作 |
| --- | --- |
| 新建标签页 | `⌘T` |
| 关闭当前标签页 | `⌘W` |
| 切换到下一个标签页 | `⌃⇥` |
| 切换到上一个标签页 | `⌃⇧⇥` |
| 切换到第 1～9 个标签页 | `⌘1` ～ `⌘9` |
| 在新标签页打开链接 | `⌘` + 点击链接 |
| 在新标签组打开链接 | `⌘⌥` + 点击链接 |
| 在新窗口打开链接 | `⌘⌥⇧` + 点击链接 |
| 在快速切换器中用新标签页打开笔记 | `⌘Enter` |

## 建议自行设置的快捷键

进入 `设置 → 快捷键`，搜索对应命令名称后添加快捷键。

| 命令名称 | 建议快捷键 | 用途 |
| --- | --- | --- |
| 切换实时阅览/源码模式 | `⌘⇧E` | 在两种编辑模式之间快速切换 |
| 切换高亮文本（Highlight） | `⌘⇧H` | 给选中文字添加或取消高亮 |
| 切换删除线（Strikethrough） | `⌘⌥S` | 给选中文字添加或取消删除线 |

> [!warning]
> 自定义快捷键前应检查是否与系统、Obsidian 插件或其他命令冲突。

## 快捷键设置与检查

1. 打开 `设置 → 快捷键`。
2. 使用搜索框查找命令。
3. 点击命令右侧的加号。
4. 按下想要使用的快捷键并保存。
5. 点击筛选按钮，可以只查看已经分配快捷键的命令。

也可以按 `⌘P` 打开命令面板。命令名称右侧如果显示快捷键，说明该命令已经设置。
