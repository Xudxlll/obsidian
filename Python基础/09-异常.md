# 一、异常

## 1.1 什么是异常？

**异常**（`Exception`）是指程序在运行过程中发生的错误或意外情况，它会**中断程序**的正常执行流程。

异常通常是由于程序中的错误、用当、外部条件变化（如文件不存在、网络中断等）或其他不可预见的情况引起的。

在编程中，异常是一种用于处理错误的机制。通过异常处理，可以捕获和处理这些错误，从而避免程序直接崩溃，并提供更好的用户体验。

**异常的特点**

● 运行时错误：异常是在程序运行过程中发生的错误，而不是编译时的错误。

● 中断程序执行：当异常发生时，程序会停止当前的执行，转而寻找相应的异常处理程序。

● 可捕获和处理：通过异常处理机制（如 `try...except`），程序可以捕获异常并采取适当的措施，而不是直接退出。

● 层次化结构：异常在 `Python` 中是基于类的，所有异常类都继承自内置的 `BaseException` 类。

`Python` 中的异常分为内置异常和用户自定义异常。

所有异常都继承自 `BaseException`，内置异常是 `Python` 提供的标准异常类型，而用户可以通过继承 `Exception` 或其他异常类来自定义异常类型。

`Python` 自带的内置异常会在特定情况下由 `Python` 解释器自动触发。也就是说，当程序运行到某些错误的代码时，`Python` 会自动检测并抛出相应的异常。

## 1.2 异常处理机制

`Python` 提供了一套异常处理机制，主要通过 `try...except` 块来捕获和处理异常。

```python

try:
    # 可能会引发异常的代码
    pass
except ExceptionType1 as e:
    # 当捕获到 ExceptionType1 时执行的代码
    pass
except ExceptionType2 as e:
    # 当捕获到 ExceptionType2 时执行的代码
    pass
except Exception as e:
    # 捕获其他所有异常
    pass
else:
    # 如果 try 块中没有发生异常，则执行此处代码
    pass
finally:
    # 无论是否发生异常，都会执行此处代码
    pass

```

各部分说明

**1.`try` 块**

包含可能会引发异常的代码。

如果代码运行正常，程序会跳过 `except` 块，直接进入 `else` 块（如果存在）或继续执行后续代码。

如果代码引发异常，会跳过 `try` 块剩余的代码，进入与异常类型匹配的 `except` 块。

 **2.`except` 块**

用于捕获异常并处理它。

可以指定捕获特定类型的异常（如 `ZeroDivisionError`、`ValueError` 等），也可以使用通用的 `Exception` 来捕获所有异常。

`as e` 的作用是将异常对象赋值给变量 `e`，以便访问异常的详细信息。

**3.`else` 块**

如果 `try` 块中的代码没有发生异常，则会执行 `else` 块中的代码。

`else` 块通常用于处理没有异常时的逻辑。

**4.`finally` 块**

无论是否发生异常，都会执行 `finally` 块中的代码。

`finally` 块通常用于清理资源，例如关闭文件、释放锁、断开网络连接等。

## 1.3 异常类型

`Python` 提供了多种内置的异常类型，每种异常都表示一种特定的错误。以下是一些常见的异常类型：

| 异常类型            | 描述                                                         |
| ------------------- | ------------------------------------------------------------ |
| `Exception`         | 所有异常的基类，所有异常类都继承自它。                       |
| `AttributeError`    | 试图访问对象不存在的属性时引发，比如 `obj.non_existent_attribute`。 |
| `IndexError`        | 列表或元组等序列类型访问超出范围的索引时引发。               |
| `KeyError`          | 试图访问字典中不存在的键时引发。                             |
| `ValueError`        | 函数接收到参数类型正确，但值不合适时引发。                   |
| `TypeError`         | 对不支持的操作或不兼容的类型执行操作时引发。                 |
| `ZeroDivisionError` | 除以零时引发的异常。                                         |
| `FileNotFoundError` | 试图打开一个不存在的文件时引发。                             |
| `NameError`         | 试图访问未声明的变量时引发。                                 |
| `IOError`           | 输入/输出操作失败时引发（如文件无法打开）。                  |
| `ImportError`       | 导入模块失败时引发。                                         |
| `KeyBoardInterrupt` | 用户中断程序执行时（通常是按下 `Ctrl+C`）。                  |

## 1.4 自定义异常

在 `Python` 中，可以通过继承 `Exception` 类来自定义异常。

自定义异常的步骤：

第1步： 创建自定义异常类，并继承自 `Exception` 类或者子类。

第2步： 根据需要为异常类添加 `__init__` 方法和自定义属性。

第3步： 在程序代码中，通过逻辑判断决定是否需要抛出异常，并使用 `raise` 抛出异常。

第4步： 使用 `try-except` 捕获和处理异常，根据业务需求进行相应的处理。

```python

class CustomException(Exception):
    """自定义异常类的描述"""
    
    def __init__(self, message):
        # 初始化异常信息
        self.message = message
        super().__init__(self.message)

# 使用自定义异常
try:
    # 可能引发异常的代码
    raise CustomException("这是一个自定义异常")
except CustomException as e:
    # 捕获并处理自定义异常
    print(f"捕获到自定义异常：{e}")

```

**自定义异常的关键点**

**1.继承 `Exception` 类**：

● 所有异常类都需要继承自 `Python` 的内置 `Exception` 类。

● 这使得自定义异常可以被标准的异常处理机制捕获。

**2.`__init__` 方法**：

● 定义构造函数 `__init__` 来初始化异常的描述信息。

● 使用 `super().__init__(message)` 调用父类的构造函数，以便继承父类的功能。

**3.自定义异常类的描述**：

● 可以通过为类添加文档字符串（`docstring`）描述异常的用途。

● 也可以在类中添加额外的属性或方法，提供更多的上下文信息。

```python

class InvalidAgeError(Exception):
    """自定义异常：无效年龄"""
    
    def __init__(self, age, message="年龄无效，必须是正整数！"):
        self.age = age
        self.message = message
        super().__init__(self.message)

# 使用自定义异常
def set_age(age):
    if age < 0:
        raise InvalidAgeError(age)
    print(f"年龄设置为：{age}")

try:
    set_age(-5)
except InvalidAgeError as e:
    print(f"捕获到异常：{e.message} (输入的年龄：{e.age})")

```

## 1.5 `raise`

在 `Python` 中，**`raise`** 是一个关键字，用于主动引发异常。

它可以将程序的控制流转移到异常处理机制中，从而终止当前代码的正常执行，并引发指定的异常。

通过使用 `raise`，程序员可以显式地表示某些错误或异常情况。

`raise` 的基本语法

```python

raise ExceptionType("错误信息")

```
