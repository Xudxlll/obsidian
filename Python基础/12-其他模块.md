# 一、`urllib`

## 1.1 概述

`urllib` 是 `Python` 标准库里用于处理 `URL` 与发起/处理 `HTTP` 请求的包。

`urllib`模块提供了从构造 `URL`、编码参数、发送请求、处理响应、处理错误、解析 `robots` 协议等一整套基础能力。

`urllib`模块主要有5个子模块构成：

**1.`urllib.parse`**

**2.`urllib.request`**

**3.`urllib.error`**

**4.`urllib.response`**

**5.`urllib.robotparser`**

## 1.2 `urllib.parse`模块

### 1.2.1 概述

`urllib.parse` 是 `Python` 标准库 `urllib` 包中负责 `URL` 的解析、拼接与编码/解码 的子模块。

`urllib.parse`模块不负责发 `HTTP` 请求（那是 `urllib.request`），而是专注于把 `URL` 当作字符串/结构化数据来处理。

**典型用途**

● 拆分 `URL` 各组成部分（`scheme`/`host`/`path`/`query`/`fragment`）

● 合并/拼接 `URL`（相对路径转绝对路径）

● 查询参数（`query string`）的编码与解析

● `URL` 转义/反转义（百分号编码 `percent-encoding`）

### 1.2.1 `URL` 分解与组合

● `urlparse(urlstring, scheme='', allow_fragments=True)`

将 `URL` 字符串分解为 6 个部分（`scheme、netloc、path、params、query、fragment`）。

返回值：`ParseResult`（类似元组，可通过属性访问各部分）

**示例**：

```python
from urllib.parse import urlparse

result = urlparse('https://user:pass@www.example.com:8080/path;params?query=abc#frag')
print(result)
# ParseResult(scheme='https', netloc='user:pass@www.example.com:8080', path='/path', params='params', query='query=abc', fragment='frag')

print(result.scheme)    # https
print(result.netloc)    # user:pass@www.example.com:8080
print(result.path)      # /path
print(result.params)    # params
print(result.query)     # query=abc
print(result.fragment)  # frag
```

● `urlunparse(parts)`

将 6 个部分（元组或列表）合成 `URL` 字符串。

长度为 6 的元组或列表（`scheme, netloc, path, params, query, fragment`）

```python
from urllib.parse import urlunparse

url = urlunparse(('https', 'www.example.com', '/index.html', '', 'id=1', 'top'))
print(url)  # https://www.example.com/index.html?id=1#top
```

● `urlsplit(urlstring, scheme='', allow_fragments=True)`

类似 `urlparse`，但不解析 `params`，只分为 5 部分（`scheme, netloc, path, query, fragment`）。

```python
from urllib.parse import urlsplit

result = urlsplit('https://www.example.com/path;params?query=abc#frag')
print(result)
# SplitResult(scheme='https', netloc='www.example.com', path='/path;params', query='query=abc', fragment='frag')
```

● `urlunsplit(parts)`

与 `urlsplit` 相反，将 5 个部分合成 `URL` 字符串。

长度为 5 的元组或列表

```python
from urllib.parse import urlunsplit

url = urlunsplit(('https', 'www.example.com', '/index.html', 'id=1', 'top'))
print(url)  # https://www.example.com/index.html?id=1#top
```

### 1.2.2. `URL` 拼接

● `urljoin(base, url)`

根据基准 `URL` 拼接相对 `URL`，得到绝对 `URL`。

```python
from urllib.parse import urljoin

print(urljoin('https://www.example.com/dir/', 'sub/page.html'))
# https://www.example.com/dir/sub/page.html
```

### 1.2.3 `URL` 编码与解码

● `quote(string, safe='/', encoding=None, errors=None)`

将字符串编码为 `URL` 安全格式（百分号编码）。

参数

`string`：待编码字符串

`safe`：不需要编码的字符（默认 `/` 保留）

```python
from urllib.parse import quote

print(quote('中国'))  # %E4%B8%AD%E5%9B%BD
print(quote('a/b', safe=''))  # a%2Fb
```

● `unquote(string, encoding='utf-8', errors='replace')`

将百分号编码的字符串解码为普通字符串。

```python
from urllib.parse import unquote

print(unquote('%E4%B8%AD%E5%9B%BD'))  # 中国
```

● `quote_plus(string, safe='', encoding=None, errors=None)`

类似 `quote`，但会将空格编码为 `+`，常用于 `query string`。

```python
from urllib.parse import quote_plus

print(quote_plus('a b+c'))  # a+b%2Bc
```

● `unquote_plus(string, encoding='utf-8', errors='replace')`

解码 `quote_plus` 编码的字符串，将 `+` 转为空格。

```python
from urllib.parse import unquote_plus

print(unquote_plus('a+b%2Bc'))  # a b+c
```

### 1.2.4 查询参数处理

● `urlencode(query, doseq=False, safe='', encoding=None, errors=None, quote_via=quote_plus)`

将字典或序列转换为 URL 查询字符串（`key1=value1&key2=value2`）。

`query`：字典或二元组序列

`doseq`：为 `True` 时，值为列表会展开多个同名参数

```python
from urllib.parse import urlencode

params = {'name': 'Tom', 'age': 18}
print(urlencode(params))  # name=Tom&age=18

params = {'name': ['Tom', 'Jerry'], 'age': 18}
print(urlencode(params, doseq=True))  # name=Tom&name=Jerry&age=18
```

● `parse_qs(qs, keep_blank_values=False, strict_parsing=False, encoding='utf-8', errors='replace', max_num_fields=None)`

将查询字符串解析为字典，值都是列表。

```python
from urllib.parse import parse_qs

qs = 'name=Tom&name=Jerry&age=18'
print(parse_qs(qs))  # {'name': ['Tom', 'Jerry'], 'age': ['18']}
```

● `parse_qsl(qs, keep_blank_values=False, strict_parsing=False, encoding='utf-8', errors='replace', max_num_fields=None)`

将查询字符串解析为`（key, value）`元组列表。

```python
from urllib.parse import parse_qsl

qs = 'name=Tom&name=Jerry&age=18'
print(parse_qsl(qs))  # [('name', 'Tom'), ('name', 'Jerry'), ('age', '18')]
```

### 1.2.5 `URL` 组件合并与拆分

● `splitquery(url)`

将 `URL` 拆分为 (主干, 查询字符串)。

```python
from urllib.parse import splitquery

print(splitquery('https://www.example.com/index.html?id=1'))
# ('https://www.example.com/index.html', 'id=1')
```

● `splittag(url)`

将 `URL` 拆分为 (主干, `fragment`)。

```python
from urllib.parse import splittag

print(splittag('https://www.example.com/index.html#top'))
# ('https://www.example.com/index.html', 'top')
```

● `splituser(host)`

将 `user:password@host` 拆分为 (`user:password, host`)。

```python
from urllib.parse import splituser

print(splituser('user:pass@www.example.com'))
# ('user:pass', 'www.example.com')
```

● `splitpasswd(userinfo)`

将 `user:password` 拆分为 (`user, password`)。

```python
from urllib.parse import splitpasswd

print(splitpasswd('user:pass'))
# ('user', 'pass')
```

# 二、`mimetypes`

## 2.1 概述

`mimetypes` 是 `Python` 标准库中用于处理 **文件扩展名** 和 **MIME 类型** 对应关系的模块。

它不是第三方模块，不需要使用 `pip install` 安装，可以直接导入：

```python
import mimetypes
```

不过如果严格区分：

● `mimetypes` 属于 **标准库模块**，也就是 Python 自带的模块。

● 它不是严格意义上的 **内置模块**。内置模块通常指解释器内部直接提供的模块，比如 `sys`、`time`、`math` 等。

● 它也不是 **第三方模块**。第三方模块一般需要通过 `pip install` 安装，比如 `requests`、`pandas`、`flask` 等。

所以可以记成：

> `mimetypes` 是 Python 自带的标准库模块，不需要安装，主要用于根据文件名猜 MIME 类型，或者根据 MIME 类型猜文件后缀。

## 2.2 什么是 MIME 类型

`MIME` 类型是一种描述文件内容类型的字符串，常见格式为：

```text
大类型/子类型
```

例如：

```text
PNG 图片：image/png
JPG 图片：image/jpeg 或 image/jpg
TXT 文件：text/plain
HTML 文件：text/html
JSON 文件：application/json
```

在网络请求、文件上传、浏览器识别文件类型时，经常会用到 MIME 类型。

例如服务器返回一张 PNG 图片时，响应头里可能会包含：

```text
Content-Type: image/png
```

这表示返回的数据是一张 PNG 图片。

## 2.3 `guess_type()`：根据文件名猜 MIME 类型

`guess_type()` 用来根据文件名或路径中的扩展名，猜测文件的 MIME 类型。

语法：

```python
mimetypes.guess_type(url, strict=True)
```

常用写法：

```python
import mimetypes

mime_type, encoding = mimetypes.guess_type('images/0612/123.png')

print(mime_type)
print(encoding)
```

输出结果：

```python
image/png
None
```

其中：

● `mime_type` 表示猜出来的 MIME 类型，比如 `image/png`。

● `encoding` 表示编码方式，普通图片、文本通常是 `None`。

需要注意：

> `guess_type()` 主要是根据文件后缀名判断类型，并不会真正打开文件检查内容。

例如：

```python
import mimetypes

print(mimetypes.guess_type('a.png'))
print(mimetypes.guess_type('a.txt'))
print(mimetypes.guess_type('a.html'))
print(mimetypes.guess_type('a.json'))
```

可能输出：

```python
('image/png', None)
('text/plain', None)
('text/html', None)
('application/json', None)
```

## 2.4 `guess_extension()`：根据 MIME 类型猜文件后缀

`guess_extension()` 用来根据 MIME 类型，反推出常见文件后缀。

语法：

```python
mimetypes.guess_extension(type, strict=True)
```

示例：

```python
import mimetypes

extension = mimetypes.guess_extension('image/png')
print(extension)
```

输出结果：

```python
.png
```

再例如：

```python
import mimetypes

print(mimetypes.guess_extension('text/plain'))
print(mimetypes.guess_extension('image/jpeg'))
print(mimetypes.guess_extension('application/json'))
```

可能输出：

```python
.txt
.jpg
.json
```

## 2.5 结合使用：先猜 MIME 类型，再猜后缀

下面这段代码就是先根据文件路径猜出 MIME 类型，再根据 MIME 类型反推出文件后缀：

```python
import mimetypes

types, _ = mimetypes.guess_type('images/0612/123.png')

extension = mimetypes.guess_extension(types)

print(extension)
```

执行过程可以拆成三步理解：

**第一步：根据路径猜 MIME 类型**

```python
types, _ = mimetypes.guess_type('images/0612/123.png')
```

因为文件路径以 `.png` 结尾，所以 `types` 的值是：

```python
'image/png'
```

这里的 `_` 用来接收第二个返回值，表示这个返回值暂时不用。

**第二步：根据 MIME 类型猜文件后缀**

```python
extension = mimetypes.guess_extension(types)
```

相当于执行：

```python
extension = mimetypes.guess_extension('image/png')
```

所以 `extension` 的值是：

```python
'.png'
```

**第三步：打印结果**

```python
print(extension)
```

输出：

```python
.png
```

## 2.6 常见注意点

### 2.6.1 它只根据后缀名判断

`mimetypes` 不会读取文件真实内容，只看文件名后缀。

例如：

```python
import mimetypes

print(mimetypes.guess_type('fake.png'))
```

即使 `fake.png` 不是一张真正的图片，只要名字以 `.png` 结尾，它也可能返回：

```python
('image/png', None)
```

### 2.6.2 没有后缀或未知后缀可能返回 `None`

```python
import mimetypes

print(mimetypes.guess_type('README'))
print(mimetypes.guess_type('file.unknownxxx'))
```

可能输出：

```python
(None, None)
(None, None)
```

所以实际使用时，可以先判断结果是否为 `None`：

```python
import mimetypes

mime_type, _ = mimetypes.guess_type('file.unknownxxx')

if mime_type is None:
    print('无法判断文件类型')
else:
    print(mime_type)
```

### 2.6.3 `image/jpeg` 通常对应 `.jpg` 或 `.jpeg`

同一种 MIME 类型可能对应多个文件后缀。

例如：

```text
image/jpeg
```

既可以对应：

```text
.jpg
.jpeg
```

所以 `guess_extension('image/jpeg')` 返回哪一个，取决于 Python 当前的 MIME 类型映射规则。

## 2.7 小结

`mimetypes` 模块可以简单记为：

```text
文件后缀  <==>  MIME 类型
```

常用函数有两个：

● `mimetypes.guess_type(文件名或路径)`：根据文件名猜 MIME 类型。

● `mimetypes.guess_extension(MIME类型)`：根据 MIME 类型猜文件后缀。

它的核心特点是：

● Python 标准库模块，不是第三方模块。

● 不需要安装，直接 `import mimetypes`。

● 主要根据文件扩展名判断，不会真正检查文件内容。
