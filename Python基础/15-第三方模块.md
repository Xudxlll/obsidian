# 一、`requests`

## 1.1 概述

`requests` 是 Python 中非常常用的 **第三方 HTTP 请求库**。

它主要用于让 Python 程序向服务器发送网络请求，并接收服务器返回的数据。

例如：

● 查询天气接口

● 调用 AI 接口

● 请求网页内容

● 上传文件

● 下载图片、PDF、压缩包

● 调用后端 API

`requests` 不是 Python 标准库模块，使用前通常需要先安装：

```bash
pip install requests
```

导入方式：

```python
import requests
```

可以简单记成：

```text
urllib：Python 自带，偏底层
requests：第三方库，偏简单易用
```

`requests` 最常见的使用流程是：

```text
准备 URL
准备请求参数
发送请求
得到响应 response
判断状态码
解析响应内容
```

例如：

```python
import requests

url = 'https://apis.juhe.cn/simpleWeather/query'

params = {
    'key': '你的APIKey',
    'city': '北京',
}

response = requests.get(url, params=params)

if response.status_code == 200:
    result = response.json()
    print(result)
else:
    print('请求异常')
```

这段代码的意思是：

```text
使用 GET 请求访问天气接口，并把 key 和 city 作为查询参数发送给服务器。
```

## 1.2 安装与导入

### 1.2.1 安装 `requests`

因为 `requests` 是第三方模块，所以不是 Python 安装后天然就有的。

如果直接运行：

```python
import requests
```

出现类似错误：

```text
ModuleNotFoundError: No module named 'requests'
```

就说明当前 Python 环境里还没有安装 `requests`。

可以在终端中安装：

```bash
pip install requests
```

如果电脑上有多个 Python 版本，也可以用：

```bash
python -m pip install requests
```

或者：

```bash
python3 -m pip install requests
```

### 1.2.2 导入 `requests`

安装完成后，在代码中导入：

```python
import requests
```

导入之后，就可以使用：

```python
requests.get()
requests.post()
requests.put()
requests.delete()
```

这些方法来发送不同类型的 HTTP 请求。

## 1.3 HTTP 请求基础

### 1.3.1 什么是 URL

`URL` 是网络资源的地址。

例如：

```text
https://apis.juhe.cn/simpleWeather/query
```

可以把它理解成：

```text
服务器上某个接口的具体位置
```

一个 URL 通常可以拆成几部分：

```text
https://apis.juhe.cn/simpleWeather/query?key=xxx&city=北京
```

其中：

● `https`：协议

● `apis.juhe.cn`：域名

● `/simpleWeather/query`：路径

● `?key=xxx&city=北京`：查询参数

### 1.3.2 什么是 HTTP 请求

当 Python 程序访问一个接口时，本质上是在向服务器发送 HTTP 请求。

常见请求方法有：

● `GET`：获取数据

● `POST`：提交数据

● `PUT`：整体更新数据

● `PATCH`：局部更新数据

● `DELETE`：删除数据

在 `requests` 中，对应写法是：

```python
requests.get(url)
requests.post(url)
requests.put(url)
requests.patch(url)
requests.delete(url)
```

### 1.3.3 什么是响应

服务器收到请求后，会返回一个响应。

在 `requests` 中，响应结果通常保存在 `response` 变量里：

```python
response = requests.get(url)
```

这个 `response` 里面包含：

● 状态码

● 响应文本

● 响应头

● Cookie

● JSON 数据

● 原始二进制内容

## 1.4 `GET` 请求

### 1.4.1 基本写法

`GET` 请求通常用于获取数据。

```python
import requests

url = 'https://httpbin.org/get'

response = requests.get(url)

print(response.status_code)
print(response.text)
```

执行过程可以理解为：

```text
Python 程序请求这个 URL
服务器返回结果
response 接收服务器返回的数据
```

### 1.4.2 使用 `params` 传递查询参数

实际调用接口时，经常需要带参数。

例如天气接口：

```python
import requests

url = 'https://apis.juhe.cn/simpleWeather/query'

params = {
    'key': '你的APIKey',
    'city': '北京',
}

response = requests.get(url, params=params)

print(response.url)
print(response.text)
```

这里的：

```python
params=params
```

表示把字典中的参数拼接到 URL 后面。

例如：

```text
https://apis.juhe.cn/simpleWeather/query?key=你的APIKey&city=北京
```

所以：

```python
requests.get(url, params=params)
```

大致相当于：

```python
requests.get('https://apis.juhe.cn/simpleWeather/query?key=你的APIKey&city=北京')
```

但是实际开发中更推荐使用 `params`，因为它会自动帮我们处理 URL 编码。

例如城市名是中文：

```python
params = {
    'city': '北京',
}
```

`requests` 会自动把中文转换成适合放进 URL 的格式。

### 1.4.3 `params` 和 `urllib.parse.urlencode()` 的关系

在 `urllib.parse` 中，可以用 `urlencode()` 把字典转成查询字符串：

```python
from urllib.parse import urlencode

params = {
    'name': 'Tom',
    'age': 18,
}

query_string = urlencode(params)

print(query_string)
```

输出结果：

```text
name=Tom&age=18
```

而在 `requests` 中：

```python
requests.get(url, params=params)
```

底层也会完成类似的事情：

```text
把字典参数转换成 URL 查询字符串
```

所以可以这样理解：

```text
urllib.parse.urlencode()：手动把参数编码成查询字符串
requests 的 params：自动帮你完成参数编码和拼接
```

## 1.5 `POST` 请求

### 1.5.1 基本写法

`POST` 请求通常用于提交数据。

例如登录、注册、提交表单、创建资源等。

```python
import requests

url = 'https://httpbin.org/post'

data = {
    'username': 'Tom',
    'password': '123456',
}

response = requests.post(url, data=data)

print(response.status_code)
print(response.text)
```

这里的：

```python
data=data
```

表示把数据作为表单数据提交给服务器。

### 1.5.2 `data` 参数

`data` 通常用于提交表单格式的数据。

```python
import requests

url = 'https://httpbin.org/post'

data = {
    'name': 'Tom',
    'age': 18,
}

response = requests.post(url, data=data)

print(response.text)
```

常见场景：

● 提交登录表单

● 提交注册信息

● 提交普通表单字段

### 1.5.3 `json` 参数

很多现代 API 接口要求提交 JSON 数据。

这时应该使用 `json` 参数：

```python
import requests

url = 'https://httpbin.org/post'

payload = {
    'name': 'Tom',
    'age': 18,
}

response = requests.post(url, json=payload)

print(response.text)
```

这里的：

```python
json=payload
```

会自动完成两件事：

```text
1. 把 Python 字典转换成 JSON 字符串
2. 设置请求头 Content-Type: application/json
```

如果手动写，大致相当于：

```python
import json
import requests

url = 'https://httpbin.org/post'

payload = {
    'name': 'Tom',
    'age': 18,
}

headers = {
    'Content-Type': 'application/json',
}

response = requests.post(url, data=json.dumps(payload), headers=headers)

print(response.text)
```

所以实际开发中，如果接口要求 JSON 格式，优先使用：

```python
requests.post(url, json=payload)
```

### 1.5.4 `data` 和 `json` 的区别

可以这样记：

```text
data：提交表单数据
json：提交 JSON 数据
```

示例：

```python
requests.post(url, data={'name': 'Tom'})
requests.post(url, json={'name': 'Tom'})
```

虽然看起来都传入了字典，但发送给服务器的格式不同。

`data` 更接近：

```text
name=Tom
```

`json` 更接近：

```json
{
    "name": "Tom"
}
```

## 1.6 响应对象 `response`

### 1.6.1 `status_code`：状态码

`status_code` 用来查看 HTTP 响应状态码。

```python
import requests

response = requests.get('https://httpbin.org/get')

print(response.status_code)
```

常见状态码：

● `200`：请求成功

● `201`：创建成功

● `301` / `302`：重定向

● `400`：请求参数有问题

● `401`：未认证，通常表示没有登录或 token 错误

● `403`：没有权限

● `404`：资源不存在

● `500`：服务器内部错误

示例：

```python
if response.status_code == 200:
    print('请求成功')
else:
    print('请求失败')
```

### 1.6.2 `text`：字符串内容

`response.text` 会以字符串形式返回响应内容。

```python
import requests

response = requests.get('https://httpbin.org/get')

print(response.text)
```

适合处理：

● HTML 页面

● 普通文本

● 查看接口返回的原始内容

### 1.6.3 `json()`：解析 JSON 数据

如果服务器返回的是 JSON 数据，可以使用：

```python
response.json()
```

示例：

```python
import requests

response = requests.get('https://httpbin.org/get')

result = response.json()

print(type(result))
print(result)
```

`response.json()` 会把 JSON 字符串转换成 Python 对象。

常见转换关系：

```text
JSON 对象  -> Python 字典 dict
JSON 数组  -> Python 列表 list
JSON 字符串 -> Python 字符串 str
JSON 数字  -> Python int 或 float
true       -> True
false      -> False
null       -> None
```

注意：

> 只有响应内容本身是合法 JSON 时，`response.json()` 才能成功。

如果返回的是普通 HTML 页面，却强行调用：

```python
response.json()
```

可能会报错。

更稳妥的写法：

```python
import requests

response = requests.get('https://httpbin.org/get')

try:
    result = response.json()
    print(result)
except ValueError:
    print('响应内容不是合法 JSON')
```

### 1.6.4 `content`：二进制内容

`response.content` 会返回字节数据。

适合处理：

● 图片

● PDF

● 音频

● 视频

● 压缩包

例如下载图片：

```python
import requests

url = 'https://example.com/image.png'

response = requests.get(url)

with open('image.png', 'wb') as file:
    file.write(response.content)
```

这里使用的是：

```python
'wb'
```

表示以二进制写入模式保存文件。

### 1.6.5 `headers`：响应头

响应头中保存了服务器返回的附加信息。

```python
import requests

response = requests.get('https://httpbin.org/get')

print(response.headers)
print(response.headers.get('Content-Type'))
```

常见响应头：

● `Content-Type`：响应内容类型

● `Content-Length`：响应内容长度

● `Set-Cookie`：服务器设置的 Cookie

### 1.6.6 `url`：最终请求地址

`response.url` 可以查看最终请求的 URL。

```python
import requests

url = 'https://httpbin.org/get'

params = {
    'name': 'Tom',
    'age': 18,
}

response = requests.get(url, params=params)

print(response.url)
```

输出类似：

```text
https://httpbin.org/get?name=Tom&age=18
```

这个属性很适合用来检查：

```text
params 参数到底有没有拼接成功
```

### 1.6.7 `encoding`：响应编码

`response.text` 会根据编码把字节内容转换成字符串。

如果页面中文乱码，可以查看或手动设置编码：

```python
import requests

response = requests.get('https://example.com')

print(response.encoding)

response.encoding = 'utf-8'

print(response.text)
```

## 1.7 请求头 `headers`

### 1.7.1 什么是请求头

请求头是客户端发送给服务器的附加信息。

例如：

```text
我是谁
我能接收什么格式的数据
我是否携带认证信息
我使用什么浏览器或客户端
```

在 `requests` 中，可以通过 `headers` 参数传递请求头：

```python
import requests

url = 'https://httpbin.org/headers'

headers = {
    'User-Agent': 'Mozilla/5.0',
}

response = requests.get(url, headers=headers)

print(response.text)
```

### 1.7.2 常见请求头

常见请求头有：

● `User-Agent`：客户端身份信息

● `Content-Type`：请求体的数据格式

● `Accept`：希望服务器返回什么类型的数据

● `Authorization`：认证信息

例如调用需要 token 的接口：

```python
import requests

url = 'https://api.example.com/user'

headers = {
    'Authorization': 'Bearer 你的token',
}

response = requests.get(url, headers=headers)

print(response.text)
```

这里的：

```text
Bearer 你的token
```

是一种常见的接口认证写法。

## 1.8 超时时间 `timeout`

网络请求可能因为网络问题、服务器问题而长时间卡住。

所以实际开发中建议设置 `timeout`。

```python
import requests

url = 'https://httpbin.org/get'

response = requests.get(url, timeout=5)

print(response.status_code)
```

这里的：

```python
timeout=5
```

表示最多等待 5 秒。

也可以分别设置连接超时和读取超时：

```python
response = requests.get(url, timeout=(3, 10))
```

含义是：

```text
连接服务器最多等 3 秒
服务器返回数据最多等 10 秒
```

推荐习惯：

```python
requests.get(url, timeout=10)
```

不要让请求无限等待。

## 1.9 异常处理

### 1.9.1 为什么要处理异常

网络请求不一定总是成功。

可能出现：

● 网络断开

● 域名解析失败

● 请求超时

● SSL 证书错误

● 服务器拒绝连接

● 返回内容不是合法 JSON

所以实际使用 `requests` 时，通常要配合 `try` / `except`。

### 1.9.2 常见异常

`requests` 常见异常包括：

● `requests.exceptions.Timeout`：请求超时

● `requests.exceptions.ConnectionError`：连接错误

● `requests.exceptions.HTTPError`：HTTP 状态码错误

● `requests.exceptions.RequestException`：请求相关异常的父类

### 1.9.3 基本异常处理写法

```python
import requests

url = 'https://httpbin.org/get'

try:
    response = requests.get(url, timeout=5)
    print(response.status_code)
    print(response.text)
except requests.exceptions.Timeout:
    print('请求超时')
except requests.exceptions.ConnectionError:
    print('连接失败')
except requests.exceptions.RequestException as error:
    print('请求出现异常：', error)
```

### 1.9.4 `raise_for_status()`

默认情况下，即使服务器返回 `404` 或 `500`，`requests` 也不会自动抛出异常。

例如：

```python
response = requests.get(url)
print(response.status_code)
```

如果想让错误状态码自动变成异常，可以使用：

```python
response.raise_for_status()
```

示例：

```python
import requests

url = 'https://httpbin.org/status/404'

try:
    response = requests.get(url, timeout=5)
    response.raise_for_status()
    print(response.text)
except requests.exceptions.HTTPError as error:
    print('HTTP 状态码异常：', error)
except requests.exceptions.RequestException as error:
    print('请求异常：', error)
```

这时如果返回 `404`，就会进入异常处理。

## 1.10 Cookie

### 1.10.1 什么是 Cookie

`Cookie` 是服务器保存在客户端的一小段数据。

常见用途：

● 记录登录状态

● 识别用户

● 保存访问偏好

在 `requests` 中，可以查看响应里的 Cookie：

```python
import requests

response = requests.get('https://httpbin.org/cookies/set/name/Tom')

print(response.cookies)
```

### 1.10.2 发送 Cookie

可以手动发送 Cookie：

```python
import requests

url = 'https://httpbin.org/cookies'

cookies = {
    'name': 'Tom',
}

response = requests.get(url, cookies=cookies)

print(response.text)
```

不过更常见的做法是使用 `Session` 自动保存 Cookie。

## 1.11 `Session` 会话

### 1.11.1 什么是 `Session`

`Session` 可以在多次请求之间保持一些公共信息。

例如：

● Cookie

● 公共请求头

● 连接复用

普通请求：

```python
requests.get(url)
requests.get(url2)
```

每次请求相对独立。

使用 `Session`：

```python
session = requests.Session()

session.get(url)
session.get(url2)
```

可以让多次请求共享同一个会话。

### 1.11.2 使用 `Session` 保持 Cookie

```python
import requests

session = requests.Session()

session.get('https://httpbin.org/cookies/set/name/Tom')

response = session.get('https://httpbin.org/cookies')

print(response.text)
```

执行过程：

```text
第一次请求：服务器设置 Cookie
Session 自动保存 Cookie
第二次请求：Session 自动带上 Cookie
服务器识别出之前的状态
```

### 1.11.3 设置公共请求头

```python
import requests

session = requests.Session()

session.headers.update({
    'User-Agent': 'Mozilla/5.0',
})

response1 = session.get('https://httpbin.org/headers')
response2 = session.get('https://httpbin.org/get')

print(response1.text)
print(response2.text)
```

这样之后通过 `session` 发出的请求，都会默认带上这个请求头。

## 1.12 文件上传

### 1.12.1 上传单个文件

上传文件时使用 `files` 参数。

```python
import requests

url = 'https://httpbin.org/post'

with open('image.png', 'rb') as file:
    files = {
        'file': file,
    }

    response = requests.post(url, files=files)

print(response.text)
```

这里的：

```python
'rb'
```

表示以二进制读取模式打开文件。

### 1.12.2 同时上传文件和普通字段

```python
import requests

url = 'https://httpbin.org/post'

data = {
    'username': 'Tom',
}

with open('image.png', 'rb') as file:
    files = {
        'avatar': file,
    }

    response = requests.post(url, data=data, files=files)

print(response.text)
```

其中：

● `data`：普通表单字段

● `files`：文件字段

## 1.13 文件下载

### 1.13.1 下载小文件

如果文件不大，可以直接使用 `response.content`：

```python
import requests

url = 'https://example.com/file.pdf'

response = requests.get(url, timeout=10)

with open('file.pdf', 'wb') as file:
    file.write(response.content)
```

### 1.13.2 下载大文件

如果文件比较大，建议使用流式下载：

```python
import requests

url = 'https://example.com/big-file.zip'

response = requests.get(url, stream=True, timeout=10)

with open('big-file.zip', 'wb') as file:
    for chunk in response.iter_content(chunk_size=8192):
        if chunk:
            file.write(chunk)
```

这里的：

```python
stream=True
```

表示不要一次性把全部内容读入内存。

`iter_content()` 会分块读取响应内容。

适合下载：

● 大图片

● 大 PDF

● 视频

● 压缩包

## 1.14 认证

### 1.14.1 Basic Auth

有些接口需要用户名和密码认证。

可以使用 `auth` 参数：

```python
import requests

url = 'https://httpbin.org/basic-auth/user/pass'

response = requests.get(url, auth=('user', 'pass'))

print(response.status_code)
print(response.text)
```

### 1.14.2 Token 认证

更多接口会使用 token。

常见写法是把 token 放进请求头：

```python
import requests

url = 'https://api.example.com/user'

headers = {
    'Authorization': 'Bearer 你的token',
}

response = requests.get(url, headers=headers)

print(response.text)
```

注意：

> 真实项目中不要把重要 token 直接公开写在代码里。

可以考虑放在环境变量或配置文件中。

## 1.15 代理

### 1.15.1 使用代理

`requests` 支持通过代理发送请求。

```python
import requests

url = 'https://httpbin.org/ip'

proxies = {
    'http': 'http://127.0.0.1:7890',
    'https': 'http://127.0.0.1:7890',
}

response = requests.get(url, proxies=proxies, timeout=10)

print(response.text)
```

这里的代理地址要根据自己电脑上的代理软件实际端口来填写。

### 1.15.2 什么时候会用到代理

常见场景：

● 公司内网要求走代理

● 调试网络请求

● 抓包分析请求

● 访问某些需要特定网络环境的资源

## 1.16 SSL 证书验证

### 1.16.1 默认验证证书

使用 `https` 请求时，`requests` 默认会验证 SSL 证书。

```python
import requests

response = requests.get('https://example.com')

print(response.status_code)
```

如果证书异常，可能会出现 SSL 相关错误。

### 1.16.2 `verify=False`

可以关闭证书验证：

```python
import requests

response = requests.get('https://example.com', verify=False)

print(response.status_code)
```

但是要注意：

> `verify=False` 会降低安全性，不建议在正式代码中随便使用。

更推荐解决证书本身的问题，而不是直接关闭验证。

## 1.17 重定向

### 1.17.1 自动跟随重定向

默认情况下，`requests` 会自动跟随重定向。

```python
import requests

response = requests.get('https://httpbin.org/redirect/1')

print(response.status_code)
print(response.url)
print(response.history)
```

其中：

```python
response.history
```

保存了重定向过程中的历史响应。

### 1.17.2 禁止自动重定向

```python
import requests

response = requests.get('https://httpbin.org/redirect/1', allow_redirects=False)

print(response.status_code)
print(response.headers.get('Location'))
```

这里的：

```python
allow_redirects=False
```

表示不要自动跳转。

## 1.19 天气接口示例

### 1.19.1 原始写法

下面是一个根据城市查询天气的基本示例：

```python
import requests

apiUrl = 'https://apis.juhe.cn/simpleWeather/query'
apiKey = '你申请的APIKey'

requestParams = {
    'key': apiKey,
    'city': '北京',
}

response = requests.get(apiUrl, params=requestParams)

if response.status_code == 200:
    responseResult = response.json()
    print(responseResult)
else:
    print('请求异常')
```

### 1.19.2 逐行理解

导入第三方模块：

```python
import requests
```

保存接口地址：

```python
apiUrl = 'https://apis.juhe.cn/simpleWeather/query'
```

保存 API Key：

```python
apiKey = '你申请的APIKey'
```

准备请求参数：

```python
requestParams = {
    'key': apiKey,
    'city': '北京',
}
```

发送 GET 请求：

```python
response = requests.get(apiUrl, params=requestParams)
```

判断 HTTP 状态码：

```python
if response.status_code == 200:
```

把 JSON 响应转换为 Python 数据：

```python
responseResult = response.json()
```

打印结果：

```python
print(responseResult)
```

### 1.19.3 更稳妥的写法

实际写代码时，建议加上 `timeout` 和异常处理：

```python
import requests

api_url = 'https://apis.juhe.cn/simpleWeather/query'
api_key = '你申请的APIKey'

params = {
    'key': api_key,
    'city': '北京',
}

try:
    response = requests.get(api_url, params=params, timeout=10)
    response.raise_for_status()

    result = response.json()

    print(result)
except requests.exceptions.Timeout:
    print('请求超时')
except requests.exceptions.HTTPError as error:
    print('HTTP 状态码异常：', error)
except requests.exceptions.RequestException as error:
    print('请求异常：', error)
except ValueError:
    print('响应内容不是合法 JSON')
```

这个版本比原始写法更稳妥，因为它处理了：

● 请求超时

● HTTP 状态码异常

● 网络连接异常

● JSON 解析异常

### 1.19.4 封装成函数

如果要多次查询不同城市，可以封装成函数：

```python
import requests


def get_weather(city, api_key):
    api_url = 'https://apis.juhe.cn/simpleWeather/query'

    params = {
        'key': api_key,
        'city': city,
    }

    try:
        response = requests.get(api_url, params=params, timeout=10)
        response.raise_for_status()

        return response.json()
    except requests.exceptions.RequestException as error:
        print('请求异常：', error)
        return None
    except ValueError:
        print('响应内容不是合法 JSON')
        return None


result = get_weather('北京', '你申请的APIKey')

if result is not None:
    print(result)
```

封装成函数的好处：

● 代码可以重复使用

● 城市名可以灵活传入

● 请求逻辑集中管理

● 出错时可以统一处理

## 1.20 常见错误

### 1.20.1 把 `requests` 写成 `request`

模块名是：

```python
requests
```

不是：

```python
request
```

正确写法：

```python
import requests
```

错误写法：

```python
import request
```

### 1.20.2 忘记安装第三方模块

错误信息：

```text
ModuleNotFoundError: No module named 'requests'
```

解决方式：

```bash
pip install requests
```

### 1.20.3 忘记填写参数

例如：

```python
requestParams = {
    'key': apiKey,
    'city': '',
}
```

这里的 `city` 是空字符串。

如果接口要求城市名不能为空，就需要改成：

```python
requestParams = {
    'key': apiKey,
    'city': '北京',
}
```

### 1.20.4 API Key 错误

如果 API Key 不正确，HTTP 状态码可能仍然是 `200`，但是接口返回的数据中会提示业务错误。

所以不能只看：

```python
response.status_code == 200
```

还要看接口返回的 JSON 内容。

例如：

```python
result = response.json()
print(result)
```

有些接口会返回：

```json
{
    "error_code": 10001,
    "reason": "错误的请求KEY"
}
```

这说明 HTTP 请求本身成功了，但业务请求失败了。

### 1.20.5 把 HTTP 成功等同于业务成功

`status_code == 200` 只表示：

```text
HTTP 层面请求成功
```

不一定表示：

```text
接口业务处理成功
```

更严谨的接口代码通常会同时判断：

```python
if response.status_code == 200:
    result = response.json()

    if result.get('error_code') == 0:
        print('业务成功')
    else:
        print('业务失败：', result.get('reason'))
else:
    print('HTTP 请求失败')
```

不同接口返回字段不一样，实际判断方式要以接口文档为准。

### 1.20.6 没有设置 `timeout`

如果不设置 `timeout`：

```python
response = requests.get(url)
```

请求可能因为网络问题一直等待。

更推荐：

```python
response = requests.get(url, timeout=10)
```

## 1.21 `requests` 和 `urllib` 的区别

### 1.21.1 `urllib`

`urllib` 是 Python 标准库。

特点：

● 不需要额外安装

● 更底层

● 功能分散在多个子模块里

● 写法相对繁琐

例如：

```python
from urllib.parse import urlencode
from urllib.request import urlopen

url = 'https://example.com'

query = urlencode({
    'name': 'Tom',
    'age': 18,
})

full_url = url + '?' + query

response = urlopen(full_url)

content = response.read().decode('utf-8')

print(content)
```

### 1.21.2 `requests`

`requests` 是第三方库。

特点：

● 需要安装

● 写法更简洁

● 更适合日常开发

● 参数、请求头、Cookie、JSON、文件上传等操作更直观

例如：

```python
import requests

url = 'https://example.com'

params = {
    'name': 'Tom',
    'age': 18,
}

response = requests.get(url, params=params)

print(response.text)
```

可以简单记成：

```text
学习底层原理：urllib
日常发请求：requests
```

## 1.22 小结

`requests` 是 Python 中最常用的第三方 HTTP 请求库之一。

它的核心作用是：

```text
让 Python 程序可以方便地向服务器发送请求，并处理服务器返回的数据。
```

本章需要重点掌握：

● `requests` 是第三方模块，需要安装

● `requests.get()` 用于发送 GET 请求

● `requests.post()` 用于发送 POST 请求

● `params` 用于 URL 查询参数

● `data` 用于提交表单数据

● `json` 用于提交 JSON 数据

● `headers` 用于设置请求头

● `timeout` 用于设置超时时间

● `response.status_code` 用于查看状态码

● `response.text` 用于获取字符串响应

● `response.json()` 用于解析 JSON 响应

● `response.content` 用于获取二进制响应

● `try` / `except` 用于处理网络异常

● `Session` 用于保持 Cookie 和复用会话

● `files` 用于上传文件

● `stream=True` 用于下载大文件

最常见模板：

```python
import requests

url = 'https://api.example.com/data'

params = {
    'key': 'value',
}

try:
    response = requests.get(url, params=params, timeout=10)

    print('响应内容不是合法 JSON')
```
