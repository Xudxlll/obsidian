# 如何判断模型效果与下一步

返回 [[00 项目总览与学习路线]]。

## 1. 为什么不能只数画了多少框？

模型画得多，可能找到更多目标，也可能多报；画得少，可能更谨慎，也可能漏掉形态。需要先有一份可审查的参考标签，再判断类别和位置是否匹配。

- TP：画对类别且位置达到要求。
- FP：输出的框没有与参考标签正确匹配，包括多余框或类别错误。
- FN：参考标签中有形态，但没有被正确匹配到。

查准率 Precision = TP / (TP + FP)，看输出的框有多少符合标签；召回率 Recall = TP / (TP + FN)，看标签中的目标找到了多少。F1是两者的调和平均。类别错误可同时造成一个FP和一个FN；重复预测同一标签，最多一个框计TP。

检测框和标签框是否对得上，常用 IoU：两个框交集面积 / 并集面积。本次主规则是同类别、一对一且 IoU≥0.5。位置大幅不一致可能无法匹配，即使看起来大致在相同位置。更详细概念见 [[Python、数据分析与人工智能/深度学习/08_目标检测_笔记|目标检测笔记]]。

## 2. 原模型：12张图的探索性检查

从之前117张 AAPL 图片中，按时间选出12张互不共享交易日的图，共720个交易日。先冻结本轮助手视觉标签，再重新运行原项目：11个明确标签、3个含糊区域。

| 项目 | 结果 |
|---|---:|
| 模型输出总框数 | 13 |
| 匹配正确 TP | 5 |
| 未匹配 FP | 7 |
| 漏检 FN | 6 |
| 含糊区域暂不判分 | 1个预测框 |
| 查准率 | 5 / 12 = 41.7% |
| 召回率 | 5 / 11 = 45.5% |
| F1 | 43.5% |

本次阈值为置信度≥0.30、IoU≥0.50；模型内部NMS参数见评估报告。含糊区的预测先尝试匹配明确标签，否则与含糊区相交面积占预测框至少50%时暂不判分。不排除含糊区时，查准率38.5%、召回率45.5%；放宽匹配IoU至0.30后总体计数不变。此处的固定阈值查准率不是mAP，不能直接与不同数据上的mAP比较。

上图左边蓝框是助手标签，棕框是预先声明的含糊区，右边绿框是模型输出。这个例子中有正确匹配，也有更大范围的重复／定位不符框；棕色区域内的相关输出暂不判分。图中绿色数字是模型置信度，**不是胜率或真实准确率**。

## 3. 怎样看待这个结果？

这只是一次小规模探索。图片不共享日期，却仍来自同一只股票和相邻市场环境；标注者是AI助手，不是人类专家，且此前助手看过部分图片与模型输出，所以不属于严格盲评。原模型训练集未在项目中提供，也无法确认它与本批行情没有重叠。标签只覆盖部分类型；没有对应真值的类别，无法可靠估计召回率。

进一步说，标签未必穷尽所有尺度的局部形态：某些预测被记为FP，可能是模型识别了本轮没有标注的小尺度结构。因此需要人复核标签，而不是把FP视为绝对裁决。完整逐图数据和规则见 `outputs/original-yolo-evaluation/README.md`。

## 4. 想进一步做好，先做什么？

1. 固定可操作的标注手册：形态尺度、完成条件、画框边界、含糊处理；请人类标注者独立复核并记录分歧。
2. 增加不同股票、时期、市场和足够多的独立事件；确保训练、验证、最终测试没有同一事件泄漏，保留真正未见的股票或未来区间。
3. 分类别报告检测指标、样本数和误差案例；在验证集选择设置，最终测试集只用于最终评价。
4. 如果进一步研究交易：只在形态可观察完成之后产生信号，预先定义入场、退出、交易成本、基准和样本外回测。检测对了不意味着未来会按想象走势发展。

这些是建议的后续研究，不是已完成成果。不要把本次41.7%查准率写成模型的普遍准确率，更不要写成交易胜率。
