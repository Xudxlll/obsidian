# K线形态识别项目：总览与学习路线

> [!abstract] 先用一句话理解
> 把股票的历史价格画成统一样式的K线图，再让目标检测模型在图片上框出它认为存在的形态。**识别历史图形不等于预测未来涨跌，也不等于交易盈利。**

## 这个项目有两条不同路线

```text
Yahoo AAPL日线 → 清洗和调整 → 统一绘制K线图片
                                  ├─ 原GitHub项目 + 现成FODUU权重 → 检测 → 小样本评估
                                  └─ 自己的双顶/双底候选 → 视觉复核 → 导出标签 → 微调YOLOv8n → 测试
```

两条路线共用图片，但模型、标签和评估不同。原项目使用的是FODUU现成六类模型；自建实验从Ultralytics通用预训练权重微调成双顶、双底两类。不能把自己微调得到的结果说成原模型结果，也不能说我们从零设计或训练了YOLO网络。
