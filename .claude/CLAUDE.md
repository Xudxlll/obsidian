# CLAUDE.md

此文件记录用户偏好，Claude Code 会在每个会话中自动读取。

## 学习笔记编写规则

向笔记中插入内容时，遵循以下排版和风格规范：

### 公式

- 复杂公式使用 `$$` 独立块 + `aligned` 环境，多行对齐
- 行间适当留白：概率值紧凑（`\\[4pt]`），计算步骤前留白分隔（`\\[8pt]`）
- 行内公式用单 `$`，注意特殊字符转义（如 `\_` 表示下划线，裸 `_` 会被解析为下标）
- 公式配合直觉解释，先说人话再给公式，最后走一遍数字例子

### 图示

- **Mermaid flowchart**：仅在流程图、决策树等树状结构时使用，可直接渲染
- **ASCII 树状图**：用 `└──` `├──` `│` 画层级结构，适合目录、分类、组织关系等非决策树的树形内容
- **ASCII 字符框图**：简单结构用 ┌───┼───┐ 画关系图，直观且不依赖渲染
- Mermaid 节点用 `<br/>` 换行，用 `style` 给节点上色区分状态（如绿色=纯、红色=停、黄色=未纯）
- 不依赖外部图片，尽量用文字和 Mermaid 解决问题
- `---` 横线仅用于段落之间的视觉分隔，不作为核心图示手段

### 标题与排版层级

- **一级标题**：`# 一、xxxx`（大章开头，如「一、Numpy 概述」）
- **二级标题**：`## 1.1 xxx`（章节内的分段，如「1.1 什么是决策树」）
- **三级标题**：`### 1.1.1 xxx`（细分的知识点）
- 最多用到三级或四级标题，如果还需要细分则用**加粗**作为视觉层级
- 善用**加粗**强调核心概念、**无序列表**展开并列要点、**有序列表**描述步骤流程
- 段落之间适当用 `---` 横线做视觉呼吸，避免连续多段纯文字堆叠

### 代码

- 代码块标注语言类型（`python`、`text`、`bash`）
- 关键参数和概念在代码上方或下方用短句解释
- 线性回归和决策树部分的 sklearn API 保持原有格式，调用后解释结果含义

### 表格

- 对比表格：用于算法的多维度对比（如 ID3/C4.5/CART），表格中尽量使用符号增强可读性（✅/❌、✓/✗）
- 解释表格：用于符号与含义的对应（如参数名→含义→水果例子中的值），适合概念讲解
- 总结表格：放在长段解释之后，提炼核心结论
- 表格与 Mermaid 图、LaTeX 公式配合使用，互为补充而非重复

### 解释结构

讲解新概念时采用递进式：
1. **直觉先行**：用一句话说清这个东西在干什么
2. **符号定义**：列符号对照表，每个符号对应一个具体例子中的数值
3. **走一遍例子**：用笔记中已有的数据从头算到尾
4. **对比总结**：和相近概念放在一起对比，突出区别
5. **补充边缘知识**：解释原因（为什么这样设计）、应用场景、常见坑

### 中文风格

- 使用简体中文，专业术语保留英文对照（如：信息增益（Information Gain））
- 数学符号和中文混排时，中文与 LaTeX 之间不加空格
- 语气直接、口语化，用「你」而非「我们」，用「这句话就是说」而非「可以理解为」
- 避免学术腔和套话，拒绝「综上所述」「值得注意的是」「在一定程度上」等

### 笔记联动

- 插入内容时尊重已有结构和原有内容，不随意删除或重排
- 新增内容放在相关段落的末尾或合适的空白行处
- 如果内容涉及其他笔记中的知识，主动建议用 wiki-link 相互引用
- 读笔记时主动关注嵌入的图片和 Mermaid 图，确保上下文理解完整

## 网页文章整理规则

当用户要求整理从网页爬取的文章时，遵循以下流程：

1. **图片本地化**：将文章中的所有外部图片下载到笔记所在目录的 `assets/` 文件夹中，并将链接替换为 Obsidian wiki-link 本地引用（如 `![[目录/assets/image.png]]`）
2. **繁简转换**：将繁体中文转换为简体中文，同时将台湾用语转换为大陆对应表达（如：演算法→算法、分群→聚类、雜訊→噪声、程式碼→代码 等）
3. **去广告清理**：移除文章中的推广内容、广告模块、电子报订阅、赞助信息等无关内容
4. **结构化整理**：重新组织为层次清晰的学习笔记，添加适当的标题层级、表格总结等

## B站视频嵌入

当笔记中出现 B站视频链接（`bilibili.com/video/BVxxxxxx`）且用户要求嵌入播放时，提取链接中的 BV 号，替换为嵌入式 iframe 播放器：

```html
<iframe src="https://player.bilibili.com/player.html?bvid={BV号}&page=1&autoplay=0" scrolling="no" border="0" frameborder="no" framespacing="0" allow="fullscreen; picture-in-picture" allowfullscreen="true" style="height:100%;width:100%; aspect-ratio: 16 / 9;"> </iframe>
```

- 从链接中提取 BV 号（如 `BV1WUUaBSEzx`），填入 `bvid=` 参数
- 用户说「做成可以点开的视频样式」「嵌入播放」「换成播放器」等表达时触发此规则
- **嵌入播放器的同时**，在 iframe 下方额外生成一行可点击跳转原始链接的引用，格式为：
  ```
  > 🎬 参考视频：[视频标题](原始B站链接)
  ```
  如果不知道视频标题，用「B站视频」作为占位标题
