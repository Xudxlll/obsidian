# CLAUDE.md

此文件记录用户偏好，Claude Code 会在每个会话中自动读取。

## 网页文章整理规则

当用户要求整理从网页爬取的文章时，遵循以下流程：

1. **图片本地化**：将文章中的所有外部图片下载到笔记所在目录的 `assets/` 文件夹中，并将链接替换为 Obsidian wiki-link 本地引用（如 `![[目录/assets/image.png]]`）
2. **繁简转换**：将繁体中文转换为简体中文，同时将台湾用语转换为大陆对应表达（如：演算法→算法、分群→聚类、雜訊→噪声、程式碼→代码 等）
3. **去广告清理**：移除文章中的推广内容、广告模块、电子报订阅、赞助信息等无关内容
4. **结构化整理**：重新组织为层次清晰的学习笔记，添加适当的标题层级、表格总结等
