# 机器学习概述

## 1. 什么是机器学习

1975年图灵奖获得者、1978年诺贝尔经济学奖获得者、著名学者赫伯特.西蒙（Herbert Simon）曾下过一个定义：如果一个系统，能够通过执行某个过程，就此改进了它的性能，那么这个过程就是学习。由此可看出，学习的目的就是改善性能，机器学习是一门能够让编程计算机从数据中学习的计算机科学。

卡耐基梅隆大学机器学习和人工智能教授汤姆.米切尔（Tom Mitchell）在他的经典教材《机器学习》中，给出了更为具体的定义：对于某类任务（Task，简称 T ）和某项性能评价准则（Performance，简称 P ），如果一个计算机在程序 T 上，以 P 作为性能度量，随着经验（Experience，简称 E ）的积累，不断自我完善，那么我们称计算机程序从经验E中进行了学习。

![basketball](./img/basketball.png)

例如，篮球运动员投篮训练过程：球员投篮（任务 T ），以准确率为性能度量（ P ）随着不断练习（经验 E ），准确率不断提高，这个过程称为学习。

## 2. 机器学习的形式

1. 建模问题
   所谓机器学习建模，在形式上可这样理解：在数据对象中通过统计或推理的方法，寻找一个接受特定输入 X，并给出预期输出 Y 的功能函数 f，即$ Y = f(x)$，这个函数以及确定函数的参数被称为模型。
2. 评估问题
   针对已知的输入，函数给出的输出(预测值)与实际输出(目标值)之间存在一定的误差，因此需要构建一个评估体系，根据误差的大小判定函数的优劣。
3. 优化问题
   学习的核心在于改善性能，通过数据对算法的反复锤炼，不断提升函数预测的准确性，直至获得能够满足实际需求的最优解，这个过程就是机器学习。

## 3. 机器学习的种类

### 3.1 有监督学习

定义：在已知数据输出（经过标注的）的情况下对模型进行训练，根据输出进行调整、优化的学习方式称为有监督学习。

根据图片，预测图像的类别。

![有监督学习](./img/%E6%9C%89%E7%9B%91%E7%9D%A3%E5%AD%A6%E4%B9%A0.png)

### 3.2 无监督学习

定义：没有已知输出的情况下，仅仅根据输入信息的相关性，进行类别的划分。

![无监督学习](./img/%E6%97%A0%E7%9B%91%E7%9D%A3%E5%AD%A6%E4%B9%A0.png)

### 3.3 半监督学习

定义：先通过无监督学习划分类别，再人工标记通过有监督学习方式来预测输出。

例如先对相似的水果进行聚类，再识别是哪个类别。

![半监督学习](./img/%E5%8D%8A%E7%9B%91%E7%9D%A3%E5%AD%A6%E4%B9%A0.png)

### 3.4 批量学习和增量学习

1. 批量学习：将学习的过程和应用的过程截然分开，用全部的训练数据训练模型，然后再在应用场景中实现预测，当预测结果不够理想时，重新回到学习过程，如此循环。
2. 增量学习：将学习的过程和应用的过程统一起来，在应用的同时以增量的方式，不断学习新的内容，边训练边预测。

### 3.5 基于实例的学习和基于模型的学习

- **基于实例的学习**

根据以往经验，寻找与待预测输入最接近的样本，以其输出作为预测结果（从数据中心找答案）。例如有如下一组数据：

| 年龄 | 学历 | 经验 | 性别 | 月薪 |
| ---- | ---- | ---- | ---- | ---- |
| 25   | 硕士 | 2    | 女   | 中   |
| 20   | 本科 | 3    | 男   | 低   |
| ...  | ...  | ...  | ...  | ...  |
| 20   | 本科 | 3    | 男   | ？   |

- **基于模型的学习**

根据样本数据，建立用于联系输入和输出的某种数学模型，将待预测输入带入该模型，预测其结果。

| 输入(x) | 输出(y) |
| ------- | ------- |
| 1       | 2       |
| 2       | 4       |
| 3       | 6       |
| 4       | 8       |

根据数据，得到模型 $y = 2x$

预测：输入9时，输出是多少？

## 4. 机器学习的一般过程

- **数据处理**

1. 数据收集 （手工采集、设备自动化采集、爬虫）
2. 数据清洗（数据规范、具有较大误差的、没有意义的数据进行清理）
3. 特征工程（特征提取、特征转换、特征选择）

- **模型搭建**

1. 选择模型 （算法）
2. 训练模型 （算法）
3. 评估模型 （工具、框架、算法知识）
4. 测试模型

- **模型部署**

1. 应用模型
2. 维护模型

## 1.6 机器学习的基本问题

- 回归（Regression）问题

  根据已知的输入和输出，寻找某种性能最佳的模型，将未知输出的输入代入模型，得到**<u>连续的输出</u>**.例如：

  - 根据房屋面积、地段、修建年代以及其它条件预测房屋价格
  - 根据各种外部条件预测某支股票的价格
  - 根据农业、气象等数据预测粮食收成
  - 计算两个人脸的相似度

- 分类（Classification）问题

  根据已知的输入和输出，寻找性能最佳的模型，将未知输出的输入带入模型，得到**<u>离散的输出</u>**，例如：

  - 手写体识别（10个类别分类问题）
  - 水果、鲜花、动物识别
  - 工业产品瑕疵检测（良品、次品二分类问题）
  - 识别一个句子表达的情绪（正面、负面、中性）

- 聚类问题

  根据已知输入的相似程度，将其划分为不同的群落（簇），例如：

  - 根据一批麦粒的数据，判断哪些属于同一个品种
  - 根据客户在电商网站的浏览和购买历史，判断哪些客户对某件商品感兴趣
  - 判断哪些客户具有更高的相似度

- 降维问题

  在性能损失尽可能小的前提下，降低数据的复杂度，数据规模缩小都称为降维问题
