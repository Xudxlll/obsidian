number = 10

        total += number
        print(number, total)
        number += 1
    else:
        number += 1
        continue

  123 ==> 321

    digit = number % 10

    number //= 10
print(result)

> **新学代码怎么理解**

> - **continue**：跳过本轮后续语句，直接进入下一轮循环，常用于过滤不符合条件的数据。
