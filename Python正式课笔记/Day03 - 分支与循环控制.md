### Day03/exercise09.py

```python
"""
用户输入一个3位整数
把各个位数上的数字+5后取个位,在反转输出
123 ==> 678 ==> 876
689 ==> 134 ==> 431
"""
# 说明：把右侧结果保存到 `number`。
number = int(input("请输入三位整数:"))
# 说明：把右侧结果保存到 `result`。
result = 0
# 说明：只要条件为 True，就持续循环。
while number > 0:
    # 个位 数位 百位
    # 说明：把右侧结果保存到 `digit`。
    digit = number % 10
    # 每个位数+5后的结果 如果+5后变成2位数那就取个位数
    # 说明：把右侧结果保存到 `processed`。
    processed = (digit + 5) % 10
    # 说明：把右侧结果保存到 `result`。
    result = result * 10 + processed
    # 说明：更新 `number //` 的值，属于复合赋值。
    number //= 10
```

## 融会贯通笔记

### 分支：把现实规则翻译成条件

- `if` 后面放布尔表达式，表达式为 True 才执行缩进代码块。
- 多个互斥条件用 `elif` 串起来，最后用 `else` 兜底。
- 条件判断最重要的是覆盖完整情况：满足、不满足、边界值都要想清楚。

### 循环：把重复动作交给程序

- `while` 的核心是“条件还成立吗”，所以要小心死循环。
- 循环里通常会有计数器或状态更新，例如 `i += 1`。
- 累计求和、重复输入、菜单系统都很适合用循环表达。

### break 和 continue 的区别

- `break` 是结束整场循环。
- `continue` 是结束当前这一轮，下一轮还会继续。
- 如果循环里还有很多后续逻辑，`continue` 可以提前跳过不需要处理的情况。
