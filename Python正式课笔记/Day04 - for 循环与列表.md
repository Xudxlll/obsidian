```python
循环语句for

    代码
```

### Day04/02_for_for.py

```python
"""
双层for嵌套
1.最先开始执行的是外层循环,然后才是内层
2.外层循环执行1次,内层循环从头开始执行n次(受条件影响)
3.外层循环结束,整个循环终止

"""
for i in range(3):
    print("外层i:", i)
    for j in range(2):
        print("内层j:", j)

print('--' * 10)

# 外层控制内层
for i in range(4):
    print("外层i:", i)
    for j in range(i):
        print("内层j:", j)
```

### Day04/03_list.py

```python
"""
容器类型-列表(数据结构 可迭代对象)
由一系列变量组成的可变序列容器
可变:创建完成之后还可以继续删除/添加/修改
序列:有顺序的
容器:可以装多个数据

"""
# 1.创建
list_movie = ["749局", "昆池岩", "寂静岭", "咒怨", "灰姑娘", "咒怨"]
list_index = [123, 10010, 10086]
print(list_movie)

# 2.访问
# 索引 获取单个元素
# 正:索引从0开始 最大索引 长度-1
# 反:从 -1 开始
print(list_movie[0])
print(list_movie[-1])
# 索引越界 IndexError: list index out of range
# print(list_movie[40])

# 切片 获取多个元素(新列表) [开始:结束:步长]
# 包含开始,不包含结束 默认从0开始,默认到结尾,步长默认为1
# [开始:结束]
print(list_movie[1:4])
# [开始:结束:步长]
print(list_movie[1:4:2])
# [开始:]
print(list_movie[3:])
# [:结束]
print(list_movie[:3])
# [:] 等价 [::]
print(list_movie[:])
# 反向切片
print(list_movie[::-1])

# 3.修改
list_movie[0] = "微笑"

# 4.删除
del list_movie[0]
del list_movie[:2]
# 删除第一个匹配到的值
list_movie.remove("咒怨")

# 5.添加
list_movie.append("北上")  # 结尾
list_movie.insert(0, "哪吒")  # 指定位置
# 要求是可迭代对象
list_movie.extend(["釜山行", "生化危机"])
print(list_movie)

# 6.遍历
for item in list_movie:
    print(item) #每一个元素
```

> [!note] 这份文件实际讲了什么
> - 文件说明/题目写的是：容器类型-列表(数据结构 可迭代对象)；由一系列变量组成的可变序列容器；可变:创建完成之后还可以继续删除/添加/修改；序列:有顺序的；容器:可以装多个数据。
> - 主要变量/数据名包括：`list_movie`、`list_index`、`list_movie[...]`。

> [!example] 本文件出现的新代码 / 函数 / 方法
> - 列表 `[]`：保存一组有顺序、可修改的数据。
> - `.remove()`：按值删除元素。
> - `.append()`：向列表末尾添加一个元素。
> - `.insert()`：在指定位置插入元素。
> - `.extend()`：把另一个可迭代对象的元素批量加入列表。

> [!abstract] 代码逻辑怎么走
> - 使用 `for` 遍历序列或容器，对每个元素执行同样的处理。
> - 通过赋值语句保存中间结果，主要变量包括：`list_movie`、`list_index`、`list_movie[...]`。

```python
不允许使用任何函数,需要考虑空列表,空列表时提示空列表
假设法

    if list_num[i] < min_num:
        min_num = list_num[i]
print(min_num)
```

> **新学代码怎么理解**
> - **for**：逐个遍历序列或容器，适合批量处理数据。
> - **range()**：生成整数序列，常用来控制 for 循环次数。
> - 列表 `[]`：保存一组有顺序、可修改的数据。
> - **.remove()**：按值删除元素，删除前要确认目标元素是否存在。
> - **.append()**：向列表末尾添加元素，是收集多条数据最常用的方法。
> - **.insert()**：按位置插入元素，适合需要控制顺序的列表操作。
> - `.extend()`：把另一个可迭代对象的元素批量加入列表。
> - `len()`：获取字符串或容器长度。
