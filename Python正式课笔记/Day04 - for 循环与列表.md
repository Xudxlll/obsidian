### Day04/01_for.py

```python
"""
循环语句for

可迭代对象(先把它当做一个数据类型,后续课程会讲...)

for 变量 in 可迭代对象:
    代码

"""
# range()函数 产生一个包含开始,但不包含结束的整数序列 ==> 可迭代对象

# i变量(名称任意) 代表数据
# 循环: 依次获取值
# range(结束) 默认从0开始
# 说明：遍历可迭代对象，逐个取值执行循环体。
for i in range(5):
    # 说明：输出内容到控制台，常用于观察程序运行结果。
    print(i)

# range(开始,结束)
# 说明：遍历可迭代对象，逐个取值执行循环体。
for i in range(2, 6):
    # 说明：输出内容到控制台，常用于观察程序运行结果。
    print(i)

# range(开始,结束,步长) 步长默认为1
# 说明：遍历可迭代对象，逐个取值执行循环体。
for i in range(1, 10, 3):
    # 说明：输出内容到控制台，常用于观察程序运行结果。
    print(i)
```

### Day04/02_for_for.py

```python
"""
双层for嵌套
1.最先开始执行的是外层循环,然后才是内层
2.外层循环执行1次,内层循环从头开始执行n次(受条件影响)
3.外层循环结束,整个循环终止

# 说明：遍历可迭代对象，逐个取值执行循环体。

    print("外层i:", i)
    # 说明：遍历可迭代对象，逐个取值执行循环体。
    for j in range(2):
        # 说明：输出内容到控制台，常用于观察程序运行结果。
        print("内层j:", j)

# 说明：输出内容到控制台，常用于观察程序运行结果。
print('--' * 10)

# 外层控制内层
# 说明：遍历可迭代对象，逐个取值执行循环体。
for i in range(4):
```

### Day04/03_list.py

```python
"""
容器类型-列表(数据结构 可迭代对象)
由一系列变量组成的可变序列容器
可变:创建完成之后还可以继续删除/添加/修改
序列:有顺序的
容器:可以装多个数据

"""
# 1.创建
# 说明：把右侧结果保存到 `list_movie`。
list_movie = ["749局", "昆池岩", "寂静岭", "咒怨", "灰姑娘", "咒怨"]

# 正:索引从0开始 最大索引 长度-1
# 反:从 -1 开始
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(list_movie[0])
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(list_movie[-1])
# 索引越界 IndexError: list index out of range
# print(list_movie[40])

# 切片 获取多个元素(新列表) [开始:结束:步长]
# 包含开始,不包含结束 默认从0开始,默认到结尾,步长默认为1
# [开始:结束]
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(list_movie[1:4])

# 说明：输出内容到控制台，常用于观察程序运行结果。
print(list_movie[1:4:2])
# [开始:]
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(list_movie[3:])
# [:结束]
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(list_movie[:3])
# [:] 等价 [::]
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(list_movie[:])
# 反向切片
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(list_movie[::-1])

# 3.修改
# 说明：把右侧结果保存到 `list_movie[0]`。
list_movie[0] = "微笑"

# 4.删除
del list_movie[0]
del list_movie[:2]
# 删除第一个匹配到的值
# 说明：按值删除元素。
list_movie.remove("咒怨")

# 5.添加
# 说明：向列表末尾追加元素。
list_movie.append("北上")  # 结尾
# 说明：按索引插入元素。
list_movie.insert(0, "哪吒")  # 指定位置
# 要求是可迭代对象
list_movie.extend(["釜山行", "生化危机"])
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(list_movie)

# 6.遍历
# 说明：遍历可迭代对象，逐个取值执行循环体。
for item in list_movie:
    # 说明：输出内容到控制台，常用于观察程序运行结果。
    print(item) #每一个元素
```

```python
        # 说明：判断条件是否成立，成立才执行下面缩进代码。
        if item > max_val:
            # 说明：把右侧结果保存到 `max_val`。
            max_val = item
        # 如果item比最小值还大,item就是最小
        # 说明：前面条件不成立时，继续判断这个分支。
        elif item < min_val:
            # 说明：把右侧结果保存到 `min_val`。
            min_val = item

    # 说明：输出内容到控制台，常用于观察程序运行结果。
    print(f"最大值:{max_val},最小值:{min_val}")
```

## 融会贯通笔记

### for 循环更适合“已知范围”的重复

- 如果明确知道要遍历哪些值，优先想到 `for`。
- `range(start, stop, step)` 左闭右开，不包含 stop。
- 嵌套 for 的关键是分清外层控制什么、内层控制什么。

### 列表是最常用的批量数据容器

- 列表可以保存多个值，并且顺序稳定。
- 索引从 0 开始，负数索引从末尾倒着取。
- 切片 `list[a:b:c]` 也是左闭右开，常用于取一段数据。

### 列表方法要分清“改原列表”还是“产生新结果”

- `append/insert/remove/pop/sort/reverse` 多数会直接修改原列表。
- 删除数据前要想清楚是按索引删，还是按值删。
- 遍历列表时同时删除元素容易漏数据，最好先收集目标或倒序处理。
