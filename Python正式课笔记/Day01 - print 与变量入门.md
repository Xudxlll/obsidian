### Day01/02_variable.py

```python
"""
变量
   数据的名字
   规范:
    不允许使用数字开头,
    使用字母,下划线开头,后面跟字母 数字 下划线
    不允许使用python保留字 for if pass ...
    符合: name1 user_name _name
    不符合: 1name print for

赋值
    过程 通过等号 = 来实现

变量 = 值   把等号右边的值赋值给左边的变量

"""
# 说明：把右侧结果保存到 `name`。
name = "小艺"
# 说明：把右侧结果保存到 `age`。
age = 18

# 打印多个变量
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(name, age)
# 我是小艺,今年18岁 %占位符 %s字符串 %d数字
# 说明：输出内容到控制台，常用于观察程序运行结果。
print("我是%s,今年%d岁" % (name, age))
# 推荐!
# 说明：输出内容到控制台，常用于观察程序运行结果。
print(f"我是{name},今年{age}岁")
```

## 融会贯通笔记

### 程序先要能被看见：print 输出

- `print()` 是调试和观察结果最常用的入口。
- `print("你好", end="")` 可以修改默认换行行为，让下一次输出接在同一行。
- 输出多个变量时可以直接用逗号分隔，也可以用 `%` 或 f-string 拼成完整句子。

### 变量是给数据贴标签

- 变量名要有意义，并且不能用数字开头，也不能占用 `for`、`if`、`pass` 等保留字。
- `name = "小艺"` 不是数学里的等号，而是“把右边的值交给左边这个名字管理”。
- f-string 写法 `f"我是{name}"` 更直观，后面写项目时也更容易维护。

### 注释和多行字符串

- `#` 后面的内容不会执行，适合写短说明。
- 三引号可以写多行说明，也可以临时包住一大段文字；在课程代码里常用来记录概念。
