作业②用户输入质量m和速度v,计算动能E
    动能 = 0.5 * 质量 * 速度的平方
"""
m = float(input("请输入质量(单位kg)："))
v = float(input("请输入速度(单位m/s)："))
E = 0.5 * m * v ** 2
print(f"动能为：{round(E, 2)}焦耳")

"""
作业③输入一个3位数,判断是否为阿姆斯特朗数
    各个位上的数字的3次幂之和等于这个数本身
    153 = 1*1*1 + 5*5*5 +3*3*3
"""
number = int(input("请输入一个3位数："))
a = number // 100
b = number // 10 % 10
c = number % 10
d = a ** 3 + b ** 3 + c ** 3
if d == number:
    print(f"{number}是阿姆斯特朗数")
else:
    print(f"{number}不是阿姆斯特朗数")

> **新学代码怎么理解**
> - **type()**：查看变量当前的数据类型，用来确认转换是否成功。
> - **input()**：接收终端输入，得到的内容默认是字符串，常常需要再做类型转换。
> - **int()**：把数据转换成整数，适合处理计数、下标、整数题目。
> - **float()**：把数据转换成小数，适合处理金额、速度、质量这类带小数的数据。
> - **str()**：把数据转换成字符串，适合拼接、输出或保存文本。
> - `bool()`：把数据转换为布尔值。
> - **round()**：按指定小数位保留结果，常用于输出更整洁的计算结果。
> - **if**：根据条件决定代码是否执行，是分支判断的核心。
