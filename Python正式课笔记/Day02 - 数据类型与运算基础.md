### Day02/09_logic.py

```python
"""
逻辑运算符 布尔值

and or not
"""
# and 逻辑与  且的关系  一假俱假 全真才是真
# 说明：组合多个布尔条件。
print(0 < 1 and 0 == 0)
# 说明：组合多个布尔条件。
print(0 < 1 and 0 != 0)

# or 逻辑或 或者关系 一个真就是真 全假才是假
# 说明：组合多个布尔条件。
print(0 > 1 or 0 != 0)
# 说明：组合多个布尔条件。
print(0 > 1 or 0 == 0)

# 观察下代码是否有输出? 如果有输出是啥? 如果没有为啥?
# 都没有 短路求值
# 当,前一个表达式就能够确定整个结果的时候,后面的内容不被执行
# 说明：组合多个布尔条件。
0 != 0 and print("Hello")
# 说明：组合多个布尔条件。
0 < 1 or print("Hi")

# not 逻辑非 取反
# 说明：组合多个布尔条件。
print(not True)
# 说明：组合多个布尔条件。
print(not False)
```

## 融会贯通笔记

### 数据类型决定能做什么运算

- 数字能做加减乘除，字符串能拼接、索引、切片，容器能保存多个数据。
- `type()` 可以查看数据类型；学习阶段遇到结果不对，先看类型往往很有效。
- 变量本身没有固定类型，真正有类型的是变量指向的那个对象。

### 输入与类型转换是一组固定搭档

- `input()` 负责从键盘拿到内容，但拿到的一定是字符串。
- 想把输入当数字计算，要用 `int()` 或 `float()` 转换。
- 转换失败通常说明输入内容不符合目标类型，比如把 `abc` 转成整数。

### 运算符是表达式的骨架

- 算术运算：`+ - * / // % **`，分别对应加减乘除、整除、取余、幂。
- 赋值运算：`+=`、`-=` 等是在原变量基础上更新。
- 比较运算返回布尔值，逻辑运算用 `and`、`or`、`not` 组合多个条件。
- 优先级复杂时不要硬记，直接加括号让意图变清楚。
