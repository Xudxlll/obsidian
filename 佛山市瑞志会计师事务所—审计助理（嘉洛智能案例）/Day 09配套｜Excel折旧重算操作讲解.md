## 三、DATEDIF：为什么拼对了还会少一个月

### 1. 函数计算的是完整月份间隔

在“月数边界测试”中，B22是2024-07-15，D22是2024-12-31，F22的公式为：

```excel
=DATEDIF(B22,D22,"m")
```

结果为5，因为这两个日期之间只经过了5个完整月。函数不知道你的会计政策，也不知道你要把七月算成一个计提月份。

### 2. 先确认首次计提月份，再统一月初

固定资产重算!L8：

```excel
=IF(E8<>"可计算","待核",DATE(YEAR(I8),MONTH(I8)+1,1))
```

I8是六月十五日，月份加1、日期取1，得到七月一日。`DATE`会处理跨年，因此十二月启用得到次年一月一日，不必手工写跨年分支。

N列取本期开始与首次计提月份的较晚者；O列取预计截止月、寿命最后计提月和处置月的较早者。**先确定实际允许计提的区间，DATEDIF才有意义。**

### 3. 对齐后按“包含起止当月”计算

固定资产重算!P8：

```excel
=IF(E8<>"可计算","待核",IF(O8<N8,0,DATEDIF(N8,O8,"m")+1))
```

七月一日至十二月一日的月间隔是5，包含七、八、九、十、十一、十二这6个计提月份，因此加1。结束早于开始时返回0，避免DATEDIF产生`#NUM!`。

**不能对任意原始日期盲目加1。** 这里成立的前提是按月政策已确定，起止日期已经统一为月初，寿命与处置也已经截断。试改“月数边界测试”B8，I8会自动变化，J8保留原手算答案供你重新核对。

## 四、XLOOKUP：先核唯一性，才相信匹配结果

查找残值率的核心形式是：

```excel
=XLOOKUP(A8,政策与口径!$A$16:$A$33,政策与口径!$B$16:$B$33,"待核：未匹配",0)
```

| 参数 | 本例含义 |
| --- | --- |
| A8 | 当前资产编号0001 |
| A16:A33 | 去政策表的资产编号列找 |
| B16:B33 | 返回同一行的预计残值率 |
| 未找到时的文字 | 保留“待核”，避免误当0%残值率 |
| 最后一个0 | 要求精确匹配 |

实际工作簿在查找前还检查编号是否唯一、匹配项是否有值。用于检查唯一性的函数是：

```excel
=COUNTIFS(政策与口径!$A$16:$A$33,A8)
```

结果为1才表示恰好匹配一条；0条或多条都应待核。政策表中的**0012故意出现两次，寿命分别为5年和8年**。在“月数边界测试”C41，单独使用XLOOKUP会返回首个匹配的5；主表却会把该资产拦住，防止误把首个结果当成已确认政策。

编号**0001是文本，数值17是数值**。编号显示格式不能代替数据类型，丢失的前导零也不能未经核实就补齐。文本金额80000看起来像数字，但`ISNUMBER`会识别它不是数值；本例保留原始问题，让你向带教确认后再处理。

## 五、MIN与MAX：怎样避免已提足资产继续计提

固定资产重算!Q8计算未先取整的单月折旧：

```excel
=IF(E8<>"可计算","待核",F8*(1-G8)/(H8*12))
```

T8计算期初剩余可折旧金额：

```excel
=IF(E8<>"可计算","待核",MAX(0,F8*(1-G8)-K8))
```

Y8才是预计全年重算：

```excel
=IF(E8<>"可计算","待核",ROUND(MIN(T8,P8*Q8),2))
```

`MIN`在“本期按月计算的金额”与“期初剩余可折旧金额”中取较小值。寿命和处置的限制已经体现在P列月数中，所以不能只做金额上限却忘记到期停止。

重点观察：

- **0004，第11行：** 原值60,000，残值3,000，期初累计57,000，已提足；仍在使用也不再计提。Y11＝0。
- **0006，第13行：** 2022年十一月开始、24个月寿命，最后计提在2024年十月，本年10个月，Y13＝5,000。
- **0007，第14行：** 五月处置，五月仍提，六月起不提；Y14＝1,900。
- **0009，第16行：** 原值10,000、零残值、期初累计6,666.72，剩余3,333.28；本期金额被限制为3,333.28，而不是机械计算3,333.33。期初0.05元的舍入差异单列在S16。
- **0010，第17行：** 理论期初累计46,550，账面45,000，S17＝－1,550；本期只算一月至十一月10,450，不自动把历史差额补进本期。需要先查历史、估计变更或其他原因，再请带教评价。

## 六、SUMIFS：怎样按部门和科目汇总

“重算总览”B9的核心汇总部分为：

```excel
=SUMIFS(固定资产重算!$Y$8:$Y$26,固定资产重算!$C$8:$C$26,A9,固定资产重算!$E$8:$E$26,"可计算")
```

意思是：只加总Y列中同时满足“部门等于A9的生产部”和“输入状态为可计算”的金额。实际单元格的外层还检查是否有可计算记录，避免没有任何合格记录时，用一个看似正常的零掩盖缺失。

汇总分两件事看：

1. **重算与账面比较：** 用同期间的1—11月重算53,972.23，对比账面53,472.25，净差499.98。差异分别来自生产部500和研发部－0.02，需分项解释，不能只看净额。
2. **台账与总账勾稽：** 对同一组选样，按“制造费用、管理费用、研发费用”汇总账面实提，再与独立输入的总账对照金额比较。这三项差额为0，只说明同范围的账面汇总对上，不能替代折旧重算，也不证明全量完整。

总账对照样例位于“资产台账”A31:D34，仅覆盖0001—0010。其余9条异常未解决前，不做全量完成结论。

## 七、无形资产和长期待摊为什么另放一页

在“无形与待摊”中：

| 示例 | 起点及本例约定 | 本年预计金额 |
| --- | --- | ---: |
| 软件许可 | 六月十五日可供使用；教学政策明确六月按整月摊销，60个月、零残值 | 7×600＝4,200 |
| 符合条件的装修支出 | 已确认支出实质和受益期，五月起24个月 | 8×3,000＝24,000 |
| 不确定寿命的无形资产 | 不进行摊销，另作减值测试和寿命复核 | 不摊销 |

无形资产准则要求自可供使用时起摊销；**“当月按整月”的月度处理是本例明确的教学约定，不能当成所有无形资产都必须整月摊销的规定。** 装修也要先判断应确认为何种资产或费用，不能看到装修两个字就自动放入长期待摊。

## 八、三个可以亲手改的练习

### 练习A：从一个输入追到汇总

把“资产台账”E8由120,000改成130,000。

- 固定资产重算!Y8应从11,400变成12,350。
- 重算总览!B5应从58,366.61变成59,316.61。
- 看完把E8改回120,000。不要直接修改重算表的结果公式。

### 练习B：为什么改成终版仍然不显示全年差额

将“政策与口径”B10改为“终版已确认”，但保持“资产台账”K8:K17为空。总览B24仍应显示“待终版”，因为只有版本声明，没有实提金额。

如果只是为了测试，可以在副本中把这10条样例各自的预计金额录进对应K列，再确认版本，此时全年差额为0。**这种录入只是教学自测，不是从重算结果倒填客户实际。** 正式比较必须取自客户已结账、可核对的独立记录。测试后恢复K列空白，B10恢复“未结账”。

### 练习C：看缺失和合法零的区别

先将“政策与口径”B16的5%清空：资产0001应显示待核。再恢复5%。接着看资产0006的残值率为0%，仍能正常计算。

同样，全年实提明确录入0表示“有依据的零”，清空则表示“还没有数据”。公式用`ISBLANK`检查源单元格，并用`ISNUMBER`检查数值类型，不能拿0来填补未知。

## 九、已核验内容与使用范围

工作簿已在生成环境执行公式重算，对照独立手算检验10条可计算资产、10个月数边界与3个累计上限/历史案例，并测试改原值、清空参数、合法零、缺失实提及终版流程，测试后恢复初始数据。公式错误扫描未发现错误，并检查了各表预览和导出的公式、编号类型及空白状态。

本机未能调用Microsoft Excel，因此**尚未在Excel原生应用中实测重算**。工作簿保存了公式和计算结果，建议用支持XLOOKUP的Excel打开后按练习A试改一次。不要把文件预览中显示的缓存数字当成已在你所用版本实测的证明。

正式资料有新增、改序或范围扩大时，应同步核对公式覆盖范围；本例范围为台账第8—26行、政策第16—33行，不声称新增行会自动纳入全部公式。固定资产主表中的输入状态是计算必要的验证，独立边界测试不会反向决定主表结果。

公开规则与函数链接统一放在工作簿“政策与口径”页。它们支持规则和函数用法，不证明虚构人物、内部确认或审计项目真实发生。
