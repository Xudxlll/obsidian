# 审计程序、科目与证据路线

下面是围绕虚构设备制造项目的学习说明，不是嘉洛真实账、不替真实项目形成结论。程序需按风险、重要性和证据设计，不能把这一页当作适用于所有企业的固定审计方案。

## 基本工作关系

管理层负责财务报表、会计记录与相关内部控制；注册会计师获取充分、适当证据，形成意见。客户付费购买专业服务，不意味着可以要求指定意见或由审计人员替其编造证据。实习生受指导做其中的基础工作。

小项目可能一个人接触多个科目，但“接触过”与“独立负责并完成”不同。故事中经理定方向，带教指导与复核，实习生执行指定步骤和记录问题。

## 从资料到结论的路线

```mermaid
flowchart LR
    A[明确问题与认定] --> B[核资料范围与口径]
    B --> C[执行计划中的程序]
    C --> D[记录证据与例外]
    D --> E[带教复核与追加程序]
    E --> F[专业评价与后续报告]
```

不是“导入成功→自动识别风险→审计完成”。遇到异常，先查自身映射、单位和版本，再调查业务原因；证据不足时继续保留未完成状态。

## 各项工作具体在查什么

| 工作 | 常见资料 | 本套实习生做什么 | 不能直接推论什么 |
| --- | --- | --- | --- |
| 抽凭与细节检查 | 序时账、凭证、合同、发票、收发与验收、付款 | 按带教清单找证据、核字段、记缺口 | 一张发票证明所有认定，选几笔代表全年 |
| 银行函证 | 账户范围、授权、办理信息、发出与回收、合同 | 控制台账、基础字段核对、差异索引 | 对账单替代全部函证，客户转发图就是直接回函 |
| 存货监盘 | 客户盘点安排、记录、实物、流转单据 | 随队观察和抽盘、记单位与截止 | 看见实物就证明数量、权利与价值全正确 |
| 固定资产 | 台账、取得与可用证据、用途、处置、重算 | 指定实物及来源核对、计算与勾稽 | 车间机器一律是自用资产 |
| 应付职工薪酬 | 汇总、计提、审批、支付、分配 | 核滚动、归属、净额与成本费用去向 | 一月付款一律是一月费用 |
| 无形与待摊 | 合同、许可/服务性质、可用与受益证据 | 分类型重算、期限与归集核对 | 软件都资本化，装修都摊同样年限 |
| 应收账龄 | 未结项、起算与到期日、核销、回款 | 核总体、分段、逐笔回款对应 | 最近交易日重置老账，一笔回款代表全部结清 |
| 收入截止 | 合同、履约、发货、运输、验收、入账 | 时间线与证据对应 | 开票、报关或收款必然等于收入 |
| 未入账负债 | 期后付款、收货、发票、暂估等 | 按计划反查年末义务 | 一月事项全部回补十二月，查付款就覆盖所有负债 |
| 附注协作 | 已采用账表、政策、变动表、底稿 | 填基础明细、逐列勾稽、索引与版本 | 实习生形成审计意见，模板文字就是客户政策 |

## 设备制造原型为什么有用

同样看起来像设备，可能是自用机器、给客户制造的在制或成品、借入测试件或客户送样。先理解用途与权利，再确定科目和程序，不能只按外观分类。

非标订单还涉及方案、物料采购、加工、装配、试机、运输、安装和验收。成本按项目归集是否合理，收入对应何种履约义务和控制权，需要合同与实际执行支持。**定制不自动意味着按时段确认；报关也不自动等于收入时点。** 本套不替嘉洛判断真实合同。

海外业务可以在取证中引出币种、合同、物流和回款对应问题；无需编海外大客户、收入占比或跨境争议。用户提供的宽泛背景足以支持流程想象，不足以支持真实交易细节。

## 银行函证的前后时间

准备账户与渠道 → 年末后确认目标日资料 → 核授权与范围 → 审计组控制发出 → 受控接收 → 评价来源和内容 → 差异与未回继续处理。

截至2024年末，采用当时已生效的2024版操作指引作参考。纸质或电子方式依现实条件选择，本文情境用纸质受控办理，不推断真实机构平台。不能在12月27日取得尚未到来的12月31日余额回函。

## 存货盘点与监盘的区别

客户组织盘点，审计组观察、检查和抽盘。从记录找实物与从实物追记录各有作用，不能只抄客户数。需要关注单位、库位、客户送样、第三方保管、状态和盘点前后移动。

即使账实数量一致，成本、归属和价值仍有问题要查。盘点安排在年末某个时间，仍需核到报表时点的相关移动；不能以当天上午数过就省略截止。异常是进一步核查起点，不是实习生独立给出盘亏或减值结论。

## 了解、穿行与控制测试

了解包括询问、观察、检查等以掌握业务与控制；一笔穿行把某交易从头跟到尾，帮助理解设计与执行。控制运行有效性测试还要明确测试目标、总体、期间、样本及证据。

审计软件能做导入、索引、样本管理和状态追踪。控制是否值得依赖、例外影响、是否追加实质性程序，由审计人员判断。客户事后补一个说明，不自动证明当时控制已经执行。

## 趋势分析与“预测”的限度

先核比较期间、重分类、币种和一次性事项。以可比月份或业务量构造分析预期，可以协助定位进一步检查方向。设备交付可能集中，不把月度波动简单当成错报。

同比、移动均值、账龄和期后回款都不是会计结论本身。对预期与实际差异，要有事实解释和追加程序；具体门槛由审计人员安排，不凭一个软件异常分数认定风险或客户违规。

## 工作状态的常用词

- **已取得：** 文件到手，尚不保证执行检查。
- **已检查：** 做了记录的步骤，仍可能待复核。
- **待解释/待补：** 信息不足，不等同已经认定错误。
- **拟调整：** 尚待评价、沟通与确认，不直接当审定数。
- **客户已入账：** 要追更新后的账表及相关科目，不等于最终审计评价完成。
- **待复核：** 实习生不能替负责人签结论。
- **阶段交接：** 让后续人员接续，不是报告出具后的最终归档。
