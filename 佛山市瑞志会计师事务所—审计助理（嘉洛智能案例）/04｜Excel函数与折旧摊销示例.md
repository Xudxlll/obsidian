# Excel函数与折旧摊销示例

> [!note] 全部数字是虚构练习
> 不是嘉洛真实资产、薪酬或应收数据。下面给计算思路与可复制的示意公式，没有实际创建客户工作簿或执行审计重算。

## 先更正一个拼写

正确名称是**DATEDIF**，不是原描述的DATEIF。它计算两个日期之间的日、月、年间隔，但不会决定会计上哪个月开始折旧。部分单位存在已知限制，不能只看函数返回数就认为期间正确。[Microsoft说明](https://support.microsoft.com/zh-cn/excel/functions/datedif-function)

XLOOKUP用于查找，不是汇总；SUMIFS用于满足多个条件的求和。两者都依赖输入键、数据类型、范围和完整性。旧版Excel可能不支持XLOOKUP，真实环境应确认版本并用适当替代，不假设客户一定使用某一版本。

## 一、先定口径，再算固定资产折旧

本例假设执行企业会计准则、按月直线法、无减值及寿命变更，新增通常次月起提，减少当月仍提。**可使用时点不是随便取发票日或付款日**。会计与税务扣除不同，例子不代替具体政策判断。[财政部答复](https://www.mof.gov.cn/bd/mhwzzxly/hjs/202312/t20231225_3923738.htm)

设资产A001原值120,000元、残值率5%、使用寿命60个月，2022年6月20日达到预定可使用状态，无处置。则2022年7月开始计提：

$$

月折旧额=\frac{120000\times(1-5\%)}{60}=1900\text{元}

$$

2024年覆盖1—12月，共12个月，本年折旧22,800元。2022年7月至2024年12月累计30个月，累计57,000元，未考虑其他变化时净额63,000元。这恰好也能说明为何核2024年折旧，需要回看2022年的取得和使用依据。

### 辅助列示例

同一工作表中，H1放截至日2024-12-31，H2放本年起点2024-01-01。

| 列 | 含义 |
| --- | --- |
| A | 资产唯一编号 |
| B | 原值 |
| C | 残值率，如5% |
| D | 寿命月数，必须大于0 |
| E | 达到可使用状态日期 |
| F | 处置日期，无则空白 |
| G | 折旧起始月的月初 |
| I | 未取整的单月折旧 |
| J | 截至日所在月份的下月月初 |
| K | 考虑处置后的排他截止月初 |
| L | 截至报告期末的累计计提月数 |
| M | 截至本年开始前的累计计提月数 |
| N | 本年计提月数 |
| O | 本年重算金额 |

```excel
G2 = EOMONTH(E2,0)+1
I2 = B2*(1-C2)/D2
J2 = EOMONTH($H$1,0)+1
K2 = IF(F2="",J2,MIN(J2,EOMONTH(F2,0)+1))
L2 = IF(K2<=G2,0,MIN(D2,DATEDIF(G2,K2,"m")))
M2 = IF(MIN($H$2,K2)<=G2,0,MIN(D2,DATEDIF(G2,MIN($H$2,K2),"m")))
N2 = MAX(0,L2-M2)
O2 = ROUND(I2*N2,2)
```

公式列名和等号左侧是说明，实际粘贴单元格只使用右边以等号开头的表达式。日期、原值、寿命和残值率要先验证；缺失或不合法日期应列待核，不能用0掩盖。

这里先把端点归一到月初，用排他截止避免月中取得和月底天数导致差一月；累计月数以寿命封顶。它是简化算法，**不覆盖**减值后重算、寿命或残值变更、非直线法、组件拆分、多次处置与复杂历史调整。

## 二、有限寿命无形资产不能整套照搬

例：外购软件符合资产确认条件，成本24,000元、有限寿命24个月，2024年4月20日可供使用。仅为教学，假设经确认采用可使用当月计入整月的月度口径，直线法、残值0、无减值，则4—12月9个月，每月1,000元，本年摊销9,000元、期末净额15,000元。

这里**当月整月**是例子政策，不是把准则表述简化成所有企业统一的日数规则。准则要求自可供使用时系统合理摊销；实际按日或按月如何体现，需要一致且合理的政策。软件订阅、服务费或不符合资本化条件的支出不能强行放进无形资产。[无形资产准则](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/200806/t20080618_46242.htm)

## 三、长期待摊费用看支出实质与受益期

例：一项装修支出经适用制度和业务评估符合长期待摊确认，金额36,000元，受益期2024-06-01至2027-05-31共36个月，按月均摊、无其他变化。2024年6—12月7个月，摊销7,000元，期末29,000元。

36个月只是本例，不是所有装修的法定统一年限。可能涉及租赁、其他资产或费用的支出，要先核分类，不能重复资本化。租期变化、提前终止或剩余受益不成立时，也不能继续机械摊完。

## 四、XLOOKUP匹配什么

假设“政策表”A列有唯一资产类别代码、B列是带教核准的寿命参数：

```excel
=XLOOKUP(A2,政策表!$A$2:$A$100,政策表!$B$2:$B$100,"待核",0)
```

“政策表”是示例工作表名，并未实际创建。A2也应使用与查找区域一致的类别键。先确认唯一性，重复代码可能只返回首个匹配；合同或明细一对多不能用一个查找结果当全部记录。找不到显示待核，不用IFERROR统一变0。[官方说明](https://support.microsoft.com/zh-cn/excel/functions/xlookup-function)

## 五、SUMIFS汇总什么

例如“重算表”A列是科目，B列是部门，C列是本年重算金额，按科目与部门汇总：

```excel
=SUMIFS(重算表!$C$2:$C$1000,重算表!$A$2:$A$1000,$A2,重算表!$B$2:$B$1000,B$1)
```

求和区域在最前，所有范围长度一致，科目与部门使用同样编码。要防止金额是文本、重复行、汇总行与明细一起相加，以及币种混用。汇总能回总账，不代表每笔归集就合理。[官方说明](https://support.microsoft.com/zh-cn/excel/functions/sumifs-function)

## 六、账龄与逾期分开

单独的应收示例表中，截止日为2024-12-31，逐笔保留首次确认日期、合同到期日、未结金额、核销与回款，不按客户最后一笔交易统一起算。

- **账龄：** 截止日与该未结项相关起算日之间的时间，按已确认列示口径计算。
- **逾期：** 相对合同到期日的未结时间，未到期通常记0。
- **边界：** 如果用0—90、91—180、181—365、365以上天数，按日差分，不用“3个月乘30”冒充90天。
- **异常：** 未来日期或空日期先列待核，不用MAX取0把错误藏掉。
- **回款：** 需对应具体年末余额，部分结清或新订单预收不能当全额冲老账。
- **判断：** 账龄长不是自动全额坏账，减值评价还需其他证据及适用模型。

## 七、趋势预测怎样说才准确

可以用历史可比月份、人数和工资水平等形成简单合理性预期，比较实际值并查差异。不能把移动均值描述成独立经营预测系统，不能用行业增长替代客户实际业绩，也不把预测偏差当错报金额。
