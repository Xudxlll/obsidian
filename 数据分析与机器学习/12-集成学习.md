# 1. 集成学习

# 2. 概述

集成学习（ensemble learning）是一种经典的机器学习范式，它的核心思想是“三个臭皮匠顶个诸葛亮”，即通过构建并合并多个单模型（通常叫做"弱学习器"或"基学习器"）来完成学习任务，从而获得比单一学习模型更显著优越的泛化性能，简言之，集成学习就是利用模型的“集体智慧”，提升预测的准确率。

![集成学习1](img/集成学习1.png)

**集成学习的核心原理：为何 “组合” 能提升性能？**

集成学习的有效性源于对 **偏差（Bias） 和 方差（Variance）** 的协同优化，这两个指标是衡量模型泛化能力的关键：

- **偏差**：模型对数据真实规律的拟合能力不足，表现为 “欠拟合”（如简单线性模型无法捕捉非线性数据）。
- **方差**：模型对训练数据的波动过于敏感，表现为 “过拟合”（如复杂决策树在训练集上准确率极高，但在测试集上大幅下降）。

单个模型往往难以同时降低偏差和方差（例如，增加模型复杂度会降低偏差但升高方差），而集成学习通过以下逻辑实现优化：

1. **降低方差**：多个弱学习器的预测结果存在随机性差异，“多数投票” 或 “结果平均” 能抵消个体模型的极端误差（类似 “集体决策优于个人判断”）。
2. **降低偏差**：通过对弱学习器的迭代优化（如 Boosting），逐步修正前期模型的错误，迫使后续模型聚焦于难分样本，从而整体提升拟合能力。

# 3. 集成学习的核心范式

根据弱学习器的生成方式和组合策略，集成学习主要分为三大类：**Bagging、Boosting、Stacking**，三者在原理、流程和适用场景上差异显著。

| 维度 | **Bagging** | **Boosting** | **Stacking** |
|------|------------|-------------|-------------|
| **核心目标** | 降低**方差**（Variance） | 降低**偏差**（Bias） | 提升**泛化能力**（综合利用异构模型） |
| **基学习器关系** | **并行**生成，互不依赖 | **串行**生成，强依赖 | **并行**训练基学习器，**再训练**元学习器 |
| **样本处理** | Bootstrap 自助采样（有放回） | 每轮调整样本权重，聚焦错分样本 | 原始数据划分，基学习器独立训练 |
| **结果组合** | 投票（分类）/ 平均（回归） | 加权投票 / 加权平均 | 通过**元学习器**自动学习组合策略 |
| **典型算法** | 随机森林、Extra-Trees | AdaBoost、GBDT、XGBoost、LightGBM、CatBoost | StackingClassifier、Blending |
| **并行能力** | ✅ 高（基学习器可同时训练） | ❌ 低（必须串行迭代） | ✅ 基学习器可并行，元学习器需等待 |

## 3.1 Boosting

### 3.1.1 什么是Boosting

Boosting是集成学习方法中的一个大类，其目标是通过==减少整体的偏差==来提高系统的性能。具体来讲，这类集成学习方法会依次训练若干个“基学习器”，其中每个“基学习器”都试图纠正前一个“基学习器”的错误，最后通过对所有“基学习器”的结果以==加权投票==的方式进行结合得到最终结果。因此，这类集成学习方法中的“基学习器”之间存在强依赖的串行关系。

![集成学习2](img/集成学习2.png)

其工作原理是：

- 先训练出一个初始模型；
- 根据模型的表现进行调整，**使得模型预测错误的数据获得更多的关注**，再重新训练下一个模型；
- 不断重复第二步，直到模型数量达到预先设定的数目T，最终将这T个模型**加权结合**（所有弱学习器按各自权重加权投票（分类）或加权平均（回归），得到最终结果）。

### 3.1.2 AdaBoost算法

AdaBoost是Boosting算法族中最著名的算法，它根据每次训练集之中每个样本的分类是否正确，以及上次的总体分类的准确率，来确定每个样本的权值。将修改过权值的新数据集送给下层分类器进行训练，最后将每次训练得到的分类器最后融合起来，作为最后的决策分类器。

![集成学习3](img/集成学习3.png)

**具体来讲，AdaBoost的工作原理可概括为：**

**Step1（初始化权重）**：首先，为数据集中的每个样本分配相同的初始权重，确保所有样本在第一次迭代时都被平等对待。

**Step2（迭代训练“基学习器”）**：
- 在每一轮迭代中，使用当前权重分布的数据集来训练一个“基学习器”。
- 根据该“基学习器”的表现调整样本的权重。具体来说，**如果某个样本被正确分类，则降低其权重；若被错误分类，则增加其权重**。这样做是为了让下一轮“基学习器”更多地关注那些之前被误分类的样本。

**Step3（计算“基学习器”的重要性）**：每个“基学习器”都会根据其准确率获得一个权重值，这个值决定了它在最终决策中的话语权。准确率越高的“基学习器”将获得更高的权重。

**Step4（组合“基学习器”）**：最后，所有训练好的“基学习器”按照各自的重要性进行加权投票或加权求和，形成最终的“强学习器”。

### 3.1.3 GBDT算法

GBDT（Gradient Boosting Decision Tree 梯度提升树）通过多轮迭代，每轮迭代产生一个弱分类器，每个分类器在上一轮分类器的残差（**残差在数理统计中是指实际观察值与估计值（拟合值）之间的差**）基础上进行训练。基于预测结果的残差设计损失函数。GBDT训练的过程即是求该损失函数最小值的过程。

**具体来讲，GBDT的工作原理可概括为：**

**Step1（初始化模型）**：首先，初始化一个简单的模型（通常是一个常数值），作为初始预测结果。

**Step2（计算负梯度/伪残差）**：对于每个样本，基于当前模型的预测值计算损失函数相对于预测值的负梯度。这个负梯度在GBDT中充当了“残差”的角色，表示模型预测与真实值之间的差异。

**Step3（拟合“基学习器”到负梯度）**：使用当前的负梯度作为目标变量，训练一个新的决策树来拟合这些值。这一步的目标是找到能够最好解释负梯度（即残差）的模型。

**Step4（更新模型）**：将新训练的决策树添加到现有模型中，并根据学习率调整其贡献程度。学习率是一个介于0和1之间的参数，用于控制每棵新树对整体模型的影响大小。

**Step5（重复步骤2-4）**：重复上述过程，直到达到预设的最大迭代次数或满足其他停止条件（如模型不再显著改善）。

```python
import numpy as np
import matplotlib.pyplot as plt
import sklearn.datasets as sd
import sklearn.model_selection as ms
import sklearn.ensemble as se
import sklearn.metrics as sm
import sklearn.inspection as si

# 设置字体为 SimHei（黑体），支持中文显示
plt.rcParams["font.family"] = ["SimHei"]

# 1. 准备数据
# 加载鸢尾花数据集
iris = sd.load_iris()
X = iris.data[:, :2]  # 只使用前两个特征，便于可视化
y = iris.target

# 将其转换为二分类问题（类别0 vs 类别1和2）
y = np.where(y == 0, 0, 1)  # np.where(condition,x,y) 判断条件，为True的地方设置为x,否则为y
# print(y)

# 划分训练集和测试集
X_train, X_test, y_train, y_test = ms.train_test_split(
    X, y, test_size=0.3, random_state=7
)

# 2. 创建并训练GBDT模型
gbdt = se.GradientBoostingClassifier(
    n_estimators=100,  # 弱学习器的数量
    learning_rate=0.1,  # 学习率
    max_depth=3,  # 决策树的最大深度
    random_state=7
)

# 训练模型
gbdt.fit(X_train, y_train)

# 3. 模型评估
# 在测试集上进行预测
y_pred = gbdt.predict(X_test)

# 计算准确率
accuracy = sm.accuracy_score(y_test, y_pred)
print(f"准确率: {accuracy:.4f}")

# 打印分类报告
print("\n分类报告:")
print(sm.classification_report(y_test, y_pred))

# 4. 特征重要性分析
feature_importance = gbdt.feature_importances_
feature_names = iris.feature_names[:2]

print("\n特征重要性:")
for name, importance in zip(feature_names, feature_importance):
    print(f"{name}: {importance:.4f}")

# 5. 可视化决策边界
_, ax = plt.subplots(figsize=(10, 6))
si.DecisionBoundaryDisplay.from_estimator(
    gbdt, X, ax=ax, response_method="predict",
    cmap=plt.cm.Paired, alpha=0.8,
    xlabel=feature_names[0], ylabel=feature_names[1]
)

# 绘制训练点
plt.scatter(X_train[:, 0], X_train[:, 1], c=y_train, cmap=plt.cm.Paired, edgecolors="k", label="训练集")
# 绘制测试点
plt.scatter(X_test[:, 0], X_test[:, 1], c=y_test, cmap=plt.cm.Paired, edgecolors="r", marker="s", label="测试集")

plt.title("GBDT分类决策边界")
plt.legend()
plt.show()

# 6. 观察不同数量的弱学习器对性能的影响
train_errors = []
test_errors = []
n_estimators_range = range(1, 101)

for n_estimators in n_estimators_range:
    gbdt = se.GradientBoostingClassifier(
        n_estimators=n_estimators,
        learning_rate=0.1,
        max_depth=3,
        random_state=42
    )
    gbdt.fit(X_train, y_train)

    # 计算训练误差
    y_pred_train = gbdt.predict(X_train)
    train_errors.append(1 - sm.accuracy_score(y_train, y_pred_train))

    # 计算测试误差
    y_pred_test = gbdt.predict(X_test)
    test_errors.append(1 - sm.accuracy_score(y_test, y_pred_test))

# 绘制误差曲线
plt.figure(figsize=(10, 6))
plt.plot(n_estimators_range, train_errors, label="训练误差")
plt.plot(n_estimators_range, test_errors, label="测试误差")
plt.xlabel("弱学习器数量")
plt.ylabel("误差率")
plt.title("不同数量的弱学习器对GBDT性能的影响")
plt.legend()
plt.grid(True)
plt.show()
```

### 3.1.4 XGBoost（极端梯度提升）

XGBoost（eXtreme Gradient Boosting）是 GBDT 的**工程优化版**，由陈天奇于 2014 年提出。它在保留 GBDT 核心思想（拟合残差/负梯度）的基础上，从算法和工程两个层面做了大量改进，是目前 Kaggle 竞赛和工业界最广泛使用的算法之一。

**核心改进点**：

| 改进维度 | GBDT | XGBoost |
|----------|------|---------|
| **损失函数近似** | 使用一阶导数（负梯度） | 使用**二阶泰勒展开**，同时利用一阶和二阶导数，拟合更精确 |
| **正则化** | ❌ 无 | ✅ 在目标函数中加入 **L1（Lasso）和 L2（Ridge）正则项**，控制树的复杂度，防止过拟合 |
| **列抽样** | ❌ 只用全部特征 | ✅ 支持列抽样（Column Subsampling），类似随机森林的思路，降低方差 |
| **缺失值处理** | 需手动填充 | ✅ 内置稀疏感知（Sparsity-aware）算法，自动学习缺失值的最佳分裂方向 |
| **并行化** | 串行训练 | ✅ 特征粒度并行：分裂节点时按特征并行计算，极大加速训练 |
| **剪枝策略** | 自底向上剪枝 | 自顶向下**后剪枝**：生长到 max_depth 后反向剪枝，避免贪心陷阱 |
| **学习率衰减** | 固定学习率 | 支持学习率衰减（Shrinkage），每棵树贡献乘以学习率 |

**sklearn API**：

```python
import xgboost as xgb

# 回归
model = xgb.XGBRegressor(
    n_estimators=100,        # 树的数量
    learning_rate=0.1,       # 学习率（Shrinkage）
    max_depth=6,             # 树的最大深度
    subsample=0.8,           # 样本采样比例
    colsample_bytree=0.8,    # 特征采样比例
    reg_alpha=0,             # L1 正则化
    reg_lambda=1,            # L2 正则化
    random_state=7
)

# 分类
model = xgb.XGBClassifier(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=6,
    subsample=0.8,
    colsample_bytree=0.8,
    random_state=7
)

model.fit(train_x, train_y)
pred_test_y = model.predict(test_x)
```

**核心参数速查**：

| 参数 | 含义 | 建议值 |
|------|------|--------|
| `n_estimators` | 迭代轮数/树的数量 | 100~1000 |
| `learning_rate` | 学习率（η），控制每棵树的贡献 | 0.01~0.3 |
| `max_depth` | 树的最大深度 | 3~10 |
| `subsample` | 每棵树使用的样本比例 | 0.6~1.0 |
| `colsample_bytree` | 每棵树使用的特征比例 | 0.6~1.0 |
| `reg_alpha` | L1 正则化权重 | 0~∞ |
| `reg_lambda` | L2 正则化权重 | 0~∞ |

> **调参口诀**：先调 `n_estimators` 和 `learning_rate`（二者成反比——学习率小则树多），再调 `max_depth` 和 `subsample` 控制过拟合，最后用 `reg_alpha` / `reg_lambda` 微调正则化。

### 3.1.5 LightGBM（轻量梯度提升机）

LightGBM（Light Gradient Boosting Machine）是微软于 2017 年开源的 GBDT 实现，核心目标是解决 XGBoost 在**大数据量、高维度**场景下的训练效率瓶颈。

**核心创新**：

**① 直方图算法（Histogram-based Algorithm）**

传统 GBDT 在分裂节点时需要遍历每个特征的所有取值来寻找最优分割点，复杂度为 O(数据量 × 特征数)。LightGBM 将连续特征**离散化为 K 个桶（bins）**，只需在 K 个桶的边界中搜索最优分割点，复杂度降为 O(K × 特征数)，极大减少了计算和内存开销。

**② 单边梯度采样（GOSS，Gradient-based One-Side Sampling）**

不是所有样本对信息增益的贡献相同——**梯度大**的样本（训练不足，需要重点关注）贡献更大。GOSS 保留所有大梯度样本，对大梯度样本做随机采样，在保证精度的同时大幅减少训练数据量。

**③ 互斥特征绑定（EFB，Exclusive Feature Bundling）**

在高维稀疏数据中，许多特征是互斥的（不同时为非零值），EFB 将这些互斥特征合并为一个特征包（bundle），从而减少有效特征维度，进一步提升效率。

**④ Leaf-wise 生长策略（按叶子生长）**

| 策略 | 方式 | 优点 | 缺点 |
|------|------|------|------|
| **Level-wise**（XGBoost、GBDT） | 按层逐层生长 | 平衡性好，可并行按层计算 | 分裂了不必要的节点 |
| **Leaf-wise**（LightGBM） | 选取分裂后增益最大的叶子分裂 | **精度更高、训练更快**，减少无效分裂 | 小数据集容易过拟合 |

**sklearn API**：

```python
import lightgbm as lgb

# 回归
model = lgb.LGBMRegressor(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=-1,             # -1 表示不限制（Leaf-wise 下靠 num_leaves）
    num_leaves=31,            # 叶子节点最大数（控制树的复杂度）
    subsample=0.8,
    colsample_bytree=0.8,
    random_state=7
)

# 分类
model = lgb.LGBMClassifier(
    n_estimators=100,
    learning_rate=0.1,
    num_leaves=31,
    subsample=0.8,
    colsample_bytree=0.8,
    random_state=7
)

model.fit(train_x, train_y)
pred_test_y = model.predict(test_x)
```

**核心参数速查**：

| 参数 | 含义 | 建议值 |
|------|------|--------|
| `num_leaves` | 叶子节点数量（控制复杂度） | < 2^max_depth，通常 31~127 |
| `min_data_in_leaf` | 每个叶子的最小样本数 | 20~100（防止过拟合） |
| `bagging_freq` | Bagging 频率（每 k 轮做一次采样） | 1~5 |
| `feature_fraction` | 每轮随机选择的特征比例 | 0.6~0.9 |

> ⚠️ **注意**：LightGBM 的 `num_leaves` 是控制模型复杂度的核心参数，而非 `max_depth`。Leaf-wise 策略下，应**限制 num_leaves** 而非 max_depth 来防止过拟合。

**适用场景**：
- 大数据量（百万级以上样本/高维度特征）
- 对训练速度和内存占用有严格要求
- 在线学习或增量学习需求

### 3.1.6 CatBoost（分类特征增强提升）

CatBoost（Categorical Boosting）由俄罗斯 Yandex 公司于 2017 年开源，核心亮点是对**类别特征**（Categorical Features）的原生支持，以及通过**有序提升**（Ordered Boosting）解决传统 GBDT 的**预测偏移**（Prediction Shift）问题。

**核心创新**：

**① 类别特征的原生处理**

传统 GBDT 变体需要对类别特征做预处理（独热编码 / 标签编码 / 目标编码），这些方法各有缺陷：独热编码导致维度爆炸，标签编码引入了不存在的序关系，目标编码容易过拟合。

CatBoost **不需要手动处理类别特征**，只需指定哪些列是类别特征即可。它在训练时使用**有序目标统计（Ordered Target Statistics, Ordered TS）**，基于排列组合的方式对每个样本计算目标统计量，有效避免了数据泄露。

```python
# CatBoost 可以自动识别和编码类别特征
catboost_model.fit(
    X_train, y_train,
    cat_features=['gender', 'city', 'product_type']  # 只需指定类别列名
)
```

**② 有序提升（Ordered Boosting）**

传统 GBDT 在计算梯度时使用与训练相同的样本，导致**预测偏移**（模型在训练样本上的残差分布与测试样本不一致，产生有偏估计）。

CatBoost 对每个样本使用一个**排在该样本之前的子集**训练的模型来计算残差，确保残差估计无偏，从而提升泛化能力。

**③ 对称树（Oblivious Trees）**

CatBoost 默认使用对称树结构，即同一层的所有节点使用相同的分裂特征和阈值。这带来了两个好处：
- 预测速度极快（通过索引查表即可完成）
- 天然的模型紧凑性，降低过拟合

**sklearn API**：

```python
import catboost as cb

# 回归
model = cb.CatBoostRegressor(
    iterations=500,           # 迭代次数（等价于 n_estimators）
    learning_rate=0.03,
    depth=6,                  # 树深度（对称树，同层特征相同）
    l2_leaf_reg=3,            # L2 正则化
    random_seed=7,
    verbose=100               # 每 100 轮打印一次日志
)

# 分类
model = cb.CatBoostClassifier(
    iterations=500,
    learning_rate=0.03,
    depth=6,
    l2_leaf_reg=3,
    random_seed=7,
    verbose=100
)

model.fit(
    train_x, train_y,
    cat_features=cat_feature_indices,  # 指定类别特征列的索引
    eval_set=(test_x, test_y),         # 验证集（用于早停）
    early_stopping_rounds=50           # 50 轮不提升则早停
)

pred_test_y = model.predict(test_x)
```

**核心参数速查**：

| 参数 | 含义 | 建议值 |
|------|------|--------|
| `iterations` | 迭代次数 | 500~2000 |
| `learning_rate` | 学习率 | 0.01~0.1 |
| `depth` | 对称树深度 | 4~10 |
| `l2_leaf_reg` | L2 正则化系数 | 1~10 |
| `random_strength` | 随机噪声强度（防过拟合） | 0~1 |
| `one_hot_max_size` | 类别数低于此值的特征使用独热编码 | 2~10 |

**适用场景**：
- 数据中包含大量类别特征（无需手动编码）
- 希望减少特征工程工作量
- 需要可靠的默认参数（CatBoost 对默认参数不敏感，不调参也能取得不错效果）

## 3.2 Bagging

### 3.2.1 什么是Bagging

Bagging（Bootstrap Aggregating）是集成学习方法中的一个大类，其目标是通过==减少整体的方差==来提高系统的性能。具体来讲，这类集成学习方法通过自助采样法（Bootstrap Sampling，随机有放回的抽样）生成多个训练集，然后在每个训练集上训练出一个“基学习器”，最后通过对所有“基学习器”的结果进行投票（分类问题）或平均（回归问题）的方式得到最终结果。因此，这类集成学习方法中的“基学习器”之间不存在依赖关系。

### 3.2.2 随机森林（Random Forest）

#### 3.2.2.1 什么是随机森林

随机森林（Random Forest，简称RF）是专门为决策树设计的一种集成方法，是Bagging法的一种拓展，它是指每次构建决策树模型时，==不仅随机选择部分样本，而且还随机选择部分特征来构建多棵决策树.==  这样不仅规避了强势样本对预测结果的影响，而且也削弱了强势特征的影响，使模型具有更强的泛化能力。

随机森林简单、容易实现、计算开销小，在很多现实任务中展现出强大的性能，被誉为“代表集成学习技术水平的方法”。

![集成学习6](img/集成学习6.png)

**具体来讲，Random Forest的工作原理可概括为：**

**Step1（数据采样）**：首先，从原始训练集中使用Bootstrap方法生成多个不同的子集。这一步骤有助于增加模型之间的多样性，若每棵树的样本集都一样，训练得到的每棵决策树都将会是一样的；若不放回抽样，每个训练样本集及其分布都不一样，可能导致训练的各决策树差异性很大，最终将难以进行结果汇总。

**Step2（特征选择）**：对于每棵决策树，在每一个节点上，不是考虑所有特征，而是随机选择一个特征子集，并从中选择最佳分割点。这一步骤有助于增加模型之间的多样性，从而提高整体模型的泛化能力和抗噪能力。

**Step3（构建决策树**）：在每个子集上构建一棵决策树。通常，这些树会生长到最大深度，不做剪枝处理。这是因为随机森林依赖于多棵树的平均效果来减少过拟合的风险，而不是单棵树的表现。

**Step4（结果汇总）**：

- 对于分类问题，最终输出是各个决策树预测结果的多数投票。

- 对于回归问题，最终输出是各个决策树预测结果的平均值。

#### 3.2.2.2 如何实现随机森林

sklearn中，随机森林相关API：

```python

    n_estimators, # 决策树数量
    min_samples_split)# 子表中最小样本数 若小于这个数字，则不再继续向下拆分
```

### 3.2.3 Extra-Trees（极端随机树）

Extra-Trees（Extremely Randomized Trees，极端随机树）是随机森林的进一步随机化变体。与随机森林相比，它在**列采样（特征选择）**和**阈值选取**两个维度都引入了更强的随机性：

| 维度 | 随机森林 | Extra-Trees |
|------|---------|------------|
| **样本采样** | Bootstrap 有放回抽样 | Bootstrap 有放回抽样（也可用全量数据） |
| **特征选择** | 每个节点随机选特征子集 | 每个节点随机选特征子集 |
| **分裂阈值** | 在候选特征上搜索**最优分割点** | 在候选特征上**随机选择分割点** |

由于分裂阈值完全随机选取，Extra-Trees 的方差比随机森林更低，单棵树的偏差会更高，但通过大量树的聚合仍能获得优秀的整体性能。同时，省去了最优分割点的搜索过程，**训练速度明显快于随机森林**。

**适用场景**：
- 数据维度极高、特征数量大的场景
- 对训练时间有严格要求的生产环境
- 作为快速 baseline 验证集成学习效果

**sklearn API**：

```python
import sklearn.ensemble as se

model = se.ExtraTreesRegressor(
    max_depth=10,           # 决策树最大深度
    n_estimators=100,       # 决策树数量
    min_samples_split=2,    # 子节点最小样本数
    random_state=7
)
model.fit(train_x, train_y)
pred_test_y = model.predict(test_x)
```

## 3.3 Stacking（堆叠法）

### 3.3.1 什么是 Stacking

Stacking（Stacked Generalization，堆叠泛化）是一种**元学习（Meta-Learning）**方法，其核心思想是：让多个不同类型的强学习器并行预测，再由一个"元学习器"来学习如何最优地组合这些预测结果。

与 Bagging / Boosting 不同：

- **Bagging / Boosting**：使用同质弱学习器（通常是决策树），通过投票或平均的方式组合，组合策略是人工预设的（"多数投票"或"加权平均"）。
- **Stacking**：不对基学习器的类型做限制（可以是决策树、SVM、逻辑回归、KNN 等异构模型），组合策略不是人工设定，而是**由一个额外的模型（元学习器）从数据中自动学习**出来。

**工作流程**：

![Stacking 流程示意](img/Stacking流程.png)

1. **第一层（基学习器层 / Level-0）**：用原始训练数据训练 $N$ 个异构基学习器
2. **生成元特征**：使用 **K 折交叉验证**让每个基学习器对训练集做预测，将 $N$ 个模型的预测值拼接成 $N$ 列"元特征"
3. **第二层（元学习器层 / Level-1）**：以元特征为输入、原始标签为目标，训练元学习器，学习最优组合策略
4. **最终预测**：新数据先经第一层各模型预测得到元特征，再经第二层元学习器得到最终结果

> ⚠️ **关键细节**：元特征必须通过交叉验证（Out-of-Fold Prediction）生成，禁止用训练集的直接预测值。否则会出现严重的数据泄露，导致元学习器严重过拟合。

### 3.3.2 Stacking 的实现

sklearn 提供了 `StackingClassifier` 和 `StackingRegressor`：

```python
from sklearn.ensemble import StackingClassifier, StackingRegressor
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC
from sklearn.tree import DecisionTreeClassifier
from sklearn.neighbors import KNeighborsClassifier

# 定义第一层基学习器（异构模型）
estimators = [
    ('dt', DecisionTreeClassifier(max_depth=5)),
    ('svm', SVC(probability=True)),
    ('knn', KNeighborsClassifier(n_neighbors=5)),
]

# 定义第二层元学习器（通常用简单模型，如逻辑回归）
final_estimator = LogisticRegression()

# 构建 Stacking 模型
stacking_clf = StackingClassifier(
    estimators=estimators,
    final_estimator=final_estimator,
    cv=5,  # 5折交叉验证生成元特征
    stack_method='predict_proba'  # 使用概率而非类别标签（信息更丰富）
)

# 训练与预测
stacking_clf.fit(X_train, y_train)
y_pred = stacking_clf.predict(X_test)
```

**完整示例：Stacking 分类**

```python
import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.ensemble import StackingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC
from sklearn.tree import DecisionTreeClassifier
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score, classification_report

# 加载乳腺癌数据集
data = load_breast_cancer()
X, y = data.data, data.target
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# 第一层：异构基学习器
estimators = [
    ('dt', DecisionTreeClassifier(max_depth=5, random_state=42)),
    ('svm', SVC(kernel='rbf', probability=True, random_state=42)),
    ('knn', KNeighborsClassifier(n_neighbors=5)),
]

# 第二层：元学习器
final_estimator = LogisticRegression(max_iter=1000)

# 构建 Stacking 模型
stacking_clf = StackingClassifier(
    estimators=estimators,
    final_estimator=final_estimator,
    cv=5  # 5折交叉验证
)

# 训练
stacking_clf.fit(X_train, y_train)

# 预测与评估
y_pred = stacking_clf.predict(X_test)
print(f"Stacking 准确率: {accuracy_score(y_test, y_pred):.4f}")
print("\n分类报告:")
print(classification_report(y_test, y_pred, target_names=data.target_names))

# 对比各单模型的性能
for name, model in estimators:
    model.fit(X_train, y_train)
    y_pred_single = model.predict(X_test)
    acc = accuracy_score(y_test, y_pred_single)
    print(f"{name} 单独准确率: {acc:.4f}")

print("\n可以看到，Stacking 通常优于任一单独的基学习器。")
```

### 3.3.3 Blending（简易堆叠）

Blending 是 Stacking 的简化版本，区别在于**不使用交叉验证**生成元特征，而是直接划分一个 hold-out 验证集：

| 对比维度 | Stacking | Blending |
|----------|---------|----------|
| **训练集划分** | 原始训练集完整用于 K 折交叉验证 | 划分出 hold-out 验证集（如 10%~20%） |
| **元特征生成** | K 折交叉验证（Out-of-Fold） | 直接用验证集的预测值 |
| **数据利用率** | 高（K-1/K 的数据参与训练） | 较低（验证集不参与基学习器训练） |
| **过拟合风险** | 低（交叉验证有效防止泄露） | 较高（数据量少时元特征不稳定） |
| **实现复杂度** | 中等 | 低（逻辑更直观） |

**Blending 流程**：
1. 将训练集分为两份：主训练集（80%）和验证集（20%）
2. 在主训练集上训练所有基学习器
3. 用验证集生成元特征
4. 以元特征训练元学习器（逻辑回归等）

**适用场景**：数据量较大时（验证集不会损失太多信息），追求快速原型验证。

```python
# Blending 简易实现示例
from sklearn.model_selection import train_test_split

# 1. 划分主训练集和验证集
X_main, X_val, y_main, y_val = train_test_split(
    X_train, y_train, test_size=0.2, random_state=42
)

# 2. 在主训练集上训练基学习器
model1 = DecisionTreeClassifier(max_depth=5).fit(X_main, y_main)
model2 = SVC(probability=True).fit(X_main, y_main)
model3 = KNeighborsClassifier(n_neighbors=5).fit(X_main, y_main)

# 3. 用验证集生成元特征
import numpy as np
meta_features = np.column_stack([
    model1.predict_proba(X_val)[:, 1],  # 只取正类概率
    model2.predict_proba(X_val)[:, 1],
    model3.predict_proba(X_val)[:, 1],
])

# 4. 训练元学习器
meta_model = LogisticRegression().fit(meta_features, y_val)

# 5. 在测试集上最终预测
test_meta = np.column_stack([
    model1.predict_proba(X_test)[:, 1],
    model2.predict_proba(X_test)[:, 1],
    model3.predict_proba(X_test)[:, 1],
])
y_pred_final = meta_model.predict(test_meta)
```
