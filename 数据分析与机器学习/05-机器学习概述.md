# 机器学习概述

## 1. 什么是机器学习

1975年图灵奖获得者、1978年诺贝尔经济学奖获得者、著名学者赫伯特.西蒙（Herbert Simon）曾下过一个定义：如果一个系统，能够通过执行某个过程，就此改进了它的性能，那么这个过程就是学习。由此可看出，学习的目的就是改善性能，机器学习是一门能够让编程计算机从数据中学习的计算机科学。

卡耐基梅隆大学机器学习和人工智能教授汤姆.米切尔（Tom Mitchell）在他的经典教材《机器学习》中，给出了更为具体的定义：对于某类任务（Task，简称 T ）和某项性能评价准则（Performance，简称 P ），如果一个计算机在程序 T 上，以 P 作为性能度量，随着经验（Experience，简称 E ）的积累，不断自我完善，那么我们称计算机程序从经验E中进行了学习。

![basketball](./img/basketball.png)

例如，篮球运动员投篮训练过程：球员投篮（任务 T ），以准确率为性能度量（ P ）随着不断练习（经验 E ），准确率不断提高，这个过程称为学习。

## 2. 机器学习的形式

1. 建模问题
   所谓机器学习建模，在形式上可这样理解：在数据对象中通过统计或推理的方法，寻找一个接受特定输入 X，并给出预期输出 Y 的功能函数 f，即：

$$
Y = f(x)
$$

这个函数以及确定函数的参数被称为模型。
   
2. 评估问题
   针对已知的输入，函数给出的输出(预测值)与实际输出(目标值)之间存在一定的误差，因此需要构建一个评估体系，根据误差的大小判定函数的优劣。
   
3. 优化问题
   学习的核心在于改善性能，通过数据对算法的反复锤炼，不断提升函数预测的准确性，直至获得能够满足实际需求的最优解，这个过程就是机器学习。

## 3. 机器学习的种类

### 3.1 有监督学习

定义：在已知数据输出（经过标注的）的情况下对模型进行训练，根据输出进行调整、优化的学习方式称为有监督学习。

根据图片，预测图像的类别。

![有监督学习](./img/%E6%9C%89%E7%9B%91%E7%9D%A3%E5%AD%A6%E4%B9%A0.png)

### 3.2 无监督学习

定义：没有已知输出的情况下，仅仅根据输入信息的相关性，进行类别的划分。

![无监督学习](./img/%E6%97%A0%E7%9B%91%E7%9D%A3%E5%AD%A6%E4%B9%A0.png)

### 3.3 半监督学习

定义：先通过无监督学习划分类别，再人工标记通过有监督学习方式来预测输出。

例如先对相似的水果进行聚类，再识别是哪个类别。

![半监督学习](./img/%E5%8D%8A%E7%9B%91%E7%9D%A3%E5%AD%A6%E4%B9%A0.png)

**有监督、无监督、半监督的区别**

| 学习方式  | 是否有标签       | 例子                |
| ----- | ----------- | ----------------- |
| 有监督学习 | 全部或大部分数据有标签 | 图片已经标好苹果、香蕉、橙子    |
| 无监督学习 | 数据没有标签      | 只根据相似度把水果自动分堆     |
| 半监督学习 | 少量有标签，大量无标签 | 先分堆，再用少量标签判断每堆是什么 |

### 3.4 批量学习和增量学习

1. 批量学习：将学习的过程和应用的过程截然分开，用全部的训练数据训练模型，然后再在应用场景中实现预测，当预测结果不够理想时，重新回到学习过程，如此循环。

2. 增量学习：将学习的过程和应用的过程统一起来，在应用的同时以增量的方式，不断学习新的内容，边训练边预测。

#### 3.4.1 批量学习

批量学习也叫**离线学习**。

它的特点是：先收集一批完整数据，用这些数据一次性训练模型；训练好之后，再拿模型去预测。

也就是说，**训练阶段**和**使用阶段**是分开的。

流程可以理解为：

```text
收集大量数据
↓
一次性训练模型
↓
模型上线使用
↓
发现效果不好
↓
重新收集数据，再重新训练
```

例如：训练一个房价预测模型。

先收集很多历史房屋数据：

- 面积
- 地段
- 楼层
- 年份
- 实际成交价

然后用这一整批数据训练出一个模型。模型训练好以后，就拿它去预测新房子的价格。

如果后来房价市场变化很大，比如政策变了、区域价格上涨了，那么原来的模型可能不准了。这时就需要重新收集新数据，再重新训练模型。

> 所以批量学习的特点是：
> 
> - 一次性使用大量训练数据
> - 训练完成后模型固定
> - 新数据不会自动改变模型
> - 如果模型过时，需要重新训练

#### 3.4.2 增量学习

增量学习也叫**在线学习**。

它的特点是：模型一边使用，一边接收新数据，并不断更新自己。

也就是说，**训练阶段**和**应用阶段**不是完全分开的，而是结合在一起的。

流程可以理解为：

```text
先训练一个初始模型
↓
模型开始预测
↓
不断接收新数据
↓
模型持续更新
↓
继续预测
```

例如：短视频推荐系统。

刚开始刷视频时，系统可能不知道你喜欢什么。但你每一次点击、点赞、停留、划走，都会变成新的数据。

系统会根据这些新数据不断调整推荐模型：

- 你多看篮球视频，它就多推荐篮球
- 你不看美食视频，它就减少美食推荐
- 你突然开始看旅游内容，它也会慢慢调整

> 这就是增量学习：**模型不是训练一次就不变，而是根据新数据持续学习**。

#### 3.4.3 二者区别

| 对比点 | 批量学习 | 增量学习 |
|---|---|---|
| 学习方式 | 一次性用全部数据训练 | 持续接收新数据并更新 |
| 训练和预测 | 分开 | 同时进行 |
| 模型是否经常更新 | 不经常 | 经常 |
| 适合场景 | 数据稳定、变化慢 | 数据变化快、实时性强 |
| 例子 | 房价预测、考试成绩预测 | 推荐系统、广告系统、实时风控 |

可以这样记：

> **批量学习像“集中复习后考试”**：先把所有资料学完，再去做题。  
> **增量学习像“边工作边学习”**：遇到新情况，就不断调整自己的经验。

### 3.5 基于实例的学习和基于模型的学习

- **基于实例的学习**

根据以往经验，寻找与待预测输入最接近的样本，以其输出作为预测结果（从数据中心找答案）。例如有如下一组数据：

| 年龄  | 学历  | 经验  | 性别  | 月薪  |
| :-: | :-: | :-: | :-: | :-: |
| 25  | 硕士  |  2  |  女  |  中  |
| 20  | 本科  |  3  |  男  |  低  |
| ... | ... | ... | ... | ... |
| 20  | 本科  |  3  |  男  |  ？  |

- **基于模型的学习**

根据样本数据，建立用于联系输入和输出的某种数学模型，将待预测输入带入该模型，预测其结果。

| 输入(x) | 输出(y) |
| :---: | :---: |
|   1   |   2   |
|   2   |   4   |
|   3   |   6   |
|   4   |   8   |

根据数据，得到模型：

$$
y = 2x
$$

预测：输入9时，输出是多少？

## 4. 机器学习的一般过程

- **数据处理**

1. 数据收集 （手工采集、设备自动化采集、爬虫）
2. 数据清洗（数据规范、具有较大误差的、没有意义的数据进行清理）
3. 特征工程（特征提取、特征转换、特征选择）

- **模型搭建**

1. 选择模型 （算法）
2. 训练模型 （算法）
3. 评估模型 （工具、框架、算法知识）
4. 测试模型

- **模型部署**

1. 应用模型
2. 维护模型

## 1.6 机器学习的基本问题

- 回归（Regression）问题

  根据已知的输入和输出，寻找某种性能最佳的模型，将未知输出的输入代入模型，得到**连续的输出**.例如：

  - 根据房屋面积、地段、修建年代以及其它条件预测房屋价格
  - 根据各种外部条件预测某支股票的价格
  - 根据农业、气象等数据预测粮食收成
  - 计算两个人脸的相似度

- 分类（Classification）问题

  根据已知的输入和输出，寻找性能最佳的模型，将未知输出的输入带入模型，得到**离散的输出**，例如：

  - 手写体识别（10个类别分类问题）
  - 水果、鲜花、动物识别
  - 工业产品瑕疵检测（良品、次品二分类问题）
  - 识别一个句子表达的情绪（正面、负面、中性）

- 聚类问题（无监督学习）

  根据已知输入的**相似程度**，将其划分为不同的群落（簇），例如：

  - 根据一批麦粒的数据，判断哪些属于同一个品种
  - 根据客户在电商网站的浏览和购买历史，判断哪些客户对某件商品感兴趣
  - 判断哪些客户具有更高的相似度

- 降维问题

  在性能损失尽可能小的前提下，降低数据的复杂度，数据规模缩小都称为降维问题。

  更精确地说，**降维是指将高维空间中的数据映射到一个低维空间中，同时尽可能保留原始数据中的关键信息**。这里的"维"指的就是**特征（Feature）的数量**。

  例如，一个房价数据包含 50 个特征（面积、地段、楼层、房龄、装修、朝向、学区……），这 50 个特征就是 50 维。降维的目标是：能否用 5 个或 10 个"合成特征"来代替原来的 50 个，同时预测房价的精度基本不下降？

  **降维的核心公式**：原始数据 $X \in \mathbb{R}^{n \times d}$（n 个样本，d 个特征），降维后得到 $X' \in \mathbb{R}^{n \times k}$，其中 $k \ll d$。

  **维度灾难（Curse of Dimensionality）** 是降维最根本的动机：

| 问题 | 说明 |
|:---|:---|
| **数据稀疏化** | 维度增加时，数据点在空间中变得极其稀疏。10 个点均匀分布在一条线（1维）上很密集，但分布在 100 维超立方体中，它们之间的距离几乎没有区分度 |
| **计算开销爆炸** | 很多算法（如 KNN、K-Means）的时间复杂度与维度成正比甚至指数级增长 |
| **过拟合风险** | 特征越多，模型越容易"记住"噪声而不是学到规律，尤其样本量不够大时 |
| **可视化困难** | 人类最多只能理解 3 维空间，高维数据无法直接观察和分析 |
| **多重共线性** | 很多特征之间高度相关（如"房屋面积"和"房间数量"），冗余信息会干扰模型 |

  > 经典例子：MNIST 手写数字识别中，每张图片是 28×28 = **784 维**。用 PCA 降到 50 维后，分类准确率几乎不变，而训练速度提升了十几倍。

  **降维有两大途径：**

  **1. 特征选择（Feature Selection）**：直接挑选原始特征的一个子集，扔掉不重要的特征。

| 方法类型 | 说明 | 典型算法 |
|:---|:---|:---|
| 过滤法（Filter） | 用统计指标评分，独立于模型 | 方差阈值、卡方检验、互信息、相关系数 |
| 包裹法（Wrapper） | 用模型性能来评估特征子集 | 递归特征消除（RFE）、前向/后向搜索 |
| 嵌入法（Embedded） | 模型训练过程中自动选择 | L1 正则化（Lasso）、决策树的特征重要性 |

  - 优点：保留的维度有物理意义，可解释性强
  - 缺点：可能丢失特征组合中隐含的信息

  **2. 特征提取（Feature Extraction / Projection）**：通过数学变换，将原始特征**组合、投影**成新的低维特征。

| 方法 | 核心思想 | 有无监督 |
|:---|:---|:---|
| PCA（主成分分析） | 找到方差最大的方向（主成分），将数据投影到这些方向上 | 无监督 |
| LDA（线性判别分析） | 找到最能区分不同类别的投影方向 | 有监督 |
| t-SNE | 保持高维空间中邻近点的相对关系，映射到低维 | 无监督 |
| UMAP | 保留局部和全局结构，比 t-SNE 更快更稳定 | 无监督 |
| 自编码器（Autoencoder） | 用神经网络压缩再重建，中间层就是降维结果 | 无监督/半监督 |

  - 优点：能捕捉特征之间的复杂关系，降维效果通常更好
  - 缺点：新特征（如"主成分 1"）难以用业务语言解释

  **PCA 原理简析：**

  PCA 是使用最广泛的线性降维方法：

  1. **中心化**：将数据中心平移到原点
  2. **找第一主成分**：在所有方向中，找到数据投影后**方差最大**的方向（方差大 = 信息量大）
  3. **找第二主成分**：在与第一主成分正交的方向中，再找方差最大的方向
  4. **迭代进行**，直到得到 k 个主成分
  5. 每个主成分的方差对应**特征值**，方差占比反映其"保留了多少原始信息"：

  $$\text{信息保留比例} = \frac{\sum_{i=1}^{k} \lambda_i}{\sum_{i=1}^{d} \lambda_i}$$

  ```python
  from sklearn.decomposition import PCA
  pca = PCA(n_components=0.95)  # 保留95%的信息量，自动确定降维后的维度
  X_reduced = pca.fit_transform(X)
  ```

  **降维的应用场景：**

| 场景 | 说明 | 常用方法 |
|:---|:---|:---|
| 数据可视化 | 将高维数据降到 2D/3D 以便观察分布 | t-SNE、UMAP、PCA |
| 加速模型训练 | 减少特征数量，降低计算复杂度 | PCA、特征选择 |
| 去除噪声 | 丢弃方差小的成分（通常对应噪声） | PCA |
| 特征去相关 | 消除多重共线性，提升线性模型稳定性 | PCA |
| 数据压缩 | 减少存储和传输成本 | 自编码器、PCA |

  **降维的局限与注意事项：**

  1. **信息必然有损**：降维本质是压缩，总会丢弃一些信息，需要在"降维程度"和"信息保留比例"之间做权衡
  2. **可解释性下降**：PCA 的特征向量是原始特征的线性组合，很难说"主成分 1 代表什么"
  3. **线性假设**：PCA 只能捕捉线性关系，非线性数据需要用 t-SNE、UMAP、核 PCA 或自编码器
  4. **对尺度敏感**：PCA 依赖特征方差，降维前**必须做标准化（Standardization）**，否则数值范围大的特征会主导主成分
  5. **t-SNE 不可传递**：t-SNE 只能用于可视化，无法对新的测试数据直接变换（需重新训练）

  > **一句话总结**：降维 = 在尽量不丢失关键信息的前提下，把数据从"高维复杂空间"映射到"低维简洁空间"，以解决计算复杂度、过拟合、可视化和噪声等问题。
