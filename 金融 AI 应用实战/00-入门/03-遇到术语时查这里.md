[[金融 AI 应用实战/00-从这里开始|返回学习路线]]

| 术语 | 在本教程里的意思 | 最容易混淆的点 |
| --- | --- | --- |
| LLM | 处理并生成语言的已有模型 | 不是行情数据库 |
| Prompt | 本次任务说明和材料 | 写了要求不等于程序保证实现 |
| Context | 模型本次实际看到的信息 | 不是电脑里所有文件 |
| Token | 模型处理与计量的文本单位 | 不固定等于一个字 |
| API | 程序调用外部服务的接口 | 接口存在不表示有访问权限 |
| SDK | 接口的代码包装库 | 包名不决定实际模型厂商 |
| Tool | 可执行的查询或计算函数 | 名称和说明不等于真实返回内容 |
| Agent | 带任务上下文和能力的模型执行过程 | 不是每个都训练了新模型 |
| Workflow | 步骤与转移规则 | 不一定由模型自主规划 |
| State | 流程共享工作底稿 | 不等于模型参数或永久记忆 |
| Node | 完成一项处理的步骤函数 | 返回字段要与后续匹配 |
| Schema | 数据结构与字段约定 | 语法合法不等于金融正确 |
| JSON | 程序容易读取的结构化文本 | 能解析不等于通过业务验收 |
| Embedding | 把文本转成向量表示 | 相似不等于事实相同 |
| RAG | 检索证据后再生成 | 不必更新模型参数 |
| Memory | 保存并再次注入历史内容 | 不等于训练或自动学会收益规律 |
| MCP | 工具服务的连接协议 | 不自动提供数据、权限与规划 |
| Skill | 可复用任务流程与资源 | 不等于工具本身 |
| Async | 等待时让出执行机会 | 不保证每个任务同时完成 |
| Semaphore | 限制同时执行数量的机制 | 与总任务数不同 |
| Queue | 等待处理的任务序列 | 入队不代表执行成功 |
| SSE | 服务向浏览器持续发送事件 | 事件进度不是业务正确率 |
| WebSocket | 持续双向通信方式 | 连接成功不证明模型可用 |
| Fallback | 主路径失败后的备用选择 | 不保证质量等价 |
| Checkpoint | 可恢复的流程状态记录 | 不撤销外部现实动作 |
| Idempotency | 重复请求不重复完成同一动作 | 与简单重试不同 |
| MongoDB | 项目里保存任务等记录的文档数据库 | 与向量记忆用途不同 |
| Redis | 队列与短时状态协调使用的存储 | 不应混作全部长期证据库 |
| Chroma | 本项目检索相似历史情景的向量存储 | 不是预训练模型 |
| PE、PB、PEG | 不同估值比率或派生指标 | 定义、单位与适用性必须明确 |
| ROE | 净资产收益相关指标 | 期间、平均权益与年化不可省略 |
| Backtest | 用历史规则和数据模拟策略 | 报告生成不等于回测 |

不必一次背完。读到术语，先找到它的输入和输出，再看它处在业务链哪一步；这比只记英文全称更重要。
