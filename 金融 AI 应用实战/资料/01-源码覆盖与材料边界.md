## 这份教程如何取证

三个小案例依据此前整理笔记中的四个完整原代码块，保存为四个 Python 文件。大型项目以当前可读核心代码的具体函数和字段为依据，每篇附本地完整源码副本与原行号；其余文件登记可读性，不能把目录登记视为已逐行审阅。

项目有 556 个 .py：450 个 UTF-8 可读、106 个以 ENCZ1 开头，不能按普通 Python 正文阅读。本轮不运行或解包封装代码。前端只提供 dist 构建产物。analysis 路由、analysis_worker 等部分边界因此明确标为未核实。

README 声称 LangGraph；当前可读主引擎以 asyncio 调度。两个 compose 文件为编码长文本，README 引用的 nginx compose 文件未见。部署说明以实际可读 Dockerfile、Nginx 与应用入口为准，不承诺原包可直接运行。
