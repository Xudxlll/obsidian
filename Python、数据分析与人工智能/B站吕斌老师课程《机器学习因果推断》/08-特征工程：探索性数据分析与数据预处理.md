> 5.1 特征工程：探索性数据分析与数据预处理


> [!info] 整理原则
> 这份笔记根据老师课堂内容整理，将探索性数据分析、数据预处理、无量纲化、缺失值填补、类别编码、二值化和分段整理为课程阅读笔记。

## 一、特征工程的基本定位

### 1. 特征工程的含义

特征工程是将原始数据转化为适合机器学习模型学习的特征表示的过程。它既包括理解变量，也包括改造变量。课堂将本节内容分为两条主线：探索性数据分析和数据预处理。

### 2. 特征工程的重要性

模型效果不仅取决于算法，也取决于输入特征的质量。高质量特征能够减少噪声、突出信号、改善模型训练稳定性，并提高预测表现。

## 二、探索性数据分析

### 1. 变量分布

探索性数据分析首先关注变量分布。直方图、核密度图和箱形图可以帮助观察变量的集中趋势、离散程度、偏态和异常值。

### 2. 分组统计

分组统计用于比较不同类别下目标变量或其他特征的差异。例如，可以比较不同性别、不同舱位或不同地区的结果变量均值。分组统计有助于发现潜在预测变量。

### 3. 相关性探索

相关性分析可以初步判断变量之间是否存在线性关系。散点图、相关系数矩阵和热力图都是常用工具。但相关性不等于因果关系，机器学习中相关性可以帮助预测，因果推断中仍需识别假设。

## 三、无量纲化

### 1. 无量纲化的必要性

不同变量可能具有不同量纲和取值范围。如果某些模型依赖距离、梯度或正则化，变量尺度差异会影响训练过程。例如，收入变量可能以万元计，比例变量可能位于 0 到 1 之间，如果不处理，尺度大的变量可能主导模型。

### 2. 归一化 MinMaxScaler

归一化将变量缩放到指定范围，常见形式为：

$$
x'=\frac{x-x_{min}}{x_{max}-x_{min}}
$$

```python
from sklearn.preprocessing import MinMaxScaler

X_scaled = MinMaxScaler().fit_transform(X)
```

归一化适合需要固定取值范围的场景，但容易受极端值影响。

### 3. 标准化 StandardScaler

标准化将变量转化为均值为 0、标准差为 1 的形式：

$$
z=\frac{x-\mu}{\sigma}
$$

```python
from sklearn.preprocessing import StandardScaler

X_standard = StandardScaler().fit_transform(X)
```

标准化适合许多线性模型、距离模型和梯度优化模型。

## 四、缺失值填补

### 1. SimpleImputer

`SimpleImputer` 可以使用均值、中位数、众数或固定值填补缺失值。

```python
from sklearn.impute import SimpleImputer

imputer = SimpleImputer(strategy="mean")
X_filled = imputer.fit_transform(X)
```

### 2. 填补策略选择

连续变量可使用均值或中位数填补；类别变量可使用众数填补；如果缺失本身具有含义，也可以设置缺失指示变量。选择填补策略时应考虑缺失机制、变量类型和建模目标。

## 五、类别变量编码

### 1. 变量测量尺度

课堂区分定类、定序、定距和定比变量。

| 类型 | 含义 | 例子 | 处理方式 |
|---|---|---|---|
| 定类变量 | 只有类别，无大小顺序 | 性别、地区、行业 | 独热编码 |
| 定序变量 | 类别存在顺序 | 学历、评级 | 有序编码 |
| 定距变量 | 差值有意义，零点不表示不存在 | 摄氏温度 | 标准化 |
| 定比变量 | 比例有意义，具有真实零点 | 收入、年龄 | 标准化、归一化、对数变换 |

### 2. LabelEncoder

`LabelEncoder` 一般用于标签 `y` 的编码，而不是直接用于多列特征矩阵。它将类别标签转化为整数。

### 3. OrdinalEncoder

`OrdinalEncoder` 用于特征中的有序类别变量。如果类别本身存在顺序，例如低、中、高，可以使用有序编码。

### 4. OneHotEncoder

`OneHotEncoder` 将无序类别变量转化为哑变量，避免模型误以为类别之间存在数值大小关系。

```python
from sklearn.preprocessing import OneHotEncoder

encoder = OneHotEncoder()
X_encoded = encoder.fit_transform(X_cat)
```

## 六、二值化与分段

### 1. Binarizer

`Binarizer` 按阈值将连续变量转化为 0/1。例如，将收入是否超过某一阈值、年龄是否超过某一年龄段转化为二元变量。

```python
from sklearn.preprocessing import Binarizer

X_binary = Binarizer(threshold=0.5).fit_transform(X)
```

### 2. KBinsDiscretizer

`KBinsDiscretizer` 将连续变量划分为如果干区间。它可以采用等宽、等频或聚类方式分箱。

```python
from sklearn.preprocessing import KBinsDiscretizer

kbins = KBinsDiscretizer(n_bins=5, encode="onehot", strategy="quantile")
X_bins = kbins.fit_transform(X)
```

### 3. 离散化的代价

分箱和二值化可以增强可解释性，也可以捕捉阈值关系，但会损失连续变量中的细节信息。所以，离散化应服务于具体建模目的，而不是默认操作。

## 七、本节学习重点

### 1. EDA 与预处理的关系

探索性数据分析回答“变量是什么样的”，预处理回答“变量如何进入模型”。前者是理解数据，后者是改造数据。

### 2. 编码前必须判断变量类型

无序类别变量不应随意编码为 0、1、2，因为这可能引入虚假的大小关系。有序变量、无序变量和连续变量应采用不同预处理方式。

## 八、预处理方法总览

```text
数据预处理
├── 缺失值处理
│   ├── 均值填补
│   ├── 中位数填补
│   └── 众数填补
├── 无量纲化
│   ├── 归一化 MinMaxScaler
│   └── 标准化 StandardScaler
├── 类别编码
│   ├── LabelEncoder
│   ├── OrdinalEncoder
│   └── OneHotEncoder
└── 连续变量离散化
    ├── Binarizer
    └── KBinsDiscretizer
```

### 1. 标准化和归一化对比

| 方法 | 公式 | 结果含义 | 常见坑 |
|---|---|---|---|
| 归一化 | $x'=\frac{x-x_{min}}{x_{max}-x_{min}}$ | 压到固定范围 | 容易受极端值影响 |
| 标准化 | $z=\frac{x-\mu}{\sigma}$ | 均值0，标准差1 | 不会把数据限制在0到1 |
