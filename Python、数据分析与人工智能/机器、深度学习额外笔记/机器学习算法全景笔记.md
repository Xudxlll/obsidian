# 一、机器学习整体框架

> [!abstract] 本文主线
> - 机器学习不是一堆孤立算法，而是围绕“预测数值、预测类别、发现群体、压缩特征、提升效果”这几类任务展开。
> - 你在 `day07` 里已经接触到：`KMeans`、`Lasso`、`LogisticRegression`、`KNeighborsClassifier`、`DecisionTreeClassifier`，以及标准化、训练/测试集划分、分类报告、SMOTE、CH 指数等配套流程。
> - 初学时不要先背所有算法细节，先判断问题类型：目标值是连续数值、离散类别，还是根本没有标签。
> - 绝大多数机器学习代码都遵循同一条主线：准备 `X/y` -> 划分数据 -> 预处理 -> 建模 `fit()` -> 预测 `predict()` -> 评价。

## 1.1 先建立机器学习地图

| 问题类型 | 目标 | 常见算法 | 你目前项目中的对应例子 |
| --- | --- | --- | --- |
| 回归 | 预测连续数值 | 线性回归、岭回归、Lasso、回归树、随机森林回归 | Lasso 拟合宏观财政收入 |
| 二分类/多分类 | 预测类别 | 逻辑回归、KNN、决策树、朴素贝叶斯、SVM、随机森林、XGBoost | HR 离职预测、金融借贷违约预测 |
| 聚类 | 没有标签，自动分组 | KMeans、层次聚类、DBSCAN、GMM | NBA 球星聚类、航空客户价值分群 |
| 降维 | 压缩特征、可视化、去噪 | PCA、t-SNE、UMAP | day07 未重点展开，但后续必备 |
| 集成学习 | 把多个弱模型组合成强模型 | 随机森林、GBDT、XGBoost、LightGBM | day07 未重点展开，但风控/竞赛很常用 |

机器学习可以先记住三句话：

1. 有 `y`，而且 `y` 是数字连续值，优先想回归。
2. 有 `y`，而且 `y` 是类别，优先想分类。
3. 没有 `y`，只是想把样本分群，优先想聚类。

## 1.2 标准机器学习代码骨架

很多算法虽然名字不同，但 `sklearn` 写法非常统一：

```python
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import classification_report

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.2,
    random_state=123
)

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

model.fit(X_train_scaled, y_train)
y_pred = model.predict(X_test_scaled)

print(classification_report(y_test, y_pred))
```

> [!warning] 重要规则
> 标准化时只能在训练集上 `fit`，测试集和未来新数据只能 `transform`。否则测试集信息会提前泄露给模型，评价结果会偏乐观。

# 二、监督学习：回归算法

## 2.1 线性回归

### 2.1.1 直观理解

线性回归用一条直线或一个超平面去拟合数据关系。它回答的是：“如果特征变化，目标值大概怎么跟着变化？”

例如用房屋面积、楼层、地段预测房价，用 GDP、消费、税收等宏观指标预测财政收入。

### 2.1.2 核心公式

单变量线性回归：

$$
\hat{y}=w x+b
$$

多变量线性回归：

$$
\hat{y}=w_1x_1+w_2x_2+\cdots+w_px_p+b
$$

常用损失函数是均方误差：

$$
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

模型训练的目标就是找到一组参数，让预测值和真实值之间的误差尽量小。

### 2.1.3 代码示例

```python
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score, mean_squared_error

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=123
)

model = LinearRegression()
model.fit(X_train, y_train)

y_pred = model.predict(X_test)
print("R2:", r2_score(y_test, y_pred))
print("MSE:", mean_squared_error(y_test, y_pred))
```

### 2.1.4 现实应用

- 房价预测、销量预测、收入预测。
- 分析某个特征对目标值的影响方向和影响大小。
- 作为理解回归问题的第一个基准模型。

### 2.1.5 什么时候适合用

适合关系接近线性、特征数量不太夸张、需要解释模型系数的场景。如果数据关系明显弯曲或变量之间关系很复杂，普通线性回归可能欠拟合。

## 2.2 Lasso 回归

### 2.2.1 直观理解

Lasso 是在线性回归基础上加了“惩罚项”的模型。它不仅希望预测误差小，还希望模型尽量简单。

你的 `lasso回归算法—拟合宏观数据.py` 中，就是用 13 个宏观经济特征预测地方财政收入，并通过 `np.count_nonzero(model_lasso.coef_)` 统计最终有多少个特征被模型保留下来。

### 2.2.2 核心公式

Lasso 的目标函数：

$$
\min_w \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2+\alpha\sum_{j=1}^{p}|w_j|
$$

其中：

- 第一项是预测误差。
- 第二项是 L1 正则化惩罚。
- $\alpha$ 越大，模型越倾向于把不重要特征的系数压到 0。

Lasso 的一个重要特点是可以做特征选择。

### 2.2.3 代码示例

```python
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Lasso
from sklearn.metrics import r2_score

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=123
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model_lasso = Lasso(alpha=1)
model_lasso.fit(X_train, y_train)

pred_train = model_lasso.predict(X_train)
pred_test = model_lasso.predict(X_test)

print("训练集 R2:", r2_score(y_train, pred_train))
print("测试集 R2:", r2_score(y_test, pred_test))
print("保留下来的特征个数:", np.count_nonzero(model_lasso.coef_))
```

### 2.2.4 现实应用

- 宏观经济指标筛选。
- 医疗数据中从大量指标里挑出重要指标。
- 金融建模中从很多变量中筛选解释力较强的变量。

### 2.2.5 什么时候适合用

当特征很多、你怀疑只有一部分特征真正有用时，Lasso 很适合。它通常需要标准化，因为惩罚项会直接作用在系数上，不同量纲会影响惩罚公平性。

## 2.3 岭回归

### 2.3.1 直观理解

岭回归也是线性回归的正则化版本。和 Lasso 不同，岭回归通常不会把系数压成 0，而是把系数整体压小，让模型更稳定。

### 2.3.2 核心公式

岭回归的目标函数：

$$
\min_w \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2+\alpha\sum_{j=1}^{p}w_j^2
$$

这里的 $\sum w_j^2$ 是 L2 正则化。

可以简单理解为：

- Lasso：可能把一些特征系数变成 0，适合特征选择。
- 岭回归：让系数变小但通常不归零，适合缓解多重共线性。

### 2.3.3 代码示例

```python
from sklearn.linear_model import Ridge
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import r2_score

model = make_pipeline(
    StandardScaler(),
    Ridge(alpha=1.0)
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print("R2:", r2_score(y_test, y_pred))
```

### 2.3.4 现实应用

- 房价、收入、销量等连续数值预测。
- 特征之间相关性很强的业务数据建模。
- 作为普通线性回归的更稳健版本。

### 2.3.5 什么时候适合用

如果你不想直接删除特征，只想让模型不要过度依赖某些特征，可以优先试岭回归。

# 三、监督学习：分类算法

## 3.1 逻辑回归

### 3.1.1 直观理解

逻辑回归名字里有“回归”，但它常用于分类。它先计算一个线性分数，再通过 sigmoid 函数把分数压到 0 到 1 之间，解释为属于正类的概率。

你的 `逻辑回归算法—hr_数据挖掘.ipynb` 里，用员工满意度、考核评分、项目数量、工作时间、司龄、薪水等特征预测员工是否离职。

### 3.1.2 核心公式

线性部分：

$$
z=w^Tx+b
$$

sigmoid 函数：

$$
P(y=1|x)=\sigma(z)=\frac{1}{1+e^{-z}}
$$

分类规则：

$$
\hat{y}=
\begin{cases}
1, & P(y=1|x)\ge 0.5 \\
0, & P(y=1|x)<0.5
\end{cases}
$$

### 3.1.3 代码示例

```python
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=123
)

model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)

y_pred = model.predict(X_test)
print(classification_report(y_test, y_pred))
```

### 3.1.4 现实应用

- 员工是否离职预测。
- 用户是否流失预测。
- 客户是否违约预测。
- 邮件是否垃圾邮件。

### 3.1.5 什么时候适合用

逻辑回归适合作为分类任务的第一个基准模型。它速度快、结果稳定、可解释性较好，尤其适合二分类。

## 3.2 KNN 近邻算法

### 3.2.1 直观理解

KNN 的想法非常朴素：要判断一个新样本属于哪一类，就看它周围最近的 $K$ 个邻居多数属于哪一类。

你的金融借贷风控项目中，用 `KNeighborsClassifier()` 和逻辑回归、决策树一起比较违约预测效果。

### 3.2.2 核心公式

最常用的是欧氏距离：

$$
d(x_i,x_j)=\sqrt{\sum_{k=1}^{p}(x_{ik}-x_{jk})^2}
$$

分类时：

$$
\hat{y}=\operatorname{mode}(y_{nearest\ k\ neighbors})
$$

也就是取最近 $K$ 个邻居中出现最多的类别。

### 3.2.3 代码示例

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import classification_report

model = make_pipeline(
    StandardScaler(),
    KNeighborsClassifier(n_neighbors=5)
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(classification_report(y_test, y_pred))
```

### 3.2.4 现实应用

- 相似用户推荐。
- 根据相似历史样本判断风险。
- 简单图像分类、文本分类的入门模型。

### 3.2.5 什么时候适合用

KNN 强依赖距离，所以通常必须标准化。它适合数据量不太大、特征含义相对清楚的场景。数据量很大时，预测会变慢。

## 3.3 决策树

### 3.3.1 直观理解

决策树像一套不断追问的规则：如果收入小于某个阈值，往左走；如果负债率大于某个阈值，往右走；最后走到某个叶子节点，得到预测类别。

你的金融借贷风控项目中，用 `DecisionTreeClassifier()` 预测客户是否违约。

### 3.3.2 核心公式

分类树常用基尼系数衡量节点纯度：

$$
Gini(D)=1-\sum_{k=1}^{K}p_k^2
$$

其中 $p_k$ 是当前节点中第 $k$ 类样本所占比例。

也可以用信息熵：

$$
H(D)=-\sum_{k=1}^{K}p_k\log_2p_k
$$

树的目标是找到能让子节点更“纯”的切分方式。

### 3.3.3 代码示例

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import classification_report

model = DecisionTreeClassifier(
    max_depth=5,
    random_state=123
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(classification_report(y_test, y_pred))
```

### 3.3.4 现实应用

- 金融风控规则学习。
- 用户分层、客户画像。
- 医疗辅助判断。
- 业务规则解释。

### 3.3.5 什么时候适合用

决策树解释性强，不太需要标准化，但容易过拟合。常用限制包括 `max_depth`、`min_samples_leaf`、`min_samples_split`。

## 3.4 朴素贝叶斯

### 3.4.1 直观理解

朴素贝叶斯根据已有证据反推类别概率。它的“朴素”是假设各个特征之间相互独立，虽然这个假设经常不完全成立，但在文本分类中非常好用。

### 3.4.2 核心公式

贝叶斯公式：

$$
P(y|x)=\frac{P(x|y)P(y)}{P(x)}
$$

朴素贝叶斯分类时常写成：

$$
\hat{y}=\arg\max_y P(y)\prod_{j=1}^{p}P(x_j|y)
$$

含义是：选择在当前特征条件下概率最大的类别。

### 3.4.3 代码示例

```python
from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import classification_report

model = GaussianNB()
model.fit(X_train, y_train)

y_pred = model.predict(X_test)
print(classification_report(y_test, y_pred))
```

文本分类常用：

```python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import make_pipeline

model = make_pipeline(
    CountVectorizer(),
    MultinomialNB()
)

model.fit(text_train, y_train)
pred = model.predict(text_test)
```

### 3.4.4 现实应用

- 垃圾邮件识别。
- 新闻分类。
- 情感分析入门。
- 文档主题分类。

### 3.4.5 什么时候适合用

适合文本、离散计数特征、快速建立分类基准。它速度很快，但当特征之间强相关时，效果可能受影响。

## 3.5 支持向量机 SVM

### 3.5.1 直观理解

SVM 想找到一条分界线或一个分界平面，把不同类别尽可能分开，而且希望分界线离两边最近的样本都尽量远。

这些离分界线最近、真正决定边界的样本叫支持向量。

### 3.5.2 核心公式

线性 SVM 的分类边界：

$$
w^Tx+b=0
$$

间隔最大化可以理解为：

$$
\max \frac{2}{\|w\|}
$$

常见软间隔目标函数：

$$
\min \frac{1}{2}\|w\|^2+C\sum_{i=1}^{n}\xi_i
$$

其中 $C$ 控制“间隔更大”和“错分更少”之间的权衡。

### 3.5.3 代码示例

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import classification_report

model = make_pipeline(
    StandardScaler(),
    SVC(kernel="rbf", C=1.0, gamma="scale")
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(classification_report(y_test, y_pred))
```

### 3.5.4 现实应用

- 小中型数据分类。
- 图像识别早期方案。
- 风险识别、异常边界识别。

### 3.5.5 什么时候适合用

SVM 对特征尺度敏感，通常要标准化。它适合样本量不是特别大、边界比较复杂的分类任务。

# 四、无监督学习：聚类算法

## 4.1 KMeans 聚类

### 4.1.1 直观理解

KMeans 是无监督学习算法。它没有真实标签，只根据样本之间的距离，把样本分成 $K$ 个簇。

你在 day07 里做了两个 KMeans 项目：

- NBA 球星聚类：按篮板成绩和助攻成绩，把 8 位球星分成不同类别。
- 航空公司客户价值分析：用 LRFMC 特征把客户分成不同价值群体。

### 4.1.2 核心公式

KMeans 的目标是最小化簇内平方和：

$$
\min \sum_{i=1}^{K}\sum_{x\in C_i}\|x-\mu_i\|^2
$$

其中：

- $K$ 是簇的个数。
- $C_i$ 是第 $i$ 个簇。
- $\mu_i$ 是第 $i$ 个簇的中心点。

CH 指数常用于评价聚类效果：

$$
CH=\frac{\mathrm{tr}(B)/(k-1)}{\mathrm{tr}(W)/(n-k)}
$$

CH 越大，通常表示簇间差异更大、簇内更紧凑。

### 4.1.3 代码示例

```python
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import calinski_harabasz_score

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

model = KMeans(n_clusters=5, random_state=123)
model.fit(X_scaled)

labels = model.labels_
centers = model.cluster_centers_

print("CH 指数:", calinski_harabasz_score(X_scaled, labels))
print("聚类中心:", centers)
```

### 4.1.4 现实应用

- 航空客户价值分群。
- 电商用户分群。
- 球员能力画像。
- 门店、商品、客户的自动分组。

### 4.1.5 什么时候适合用

适合你不知道标签、但想把样本分成几群的场景。KMeans 对特征尺度敏感，通常需要标准化。它还需要提前指定 `n_clusters`，所以常配合 CH 指数、轮廓系数、业务解释一起选 $K$。

# 五、无监督学习：降维算法

## 5.1 PCA 主成分分析

### 5.1.1 直观理解

PCA 是降维算法。它试图把很多特征压缩成少数几个“主成分”，尽量保留原始数据中最重要的变化信息。

可以把它理解成：原来有很多维度，PCA 找到几个最能概括数据差异的新方向。

### 5.1.2 核心公式

PCA 寻找方差最大的投影方向：

$$
z=Xw
$$

第一主成分可以写成：

$$
w_1=\arg\max_{\|w\|=1}\operatorname{Var}(Xw)
$$

解释方差比：

$$
Explained\ Variance\ Ratio=\frac{\lambda_i}{\sum_{j=1}^{p}\lambda_j}
$$

其中 $\lambda_i$ 是第 $i$ 个主成分对应的特征值。

### 5.1.3 代码示例

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

model = make_pipeline(
    StandardScaler(),
    PCA(n_components=2)
)

X_pca = model.fit_transform(X)
print(X_pca[:5])
```

如果想看保留了多少信息：

```python
pca = PCA(n_components=2)
X_scaled = StandardScaler().fit_transform(X)
X_pca = pca.fit_transform(X_scaled)

print(pca.explained_variance_ratio_)
```

### 5.1.4 现实应用

- 高维数据可视化。
- 特征压缩。
- 去除冗余信息。
- 在建模前降低维度，减少噪声。

### 5.1.5 什么时候适合用

当特征很多、相关性强、想做可视化或压缩特征时，可以考虑 PCA。PCA 也通常需要标准化。

# 六、集成学习：表格数据强模型

## 6.1 随机森林

### 6.1.1 直观理解

随机森林是很多棵决策树组成的模型。单棵树容易过拟合，但很多棵树一起投票或平均，结果通常更稳定。

可以理解为：一个人判断可能偏，一群不同视角的人一起判断，结果更稳。

### 6.1.2 核心公式

分类任务中，随机森林通常采用多数投票：

$$
\hat{y}=\operatorname{mode}(h_1(x),h_2(x),\cdots,h_T(x))
$$

回归任务中，随机森林通常取平均：

$$
\hat{y}=\frac{1}{T}\sum_{t=1}^{T}h_t(x)
$$

其中 $h_t$ 表示第 $t$ 棵树。

### 6.1.3 代码示例

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report

model = RandomForestClassifier(
    n_estimators=200,
    max_depth=None,
    random_state=123,
    n_jobs=-1
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(classification_report(y_test, y_pred))
```

查看特征重要性：

```python
import pandas as pd

importance = pd.Series(
    model.feature_importances_,
    index=X_train.columns
).sort_values(ascending=False)

print(importance.head(10))
```

### 6.1.4 现实应用

- 金融风控。
- 客户流失预测。
- 医疗风险预测。
- 各类结构化表格数据建模。

### 6.1.5 什么时候适合用

适合表格数据，效果通常比单棵决策树稳。它对标准化不敏感，但可解释性不如单棵树直接。

## 6.2 GBDT、XGBoost 与 LightGBM

### 6.2.1 直观理解

GBDT 是梯度提升决策树。它不是一次训练很多棵独立的树，而是一棵接一棵地训练：后面的树重点修正前面模型犯的错误。

XGBoost 和 LightGBM 是 GBDT 思想的高性能实现，在表格数据竞赛、风控、广告点击率预测中非常常见。

### 6.2.2 核心公式

提升模型的整体形式：

$$
F_M(x)=\sum_{m=1}^{M}\gamma_m h_m(x)
$$

每一轮都在已有模型基础上增加一棵树：

$$
F_m(x)=F_{m-1}(x)+\gamma_m h_m(x)
$$

直观理解：第 1 棵树先做一个粗预测，第 2 棵树改正第 1 棵树没学好的部分，第 3 棵树继续改正剩余错误。

### 6.2.3 代码示例

使用 `sklearn` 自带的梯度提升树：

```python
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import classification_report

model = GradientBoostingClassifier(
    n_estimators=100,
    learning_rate=0.05,
    max_depth=3,
    random_state=123
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(classification_report(y_test, y_pred))
```

如果安装了 XGBoost：

```python
from xgboost import XGBClassifier

model = XGBClassifier(
    n_estimators=300,
    learning_rate=0.05,
    max_depth=4,
    subsample=0.8,
    colsample_bytree=0.8,
    eval_metric="logloss",
    random_state=123
)

model.fit(X_train, y_train)
```

### 6.2.4 现实应用

- 信贷违约预测。
- 用户流失预测。
- 广告点击率预测。
- 销售转化预测。
- 大多数结构化表格数据竞赛。

### 6.2.5 什么时候适合用

当你已经完成基本清洗、想追求更高预测效果时，GBDT 系列通常是表格数据的强力选择。但它比逻辑回归、决策树更需要调参，也更容易在小数据上过拟合。

# 七、机器学习配套能力

## 7.1 模型评估与交叉验证

### 7.1.1 直观理解

模型训练完不是看它“能不能跑”，而是看它在没见过的数据上表现如何。训练集成绩高不代表模型好，测试集成绩才更接近真实泛化能力。

day07 里你已经用到了：

- 回归：`r2_score`
- 分类：`classification_report`
- 聚类：`calinski_harabasz_score`

### 7.1.2 核心公式

回归常用 $R^2$：

$$
R^2=1-\frac{\sum_i(y_i-\hat{y}_i)^2}{\sum_i(y_i-\bar{y})^2}
$$

分类常用准确率：

$$
Accuracy=\frac{TP+TN}{TP+TN+FP+FN}
$$

精确率：

$$
Precision=\frac{TP}{TP+FP}
$$

召回率：

$$
Recall=\frac{TP}{TP+FN}
$$

F1 值：

$$
F1=\frac{2\cdot Precision\cdot Recall}{Precision+Recall}
$$

### 7.1.3 代码示例

```python
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(max_iter=1000)

scores = cross_val_score(
    model,
    X,
    y,
    cv=5,
    scoring="f1"
)

print("每折得分:", scores)
print("平均得分:", scores.mean())
```

### 7.1.4 现实应用

- 判断模型是否过拟合。
- 比较多个算法谁更适合当前数据。
- 在上线前估计模型稳定性。
- 风控场景中重点看召回率、精确率、F1、AUC，而不只看准确率。

### 7.1.5 什么时候必须重视

只要是机器学习项目，就必须重视评估。尤其在金融风控、医疗、离职预测这类类别不均衡任务中，不能只看准确率。

## 7.2 数据预处理：让算法吃到干净数据

### 7.2.1 直观理解

真实项目里，算法本身只是后半段。前半段更常见的工作是清洗数据、转换字段、处理异常、标准化、处理类别不均衡。

你的金融借贷风控项目中就做了很多典型步骤：

- 删除缺失值。
- 删除不适合建模的贷款状态。
- 把 `loan_status` 转成 0/1 标签。
- 处理年收入、债务收入比等异常值。
- 把 `term`、`grade`、`emp_length`、`home_ownership` 转成数值。
- 用 SMOTE 处理类别不均衡。

### 7.2.2 核心公式

标准化：

$$
z=\frac{x-\mu}{\sigma}
$$

其中 $\mu$ 是均值，$\sigma$ 是标准差。

SMOTE 的基本思想是在少数类样本和近邻之间插值：

$$
x_{new}=x_i+\lambda(x_{nn}-x_i),\quad \lambda\in[0,1]
$$

### 7.2.3 代码示例

```python
from imblearn.over_sampling import SMOTE
from sklearn.model_selection import train_test_split

X_smote, y_smote = SMOTE(random_state=123).fit_resample(X, y)

X_train, X_test, y_train, y_test = train_test_split(
    X_smote,
    y_smote,
    test_size=0.2,
    random_state=123
)
```

更推荐在严谨项目中只对训练集做 SMOTE，避免测试集被合成样本污染：

```python
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=123, stratify=y
)

X_train_res, y_train_res = SMOTE(random_state=123).fit_resample(
    X_train, y_train
)
```

### 7.2.4 现实应用

- 风控违约样本通常少，需要处理类别不均衡。
- 客户流失预测中，流失用户也常是少数类。
- 各类业务数据都需要字段转换、异常值处理、缺失值处理。

### 7.2.5 什么时候适合用

任何真实机器学习项目都离不开数据预处理。初学者最容易误以为“换算法就能提升效果”，但很多时候真正决定效果的是特征和数据质量。

## 7.3 结尾记忆清单

| 你要判断的问题 | 优先想到的算法 |
| --- | --- |
| 预测一个连续数字 | 线性回归、岭回归、Lasso、随机森林回归、GBDT 回归 |
| 判断是否离职、是否违约 | 逻辑回归、KNN、决策树、随机森林、XGBoost |
| 没有标签，只想分群 | KMeans |
| 特征太多、想压缩 | PCA |
| 想要可解释、规则清楚 | 逻辑回归、决策树 |
| 想要表格数据效果强 | 随机森林、GBDT、XGBoost、LightGBM |
| 类别不均衡 | 看 Precision、Recall、F1、AUC，必要时用 SMOTE 或类别权重 |

初学机器学习时，最稳的学习顺序是：

1. 先学清楚 `X`、`y`、训练集、测试集。
2. 再学回归、分类、聚类三大任务。
3. 然后每类掌握 2 到 3 个代表算法。
4. 最后补模型评估、交叉验证、特征工程和调参。

你现在 day07 的学习已经跨过了“只会调用算法”的第一步，开始进入“能按业务问题选择算法、解释评价结果、理解数据预处理”的阶段。
