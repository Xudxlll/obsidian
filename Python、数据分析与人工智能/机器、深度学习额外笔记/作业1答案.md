# Numpy 作业

**题目 1：广播机制判断**

判断以下哪组数组可以进行广播运算，并说明广播过程和结果的 shape；对于不能广播的，说明原因：

1. `A` 的 shape 为 `(3, 4)`，`B` 的 shape 为 `(4,)`
2. `A` 的 shape 为 `(2, 3)`，`B` 的 shape 为 `(2,)`
3. `A` 的 shape 为 `(3, 1)`，`B` 的 shape 为 `(1, 4)`

答案：

1. **可以广播**。`B: (4,)` → 补全为 `(1, 4)` → 广播为 `(3, 4)`，结果 shape 为 `(3, 4)`
2. **不可以广播**。`B: (2,)` → 补全为 `(1, 2)`，与 `A: (2, 3)` 比较，最后一维 2 ≠ 3 且都不为 1，不兼容
3. **可以广播**。`A: (3, 1)` 与 `B: (1, 4)`，第 1 维 3 vs 1 可扩展为 3，第 2 维 1 vs 4 可扩展为 4，结果 shape 为 `(3, 4)`

**题目 2：多维数组切片**

给定三维数组：

```python
a = np.arange(1, 28).reshape(3, 3, 3)
```

请写出切片表达式，分别取出：

1. 第 2 页的所有数据
2. 所有页的第 1 行
3. 第 0 页第 2 行第 1 列的元素值

答案：

1. `a[2, :, :]` 或 `a[2]` —— 取第 2 页
2. `a[:, 1, :]` —— 所有页的第 1 行
3. `a[0, 2, 1]` —— 第 0 页、第 2 行、第 1 列，值为 22

# Matplotlib 作业

**题目 1：窗口操作与饼图**

某电商平台统计了 5 个品类的年度销售额占比，数据如下：

| 品类     | 销售额占比(%) |
| -------- | ------------- |
| 电子产品 | 32            |
| 服装     | 25            |
| 食品     | 18            |
| 家居     | 15            |
| 图书     | 10            |

请完成以下任务：

1. 创建一个标题为`Sales Distribution`、背景色为 `lightgray` 的图形窗口
2. 绘制饼图，要求：
   - 电子产品扇形与其他扇形之间间距为 0.05，其余间距为 0.01（突出显示最大占比品类）
   - 启用阴影效果
   - 起始角度为 90°
   - 标签显示百分比格式（如 `32%`）
   - 添加图例
3. 设置等轴比例
4. 保存图片到当前目录下的`sales_pie.png`

请写出完整代码，并解释饼图中 `spaces` 参数的作用：如果所有 `spaces` 都设为 0，图表会怎样？

答案：

```python
import matplotlib.pyplot as plt

values = [32, 25, 18, 15, 10]
spaces = [0.05, 0.01, 0.01, 0.01, 0.01]
labels = ['Electronics', 'Clothing', 'Food', 'Home', 'Books']
colors = ['dodgerblue', 'orangered', 'limegreen', 'violet', 'gold']

plt.figure('Sales Distribution', facecolor='lightgray')
plt.title('Sales Distribution', fontsize=20)

plt.axis('equal')
plt.pie(
    values,
    spaces,
    labels,
    colors,
    '%d%%',
    shadow=True,
    startangle=90,
    radius=1
)

plt.legend()
plt.savefig('sales_pie.png')
plt.show()
```

spaces 参数控制每个扇形之间的间距。如果所有 spaces 都设为 0，则所有扇形紧密相连、没有间隙，拼合成一个完整的圆。设置非零值可以让某些扇形"弹出"突出显示，常用于强调关键数据。

**题目 2：子图布局与图表类型综合**

在一个窗口中绘制 2×2 的子图布局，要求：

1. 左上子图：绘制散点图，x 数据为`[1, 2, 3, 4, 5]`，y 数据为 `[2, 4, 5, 4, 5]`，点型为菱形，颜色为红色
2. 右上子图：绘制直方图，生成 200 个 60~100 之间的随机整数，分 20 个柱子，添加点状网格线
3. 左下子图：绘制饼图，数据为`[25, 35, 20, 20]`，标签为 `['A', 'B', 'C', 'D']`，设置等轴比例
4. 右下子图：绘制折线图，x 数据为`range(0, 10)`，y 数据为 `[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]`，线条为虚线

请写出完整代码，并说明 `plt.subplot(2, 2, 3)` 中参数 3 的含义。

答案：

```python
import numpy as np
import matplotlib.pyplot as plt

plt.figure('Subplot Demo', facecolor='lightgray')

# 左上：散点图
plt.subplot(2, 2, 1)
plt.scatter([1,2,3,4,5], [2,4,5,4,5], marker='D', color='r')
plt.title('Scatter')

# 右上：直方图
plt.subplot(2, 2, 2)
data = np.random.randint(60, 101, 200)
plt.hist(data, 20)
plt.grid(linestyle=':')
plt.title('Histogram')

# 左下：饼图
plt.subplot(2, 2, 3)
plt.pie([25,35,20,20], labels=['A','B','C','D'])
plt.axis('equal')
plt.title('Pie')

# 右下：折线图
plt.subplot(2, 2, 4)
plt.plot(range(10), [1,4,9,16,25,36,49,64,81,100], linestyle='--')
plt.title('Line')

plt.tight_layout()
plt.show()
```

`plt.subplot(2, 2, 3)` 中的 `3` 表示子图的编号。2×2 矩阵布局中，子图按行优先编号：第1行第1列为1、第1行第2列为2、**第2行第1列为3**、第2行第2列为4。因此编号 3 对应左下角的位置。
