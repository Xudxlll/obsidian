# `Python`特性

**1. 整数对象的缓存机制**

● 在 `Python` 中，整数对象在内存中是以对象的形式存储的。

● `Python` 对 -5 到 256 之间的整数对象进行了缓存，称为 小整数对象池（`Small Integer Object Pool`）。

● 这些小整数对象在 `Python` 启动时就会被创建，并在整个程序生命周期中复用；而对于超出范围的整数，每次创建时都会分配新的内存空间。

**2.字符串驻留机制（`string interning`）**

短字符串在 `Python` 中会被缓存并驻留（`interning`），即在内存中只保存一份，多个相同的短字符串会共享同一块内存空间。

长字符串通常指**长度较长或包含复杂字符的字符串**。

长字符串不会自动驻留，每次创建都会分配新的内存空间。

**短字符串的特点**：

● 通常是长度较短（一般小于 20 个字符，具体限制依赖于 `Python` 的实现）。

● 只包含字母、数字或下划线等简单字符。

● 不包含特殊字符（如空格、换行符等）。

**3. 不可变对象的驻留**

`Python` 对某些不可变对象（如字符串、整数、元组等）会尝试进行驻留和复用，以优化内存使用。

**驻留规则**

● 小整数：`-5` 到 `256` 的整数会驻留。

● 字符串：

1.短字符串（符合标识符规则，如只包含字母、数字、下划线）会驻留。

2.空字符串和单字符字符串（如 `''`, `'a'`）会驻留。

3.长字符串或包含特殊字符的字符串是否驻留，取决于 `Python` 的实现（如 `CPython` 的具体优化）。

● 元组

1.空元组 `()` 是驻留的。

2.非空元组是否驻留取决于实现，一般不会驻留。

**4.常量折叠（`Constant Folding`）**

`Python` 在编译阶段会对常量表达式（如数字、字符串、元组等）进行优化，将结果相同的常量折叠为同一个对象。

常量折叠仅适用于编译时的常量，运行时动态生成的对象不会折叠。

**示例代码**

```python

a = 3 * 5
b = 15
print(a is b)

```

**5.内存池机制（`Memory Pooling`）**

● 小对象池：小对象（通常小于 512 字节）会被分配到内存池中，并重复利用固定大小的内存块。

● 大对象分配：大对象（通常大于 512 字节）直接向操作系统申请内存，并存储在专用的内存区域。

**6.单例对象**

某些常用对象（如 `None`, `True`, `False`, 空字符串 `""`, 空元组 `()`）在内存中只会有一个实例。

**7.字符串拼接优化**

`Python` 对简单的字符串拼接（如 `+` 或 `+=`）进行了优化，可能会以原地操作的方式进行，避免频繁分配新内存。

对于复杂的字符串拼接操作，推荐使用 `''.join()`，性能更优。

**8.函数默认参数优化**

函数的默认参数只在定义时计算一次，后续调用会复用该对象。

避免使用可变对象作为默认参数。
