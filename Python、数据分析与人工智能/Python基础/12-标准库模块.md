# 一、`OS`模块

`OS`（`Operating System`，操作系统）模块是`Python`标准库中的一个模块，用于与操作系统交互。

它提供了一系列函数和方法，可以执行文件和目录操作、环境变量管理、进程管理以及其他与操作系统相关的任务。

`os`模块的功能主要分为：目录和文件操作、路径操作、环境变量操作、操作系统信息等。

```python

import os

```

## 1.1 常用属性

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| `os.name`    | 返回操作系统的名称标识字符串                                 |
| `os.sep`     | 返回操作系统用来分隔路径不同部分的字符。在 `POSIX` 上是 `'/'`，在 `Windows` 上是 `'\\'` |
| `os.pathsep` | 返回操作系统通常用于分隔搜索路径中不同部分的字符，如 `POSIX` 上是 `':'`，`Windows` 上是 `';'` |
| `os.linesep` | 返回当前平台用于分隔行的字符串。如 `POSIX` 上是 `'\n'`， `Windows` 上是 `'\r\n'` |

| `os.curdir`  | 返回当前目录符号                                             |
| `os.pardir`  | 返回上级目录符号                                             |

```python

import os
import time

# 文件路径
filepath = '1.txt'

# 获取绝对路径
realpath = os.path.realpath(filepath)
# 文件名
basename = os.path.basename(realpath)
# 所在目录
dirname = os.path.dirname(realpath)
# 是否存在
exists = os.path.exists(realpath)
# 是否为文件/目录
is_file = os.path.isfile(realpath)
is_dir = os.path.isdir(realpath)
# 路径拆分
parent_dir, file_name = os.path.split(realpath)
file_root, file_ext = os.path.splitext(realpath)

print(f"绝对路径: {realpath}")
print(f"文件名: {basename}")
print(f"所在目录: {dirname}")
print(f"是否存在: {exists}")
print(f"是否为文件: {is_file}")
print(f"是否为目录: {is_dir}")
print(f"父目录: {parent_dir}")
print(f"文件名（含扩展名）: {file_name}")
print(f"文件主名: {file_root}")
print(f"文件扩展名: {file_ext}")

if exists and is_file:
    # 文件大小
    size = os.path.getsize(realpath)
    # 时间戳转为可读时间
    mtime = os.path.getmtime(realpath)
    ctime = os.path.getctime(realpath)
    atime = os.path.getatime(realpath)
    print(f"文件大小: {size} 字节")
    print(f"最后修改时间: {time.ctime(mtime)}")
    print(f"创建时间: {time.ctime(ctime)}")
    print(f"最后访问时间: {time.ctime(atime)}")
elif exists and is_dir:
    print("该路径是一个目录。")
else:
    print("文件或目录不存在，请检查路径。")

```

在 `Python` 中，文件操作是一个非常重要的功能，主要用于对文件进行创建、读取、写入、删除等操作。

## 2.1 `open()`函数

`open()`函数用于打开 `file` 并返回对应的 `file object`，其语法结构为：

```python

open(file, mode='r',  encoding=None,  closefd=True)

```

● `file`参数要打开的文件路径及名称

常用的路径符号：

● `1.txt`：当前工作目录下的 `1.txt`

● `./1.txt`：当前工作目录下的 `1.txt`，`.` 表示当前目录

● `../1.txt`：上一级目录下的 `1.txt`，`..` 表示上一级目录

● `../../1.txt`：上上一级目录下的 `1.txt`

● `data/1.txt`：当前工作目录下 `data` 文件夹里的 `1.txt`

● `/Users/xuji/Desktop/1.txt`：绝对路径，从系统根目录开始定位文件

注意：这里的“当前目录”通常指程序运行时的**当前工作目录**，可以用 `os.getcwd()` 查看。

● `mode`参数指打开时的模式

| 字符    | 含义                                           |
| :---- | :------------------------------------------- |
| `'r'` | 读取（默认）(`read`)                               |
| `'w'` | 写入，并先截断文件(`write`)，如果文件不存在则自动创建              |
| `'x'` | 排它性创建，如果文件已存在则失败                             |
| `'a'` | 打开文件用于写入，如果文件存在则在末尾追加(`append`)，如果文件不存在则自动创建 |
| `'b'` | 二进制模式                                        |
| `'t'` | 文本模式（默认）                                     |
| `'+'` | 打开用于更新（读取与写入）                                |

**模式字符可以搭配组合**，格式为：`[核心模式][文本/二进制][更新]`，即 `r/w/x/a` + `t/b` + `+`。

- **核心模式**（四选一，不可省略）：`r` 读、`w` 写（清空）、`x` 排它创建、`a` 追加
- **t / b**（二选一，默认 `t`）：文本模式 / 二进制模式
- **+**（可选）：附加读写能力

常见组合：

| 模式 | 说明 |
|------|------|
| `'r'` | 只读，文本（等同于 `'rt'`） |
| `'rb'` | 只读，二进制（处理图片、音频等） |
| `'r+'` | 读写，文本，不截断文件 |
| `'rb+'` | 读写，二进制 |
| `'w'` | 只写，文本，**清空原内容** |
| `'wb'` | 只写，二进制，清空原内容 |
| `'w+'` | 读写，文本，清空原内容 |
| `'a'` | 追加写入，文本（文件不存在则创建） |
| `'a+'` | 读取 + 追加写入，文本 |

## 2.5 `readline()`与`readlines()`方法

这两个方法名字只差一个 `s`，但返回值完全不同，容易搞混。

---

### 2.5.1 `readline()` —— 读一行，返回字符串

每次调用读取**一行**内容，返回一个**字符串**（包含行末的 `\n` 换行符）。读到文件末尾时返回空字符串 `''`。

```python
file.readline()
```

**例子**：假设 `demo.txt` 内容如下：

```
hello world
你好 Python
第三行
```

```python
with open('demo.txt', 'r', encoding='utf-8') as f:
    line1 = f.readline()   # → 'hello world\n'
    line2 = f.readline()   # → '你好 Python\n'
    line3 = f.readline()   # → '第三行'
    line4 = f.readline()   # → ''（已到末尾）
```

> **注意**：`readline()` 返回的字符串自带 `\n`，如果你不需要换行符，可以用 `.strip()` 去掉。

---

### 2.5.2 `readlines()` —— 读所有行，返回列表

一次性读取文件中**所有行**，每行作为一个字符串元素放入**列表**返回。

```python
file.readlines()
```

**例子**：同样的 `demo.txt`：

```python
with open('demo.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()
    # → ['hello world\n', '你好 Python\n', '第三行']
    print(type(lines))  # → <class 'list'>
    print(len(lines))   # → 3
```

---

### 2.5.3 对比总结

| 方法 | 读取范围 | 返回类型 | 读完后的返回值 | 带 `\n`？ |
|------|---------|---------|--------------|----------|
| `readline()` | 一行 | `str` | `''`（空字符串） | ✅ |
| `readlines()` | 全部行 | `list[str]` | `[]`（空列表） | ✅ |
| `read()` | 全文 | `str` | `''`（空字符串） | — |

**一句话记**：带 `s` 返回列表（多行），不带 `s` 返回字符串（单行）。

> **内存提醒**：`readlines()` 会把整个文件内容一次性加载到内存，大文件慎用。逐行读取大文件推荐直接 `for line in file`，它是惰性迭代，不占内存。

## 2.7 上下文管理器

### 2.7.1 什么是上下文管理器？

上下文管理器（`Context Manager`）是 `Python` 中用于**管理资源**的工具，可以确保资源在使用后被正确地清理或释放。

上下文管理器通常通过 `with` 语句实现，它能够自动处理资源的初始化和释放，避免开发者手动管理资源的生命周期。

### 2.7.2 上下文管理器的特点

**1.资源管理**

● 用于管理需要显式打开和关闭的资源，例如文件、数据库连接、网络连接等。

● 上下文管理器会在进入和退出代码块时自动执行特定的操作（如打开和关闭资源）。

**2.自动清理**

● 无论代码块是否正常执行，或者发生异常，`with` 语句都会确保资源被正确关闭或释放。

**3.简洁性和安全性**

● 使用上下文管理器可以避免资源泄漏问题，代码更简洁、可读性更强。

### 2.7.3 **上下文管理器的基本语法**

```python

with expression as variable:
    # 在这里使用资源
    pass

# 资源会在这里自动释放

```

● `expression`：返回一个上下文管理器对象，通常是支持上下文管理的对象（如文件对象）。

● `as variable`：可选，绑定上下文管理器对象到变量，以便在代码块中使用。

### 2.7.4 常见的上下文管理器

**1.文件操作**

文件对象是最常见的上下文管理器，使用 `with` 语句可以确保文件在使用后被正确关闭。

```python

# 使用上下文管理器打开文件
with open("example.txt", "w") as file:
    file.write("Hello, World!")  # 写入内容

# 文件会在退出 `with` 代码块时自动关闭
print(file.closed)  # 输出: True

```

**2. 数据库连接**

上下文管理器可以用于管理数据库连接，确保连接在使用后被正确关闭。

```python

import sqlite3

# 使用上下文管理器管理数据库连接
with sqlite3.connect("example.db") as conn:
    cursor = conn.cursor()
    cursor.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER, name TEXT)")
    cursor.execute("INSERT INTO users VALUES (1, 'Alice')")
    conn.commit()

# 数据库连接会自动关闭

```

# 三、`datetime`模块

## 3.1 概述

提供了丰富的功能，包括日期、时间和日期时间的表示与操作，支持日期和时间的计算、格式化，以及时区处理等功能，是开发中处理时间相关需求的首选工具。

| 类名                 | 说明                   |
| -------------------- | ---------------------- |
| `datetime.date`      | 表示日期（年月日）     |
| `datetime.time`      | 表示时间（时分秒微秒） |
| `datetime.datetime`  | 表示日期和时间的组合   |
| `datetime.timedelta` | 表示时间间隔           |
| `datetime.tzinfo`    | 时区信息抽象基类       |
| `datetime.timezone`  | 时区实现类             |

**常量**

`datetime.MINYEAR`表示`date` 或 `datetime` 对象允许的最小年份数值。 `MINYEAR` 为 `1`。

`datetime.MAXYEAR`表示`date` 或 `datetime` 对象允许的最大年份数值。 `MAXYEAR` 为 `9999`。

```python

# 输出 datetime 支持的最大年份

```

## 3.2 `date` 类

`date` 对象表示一个理想化的格里高利历中的日期（年、月和日），不考虑历史上的历法变迁。

该历法被视为在时间轴上向前和向后无限延伸，但在实现中，`date` 对象可表示的日期范围是从公元 1 年 1 月 1 日到公元 9999 年 12 月 31 日。

### 3.2.1 构造方法

```python

datetime.date(year, month, day)

```

所有参数都是必要的。 参数必须是在下面范围内的整数：

● `MINYEAR <= year <= MAXYEAR`

● `1 <= month <= 12`

● `1` <= 日期 <= 给定年月对应的天数

### 3.2.3 实例方法

#### 3.2.3.1`isoformat()`方法

# 六、`hashlib`模块

## 6.1 概述

`hashlib` 是 `Python` 标准库中一个用于加密哈希和消息摘要的模块。

它提供了多种常见的哈希算法，比如 `MD5`、`SHA-1`、`SHA-256` 等。这些算法通常用于数据完整性验证、密码存储等场景。

## 6.2 哈希算法与消息摘要算法

### 6.2.1 哈希算法

哈希算法（`Hash Algorithm`）是一种将任意长度的数据通过特定算法压缩或映射为固定长度的值的算法，这个值被称为哈希值或散列值。

哈希算法广泛用于数据查找、数据校验等场景。

**哈希算法的特点**

● 确定性：相同的输入始终产生相同的哈希值。

● 不可逆性（单向性）：从哈希值反推原始输入在计算上是极其困难或不可能的。

● 固定输出长度：无论输入数据是大是小（例如一个字符或一整部电影），输出的长度都是预先定义的。

● 雪崩效应：输入的微小变化（即使只改动一个位）也会导致输出哈希值发生剧烈且不可预测的变化。

● 碰撞抗性：极难找到两个不同的输入能产生相同的哈希值。如果两个不同输入产生了相同输出，则称为哈希碰撞。

**常见的普通哈希算法**

**1.`CRC32（Cyclic Redundancy Check）`**

用途：文件完整性校验、网络传输错误检测等。

特点：生成 32 位的校验和，计算速度非常快，但安全性较低，容易发生碰撞。

示例：常用于压缩文件（如 `ZIP` 文件）的完整性校验。

**2.`Adler-32`**

用途：数据校验。

特点：比 `CRC32` 更快，但安全性更低，适用于对完整性要求不高的场景。

示例：`Zlib` 压缩库中常用。

**3.`MurmurHash`**

用途：哈希表、分布式系统中的一致性哈希。

特点：非加密哈希算法，速度快，碰撞率低。

示例：常用于分布式缓存系统（如 `Memcached`）。

**4.`CityHash/FarmHash`**

用途：高效的哈希函数，适用于哈希表等。

特点：由 `Google` 开发，支持高性能计算，适合大规模数据处理。

示例：用于大数据处理和存储系统。

### 6.2.2 消息摘要算法

消息摘要算法（`Message Digest Algorithm`）是一种特殊的哈希算法，主要用于生成固定长度的摘要或指纹，以唯一地标识输入数据。

消息摘要算法广泛应用于数据完整性校验、数字签名、身份认证等需要高安全性保障的场景。

消息摘要算法是哈希算法的一个子集，专为安全性设计。它们广泛应用于密码学、数据完整性校验和身份认证等领域。

**常见的消息摘要算法**

**1.`MD5（Message Digest Algorithm 5）`**

输出长度：128 位。

特点：曾经广泛使用，但由于已被证明存在严重的安全漏洞（易发生碰撞），不推荐用于安全相关场景。

示例：早期的密码存储、文件校验。

**2.`SHA-1（Secure Hash Algorithm 1）`**

输出长度：160 位。

特点：比 `MD5` 更安全，但已被发现存在碰撞漏洞，不再推荐用于安全敏感场景。

示例：早期的 `SSL/TLS` 协议、数字签名。

**3.`SHA-2（Secure Hash Algorithm 2）`**

包括：`SHA-224`、`SHA-256`、`SHA-384`、`SHA-512`。

输出长度：224 位到 512 位。

特点：目前广泛使用的安全哈希算法，适用于密码存储、数字签名、数据完整性校验等。

示例：`SSL/TLS`、区块链技术（如比特币使用 `SHA-256`）。

**4.`SHA-3（Secure Hash Algorithm 3）`**

包括：`SHA3-224`、`SHA3-256`、`SHA3-384`、`SHA3-512`。

输出长度：224 位到 512 位。

特点：基于 `Keccak` 算法，设计为对 `SHA-2` 的补充，具有更高的安全性，适用于高安全性需求的场景。

示例：密码学应用、数字签名。

**5.`BLAKE2`**

包括：`BLAKE2b`（64 位系统）、`BLAKE2s`（32 位系统）。

输出长度：可变（1 到 64 字节）。

特点：速度快，安全性高，被认为是 `SHA-3` 的强力竞争者。

示例：密码学应用、文件校验。

**6.`Argon2`**

用途：密码哈希。

特点：专为密码哈希设计，支持抗 `GPU` 攻击，适合密码存储。

示例：现代密码存储（推荐替代 `bcrypt`、`PBKDF2`）。

### 6.3 属性

`algorithms_available` 是 `hashlib` 模块的一个属性，属于模块级别，使用时无需实例化哈希对象。

`hashlib.algorithms_available`属性返回一个集合，其中包含在所运行的 `Python` 解释器上可用的哈希算法的名称，语法结构：

```python

hashlib.algorithms_available

```

## 6.4 函数

### 6.4.1 `new()`函数

`new()` 函数用于创建一个哈希对象。它提供了一种动态创建哈希对象的方式，可以根据算法名称字符串动态选择哈希算法，而不需要直接调用具体的哈希函数。

语法结构：

```python

hashlib.new(name, data=None)

```

● 支持的算法可以通过 `hashlib.algorithms_available` 或 `hashlib.algorithms_guaranteed` 查看。

● 常见的算法名称包括：`md5`、`sha1`、`sha256`、`sha512`、`sha3_256` 等。

| 算法       | 输出长度（位） | 输出长度（字节） | 安全性 | 速度 | 主要应用场景         |
| ---------- | :------------: | :--------------: | :----: | :--: | :------------------- |
| `MD5`      |      128       |        16        |  很弱  | 很快 | 校验、非安全场合     |
| `SHA1`     |      160       |        20        |  较弱  | 较快 | 校验、非安全场合     |
| `SHA224`   |      224       |        28        |  较高  | 较快 | 安全性要求较高场合   |
| `SHA256`   |      256       |        32        |   高   | 较快 | 数字签名、证书等     |
| `SHA384`   |      384       |        48        |  很高  | 较慢 | 高安全场合           |
| `SHA512`   |      512       |        64        |  很高  | 较慢 | 高安全场合           |
| `SHA3_224` |      224       |        28        |  很高  | 一般 | 替代`SHA2`的安全场合 |
| `SHA3_256` |      256       |        32        |  很高  | 一般 | 替代`SHA2`的安全场合 |
| `SHA3_384` |      384       |        48        |  很高  | 一般 | 高安全场合           |
| `SHA3_512` |      512       |        64        |  很高  | 一般 | 高安全场合           |

### 6.4.2 命名构造器

命名构造器不是 `Python` 官方语法里的专有名词，更像是一种说法/习惯用语：指那些用固定名字直接创建对象的工厂函数/构造函数。

● `new()` 方法：当需要动态选择哈希算法时（例如算法名称在运行时由用户输入），使用 `hashlib.new()` 会更灵活。

# 七、`json`模块

## 7.1 概述

`JSON` 全称是 `JavaScript Object Notation`，中文常译为 `JavaScript` 对象表示法。

它是一种常见的**文本数据格式**，主要用于在不同程序之间传递和保存结构化数据。

虽然 `JSON` 最早来自 `JavaScript`，但是现在已经是一种通用数据格式，很多编程语言都支持它，例如 `Python`、`JavaScript`、`Java`、`Go` 等。

简单理解：

● `JSON` 不是一种编程语言。

● `JSON` 是一种有固定语法规则的字符串格式。

● 只有符合 `JSON` 语法规则的字符串，才能称为 `JSON` 字符串。

例如：

```json

{
    "name": "张三",
    "age": 18,
    "is_student": true,
    "skills": ["Python", "HTML", "SQL"]
}

```

这段内容本质上是一个字符串，只是这个字符串内部按照 `JSON` 的格式组织了数据。

它看起来很像 `Python` 字典，但它不是 `Python` 字典，而是 `JSON` 格式的数据。

## 7.2 `JSON`常见使用场景

`JSON` 常用于以下场景：

● 前端页面和后端服务器之间传递数据。

● 调用接口 `API` 时接收返回结果。

● 保存配置文件。

● 把程序中的字典、列表等数据保存成文本。

● 不同编程语言之间交换数据。

例如，一个网站接口可能返回如下数据：

```json

{
    "code": 200,
    "message": "success",
    "data": {
        "username": "Tom",
        "score": 95
    }
}

```

`Python` 程序拿到这段 `JSON` 字符串后，可以把它转换成字典，然后通过键来取值。

## 7.3 `JSON`基本语法

`JSON` 中常见的数据结构主要有两种：

**1.对象**

`JSON` 对象使用 `{}` 表示，内部是一个个键值对。

```json

{
    "name": "张三",
    "age": 18
}

```

这里的 `"name"` 和 `"age"` 是键，`"张三"` 和 `18` 是值。

注意：`JSON` 中的字符串必须使用双引号，不能使用单引号。

**2.数组**

`JSON` 数组使用 `[]` 表示，内部可以放多个值。

```json

["Python", "Java", "C++"]

```

在 `Python` 中，它通常会被转换成列表。

**3.常见数据类型**

| `JSON`类型 | 示例 | 对应的`Python`类型 |
| ---------- | ---- | ------------------ |
| 对象 | `{"name": "Tom"}` | `dict` |
| 数组 | `[1, 2, 3]` | `list` |
| 字符串 | `"hello"` | `str` |
| 数字 | `18`、`3.14` | `int`、`float` |
| 布尔值 | `true`、`false` | `True`、`False` |
| 空值 | `null` | `None` |

## 7.4 `json`模块

在 `Python` 中，处理 `JSON` 数据需要使用内置模块 `json`。

它不需要额外安装，直接导入即可：

```python

import json

```

`json` 模块中最重要的四个函数是：

● `loads()`：把 `JSON` 字符串转换成 `Python` 对象。

● `dumps()`：把 `Python` 对象转换成 `JSON` 字符串。

● `load()`：从文件中读取 `JSON` 数据，并转换成 `Python` 对象。

● `dump()`：把 `Python` 对象写入 `JSON` 文件。

可以这样记：

```text

loads  读字符串
dumps  写成字符串

load   读文件
dump   写入文件

```

其中带 `s` 的 `loads()` 和 `dumps()`，可以把 `s` 理解成 `string`，表示操作的是字符串。

## 7.5 `loads()`函数

`loads()` 函数用于把 `JSON` 字符串转换成 `Python` 对象，语法结构为：

```python

json.loads(s)

```

示例：

```python

import json

json_str = '{"name": "张三", "age": 18, "is_student": true}'

data = json.loads(json_str)

print(data)
print(type(data))
print(data["name"])
print(data["age"])

```

输出结果：

```text

{'name': '张三', 'age': 18, 'is_student': True}
<class 'dict'>
张三
18

```

这里发生的转换是：

```text

JSON字符串  ->  Python字典

```

注意：`JSON` 中的 `true` 会转换成 `Python` 中的 `True`。

## 7.6 `dumps()`函数

`dumps()` 函数用于把 `Python` 对象转换成 `JSON` 字符串，语法结构为：

```python

json.dumps(obj)

```

示例：

```python

import json

data = {
    "name": "张三",
    "age": 18,
    "is_student": True
}

json_str = json.dumps(data, ensure_ascii=False)

print(json_str)
print(type(json_str))

```

输出结果：

```text

{"name": "张三", "age": 18, "is_student": true}
<class 'str'>

```

这里发生的转换是：

```text

Python字典  ->  JSON字符串

```

注意：`Python` 中的 `True` 会转换成 `JSON` 中的 `true`。

`ensure_ascii=False` 用于让中文正常显示。如果不写这个参数，中文可能会被转换成类似 `\u5f20\u4e09` 的形式。

## 7.7 `load()`函数

`load()` 函数用于从文件中读取 `JSON` 数据，并把它转换成 `Python` 对象，语法结构为：

```python

json.load(fp)

```

假设有一个 `user.json` 文件，内容如下：

```json

{
    "name": "张三",
    "age": 18
}

```

读取文件：

```python

import json

with open("user.json", "r", encoding="utf-8") as file:
    data = json.load(file)

print(data)
print(type(data))
print(data["name"])

```

输出结果：

```text

{'name': '张三', 'age': 18}
<class 'dict'>
张三

```

这里发生的转换是：

```text

JSON文件  ->  Python对象

```

## 7.8 `dump()`函数

`dump()` 函数用于把 `Python` 对象写入 `JSON` 文件，语法结构为：

```python

json.dump(obj, fp)

```

示例：

```python

import json

data = {
    "name": "张三",
    "age": 18,
    "skills": ["Python", "HTML", "SQL"]
}

with open("user.json", "w", encoding="utf-8") as file:
    json.dump(data, file, ensure_ascii=False, indent=4)

```

执行后，`user.json` 文件中的内容类似：

```json

{
    "name": "张三",
    "age": 18,
    "skills": [
        "Python",
        "HTML",
        "SQL"
    ]
}

```

这里发生的转换是：

```text

Python对象  ->  JSON文件

```

其中：

● `ensure_ascii=False`：让中文正常显示。

● `indent=4`：写入文件时使用 `4` 个空格缩进，让 `JSON` 内容更容易阅读。

## 7.9 四个函数的区别

| 函数 | 操作对象 | 转换方向 | 常见用途 |
| ---- | -------- | -------- | -------- |
| `loads()` | 字符串 | `JSON`字符串 -> `Python`对象 | 解析接口返回的字符串 |
| `dumps()` | 字符串 | `Python`对象 -> `JSON`字符串 | 生成要传输的`JSON`文本 |
| `load()` | 文件 | `JSON`文件 -> `Python`对象 | 读取`.json`配置文件 |
| `dump()` | 文件 | `Python`对象 -> `JSON`文件 | 保存数据到`.json`文件 |

最容易混淆的是：

```text

loads 和 dumps 操作字符串
load  和 dump  操作文件

```

## 7.10 常见错误

**1.`JSON`字符串不能随便写单引号**

错误写法：

```python

json_str = "{'name': '张三', 'age': 18}"

```

正确写法：

```python

json_str = '{"name": "张三", "age": 18}'

```

`JSON` 中的字符串必须使用双引号。

**2.`JSON`中的布尔值和空值不是`Python`写法**

`JSON` 中使用：

```json

{
    "is_student": true,
    "score": null
}

```

而 `Python` 中使用：

```python

{
    "is_student": True,
    "score": None
}

```

也就是说：

● `JSON`：`true`、`false`、`null`

● `Python`：`True`、`False`、`None`

**3.`loads()`读取的是字符串，不是文件名**

错误理解：

```python

data = json.loads("user.json")

```

这行代码的意思不是读取 `user.json` 文件，而是把 `"user.json"` 这几个字符当成 `JSON` 字符串去解析，因此会报错。

如果要读取文件，应该使用 `load()`：

```python

with open("user.json", "r", encoding="utf-8") as file:
    data = json.load(file)

```

## 7.11 小结

`JSON` 是一种常见的文本数据格式，用来表示结构化数据。

`Python` 中使用 `json` 模块处理 `JSON` 数据，最重要的是掌握四个函数：

```text

loads()：JSON字符串 -> Python对象
dumps()：Python对象 -> JSON字符串

load() ：JSON文件   -> Python对象
dump() ：Python对象 -> JSON文件

```

一句话记忆：

```text

有 s，操作字符串；没有 s，操作文件。

load 是读入，dump 是写出。

```

```python
print(math.trunc(-3.9))   # -3

```

它对普通浮点数的效果和 `int()` 很接近：

```python

print(int(3.9))           # 3
print(math.trunc(3.9))    # 3

print(int(-3.9))          # -3
print(math.trunc(-3.9))   # -3

```

`int()` 和 `floor()` 的主要区别在负数上：

```text

int(-3.9)        -> -3，向 0 截断
math.floor(-3.9) -> -4，向下取整

```

### 8.3.4 `fabs()`函数

`fabs()` 用于求绝对值，返回浮点数。

```python

print(math.fabs(-5))      # 5.0

```

Python 内置的 `abs()` 也可以求绝对值，并且适用的对象类型更多：

```python

print(abs(-5))            # 5
print(math.fabs(-5))      # 5.0

```

## 8.4 幂、平方根与指数

### 8.4.1 `sqrt()`函数

`sqrt()` 用于计算非负数的平方根，返回浮点数。

```python

print(math.sqrt(16))      # 4.0
print(math.sqrt(2))

```

如果参数是负数，`math.sqrt()` 会抛出 `ValueError`，因为 `math` 模块不处理复数。

### 8.4.2 `pow()`函数

`math.pow(x, y)` 用于计算 `x` 的 `y` 次方，返回浮点数。

```python

print(math.pow(2, 3))     # 8.0

```

它与运算符 `**` 的区别是：`math.pow()` 通常把参数转换成浮点数，而 `**` 会尽量保留合适的数值类型。

```python

print(math.pow(2, 3))     # 8.0
print(2 ** 3)             # 8

```

### 8.4.3 `exp()`函数

`exp(x)` 用于计算 `e` 的 `x` 次方。

```python

print(math.exp(1))
print(math.e)

```

## 8.5 对数函数

### 8.5.1 `log()`函数

`math.log(x)` 默认计算以 `e` 为底的自然对数。

```python

print(math.log(math.e))       # 1.0

```

也可以传入第二个参数指定底数：

```python

print(math.log(8, 2))         # 3.0

```

### 8.5.2 `log2()`与`log10()`函数

```python

print(math.log2(8))           # 3.0
print(math.log10(1000))       # 3.0

```

● `log2(x)`：计算以 `2` 为底的对数。

● `log10(x)`：计算以 `10` 为底的对数。

> 注意：对数的参数必须大于 `0`，否则会抛出 `ValueError`。

## 8.6 三角函数与角度转换

`math` 模块中的三角函数默认接收弧度，而不是角度。

### 8.6.1 `radians()`与`degrees()`函数

`radians()` 把角度转换成弧度，`degrees()` 把弧度转换成角度。

```python

angle = math.radians(30)

print(angle)
print(math.degrees(angle))     # 30.0

```

### 8.6.2 `sin()`、`cos()`与`tan()`函数

```python

angle = math.radians(30)

print(math.sin(angle))
print(math.cos(angle))
print(math.tan(angle))

```

如果直接写 `math.sin(30)`，Python 会把 `30` 当作 `30` 弧度，而不是 `30` 度。

## 8.7 阶乘、最大公约数、排列与组合

### 8.7.1 `factorial()`函数

`factorial(n)` 用于计算非负整数 `n` 的阶乘。

```python

print(math.factorial(5))       # 120

```

计算过程是：

```text

5! = 5 × 4 × 3 × 2 × 1 = 120

```

### 8.7.2 `gcd()`函数

`gcd()` 用于计算两个或多个整数的最大公约数。

```python

print(math.gcd(12, 18))        # 6

```

### 8.7.3 `perm()`函数

`perm(n, k)` 用于计算从 `n` 个不同元素中选出 `k` 个元素并进行排序的方案数。

```python

print(math.perm(5, 2))         # 20

```

排列与顺序有关，例如先选 A 再选 B，与先选 B 再选 A 是两种方案。

### 8.7.4 `comb()`函数

`comb(n, k)` 用于计算从 `n` 个不同元素中选出 `k` 个元素的组合数。

```python

print(math.comb(5, 2))         # 10

```

组合与顺序无关，选择 A、B 与选择 B、A 算同一种方案。

## 8.8 求和、乘积与距离

### 8.8.1 `fsum()`函数

`fsum()` 用于对一组数进行较精确的浮点数求和。

```python

numbers = [0.1, 0.2, 0.3]

print(sum(numbers))
print(math.fsum(numbers))

```

### 8.8.2 `prod()`函数

`prod()` 用于计算可迭代对象中所有数字的乘积。

```python

print(math.prod([2, 3, 4]))    # 24

```

### 8.8.3 `hypot()`与`dist()`函数

`hypot()` 可以根据直角边计算斜边长度：

```python

print(math.hypot(3, 4))        # 5.0

```

`dist()` 用于计算两个点之间的欧几里得距离：

```python

p1 = (0, 0)
p2 = (3, 4)

print(math.dist(p1, p2))       # 5.0

```

## 8.9 浮点数判断

### 8.9.1 `isclose()`函数

浮点数计算可能存在精度误差，不适合总是直接使用 `==` 比较。

```python

result = 0.1 + 0.2

print(result == 0.3)                   # False
print(math.isclose(result, 0.3))       # True

```

### 8.9.2 `isfinite()`、`isinf()`与`isnan()`函数

```python

print(math.isfinite(10))       # True
print(math.isinf(math.inf))    # True
print(math.isnan(math.nan))    # True

```

● `isfinite()`：判断是不是有限数字。

● `isinf()`：判断是不是无穷大。

● `isnan()`：判断是不是 `NaN`。

## 8.10 综合示例

```python

import math

radius = 5

area = math.pi * math.pow(radius, 2)
circumference = 2 * math.pi * radius

print(f"圆的面积：{area:.2f}")
print(f"圆的周长：{circumference:.2f}")

number = -3.9

print("向下取整：", math.floor(number))
print("向上取整：", math.ceil(number))
print("向 0 截断：", math.trunc(number))

```

代码运行逻辑：

```text

导入 math 模块
        ↓
使用 math.pi 获取圆周率
        ↓
使用 math.pow() 计算半径的平方
        ↓
计算并输出圆的面积和周长
        ↓
分别演示 floor()、ceil() 和 trunc() 的取整方向

```

## 8.11 小结

`math` 是 Python 标准库中的数学计算模块，不需要额外安装。

常用内容可以归纳为：

```text

数学常量：math.pi、math.e、math.tau

取整函数：math.floor()、math.ceil()、math.trunc()

幂与根：math.sqrt()、math.pow()、math.exp()

对数函数：math.log()、math.log2()、math.log10()

三角函数：math.sin()、math.cos()、math.tan()

组合计算：math.factorial()、math.gcd()、math.perm()、math.comb()

其他工具：math.fsum()、math.prod()、math.hypot()、math.dist()

浮点判断：math.isclose()、math.isfinite()、math.isinf()、math.isnan()

```

最需要注意的两点：

● `int()` 和 `math.trunc()` 对普通浮点数都是向 `0` 截断，`math.floor()` 才是向下取整。

● 三角函数使用弧度；如果手中是角度，应先使用 `math.radians()` 转换。
