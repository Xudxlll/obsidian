# 一、 抽象类

## 1.1 什么是抽象类？

在`Python`中，**抽象类（`Abstract Class`）** 是一种特殊的类，它不能被直接实例化，而是作为其他类的基类（父类）存在。

抽象类通常用于定义一组通用的接口或行为，具体的实现需要在子类中完成。

**抽象类的特点**

**1. 抽象性**

● 抽象类是一个**不完整的类**，它是为提供通用接口和行为规范而设计的，不能直接实例化。

● **抽象类的作用**是作为其他类的基类，定义了子类必须实现的抽象方法。

● 抽象类本身不能创建对象（实例化），只能被继承。

**2. 抽象方法**

● 抽象类中可以包含**抽象方法**，这些方法没有具体实现，必须在子类中被重写。

● 抽象方法的定义需要使用 `@abstractmethod` 装饰器。

● 抽象方法是**接口定义的一部分**，用来约束子类必须实现这些方法。

**3. 不能直接实例化**

● 抽象类不能直接实例化。如果尝试实例化抽象类，会抛出 `TypeError`。

● 只有实现了所有抽象方法的具体子类才能实例化。

**4. 可以包含具体方法和属性**

● 抽象类可以包含普通方法（有具体实现）和普通属性，子类可以直接继承这些实现。

● 抽象类不仅仅是定义抽象方法，还可以实现一些通用的功能，供子类直接使用。

**5. 子类必须实现所有抽象方法**

● 如果子类继承了抽象类，但没有实现所有的抽象方法，那么这个子类也会被视为一个抽象类，无法实例化。

● 只有当子类实现了所有的抽象方法后，才能实例化该子类。

## 1.2 如何实现抽象类？

`Python` 提供了一个专门的模块 **`abc`（`Abstract Base Classes`）**，可以用来定义抽象类和抽象方法。

抽象类的主要特性是**包含一个或多个抽象方法**，而抽象方法则是没有具体实现的方法，必须在子类中被重写。

**实现抽象类的步骤**

**第一步：导入 `abc` 模块**

```python

from abc import ABC,abstractmethod

```

● `ABC` 是所有抽象类的基类。

● `@abstractmethod` 是用来定义抽象方法的装饰器。

**第二步：定义抽象类**

抽象类需要继承 `ABC`，以表明它是一个抽象类。

在抽象类中，可以定义抽象方法和具体方法。

```python

from abc import ABC,abstractmethod

class Shape(ABC):
    pass

```

**第三步：定义抽象方法及具体方法**

使用 `@abstractmethod` 装饰器定义抽象方法。

```python

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        """计算面积"""
        pass

    @abstractmethod
    def perimeter(self):
        """计算周长"""
        pass
    
```

**第四步：实现子类**

子类继承抽象类，并实现所有的抽象方法。

如果子类没有实现所有的抽象方法，该子类也会被视为抽象类，无法实例化。

```python

# 定义子类：圆形
class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius ** 2

    def perimeter(self):
        return 2 * 3.14 * self.radius

# 定义子类：矩形
class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)
    
```

**第五步：实例化**

抽象类不能直接实例化，只有实现了所有抽象方法的具体子类才能实例化。

```python

# 使用抽象类的子类
circle = Circle(5)
rectangle = Rectangle(4, 6)

print(f"圆的面积: {circle.area()}, 圆的周长: {circle.perimeter()}")
print(f"矩形的面积: {rectangle.area()}, 矩形的周长: {rectangle.perimeter()}")

```

# 二、接口

## 2.1 什么是接口？

接口是一种规范，用于定义一组方法的集合，确保实现接口的类必须提供这些方法的具体实现。

接口本身通常不包含任何具体实现，只定义方法的签名（名称、参数），并约定子类必须实现这些方法。

**接口的特点**

1.行为约定：接口定义了一组行为规范（方法），强制实现接口的类遵守这些规范。

2.无具体实现：接口只定义方法的签名，不提供方法的具体实现。

3.解耦：接口可以将具体实现与调用者分离，提供更灵活的程序设计。

4.多态性：通过接口，可以实现不同类的统一调用，增强代码的可扩展性。

## 2.2 如何实现接口?

`Python` 本身没有像 `Java` 那样显式的 `interface` 关键字。抽象类可以充当接口的角色，用来定义一组必须实现的方法，而具体的实现由子类完成。

**实现接口的步骤**

1.导入 `abc` 模块：使用 `from abc import ABC, abstractmethod`。

2.定义接口：创建一个继承自 `ABC` 的抽象类，表示接口。

3.定义抽象方法：使用 `@abstractmethod` 装饰器定义接口中的方法。

4.实现接口：创建实现类，继承接口，并实现所有抽象方法。

**示例代码**

```python

from abc import ABC, abstractmethod

# 定义接口
class Payment(ABC):
    @abstractmethod
    def pay(self, amount):
        """支付方法"""
        pass

    @abstractmethod
    def refund(self, amount):
        """退款方法"""
        pass

# 实现接口：支付宝支付
class Alipay(Payment):
    def pay(self, amount):
        return f"使用支付宝支付 {amount} 元"

    def refund(self, amount):
        return f"使用支付宝退款 {amount} 元"

# 实现接口：微信支付
class WeChatPay(Payment):
    def pay(self, amount):
        return f"使用微信支付 {amount} 元"

    def refund(self, amount):
        return f"使用微信退款 {amount} 元"

# 实现接口：信用卡支付
class CreditCard(Payment):
    def pay(self, amount):
        return f"使用信用卡支付 {amount} 元"

    def refund(self, amount):
        return f"使用信用卡退款 {amount} 元"

# 使用接口
payment_methods = [Alipay(), WeChatPay(), CreditCard()]
for method in payment_methods:
    print(method.pay(100))
    print(method.refund(50))

```

## 2.3 接口与抽象类的异同

| 特性                 | 接口                                 | 抽象类                              |
| -------------------- | ------------------------------------ | ----------------------------------- |
| **定义方式**         | 抽象类充当接口，通过抽象方法定义规范 | 使用 `ABC` 模块定义抽象类和抽象方法 |
| **是否包含具体实现** | 通常不包含具体实现，仅定义方法签名   | 可以包含具体实现（普通方法和属性）  |
| **实例化**           | 不能直接实例化                       | 不能直接实例化                      |
| **子类约束**         | 子类必须实现接口定义的所有方法       | 子类必须实现抽象方法                |
| **多继承**           | 可以通过多继承实现多接口             | 抽象类支持多继承                    |

# 三、组合与聚合

## 3.1 组合

组合（`Composition`）一种**强关联**的关系，表示一个类包含另一个类的对象，并且这个被包含的对象的生命周期完全依赖于包含它的对象。

如果包含对象被销毁，那么被包含的对象也会随之销毁。

**特点**

● 强依赖性：被包含对象的生命周期与包含对象一致，不能单独存在。

● 整体-部分关系：表示一个类是另一个类的一部分，例如汽车和发动机、房子和房间。

● 实现方式：通过在类中作为属性包含另一个类的实例。

**示例代码**

```python

class Engine:
    def __init__(self, horsepower):
        self.horsepower = horsepower

    def start(self):
        return "引擎启动，马力：" + str(self.horsepower)

class Car:
    def __init__(self, brand, horsepower):
        self.brand = brand
        # 组合：Car 包含一个 Engine 对象
        self.engine = Engine(horsepower)

    def start(self):
        return f"{self.brand} 汽车：{self.engine.start()}"

# 创建汽车对象
car = Car("宝马", 300)
print(car.start())  # 输出：宝马 汽车：引擎启动，马力：300

# 销毁汽车时，发动机也会随之销毁
del car

```

## 3.2 聚合

聚合（`Aggregation`）是一种**弱关联**的关系，表示一个类包含另一个类的对象，但被包含的对象的生命周期独立于包含它的对象。

如果包含对象被销毁，被包含的对象可以继续存在。

**特点**

● 弱依赖性：被包含对象的生命周期独立于包含对象，可以单独存在。

● 整体-部分关系：与组合类似，但更松散。例如，班级和学生就是一种聚合关系，即使班级解散，学生仍然可以存在。

● 实现方式：通过在类中作为属性引用另一个类的实例。

**示例代码**

```python

class Student:
    def __init__(self, name):
        self.name = name

    def study(self):
        return f"{self.name} 正在学习"

class Classroom:
    def __init__(self):
        self.students = []  # 聚合：Classroom 包含多个 Student 对象

    def add_student(self, student):
        self.students.append(student)

    def roll_call(self):
        for student in self.students:
            print(f"{student.name} 到！")

# 创建学生对象
student1 = Student("小明")
student2 = Student("小红")

# 创建班级对象
classroom = Classroom()
classroom.add_student(student1)
classroom.add_student(student2)

# 点名
classroom.roll_call()
# 输出：
# 小明 到！
# 小红 到！

# 即使销毁班级，学生仍然存在
del classroom
print(student1.study())  # 输出：小明 正在学习

```
