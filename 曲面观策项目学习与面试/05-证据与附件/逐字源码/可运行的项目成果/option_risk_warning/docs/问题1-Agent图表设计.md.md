# 问题1 Agent 图表设计

交付表面：本地 Streamlit 单页控制台，Plotly 原生交互图形；最终QA在真实浏览器页面完成。

| 区域 | 分析问题 | 图形 | 数据充分性与回退 | 配色与非颜色区分 |
|---|---|---|---|---|
| IV三维曲面 | 当前时点的波动率微笑如何随期限变化 | 3D surface | 至少2个期限、每期限至少3个真实节点；缺失网格保持空白 | 单一蓝色根 `Viridis` 连续色标，真实数据范围不外推 |
| IV热力图 | 异常高低值集中在哪些期限和价内外区域 | heatmap | 同上；不足时显示数据状态而非空图 | 连续色标，坐标与3D曲面一致 |
| Greeks | Delta/Gamma/Vega/Theta风险如何分布 | 2×2 heatmap | 使用与IV完全一致的网格；NaN保持空白 | Delta/Theta使用有中心的发散色，Gamma/Vega使用单根连续色 |
| 期限曲线 | 每条期限的微笑、偏斜和局部凸起是否异常 | multi-line | 每期限最多33个网格点；只有2个期限也保留，因为比较对象就是期限 | 每条期限线型和标记共同区分，避免只靠颜色 |
| 预警时间轴 | 所选时点前核心动态风险压力如何演变、何时升级 | line + level markers | 默认最多512个15分钟时点，少于8点时改为表格/状态说明 | 核心压力深蓝线、2级状态阈值0.98用橙色虚线、3级核心阈值1.50用红色点线（并注明还需多信号）；0/1/2/3级采用绿/黄/橙/红并用不同标记 |
| 风险特征 | 哪些特征最接近或超过动态阈值 | 精确值表 | 显示全部可用特征，异常优先排序 | 状态文字与底色共同编码，数值列保留当前值、阈值、压力和变化 |

每张图必须显示：品种、市场时间、坐标单位和数据来源/代理价格提示。图形标题保持描述性，不使用未经数据证明的结论式标题。
