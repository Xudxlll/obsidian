# 问题2：风险知识图谱设计与运行说明

## 1. 交付范围

问题2不是另起一套系统，而是在问题1的唯一业务入口 `OptionRiskAgent` 内增加一个可解释结果层。用户输入、问题1曲面、Greeks、12项风险证据、动态阈值、0—3级预警和时间轴均保持不变；图谱只读取已经形成的正式结果。

```text
品种 → 可选时间点 → 确认
             ↓
       OptionRiskAgent
             ↓
问题1：曲面 / Greeks / 风险特征 / 0—3级预警
             ↓
问题2：NetworkX图谱 / 固定预设查询 / 五段解释
```

系统没有第二个Agent，不提供自由文本问答，不接入图数据库，也不根据解释反向改变预警等级。

## 2. 为什么采用四层图谱

每条活动路径固定为：

1. `Evidence`：问题1的当前值、动态阈值、压力比、变化率和数据来源；
2. `Anomaly`：规则判断出的接近阈值、超过阈值或约束违反状态；
3. `Mechanism`：对风险作用方式的谨慎描述；
4. `Conclusion`：`RiskConsequence`、原有 `WarningState` 或质量对应的 `ConfidenceState`。

`Product` 和 `RiskSnapshot` 是图谱上下文节点，不把四层传播链人为扩成更多业务层。关系只来自注册表：`NEAR_THRESHOLD`、`EXCEEDS`、`VIOLATES`、`SUPPORTS`、`MAY_AMPLIFY`、`MAY_LEAD_TO` 和 `REDUCES_CONFIDENCE`，另有上下文关系 `HAS_SNAPSHOT`、`HAS_EVIDENCE`。

## 3. 12项证据映射

| # | Evidence特征 | Anomaly | Mechanism | Conclusion |
|---:|---|---|---|---|
| 1 | `atm_iv` | ATM IV异常抬升 | 波动率整体重定价 | 短期波动风险上升 |
| 2 | `atm_iv_chg_4` | ATM IV短时变化异常 | 波动率重定价加速 | 短时波动敏感性上升 |
| 3 | `term_inversion` | 期限结构倒挂 | 近端风险压力集中 | 短期波动风险上升 |
| 4 | `convexity_violation_ratio` | 执行价凸性违反异常 | 曲面定价一致性下降 | 估值一致性风险 |
| 5 | `max_local_iv_jump` | 局部IV跳变 | 曲面局部稳定性下降 | 曲面估值稳定性风险 |
| 6 | `put_call_parity_p95_error` | Put-Call平价偏离异常 | 相对定价一致性下降 | 估值一致性风险 |
| 7 | `calendar_variance_violation_ratio` | 日历总方差约束违反 | 期限方向定价一致性下降 | 估值一致性风险 |
| 8 | `gamma_hhi` | Gamma集中异常 | 非线性敏感性集中 | Gamma敏感性风险增强 |
| 9 | `vega_hhi` | Vega集中异常 | 波动率敏感性集中 | Vega敏感性风险增强 |
| 10 | `zero_volume_share` | 零成交合约占比异常 | 市场活跃度/可观测性受限 | 解释置信度降低 |
| 11 | `iv_floor_share` | IV求解下限占比异常 | IV反解可用性受限 | 解释置信度降低 |
| 12 | `coverage_shortfall` | 曲面节点覆盖不足 | 曲面分析可靠性受限 | 解释置信度降低 |

后三项只连接到 `ConfidenceState`。即使质量压力很高，也不能连接到 `WarningState` 或上调市场风险。

## 4. 版本和时间来源

每个正式结果保存以下可复现字段：

- `schema_version`：当前为 `kg-schema-v1`；
- `rule_version`：当前为 `kg-rule-v1`；
- `policy_version`：问题1动态状态机版本；
- `policy_parameter_hash`：问题1策略参数完整哈希；
- `source_timestamp`：每个证据、节点和关系引用的数据时点；
- 产品、所选时点、规则ID、当前值、阈值、压力比和路径ID。

问题1动态阈值只使用所选时间之前的合格历史数据。问题2还执行未来数据回放：向数据源追加更晚月份记录后，重新分析同一历史时点；图节点、边、路径排序、查询结果和解释文本必须完全不变。因此报告中的“无未来数据”是已执行测试，不是口头承诺。

## 5. 用户界面

用户仍只选择品种和时间：

1. 品种下拉框来自数据源扫描，不写死；
2. 时间下拉框只显示该品种能够形成曲面并具备历史阈值的时点；
3. 点击确认后运行一次 `OptionRiskAgent.analyze()`。

六个结果页签依次为：

1. Agent决策；
2. 风险知识图谱；
3. IV与Greeks曲面；
4. 风险特征；
5. 预警时间轴；
6. 离线回测验证。

知识图谱主图最多显示三条排序最高的活动四层路径，避免遮挡；完整路径仍可查询。图谱页使用固定预设查询，不提供自由文本输入框。

## 8. 固定查询接口

### Python

```python

graph = result.knowledge_graph
query = GraphQueryService(graph)

root_rows = query.root_evidence(limit=3)
alert_paths = query.paths_to_alert()

quality_paths = query.quality_limitations()
node = query.inspect_node(root_rows[0]["node_id"])
paths = query.paths_from_anomaly(alert_paths[0]["anomaly_node_id"])
```

### CLI

```powershell
.\.venv\Scripts\python.exe .\scripts\query_knowledge_graph.py `

  --product ag `
  --timestamp "2025-04-07 10:15:00" `

```

CLI只接受注册的查询名和精确节点/异常ID；未知品种、跨品种时间、自由文本和不属于当前图的节点都会被拒绝。

## 9. 五段解释与路径追溯

解释固定包含：

1. 当前结论；
2. 关键根证据；
3. 风险传导；
4. 可能后果；
5. 限制与置信度。

带路径的解释句以 `[path_id]` 开头。生成器检查每个ID都存在于当前 `active_paths`，查询服务再从规范图重新发现路径，因此缓存或外部JSON不能通过伪造文本绕过追溯。

解释语言只允许“支持”“可能导致”“可能放大”“降低置信度”等非因果措辞。不预测涨跌方向，不提供交易建议，不声称外部新闻是确定根因，不把几何无套利违反说成可执行套利。

## 11. 人工解释评分

## 12. 已知局限

- 图谱根因是直接数据证据，不是新闻、政策或宏观事件原因识别；
- 质量证据只影响解释置信度，不能提高问题1市场风险等级；
- 图谱是风险分析工具，不预测价格方向，不提供交易建议；
- 没有独立期货行情时仍使用 `strike/moneyness` 重构标的价格代理，代理CVaR仅供探索；
- 3级最后时点在正式35品种验收中缺失，因此交付快照中的3级案例明确标为 `synthetic_contract`，只测试契约，不计入真实市场表现。
