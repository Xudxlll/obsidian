Page 44Deep ResNet bottleneck

第44页：ResNet 的 Bottleneck block

这一页解释 50 层以上的深层 ResNet 为什么常用 bottleneck 结构。

1. 图中的三层卷积在做什么

输入和输出都是 28×28×256，中间主分支是：

1×1 conv, 64 -> 3×3 conv, 64 -> 1×1 conv, 256

第一个 1×1 负责把通道数从 256 压到 64；中间的 3×3 在较低通道数上提取空间特征；最后一个 1×1 再升回 256，方便和 shortcut 相加。

2. 为什么叫 bottleneck

因为它像瓶颈一样先把宽通道压窄，再做主要计算，最后再扩回去。这样可以显著减少 3×3 卷积的计算量。

记忆法：1×1 降维，3×3 干活，1×1 升维。

Page 45Train ResNet in practice

第45页：实际训练 ResNet 的关键技巧

ResNet 能训练得很深，不只是因为残差连接，还要配合初始化、BN、优化器和学习率策略。

1. He initialization

ResNet 常用 ReLU，因此初始化要匹配 ReLU 的激活特性。He 初始化会考虑 ReLU 大约只保留一半激活的事实，让每层信号方差不要快速衰减。

2. Batch Normalization 与 Momentum

BN 放在卷积层后面，让中间激活分布更稳定。SGD + Momentum 0.9 则让优化方向更平滑，减少每个 mini-batch 带来的抖动。

课件也特别提到原始 ResNet 论文没有使用 dropout，这一点和许多早期网络不同。

He 初始化BNSGD + Momentum
Page 46权重过小

第46页：随机初始化太小会怎样

这里用 10 层 tanh 网络说明：权重尺度太小，后面几层输出会接近 0。

1. 为什么输出会变成 0 附近

每一层都近似做 y = Wx。如果权重来自 N(0, 0.01)，数值很小，信号每过一层都会被压缩一点。10 层连续压缩后，后面层的输出自然越来越接近 0。

2. 图中柱状分布的含义

每个小图表示一层输出的分布。越到后面，分布越集中在 0 附近，说明网络虽然有很多层，但后层几乎收不到有区分度的输入。

这不是“随机不随机”的问题，而是随机尺度是否合理的问题。
初始化过小信号衰减
Page 47权重过大

第47页：随机初始化太大也不行

权重来自 N(0,1) 时，tanh 输出容易接近 -1 或 1，进入饱和区。

1. tanh 的饱和区

tanh 的输出范围是 [-1, 1]。输入绝对值很大时，输出会非常接近 -1 或 1。这时函数曲线很平，导数接近 0。

2. 对反向传播的影响

反向传播要乘上激活函数导数。如果很多层都落在 tanh 饱和区，梯度会被连续乘以很小的数，于是前面层几乎学不到东西。

权重太小 -> 前向信号接近 0 权重太大 -> tanh 饱和，梯度接近 0
初始化过大tanh 饱和梯度消失
Page 48Xavier initialization

第48页：Xavier 初始化的动机

Xavier 的目标是让每一层的输入和输出方差尽量保持一致。

1. 为什么要保持方差

如果输出方差越来越小，信号会消失；如果输出方差越来越大，激活会爆掉或进入饱和区。保持方差稳定，就是让信息在深层网络中能比较健康地传递。

2. 课件中的初始化形式

w ~ N(0, 1) / sqrt(n_in)

n_in 是输入神经元数量。输入维度越大，每个权重就应该越小，因为很多项加起来之后总方差会变大。

Xavier方差稳定n_in
Page 49Xavier 推导

第49页：Xavier 初始化的方差推导

这一页把“为什么要除以 sqrt(n)”写成数学推导。

1. 从单个神经元开始

y = w1x1 + w2x2 + ... + wnxn

假设 xi 独立同分布且均值为 0，wi 也独立同分布且均值为 0。因为每一项独立，总方差可以相加。

2. 关键结论

Var(y) = n Var(wi) Var(xi)

如果希望 Var(y) = Var(x)，就需要：

n Var(wi) = 1 Var(wi) = 1 / n

所以权重标准差就是 1 / sqrt(n)。

Var(y)1/sqrt(n)
Page 50ReLU 下 Xavier 不够好

第50页：ReLU 激活下 Xavier 的问题

同样的 Xavier 初始化，换成 ReLU 后，最后几层表现不够理想。

1. ReLU 和 tanh 不一样

tanh 大致把正负信号都保留下来，只是压缩到 [-1,1]；而 ReLU 会把负数全部变成 0。

ReLU(x) = max(0, x)

2. 为什么 Xavier 不够

如果输入大致正负对称，ReLU 后大约一半神经元被置零。有效信号少了一半，原来的 Xavier 方差设定就偏保守，深层输出可能继续变弱。

ReLU半数激活
Page 51He initialization

第51页：适合 ReLU 的 He 初始化

He 初始化的关键假设是：每层大约只有一半神经元被 ReLU 激活。

1. 课件公式怎么理解

w ~ N(0, 1) / sqrt(n_in / 2)

这等价于标准差 sqrt(2 / n_in)。和 Xavier 的 sqrt(1 / n_in) 相比，它把方差放大了约 2 倍，用来补偿 ReLU 丢掉的一半信号。

2. 怎么记

如果网络主要用 tanh 或 sigmoid，优先想到 Xavier；如果主要用 ReLU，优先想到 He initialization。

He initializationsqrt(2/n_in)

Page 53Vanishing gradients

第53页：梯度消失的激活函数视角

红线是激活函数，蓝线是导数。导数小的区域会让反向传播变弱。

1. 中间区域和两端区域

以 sigmoid 或 tanh 这类 S 型函数为例，输入在中间附近时曲线最陡，导数较大；输入远离中间时曲线变平，导数接近 0。

2. 为什么和 BN 有关系

BN 会把输入拉回均值附近，使激活更可能落在导数较大的区域。这样反向传播时梯度不容易一层层变小。

Page 54Backpropagation signal

第54页：梯度在深层网络中逐渐变弱

图中反向传播信号从输出层往前传，逐层减弱。

1. 深层网络为什么难训练

反向传播本质上会经过很多层的链式法则。如果每一层都乘上一个小于 1 的导数或权重因子，乘很多次之后，梯度就会变得非常小。

2. ResNet 和 BN 的共同目标

ResNet 用 shortcut 给梯度开更短的路径；BN 让每层输入分布更稳定，减少落入饱和区的概率。它们都在帮助深层网络更容易训练。

第55页：Normalization 如何帮助梯度

这一页把输入分布、sigmoid 曲线和梯度联系起来。

1. 左侧图的意思

如果某层输入值分布很偏，很多点会落到 sigmoid 的两端饱和区。标准化之后，输入会被拉回中心附近。

2. 右侧曲线的意思

蓝色通常表示激活函数，红色虚线表示梯度/导数。中心区域导数较大，训练信号更强；两端区域导数小，学习困难。

BN 的直觉不是“让数值好看”，而是让网络更常工作在容易学习的数值区间。

Page 56BN easy view

第56页：用线性层理解 BN

课件从 y = Wx 出发，说明输入分布会影响输出和训练稳定性。

1. 两个困难场景

  • E[x] != 0：输入均值偏离 0，后续层会持续接收偏移后的信号。
  • Var[x] 很大：输入尺度太大，容易造成激活饱和或数值不稳定。

2. 为什么线性层也关心输入分布

因为 W 只是把输入加权组合。如果输入本身偏移很大或尺度很乱，输出分布也会跟着不稳定，下一层继续放大这种问题。

E[x]Var[x]y=Wx
Page 57BN target

第57页：BN 想要什么

BN 的目标是把某层激活的每个维度标准化到均值 0、方差 1。

1. 目标分布

E[x] = 0 Var[x] = 1

这不是说所有样本都变一样，而是让每个维度的整体分布更稳定。

2. 标准化公式

x_hat^(k) = (x^(k) - E[x^(k)]) / sqrt(Var[x^(k)])

这里的 k 表示某一个维度或通道。BN 会对每个维度分别计算均值和方差，而不是把所有维度混在一起。

0 均值单位方差逐维度标准化
Page 58BN training formula

第58页：训练阶段 BN 的计算

这一页给出 mini-batch 中每个维度的均值、方差和标准化公式。

1. 输入 batch 的形状

输入是 x^1, ..., x^N ∈ R^d。意思是一个 batch 有 N 个样本，每个样本有 d 个维度。

2. 对第 j 个维度做标准化

mu_j = (1/N) sum_i x_j^i sigma_j^2 = (1/N) sum_i (x_j^i - mu_j)^2 x_hat_j^i = (x_j^i - mu_j) / sqrt(sigma_j^2 + epsilon)

epsilon 是防止除以 0 的小常数。注意这里的均值和方差来自当前 mini-batch。

Page 59Learnable gamma beta

第59页：BN 的可学习参数

标准化之后再加 gamma 和 beta，避免 BN 限制模型表达能力。

1. 为什么需要 gamma 和 beta

如果 BN 永远强制输出均值 0、方差 1，模型可能失去某些有用的尺度和平移信息。因此 BN 让网络自己学习是否要放大、缩小或平移。

2. 最终输出

y_j^i = gamma_j x_hat_j^i + beta_j

gamma_j 是缩放参数，beta_j 是平移参数。它们都是训练出来的。

可以把 BN 理解成：先规范化，再把是否保留某些尺度交还给模型学习。
gammabetaaffine transform
Page 60BN during testing

第60页：测试阶段的 BN

训练时用当前 batch 统计量；测试时用训练过程中累计的 running mean 和 running variance。

1. 为什么测试不能直接用当前 batch

测试时 batch size 可能很小，甚至只有一个样本。如果直接用当前 batch 计算均值方差，结果会非常不稳定。因此要使用训练阶段累计的整体统计量。

2. 为什么说测试时 BN 是线性算子

测试阶段 mu、sigma、gamma、beta 都固定了，所以：

y = gamma * (x - mu) / sqrt(sigma^2 + epsilon) + beta

这对 x 来说就是固定的缩放和平移。

第63页：DenseNet

DenseNet 的核心是 dense connection：后面层接收前面所有层的特征。

1. Dense connection 怎么理解

普通网络更像一条链：

x0 -> x1 -> x2 -> x3

DenseNet 更像每一层都能看到之前所有层：

x0 -> x1 [x0, x1] -> x2 [x0, x1, x2] -> x3

2. 和 ResNet 的区别

ResNet 主要通过加法 shortcut 传递信息；DenseNet 通过通道维度上的拼接复用前面特征。两者都能改善梯度传播，但连接方式不同。

Page 64GoogleNet / Inception

第64页：GoogleNet 与 Inception 模块

GoogleNet 的关键组件是 Inception module：多分支并行提取不同尺度特征，再做通道拼接。

1. Inception 模块的核心思想

同一层里并行做多种操作：

1×1 conv 3×3 conv 5×5 conv 3×3 max pooling

这样网络不需要提前只选一种感受野，而是同时提取小尺度、中尺度和较大尺度特征。

2. Filter concatenation 是什么

每个分支都输出一组 feature maps，最后沿通道维度拼接。空间尺寸必须对齐，比如都保持 28×28，才能做 depth concat。

3. 和你刚才问的池化分支对应

池化层本身不改变通道数，只改变或保留空间尺寸。图里的池化分支通常是：

MaxPool 3×3, padding=1, stride=1 -> 空间尺寸保持不变，通道数不变 -> 再接 1×1 conv 调整通道数

所以如果最后看到 28×28×32，那个 32 来自后面的 1×1 conv，不是 max pooling 自己产生的。
