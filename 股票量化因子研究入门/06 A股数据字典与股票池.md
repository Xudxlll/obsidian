# 数据表的每一行究竟代表什么

因子研究常用“长表”：一行是一只股票在一个交易日的观察。主键是 `(date, asset)`，不是只有日期。所有合并前先检查主键，否则 20 只股票的表可能被错误连接成 400 行。

## 首轮数据契约

| 字段 | 含义与单位 | 为什么要关心 |
|---|---|---|
| date | 交易日，YYYY-MM-DD | 不能把自然日当交易日 |
| asset | 带交易所后缀的代码字符串 | 保留前导零，避免代码歧义 |
| open / close | 原始开盘/收盘价，元 | 原价用于成交约束；收益需处理公司行动 |
| adj_factor | 同日复权乘数 | 本实验调整价=原价×乘数 |
| amount | 实验台统一为人民币元 | Tushare daily 原始字段是千元，导入乘1000 |
| volume_shares | 股数 | Tushare daily 原始 vol 是手，导入乘100 |
| industry（可选） | 当日已知的行业分类 | 当前分类不能冒充历史分类 |
| log_mv（可选） | 历史市值的自然对数 | 说明总市值/流通市值及原单位 |

原始行情字段和单位已按 [Tushare 日线文档](https://tushare.pro/document/2?doc_id=27) 核对。数据提供方对入库时间和停牌缺行有说明；具体查询参数和原始文件保存在实验台 manifest 中。字段单位要在导入边界统一，不能“图画出来了”就默认正确。

代码先会变成宽表来做时间移动：行是交易日，列是股票。每列各自算收益，就不会把 A 股票最后一行接到 B 股票第一行。这里的统一日期应来自[交易日历](https://tushare.pro/document/2?doc_id=26)，不能仅取观察到的日期并集。

## 股票池是研究问题的一部分

“全部 A 股”不是一个固定名单。每天有上市、退市、风险警示、暂停交易、行业变动和指数换样。严格历史池 $U_t$ 必须由 $t$ 当时已知的信息构造。

例如你在 2026 年取“现在仍上市的股票”，回测 2023 年，就漏掉了后来消失的股票；取当前沪深300名单回填过去，则提前知道了未来入选者。这是幸存者/选择偏差。当前 `stock_basic` 的 `list_status='L'` 是当前正常上市名单，不是完整历史池。[官方字段说明](https://tushare.pro/document/2?doc_id=25)

本套真实实验故意选用固定 20 只股票，目的只是让你看懂横截面研究。它们是事后人工选择的，结果只描述这个样本。将来升级时，应单独保存历史上市/退市状态、上市日期、ST 与停牌状态、指数成员及生效时间；不能靠样本结果漂亮来抵消这些缺口。

## 把缺失分成原因

| 现象 | 可能原因 | 初学时正确动作 |
|---|---|---|
| 某股某日整行缺失 | 停牌或漏采 | 对统一日历补空格，查来源 |
| 上市前无历史 | 尚未上市 | 不给它编造过去收益 |
| 某字段长时间缺失 | 无覆盖、权限或数据源变化 | 报告覆盖率与时间分布 |
| 日期同股重复 | 分段重叠或版本更正 | 找原因，不直接取最后一行 |
| 非正价格 | 数据错误或占位值 | 停止并核验，不能算除法 |

本实验台不填补价格；某个回看窗口缺价就不构造该日反转值。这是明确且保守的教学规则，真实研究可另设计“停牌估值与可交易性”政策，但必须写出来。

## 本关练习

一个股票每日成交额 300000，原字段单位千元。若组合规模 1 亿元、持仓权重 10%，你估计单次买入金额占日成交额多少？

> [!answer]- 答案
> 成交额为3亿元；买入1000万元，占约3.33%。若忘乘1000，会得到3333%，容量判断完全错误。日成交额占比也只是粗筛，开盘可用流动性和真实冲击仍需另查。

**验收**：给自己的 CSV 写出主键、单位、时间范围、样本数、来源、缺失原因及股票池定义。
