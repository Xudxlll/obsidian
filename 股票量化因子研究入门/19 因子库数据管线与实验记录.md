## 先理解：因子库不是一个装公式的文件夹

假设同一个五日反转因子，昨天 IC 为正，今天为负。可能不是市场规律变了，而是你修改了股票池、复权方法或收益标签。因子库的作用是让每个数都能回答：来自哪份数据、经过什么处理、在什么时点能知道、由哪版代码算出。数据血缘（lineage）就是这条来路。

本课程主线固定为：$f_{i,t}=-(C^{adj}_{i,t}/C^{adj}_{i,t-5}-1)$；收盘数据入库并完成校验后形成信号，下一交易日开盘尝试成交；H=5 是五个开盘到开盘区间。研究价与成交价分开存放，停牌和涨跌停可使计划交易无法执行。数据管线完成不代表真实 A 股生产系统或实盘已经完成。

## 手把手：先建立五层，而不是下载更多数据

1. `raw/`：原始响应只追加，保存下载时间、接口、参数、行数与内容哈希。接口纠错后另存新版本，不覆盖旧文件。
2. `clean/`：统一股票代码、日期、单位，检查 `(trade_date, ts_code)` 唯一性；与交易日历对齐，不能把停牌空值填成正常交易。
3. `features/`：只使用信号时点已可见的信息。表含 `signal_date, ts_code, factor_name, value, data_version`。
4. `labels/`：未来收益单独保存，记录入场和退出日期；特征构造函数不接收这张表。
5. `runs/`：每次实验独立保存配置、日志、诊断图与研究结论，包括失败结果。

先在自己的项目目录建立这些文件夹。然后复制下面配置，补全你实际使用的日期与版本；这些是教学字段，不是已运行结果。

```yaml
factor: reversal_5d
lookback: 5
signal_time: after_close_data_ready
entry: next_trading_open
horizon: 5
exit: sixth_trading_open_after_signal
data_version: 请填写实际快照编号
universe_version: 请填写股票池规则编号
price_basis: adjusted_for_signal_raw_for_execution
cost_model_version: 请填写费用与滑点假设编号
code_commit: 请填写提交编号或代码文件哈希
seed: 42
```

## 一个最小的指纹操作

在 Python 中将配置规范化后计算 SHA-256。配置哈希只标识配置，还要另存原始文件哈希、代码哈希和软件版本，才能追踪结果。哈希不是数据质量证明，也不能替代 PIT 检查。

```python
import hashlib, json
config = {"factor": "reversal_5d", "lookback": 5, "horizon": 5}
payload = json.dumps(config, sort_keys=True, ensure_ascii=False).encode()
config_hash = hashlib.sha256(payload).hexdigest()
print(config_hash[:12])
```

每个实验笔记再写四句：本次只改了什么；预期为什么改变；观察到什么；下一步如何证伪。Token、密码、个人路径中的敏感信息不进入配置、截图和 Git；只记录密钥环境变量的名字。不要把“能够复现同一份错误”误当成正确。

## 现在轮到你

把五日反转窗口改为十日，其余设置不变。需要修改哪些记录？是否应覆盖原先的结果文件？

> [!answer]- 展开参考答案
> 新建因子版本和实验编号，修改回看窗口、配置哈希及相应代码版本。原始数据未变时可沿用其快照编号，但特征文件必须重新生成并记录上游依赖；标签口径不变可复用。保留五日实验及失败结果，否则无法知道自己试过多少方案，也无法进行诚实的多重检验。
