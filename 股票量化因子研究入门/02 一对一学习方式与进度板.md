# 按关卡学，不按日历赶进度

本套笔记不规定每周学习时长。你决定节奏；每次只处理一个小问题，完成后留下可检查的证据。默认状态“未学习”只表示还没有记录你的练习，不代表材料没准备好。

## 每次与我学习的固定流程

1. **定位**：告诉我当前笔记、你看到哪一步，以及已有输出。
2. **预测**：运行前先猜结果，例如“因子取负后排序会怎样”。
3. **动手**：自己算一行、写一小段或修改一个参数。
4. **解释**：描述输出意味着什么，哪里与你预期不同。
5. **反馈**：我检查你的推理和代码，只补当前最关键的缺口。
6. **留痕**：记录一个结论、一个错误和下一步。

可直接复制这段给我：

> 我正在学习《股票量化因子研究入门》的第 __ 关，笔记是《__》。请一次只带我做一个动作。先让我预测或解释，再给反馈，不要一次把答案全部告诉我。我已有的结果是 __，卡住的是 __。

## 进度板

- [ ] 0：完成五只股票手算，解释信号、标签、排序。
- [ ] 1：冻结第一个研究协议，写出可能失败的机制。
- [ ] 2：完成数据字典、股票池与 PIT 检查。
- [ ] 3：亲手构建因子、缩尾、标准化、中性化与标签。
- [ ] 4：解释 IC、分层、Q5−Q1，能区分统计诊断与可交易组合。
- [ ] 5：算一笔真实仓位漂移的换手，完成费用与容量情景。
- [ ] 6：按时间划分，剔除跨边界标签，完成一次样本外检验。
- [ ] 7：完成因子卡、版本记录和失效复盘。
- [ ] 8：做一个文本或 ML 扩展，并解释新增泄漏风险。
- [ ] 毕业：别人可从原始输入复现你的结论。

## 学习记录模板

| 字段 | 本次填写 |
|---|---|
| 日期 / 当前关卡 | |
| 今天要回答的问题 | |
| 运行前预测 | |
| 我的代码或手算位置 | |
| 实际结果（注明模拟或真实） | |
| 为什么会这样 | |
| 发现的错误和修复 | |
| 仍不理解的一件事 | |
| 下一步最小动作 | |

保留错误版本的解释，尤其是“为什么看似更好却是错的”。例如先用同日收盘成交得到漂亮曲线，纠正为次日开盘后表现减弱，这本身就是很好的研究记录。

## 自查：懂了还是只是看懂了

关掉笔记，解释下面三件事：为什么标签不能参与因子清洗；为什么下一日开盘买入仍可能有偏差；为什么测试集看过一次就需要记账。

> [!answer]- 自查方向
> 标签是事后信息；下一日开盘仍需考虑信号可见时间、停牌、涨跌停与成交量；测试集一旦影响参数或选题，就参与了研究选择，不再是全新证据。能举出自己的例子才算过关。
