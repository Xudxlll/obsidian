# 先决定怎么判，再去看结果

你想知道的是“反转假设是否得到支持”。如果看完收益再决定用什么股票、窗口、方向和费用，你实际上回答的是“怎样挑到过去最好看的结果”。预先研究协议用来减少这种自由度。

## 全流程的输入与输出

| 步骤 | 你要回答 | 必须保存 |
|---|---|---|
| 1 假设 | 为什么这些信息可能与未来收益相关，何时失败？ | 假设及反例 |
| 2 数据 | 来源、股票池、字段、发布时间、授权是什么？ | 原始快照、数据字典 |
| 3 清洗 | 缺失是停牌、未上市还是坏数据？ | 主键、缺失和异常报告 |
| 4 信号 | 精确公式、方向、窗口、时点是什么？ | 原始与处理后因子 |
| 5 标签 | 何时入场、退出，用哪类价格？ | 标签及起止日期 |
| 6 统计检验 | 是否能排序，是否稳定？ | IC、分层与覆盖率 |
| 7 组合检验 | 成本、换手、容量与风险怎样影响结果？ | 权重、成交、净收益 |
| 8 验证 | 参数是否冻结，标签是否跨边界？ | 验证和测试记录 |
| 9 交接 | 对已有组合增加了什么，何时暂停？ | 报告、因子卡、跟踪计划 |

## 第一个实验的协议

把下面内容复制到你的独立研究记录中；修改后另存版本，不覆盖旧假设。

| 字段 | 首轮默认选择 |
|---|---|
| 因子 ID | reversal_5d_v1 |
| 假设 | 暂时卖压造成的短期下跌，随后可能部分回补 |
| 反例机制 | 基本面恶化、趋势延续、信息迟滞 |
| 方向 | 数值越大越看好；预先取过去收益的负值 |
| 公式 | $x_t=-(C^{adj}_t/C^{adj}_{t-5}-1)$ |
| 信号时点 | t 收盘后，需确保所用数据已实际入库；不是收盘瞬间已知全部数据 |
| 交易与标签 | t+1 开盘到 t+6 开盘，H=5，统一交易日历 |
| 调仓 | 每 5 交易日，不与固定每周五混同 |
| 清洗 | 当日横截面缩尾、标准化；记录缺失与有效样本数 |
| 中性化 | 有可信历史行业/市值才做；缺字段时明确不做 |
| 基准 | 同一固定样本的等权组合；不是沪深300超额 |
| 统计指标 | 日度 Rank IC、非年化ICIR、五分组、衰减与覆盖率 |
| 交易指标 | 多头净收益、漂移后换手、成本压力、风格和容量情景 |
| 训练/验证/测试 | 先分时间；按标签终点剔除边界样本；测试不参与改向调参 |
| 首轮判定 | 能复现且口径正确；是否有投资价值需更多独立证据，不以单一阈值定生死 |

真实小样本取 2023、2024、2025 三个年份分别作训练、验证、测试；起始历史不足的日期不形成信号。它是教学样本，不能替代完整历史股票池。模拟实验使用自己的人工日期，具体以实验输出配置为准，不能把模拟年份和真实年份混写。

## 需要什么样的结论

“平均 IC 为正”是一项观察；“符合反转机制”是解释；“可以进入实盘”是另一个更强、需要额外证据的决定。研究报告要把这三层写清楚。即使真实样本扣费后很差，也先交出诚实的 v1 报告。

## 本关练习

第一次测试 5 日反转不好，于是改成 3、8、10、20 日，再选最佳窗口，仍把同一 2025 年叫样本外，哪里错？

> [!answer]- 参考答案
> 2025 年已参与窗口选择，它成了研究集的一部分。保留每次试验记录，在训练/验证阶段研究候选，重新冻结后使用未触碰的未来样本或前瞻观测。不要删除失败版本，也不能通过重新命名恢复独立性。

**验收**：在运行前填好股票池、公式、时点、分割和费用口径，并写出一个能推翻你的经济解释的现象。
