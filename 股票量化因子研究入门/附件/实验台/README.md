## 真实 CSV 接口契约

价格 CSV 是**长表**，一行一个 `date × asset`。不要求自己先做 pivot。另给一份含 `date` 列的**统一交易日历 CSV**，需要覆盖整个样本；真实交易日历应来自交易所或可靠数据源。不能用某只股票已经存在的记录推断日历，也不能只取全市场有数据的日期交集。

| 字段 | 是否必需 | 含义与约束 |
|---|---|---|
| `date` | 必需 | 当地交易日期，`YYYY-MM-DD`，不带时分秒或时区 |
| `asset` | 必需 | 字符串股票代码；保留前导零，建议带交易所后缀 |
| `open` | 必需 | 正数开盘价；缺价留空，不能写 0 |
| `close` | 必需 | 正数收盘价；缺价留空，不能写 0 |
| `adj_factor` | 默认必需 | 正数复权乘数；实验台使用 `价格 × adj_factor`。必须核验供应商定义 |
| `amount` | 可选 | 当日成交额，非负；本实验台未用其做交易过滤，货币/数量单位须另记来源 |
| `industry` | 可选 | **当时可知的历史行业**；没有则不做行业中性化，不能拿今天行业回填过去 |
| `log_mv` | 可选 | 当时可知、正市值的自然对数；市值单位必须全样本一致 |

## 时间与收益口径

- 信号在 `t` 日收盘后形成：`f(t) = -(close(t)/close(t-5)-1)`。
- 逐日标签从下一交易日开盘入场：`r(t,H) = open(t+1+H)/open(t+1)-1`。`H=5` 表示两次开盘之间相隔 5 个交易日。
- 每日 Rank IC 是当日因子与上述标签的 Spearman 相关。ICIR 为日度 IC 均值除以样本标准差，**不年化**。`H>1` 的逐日标签重叠，有自相关，不能把天数直接当独立样本数做显著性结论。
- 组合每 5 个交易日调仓，持有区间首尾相接；它与逐日重叠 IC 是两套样本节奏。
- Q1 为因子最低层，Q5 为最高层；因子越大代表过去跌得越多。Q5 是可理解的多头候选；等权样本基准由同日全部有效因子股票等权形成，不是沪深 300 或市场指数。
- `Q5-Q1` 仅为两条多头分层收益的差值诊断；没有融资融券、担保品或借券成本，不能标成可执行多空净值。

## 换手与费用

先让上期持仓随开盘到开盘的价格变动漂移，再与本期目标比较。这里报告的总成交额换手为：

`总成交额 / 调仓前资产 = (买入额 + 卖出额) / 调仓前资产`。

费用为总成交额乘**单边费率**，默认 `0.001=10 bps`。这只是教学参数，不是对真实 A 股统一费率的承诺；没有分别建模印花税、佣金、最低收费、冲击和滑点。没有把总成交额换手除以 2 后再收费。

目标权重占扣费后的资产。令 `x=扣费后资产/扣费前资产`，`p` 为调仓前漂移权重，`w` 为目标权重，精确解：

`x = 1 - c × Σ|xw - p|`。

所以从现金首次满仓时，买入额为 `1/(1+c)`；最后平仓再支付全部卖出费用，剩余比例为 `1-c`。零收益市场的一次完整买卖，最终净值应为 `(1-c)/(1+c)`。`trade_costs_oos.csv` 明确记录首次建仓、各次调仓及最后平仓，最后一期净收益包含末次平仓费用。

## 样本边界与缺失交易

交易日按 60%/20%/20% 划分训练、验证、最终留出。信号日与标签出场日必须均位于同一区间；跨边界标签剔除。验证/留出首日因子使用此前已经发生的历史价格是允许的；使用其未来标签来选参数则不允许。衰减图的 1/5/10/20 日使用统一的留出信号日集合，按最长 20 日统一剔除尾部。

本教程固定一个假设，完整展示留出结果，**展示以后就不能继续声称这段数据从未被看过**。进一步反复改参数需要新的未见样本，或清楚标注为探索。

本实验台未实现停牌、涨跌停、退市清算与真实撮合。组合形成只看当日因子；若已选持仓缺入场或出场开盘价，会明确停止记账，不能查看未来后把那只股票提前删除。实际研究需要在此基础上添加明确、可审计的交易规则。

## 风格与适用边界

模拟数据自带虚构行业与规模，供观察简单行业/规模暴露，并演示逐日 OLS 残差化。它不是 Barra，也不能证明因子拥有独立超额收益。真实数据缺少历史行业或规模时，应保留未知，跳过中性化。模拟股票没有真实 ST、上市天数、流动性、成分变迁或退市机制；不能用它替代真实 A 股研究。
