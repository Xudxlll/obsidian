# 日常工作流、术语与常见返工

本页解释每天反复出现的基础工作。它是比赛情境的工作流说明，不是东北证券真实操作手册。

## 普通工作日会被什么填满

早上先看公开消息和发布日历，更新上一日固定底稿状态；晨间讨论时听研究员讲观点，实习生记录待查问题。上午常是导数据、查说明和对表，下午改图、补文字、集中问问题。临近下班交已完成项、待确认项与下一步。

并不是每条新闻都要写，也不是每一天都有新宏观数据。数据没发布就保留原值和截至日期，不为了“有更新”改一个数字。带教忙时，先做已确认任务，不能等不到回复就自己猜结论。

## 发布日怎样改变节奏

| 环节 | 实习生通常在本情境中做什么 | 带教负责什么 |
| --- | --- | --- |
| 发布前 | 清模板、核前值、检查图引用和空栏 | 确认关注问题与分工 |
| 发布后 | 找官方原文、记时间、填表、核单位 | 看结构与解释意义 |
| 图表更新 | 刷图、检查数据列、图轴、来源和截至日 | 判断图是否支持讨论 |
| 事实段落 | 写读数、同比环比、与上期比较 | 形成研判并审核措辞 |
| 交稿后 | 补图注、修版本、留底和登记遗留 | 决定后续使用或继续修改 |

不会默认实习生有对外发稿权或独立署名。发布快不等于跳过核对，原始事实与推论需区分。

## “脏活”具体长什么样

- 一份导出有三行表头，先找到真正数据起点；“—”可能是缺失，不能直接当零。
- 同一个指标在两个文件里名字略有差别，回说明核对，不用模糊匹配直接合并。
- Excel图表引用旧工作表，数字已换图却没动；必须检查源区域。
- 原数据亿元、图上万亿元，转换倍数与页脚都要一致。
- 改了正文图号，图片顺序没变；逐条查引用，防止文字指错图。
- 新增一列后横轴范围没有扩展，最后一个月消失；重刷不一定自动解决。
- 图里中文字体、数字字体、图例和脚注挤在一起；按已有模板逐项修。
- 文件名都叫“最终版”，实际来自不同样本；用配置与版本记录辨认。
- 一页被改成当前版，附页仍是旧路径；交接时别人照着做就卡住。
- 新闻说“原则一致”，自己摘要写成“全面落实”；回原文保留限定词。

这些工作重复、琐碎，但会决定别人能否放心使用底稿。不是随便凑满日记的无关事务。

## 术语速查

| 术语 | 这套日记里的含义 | 常见误会 |
| --- | --- | --- |
| 底稿 | 支撑图表与文字的原始数据、加工表、说明和引用 | 只有最终图片才算成果 |
| 统计期 | 数字描述的月份或季度 | 这个月的数在这个月一定已知 |
| 发布日 | 公众第一次能看到信息的时间 | 下载日期就是发布日 |
| 可用时间 | 根据交易与发布时间规则允许进入研究输入的时间 | 同一天发布就一定能用于当天收盘前 |
| vintage | 某次发布或修订对应的数据版本 | 现在下载到的历史值永远是当年首发值 |
| 同比 | 与上年同月等同一期间比较 | 与上月比较 |
| 环比 | 与上一个相邻统计期比较 | 与去年同期比较 |
| 百分点 | 两个百分比读数相减后的单位 | 任意百分比变化都叫百分点 |
| 基点bp | 利率等百分比读数的百分之一百分点 | 1bp等于1个百分点 |
| PMI | 扩散指数形式的景气调查指标 | 49.5就表示产量同比下降0.5% |
| 社融存量同比 | 融资存量相对去年同月的增长 | 当月新增融资 |
| 社融累计增量 | 从年初到当期的新增融资累计 | 当月新增融资 |
| 财富/全收益指数 | 按发布方规则计入现金流再投资等因素的指数 | 与收益率水平可直接互换 |
| 基线 | 用简单规则给出的参照预测 | 不需要遵守数据边界 |
| 样本外 | 生成某次预测时未使用其目标训练的后续观察 | 名字叫测试集就永远独立 |
| 敏感性 | 换窗口或特征后观察是否明显改变 | 找到最好配置再只报它 |
| 交接 | 交步骤、版本、状态与未完成事项 | 把所有文件压缩发给别人 |

## 问带教时怎样说更有效

“这份表里5月数字不一样”太笼统。更可用的表达是：指出指标全称、统计期、两份来源的版本和单位、具体差异，再说自己已经查过什么。这样同事有空时能直接判断，不用先替我找问题。

汇报进度也不只说“已完成”：说明已核对哪几张图、哪些地方还不确定、影响后续什么、需要谁确认。日记里逐步形成这种习惯，是能力变化的一部分。

### 我给自己留的几种问法

刚开始经常把问题写成“这个数不对”，发出去之后才发现同事还得问我是哪个数。后来我会在自己的笔记里先写成下面这样；这是情境中的沟通草稿，不是实际发送记录。

> 林老师，我在核五月信用那页。两份表的指标全称和单位已经对过，差别出在一份写前五个月累计，另一份是单月。我先保留原表，没有覆盖。想确认这张图需要累计对比，还是改成单月；确认后我再一起改标题和正文。

给张师兄看日期问题时，我会尽量少发一大屏代码，先摆一行输入和一行目标：“这一行信息截止到这个月末，我想预测下个月从哪个观察点到哪个观察点；现在输出却对应当月，应该先查收益标签还是合并键？”我仍然未必能自己修好，但至少能把哪里不明白摊开，方便他接着看。

下班前的进度也逐渐从“今天在改图”变得具体：哪些图改过，哪些数字核过，哪一项还只是初稿，明天最先卡在哪。最开始我不太愿意把没做完的写出来，怕显得效率低。真遇到两件事同时催的时候，才发现别人需要知道我手里还剩什么，才能决定先让我停哪一项。

### 一张图从我手里出去之前

我会先关掉旁边那些正在试的窗口，只打开准备交的版本。对着图从标题读到脚注：讲的是哪个指标、哪个时期，纵轴单位是什么，最后一个月份有没有显示，来源能不能找回去。如果正文写“上升”，还要回表看它说的是读数上升，还是同比增速上升，不能靠折线朝上的印象。

有时这些都对了，粘进文档后仍会出问题：图例挤掉，单位被裁，正文引用的图号没跟着改。我以前把导出图片当成结束，后来会再看一遍别人实际收到的文档。碰上自己已经盯了很久的图，宁可请周同学只帮我看标题和单位，不用她重新做一遍整套研究。

## 报告里哪些句子会被改

| 初稿容易写成 | 带教要求的更谨慎写法 |
| --- | --- |
| 价格全面回暖 | 先写CPI、核心和PPI各自变化，再说明结构差异 |
| 明显超预期 | 有可核查的一致预期样本才比较，否则删掉 |
| 模型证明有效 | 说明相对基线、样本范围和不稳定的地方 |
| 社融增长说明企业需求回升 | 先拆政府债券、贷款等来源，不把总量直接替代需求 |
| 某特征是收益的驱动因素 | 在本模型设定下较常被利用或有一定诊断贡献 |
| 可以直接做策略 | 尚需定义执行时间、成本、约束与完整验证 |

## 交接包应让别人找到什么

输入来自哪里、口径是什么、如何更新、输出在哪、怎么复核、谁负责审阅；哪张图作废、哪段样本已看过、哪项口径没解决、下一次数据发布需要补什么。不存在“把所有状态标绿才好看”的要求。
